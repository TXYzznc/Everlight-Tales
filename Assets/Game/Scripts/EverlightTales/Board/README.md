# Everlight.Tales.Board

盘面模拟器层。程序集：`Everlight.Tales.Board`（`noEngineReferences: true`）。

## 职责

- 蜂窝格模型、六方向与坐标换算。
- 棋子与设施实体、占用层。
- 六相旋转、拍击结算事务、碰撞与触发、FIFO 能力事件队列。
- 计分、公共维修能量、机械臂、轮关判定与确定性演算。

## 边界

- 可引用：`Everlight.Tales.Data`。
- 禁止引用：Unity 引擎程序集、`Meta`／`Events`／`UI`。
- **零引擎依赖是硬约束**：本层代码必须能在无引擎环境编译与运行，用于离线批量演算与同种子复现。
