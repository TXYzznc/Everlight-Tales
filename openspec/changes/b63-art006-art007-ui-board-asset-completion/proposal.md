# UI 与盘面正式资源补齐

状态：整套方案已获开始执行授权，按前置批次顺序待实施。原任务：ART-006、ART-007（ART1）。

## Why

正式控件存在源画布/状态差异，部分来源图标仍有碎片和尺寸问题；盘面目录中有图片不能证明当前全部语义和状态均已覆盖。

## What Changes

- 按 b62 清单补齐控件37态、来源图标、20种零件与现有19种形态、8种障碍、8种异常及维修目标
- 保留 GUID，修正源图和导入设置
- 按行为启用 A-003/A-007 图标。

## Capabilities

### New Capabilities

- `formal-ui-board-resources`: 控件状态、盘面图标、语义绑定与资源可复用性。

### Modified Capabilities

无。沿用既有框架工作流与通用 UI 契约，本批新增项目行为/验收契约。

## Impact

Assets/Game/Sprites 的本项目图像、导入设置、资源映射与验证工具；依赖 b62、b60；不重做已合格资源、不恢复退役节点。
