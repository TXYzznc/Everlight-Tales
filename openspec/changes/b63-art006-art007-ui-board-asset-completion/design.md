# UI 与盘面正式资源设计

## Context

ART-006/007；依赖 b62 批准的样张和生产清单、b60行为契约。承接 design-ui-resource-binding-rules 的1.2控件画布和1.5来源图标缺口。现有导入尺寸限制不代表源图已干净或一致。

## Goals / Non-Goals

修补已使用资源并补全当前可用盘面语义。保留现有布局、文本节点、Sprite语义和GUID；不重画合格241张、不新增故事内容、不做真机/多分辨率验收。

## Decisions

| 路径 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 只改导入MaxSize | 快 | 碎片和状态画布错位仍在 | 不采用 |
| 修正源图＋核对导入元数据 | 解决实际视觉问题且引用稳定 | 需要逐态预览 | 推荐 |
| 新建全套路径并批量改引用 | 目录整齐 | GUID及池化映射回归大 | 不采用 |

37个控件状态逐项比较画布、内容包围盒、留白和九宫格Border；同组尺寸/锚点感一致，SHR-021/030重点修整。可拉伸部分采用现有Sliced契约，装饰不得进入伸缩中心；禁用态不能仅靠颜色，选中态不得冒充可点击。每态独立图片，不把多态烘在一图。状态数量与现有绑定清单核对，不机械新增37张。

五类来源图标与通用回退统一128×128源画布，擦除无关碎片，边距和中心一致；透明背景正确，并检查32/48像素显示。导入设置与现有统一导入器一致。源文件确实128与MaxSize=128分别验证，不能互代。

盘面按 b62逐键清单覆盖20P/19形态/8O/8A/标记/维修目标。利用形状/纹理区分普通、改装、障碍和异常；32/24像素及灰度预览看轮廓，数字与反馈仍由UI显示。A003/A007以 b60的可玩语义匹配新图标；在资源及行为均就绪后才移除 FormalResourceValidation 的禁止绑定断言，改为要求正确绑定。预留但未投放内容不由资源存在自动激活。

采用原路径原GUID更新合格资产；若确需新语义键，显式登记映射与通用回退。缺正式图不得静默通过验收；开发占位可保留到实际替换完成，不以全删占位证明正式覆盖。

## Risks / Trade-offs

- 九宫格Border随画布改动失效 → 每个修补状态进行最小/常用/拉伸预览。
- 相似图标只靠色相区分 → 小尺寸和灰度检查，关键对象补形状差异。
- 资源迁移丢引用 → GUID前后清单对比及定向预制体引用检查。

## Migration Plan

按控件→来源图标→盘面分组小批导入，每组即时复核引用/透明/压缩。交付生产清单结果和对照图，b65负责真实入口交互验收。回滚单组图像与meta一起恢复，不回滚无关用户资源；不调整框架核心导入机制。
