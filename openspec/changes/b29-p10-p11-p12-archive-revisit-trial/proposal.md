# b29：档案重放 / 回访交付 / 试机任务（P4-010 / P4-011 / P4-012）

## 目标
- P4-010 档案重放：已解决案件可用已解锁内容与规则变体重放，不发首次奖励。
- P4-011 回访交付：人物回访事件与奖励交付（待回访 → 已回访）。
- P4-012 试机任务 T-G01~04：借用样机、试机配置、奖励池（D-062），试机可玩。

## 范围
- `Data`：`TrialConfig` + `TrialCatalog`（四关试机：借用形态/特殊目标/图样）；`CaseConfig` 增回访奖励（图样 + 材料 + 维修费）。
- `Meta`：`RevisitService`（已解决→待回访→已回访 + 奖励交付，复用 CaseStateMachine）；档案重放标记。
- `Events`：`TrialEventShell`（借用样机 + 特殊目标判定，成功推进对应改装任务，不发直接奖励）。
- `WorldSession`：回访交付接线（红舞鞋 L-01 回访发 M-012 图样 + 材料 + 120 维修费）；试机接线（四条改装支线 → 试机关卡 → 成功推进任务）。

## 非目标
- F 类形态行为（D-060 贯通/横推/轴向/定时）本批不实现——试机以基础形态行为可玩，形态行为留后续内容批。
- 完整 D-062 四关布局与两次四选一奖励池的逐格坐标本批用简化样张（机制正确，坐标/分数留试玩校准）。
- 十五案完整回访 / 重放内容（本批以红舞鞋 L-01 为唯一可测样本）。
