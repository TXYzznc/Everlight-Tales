# b37：文案校准/资源接入/清单审校（P6-006~P6-008）

## 目标
- P6-006 首批文案统一校准：台词/提示/失败文案/UI 文案统一目录 + 校准状态。
- P6-007 正式资源批量接入（ART2 对接）：UI/盘面/音乐/立绘/音效/特效资源槽位 + 绑定状态（ART2 填路径）。
- P6-008 首批内容清单审校：片单 + 普通事件 + T-G 试机 + 十五案说明清单 + 审校状态。

## 范围
- `Data/CopyConfig.cs`：统一文案目录（分类 + 文案 + 校准标记）。
- `Data/AssetBindingConfig.cs`：资源槽位目录（分类 + 路径 + 绑定判定）。
- `Data/ContentChecklist.cs`：内容清单目录（分类 + 条目 + 审校标记）。
- `Meta/ContentAuditService.cs`：文案校准/资源绑定/清单审校的完整性审计。

## 非目标
- 真实美术/音频/立绘素材（ART0/ART2 并行，本批只做槽位与绑定状态）。
- 逐条文案润色（校准标记先固化，正式润色留试玩后）。
