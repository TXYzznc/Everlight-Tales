# b48：P2-017 关卡演算校准工具

## 目标
实现「批量跑种子统计通过率/拍数分布」的关卡演算校准工具，补上 G2 门关闭时顺延的最后一个程序任务。

## 范围
- `Board/LevelCalibrationRunner.cs`（Board 层零引擎）：通用批量演算器 + 统计报告。
- 策略：枚举 6 个重力相位 × 纯拍击（不搬动），对每个相位从同种子初盘独立演算。
- 通过判定：累计分达标 + 全特殊目标 + 事件专属目标（委托注入）。
- 无头探针用卷帘门 EV-N01 验证统计可产出。

## 非目标
- 最优解搜索 / 机械臂策略穷举（后续校准迭代再扩展）。
- UI 接入（本批仅纯逻辑 + 探针）。
