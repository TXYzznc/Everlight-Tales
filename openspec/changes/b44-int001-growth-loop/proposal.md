# b44 成长闭环 UI 收口（INT-001 流程接入 ④）

## 背景

b41～b43 已把「UI 框架接线 → 盘面可玩 → 一天闭环」接入正式运行流程。b44 是流程接入的最后一步：
把 b21～b27 已实现（仅探针验证）的**成长闭环**逻辑接进运行时 UI，使「赚维修费/材料 → 加工台解锁形态 →
图鉴收集 → 任务领图样」在 Editor 中可实际游玩。

## 目标

把以下已实现纯逻辑接上运行时 UI 与正式流程，全部通过运行验收：

1. **三页列表**（任务页签）：事件页 / 任务页 / 怪谈页，接 `WorldSession` 的供给与 `WorldState` 的任务/案件。
2. **图鉴**（图鉴页签）：`CodexLayout` 三态（已拥有/已知未拥有/完全未知）+ 收集进度。
3. **工作台 + 背包 + 经济**（工作台页签）：`WorkbenchLayout` 三段（宿主零件 → 形态卡 → 解锁/切换）
   + 材料持有 + 维修费/账目。
4. **材料奖励接线**：维修事件成功奖励里的材料（如卷帘门 MT-002）进 `WorldState.Materials`。
5. **四条改装支线**：F 类四形态（T-G01~T-G04）的图样任务种子进 `WorldState.Tasks`，任务页领奖发图样。
6. **持久化扩展**：成长闭环状态（材料/图样/已解锁形态/当前形态/已知零件/改装支线任务）随存档往返。

## 范围与非目标

- **范围内**：任务页签（三页列表）、图鉴页签、工作台页签（含背包/经济）、材料奖励、改装支线任务种子、持久化。
- **非目标**：设置页签（Tab_4，框架已提供全局设置，本批不做业务设置）；怪谈档案的完整调查/回访交互链
  （b30 四条改装支线接线时一并收口）；M 类 15 形态的完整图鉴内容（已实现，仅只读展示）。

## 里程碑

流程接入（INT-001）单任务、G3～G4 之间的接线批，不跨阶段验收门。
