# 维修轮起点快照与结算结果日志

## Why

正式运行链没有维修尝试落盘，现有快照遗漏红鞋及部分盘面状态，结算防重只在内存有效。需要兑现 D-032 的按轮恢复契约，并为后续启动恢复提供可验证的存档与结算接口。

## What Changes

- 覆盖原任务 **P2-010、P2-011、P2-012**（G2 修复收尾）；原依赖分别为 P0-009/P1-011、P2-010、P2-011。台账虽已完成，本次补实际缺口，不改 Excel 状态。
- 按 D-324 三轮确认，世界档继续使用 PlayerPrefs，尝试快照按三个槽位分别保存 JSON；新增完整轮起点快照、版本与配置兼容检查、原子替换及备份。
- 补稳定尝试编号和结算结果日志：先记录结算后的绝对结果，再由世界存档适配器提交；重放不重新累加奖励或时间。
- 正式入场及轮间奖励全部选择后写快照；明确读写失败、异常存档及“成功/失败/撤退/中断”的区别。
- 无法恢复的未结算尝试先尝试备份，仍失败则隔离、保留世界进度、无罚重开；结算日志优先，不能误当免费重试。
- 提供纯逻辑及 Editor 正式入场/换轮/结算证据；启动入口与恢复面板由依赖本批的 b59 交付。

### 状态与边界

2026-10-13方案成文后，用户已明确授权开始执行；当前实施及验证记录见verification.md。世界档批量迁移、逐拍存档、新障碍/异常行为、C-001 装配、音画制作、真人试玩、真机发布及纯度/生成一致性治理不在本批。后续按b58～b67批准顺序实施，G6 不据此关闭。

## Capabilities

### New Capabilities

- `repair-attempt-checkpoints`：可恢复的完整轮起点、尝试身份、槽位文件与损坏降级。
- `repair-settlement-journal`：不可重复累加的结算结果日志与可恢复提交协议。

### Modified Capabilities

无。主 specs 中没有对应业务能力；沿用历史 b16、b22 的有效规则并补运行契约。

## Impact

拟修改业务 Board/Events 的快照及事件状态、Meta/Save 的文件服务、UI/WorldSession 的入场/换轮/结算接线。新增 DTO 不引入 Unity 引用或程序集循环；以 UI 协调跨层，Meta 文件服务不引用 Board/Events。不修改 ScriptsBuiltin，不新增依赖。需要 b59 提供正式世界结果写入与启动恢复的适配实现；b58 本体可通过注入适配器验证协议，整体维修恢复必须两批共同运行验收后才算交付。

方案见 [design.md](design.md)，下游见 [b59](../b59-p3012-p3013-runtime-recovery/proposal.md)。
