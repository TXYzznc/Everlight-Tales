## Why

现有正式素材与 UI Prefab、动态列表、状态逻辑之间缺少完整的语义绑定规则，旧界面文档还保留已废弃的独立列表 Item 与错误图标编号。需要把每张资源的使用条件、显示位置、状态优先级、缺图回退和验收要求写成可执行设计。

## What Changes

- 建立 UI 全量素材与逐页面的资源绑定规范，区分必须接入、按需使用、预留和开发回退。
- 维持一个 `ListRowItem` 承载 16 类通用业务行，增加可选的 24×24 状态徽标，与 48×48 主图标和状态文字组合。
- 明确地图地点、事件类型、任务状态、准备槽位、材料来源、页签数量、时间状态和导航着色规则。
- 将 UI 外 61 张正式素材纳入零件/形态缩略图、盘面、调查对象及人物立绘规则；59 张 Placeholder 仅限开发回退。
- 将四类短提示与需要操作的 `DialogView` 分开；写明 Loading 与空状态的素材用途。
- 在“界面设计文档/资源接入与修订”独立目录记录旧编号错误、过期 Item 表和通用节点模板的替代规则；保留旧资料，不混写新旧设计。
- 新增增益、机械臂次数、通用异常纹样三图；用户已交付，实施接入正式目录。
- 按用户后续“开始执行”授权更新 Unity Prefab、项目 UI 脚本、导入设置与生成器；两张淘汰图在依赖为零后删除。保留原 PNG 像素和业务配置，不将静态核对作为运行验收。
- 按实际截图修复九宫格变形、图文重叠、立绘层级、计数位置、滑块布局、页签选中态和不支持的文字标记。

## Capabilities

### New Capabilities

- `ui-resource-binding`: 正式素材的语义映射、控件状态、页面挂点、缺图回退及素材覆盖要求。
- `ui-transient-feedback`: 四类非阻塞短提示与操作弹窗、加载阻挡的表现边界。

### Modified Capabilities

- `common-ui-list-row`: 通用列表行增加与主图标、状态文字相互独立的可选状态徽标，并保证绑定和回收重置。

## Impact

实施涉及 `Assets/Game/Prefabs/UI`、业务 UI 脚本、项目资源目录、Editor 生成与绑定工具及通用扩展 `PersistentButtonVisualState`；不修改 `ScriptsBuiltin` 框架核心、内容投放条件或存档字段。验收结果与未完成项见 verification.md、tasks.md 和独立修订目录的 06 文档。
