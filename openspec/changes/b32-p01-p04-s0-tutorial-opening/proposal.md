# b32：S0 三段教学与新档开场（P5-001~P5-004）

## 目标
- P5-001 S0 三段教学：61 格三段样张（撞锤+墙体/棘轮+维修对象/线圈+隔板）、宽松通过、原地重试、0 时间格、进度入存档。
- P5-002 教学引导提示与高亮：三段引导提示/高亮/文案节奏（数据配置）。
- P5-003 教学解锁与供给衔接：通过每段解锁 P-001~P-003 并进供给（D-014）。
- P5-004 新档开场流程：回城接管店铺 → 师父引导 → 工作台教学衔接。

## 范围
- `Data/TutorialHintConfig.cs`：三段引导提示配置（标题/教会目标/引导文案/高亮目标/解锁零件）。
- `Meta/TutorialService.cs`：教学进度 + 通过解锁对应零件 + 原地重试 + 0 时间格。
- `Meta/OpeningService.cs`：新档开场阶段机（回城接管→师父引导→教学衔接）。
- `WorldState.TutorialStage` + WorldSession 持久化/接线。

## 非目标
- 盘面样张本身沿用 b12 TutorialSample（三段 BoardState 已就绪），本批只做进度/解锁/引导/开场包装。
- 教学 UI 实际展示（引导提示层/高亮表现）在 b33 界面收口接入。
