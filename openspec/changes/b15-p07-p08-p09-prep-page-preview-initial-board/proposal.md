# 变更提案：b15 准备页 + 预览 + 初盘

覆盖任务：P2-007（准备页）、P2-008（关卡预览）、P2-009（初盘生成）。

## 动机

G2 一局闭环的第一段：从现场开始维修到进入第一轮。落地准备页三区（关卡信息/两栏携带/预览）的纯逻辑骨架，以及初盘固定随机混合生成（D-080），为 b16 存档结算与一局闭环提供准备入口。

## 关键决定

- 携带选择（D-123）：可用种类 = 永久拥有 ∪ 现场借用（去重），关键件自动选入，最多 6 种（min(N,6)），点击补位／拖动替换／移除，关键件缺失提示。
- 初盘生成（D-124）：固定元素 + 关键件固定工作位 → 剩余名额从携带池等权有放回抽种类 → 合法空实体格等概率落位，同种子复现。
- 预览模型（D-125）：预览只显示固定内容（固定元素 + 关键件），随机件与落位不进入预览，逐轮读取轮配置。

## 变更范围

- Board：新增 CarrySelection / InitialBoardBuilder / PreviewModel（含 FixedElementConfig）；扩展 LevelBoardConfig（借用/固定元素/目标/耗时）。
- UI 视图（准备页三区、RawImage 预览）由表现层后续组装，本批先落地纯逻辑模型。

## 验收

- UnitySkills Play Mode 综合探针（验收后删除）+ 程序集布局/纯度静态检查 + 编译 0 错 0 警。

## 边界（本批有意留出）

- 准备页三区与 RawImage RenderTexture 的视觉组装、拖动交互、逐轮渲染留表现层组装（b16 后接入）。
- 轮间资源时点（Buff BF-014/015/020）与补给生成时点留 b16 一局链路。
