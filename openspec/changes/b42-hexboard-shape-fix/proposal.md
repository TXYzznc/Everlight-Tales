# 提案：盘面形状复刻参考项目（点顶大六边形 + 残缺墙，D-088 修订）

覆盖任务：修正 b42 盘面视觉接线（commit c68f569）的几何 bug，完整复刻参考项目 2026CIGA 的棋盘形状。

## 目标

把盘面数据模型从「边长 n 的轴向半径簇（平顶大六边形）」改为参考项目的
「点顶大六边形 SDF 裁切 + 残缺墙（Normal／Wall／Outside 三分类）」，并同步视觉层：

1. **棋盘形状**：点顶大六边形（顶点朝上下），用 SDF 三投影裁切小六边形网格，产出
   Normal（6 顶点全在内）／Wall（部分顶点越界）／Outside（候选外）三分类。
2. **墙格逻辑**：墙格不可放置棋子、阻挡移动与重力下落，与正常格、盘外同一几何分类。
3. **视觉层**：正常格画完整点顶小六边形；残缺墙画「被裁切」的半格；大六边形轮廓为点顶，
   旋转后屏幕呈平顶（格子、大六边形、轮廓三者本地朝向一致，消除当前 30° 错位）。

## 前置

b42 盘面视觉接线（c68f569）已完成但几何有误；参考项目算法与设计文档（六边形棋盘
完整格与残缺墙体生成算法.docx）已由用户确认。

## 验收边界

- `boardRadius` 四档（教学 5／试机 6~8／普通 6~10／怪谈 12）正常格数与墙格数按 SDF
  分类正确生成（不硬编码，按几何推导）。
- 正常格集合 = 参考项目 `MakeMaskedShape` 口径；墙格 = `IsClippedEdgeCell` 口径。
- 旧 sideLength=5 的 61 格坐标（含红舞鞋 (-2,-2)、教程 (3,0) 等）在 boardRadius=5 下
  全部仍为 Normal（0 个越界），现有关卡坐标不破坏。
- 墙格不可放置（`Place` 拒绝）、不可移动进入（下落／预览／能力在墙格前停止）。
- 视觉上格子与大六边形屏幕均为平顶，轮廓包围完整，残缺墙被裁切。
- Board 层仍零引擎依赖（`verify_project_assemblies.py` 通过）。

## 关键决定

- 参数化从「边长 n」（D-088 旧口径）修订为「boardRadius」（可玩区半径），
  `OuterRadius = boardRadius + 1` 自动推导，格子数不再硬编码（D-088 修订）。
- 新增 `HexBoardShape`（Board 层零引擎）承载 SDF 三分类与枚举；`HexGrid` 轴向半径簇废弃。
- 墙格在数据层为 `IsValid == false` 但非 Outside，BoardState 暴露 `IsWall`／`EnumerateWall`
  供视觉渲染，逻辑阻挡复用现有 `IsValid` 判定链路。
