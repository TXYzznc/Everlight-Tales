# 正式视觉集成设计

## Context

ART-013/014/015，ART-015仅人物/背景部分。依赖 b58～b64产物。沿用主规范 common-ui-list-row 的一个共享资源、64/96高度、双回调和容器级回收；本批不重定义该契约。旧 design-ui-resource-binding-rules 4.7/7.2/7.4与部分7.3仍待真实入口证据。

## Goals / Non-Goals

证明当前首发资源和交互在正式入口可用。固定Editor 1080×1920作为本轮验收环境；多分辨率、SafeArea设备矩阵和真机性能属于第7项暂缓。本批不关闭ART2音画整体门。

## Decisions

| 验收方式 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 仅检查资源GUID/引用 | 快 | 不覆盖状态与回收 | 不足 |
| 静态清单＋正式路径逐状态运行 | 能定位文件与行为问题 | 需运行证据 | 推荐 |
| 新建全部展示页代替正式页 | 容易截图 | 掩盖真实入口断链 | 不采用 |

### 正式入口矩阵

按现有16类通用行清单逐项记录页面、进入路径、模板GUID、丰富/简约绑定、行/按钮回调、截图/日志。包含 Board 对话、Settlement 等易漏入口；五类特殊Item（WorkbenchHost、MapNode、InvestigationHotspot、SaveSlot、CarryAvailable）保持原契约。不同容器共模板时只回收自身实例；页面重开无重复监听；分类隐藏不清合法回调。

覆盖37控件态、长中文标题/副文本、省略与详情、禁用/选中/按下、拖拽成功/取消、锁定物品、跨日来源刷新/未知来源回退。准备页 Btn_CarrySlot0 的 Image/Transition 等既有缺口按定向差异修复。恢复页按 b59 的选槽→继续/撤退→加载→结果流程验收，旧世代回调不能操作新槽位。

Toast测试正常/暂停时间、去重、满队列和底部位置；Dialog测试确认/取消/关闭及重复点击；Loading测试成功/失败/重试与错误后输入恢复。无数据、加载中、配置失败都使用已有交互节点，不凭本方案额外创建全新页面结构。

盘面检查开闸叠层/夹持、A003/A007表现、目标标记、透明边缘、正确层级；人物/场景按当前时间、案件、结果选图。连续进入、退出、恢复、快进后无残留效果。32/24像素图标、32/48像素来源图、灰度及常见色觉缺陷模拟对照属于固定Editor画面的资产辨识，不扩为设备适配承诺；关键状态须有文字/形状冗余。

### 证据格式与验收

verification.md 每条填写预期/实际、环境、配置版本、入口步骤、截图或日志路径、通过/缺陷/未执行；不能只贴一张主菜单截图。每次修补后复验受影响路径，不无限重复无关测试。静态工具的断言与运行语义保持一致，A003/A007不再保留“永远不得绑定”的旧断言。

## Risks / Trade-offs

- 资源合格但回调错误 → 入口点击结果与视图同时核对。
- 整体验收被音频缺口混淆 → ART-015/P6-007明确视觉完成、音频待办，不填“全通过”。
- 新图要求大幅布局变化 → 当前只做既有布局内修补；确需重做时单独变更并走结构先行。

## Migration Plan

分UI→盘面→叙事背景导入，逐路径查验。只改发现的问题及其绑定，保留现有布局契约。交付首发视觉可用证据给 b66；资产/预制体/绑定回滚成组，保护已通过模块。
