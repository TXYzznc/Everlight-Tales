# 视觉样张与制作范围设计

## Context

ART-001～004 的工作簿状态落后于资源实际情况。已有正式图片241张（UI158、人物2、场景10、怪谈1、盘面70）及早期占位59张；数量只用作初始审计线索，不是缺口计算公式。已有都市怪谈绘本方向、背景矩阵、控件规范和页面布局；最新盘面去掉 GravitySeat 视觉。

## Goals / Non-Goals

在现有方向上确认样张和逐资源生产清单，让 b63/b64 能按清单交付；不重做页面信息架构、不把15案概念图全部变首发资源。音频样张 ART-005 暂缓。

## Decisions

推荐沿用“冷灰蓝纸感/旧物、暖铜灯光、紫青朱砂异常”方向，先整理已有合格资源。样张确认发生在本批实施阶段；本次方案批准不等于未来生成的图片自动获批。

| 方案 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 全部重画 | 风格容易统一 | 浪费已完成资源，引用风险高 | 不采用 |
| 按使用点盘点、代表样张、定向修补 | 复用现有成果，缺口可追溯 | 需先整理清单 | 推荐 |
| 仅补不存在的文件 | 速度快 | 状态/语义错误仍存在 | 不采用 |

### 生产清单

实施时输出 art/production-manifest.md，每项包含语义键、状态、原路径/GUID、正式引用点、当前截图、复用/修补/新增/后置、源尺寸/导入尺寸/Border、归属批次、样张引用和验收结果。清单不是新 UI 布局，也不取代现有 prefab-layout。只有出现新建/重做界面才另走既有结构先行流程；本方案选择保留现有节点结构。

| 子集 | 基线和交付界限 |
|---|---|
| UI | 37个控件状态；SHR-021/030重点归一；五类来源图标＋通用回退；现有页面交互状态 |
| 盘面 | 20P、当前19种形态、8O、8A、2类标记及已投放维修目标；数量按实际枚举/语义映射核对；不按旧15M清单漏掉已完成F4 |
| 人物 | 五名主角的已有状态映射；交付首发实际被引用的状态，未使用差分列后置而非删掉 |
| 怪谈 | L-01 hint/manifest/after；其它14案只留后置索引 |
| 背景 | P0九组界面背景，五地点昼夜十图逐项核对复用；其它仅交付首发引用项 |
| 动效 | 旋转、咬合、拍击震波、连锁飘字及反馈收束；不含声音 |

源文档的“normal/active/story”是角色表达槽位，不能强制重命名真实状态：主角 normal/active/night；沈遥 tense_dance/responsive/recovered；周衡 normal/lost/rescued；林岑 normal/research/warning；顾师傅 normal/craft/encourage。首发未引用的 lost/rescued 等状态不由本批新增剧情来使用。

### 样张集合与批准

UI取一套正常/按下/禁用/选中、长文本行和来源图标；盘面取普通零件/形态/障碍/异常/目标同屏；人物取沈遥、周衡和居民模板，另用现有五人参考校准身份；背景取工作台/修理铺/舞蹈教室并含昼夜对照。

先用270×480整屏缩略图检查焦点、文本留白和盘面可读性，再检查1080×1920背景和约840×1360人物工作稿。主背景前中远层分离，UI文字与交互对象不得烘焙在图上。人物透明边缘、表情辨识、同一人比例和光向一致。样张报告逐项注明用户选定版本；合格现有图可直接作为样张，无须为过门槛重画。批量只沿批准样张展开。

## Risks / Trade-offs

- 原任务表与后续方案数量不一致 → 以实际语义键枚举和首发引用核对，保留差异说明，不改只读工作簿。
- 旧方案要求恢复已删除视觉 → 最新已确认盘面结构优先，GravitySeat只保留逻辑方向。
- 人物完整设定误变当前制作承诺 → 清单明确首发使用与未来预留，未来无素材不阻塞本批。

## Migration Plan

先只读抽取引用和截图，形成清单；补代表样张并确认后锁定清单版本给 b63/b64。合格旧资产保持 GUID；替换前保留版本记录。样张未通过只返修对应样张，不推进其批量制作。无需新运行时架构或包依赖。
