# 视觉样张与制作范围确认

状态：整套方案已获开始执行授权，按前置批次顺序待实施。原任务：ART-001、ART-002、ART-003、ART-004（ART0）。

## Why

项目已有大量正式图片，但占位、控件状态不一致及人物/场景覆盖缺口并存，不能用图片数量或旧任务状态判断交付。

## What Changes

- 按现有都市怪谈绘本方向审查现有样张
- 建立到语义键、状态、引用点的生产清单
- 确认 UI、盘面、立绘和背景样张后进入批量制作。

## Capabilities

### New Capabilities

- `visual-production-baseline`: 现有资源复用、样张批准与生产清单。

### Modified Capabilities

无。沿用既有框架工作流与通用 UI 契约，本批新增项目行为/验收契约。

## Impact

美术规范、样张及资源核对清单；依赖 b61；保持当前页面布局与已取消的 GravitySeat 视觉决定；不包含音频。
