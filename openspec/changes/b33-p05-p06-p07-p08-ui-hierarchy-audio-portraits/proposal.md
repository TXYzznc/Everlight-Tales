# b33：界面收口与音画立绘接入（P5-005~P5-008）

## 目标
- P5-005 界面信息层级收口：全局配色/间距/文字层级规范（数据配置 + 主题常量）。
- P5-006 音效位与素材接入：咬合/文化/环境/维修/盘面/UI 六类音效位（数据目录 + 服务）。
- P5-007 昼夜 BGM 与环境音：昼夜 BGM 轨道 + 时段切换逻辑。
- P5-008 立绘状态接入：人物立绘登场/事件对话/情感动作状态切换。

## 范围
- `Data/UIThemeConfig.cs`：主题配置（主/辅/强调/背景色 + 标题/正文/辅助文字 + 间距）。
- `Data/AudioConfig.cs`：音效位目录（6 类）+ 昼夜 BGM 轨道（Day/Night）。
- `Meta/AudioService.cs`：音效位播放 + 昼夜 BGM 切换（纯逻辑）。
- `Data/PortraitConfig.cs`：人物立绘目录（师父周衡/沈遥/搭档）+ 场景/情感枚举。
- `Meta/PortraitService.cs`：立绘登场/对话/情感状态切换（纯逻辑）。

## 非目标
- 实际音频/立绘素材（ART0 并行，程序侧只做槽位与切换逻辑，引擎绑定留素材到位后接入）。
- 页面逐屏视觉改造（P5-005 只交付主题规范与常量，逐页应用在 b34 收口）。
