# 变更提案：盘面静态视觉预制体化

## 动机

`HexBoardView` 当前不仅动态创建网格和实体，也动态创建盘面底座、外框和边缘流光。这样能快速搭建灰盒，但正式美术接入后，静态视觉层级和布局无法直接在 `BoardPage` 预制体中调整。

## 已确认决策检查点（第 1～2 轮）

- 盘面外框使用固定尺寸；网格根据盘面边长适配。
- 底座、外框、边缘流光等固定视觉放入 `board_root` 预制体层级。
- 网格仍按盘面数据动态生成。
- 实体由预制体提供视觉和交互模板，运行时按数据实例化或复用。

## 已确认决策检查点（第 3 轮）

- `board_root` 下静态放置底座、外框、边缘流光，以及 `board_tiles`、`board_entities`、`board_overlays`、`board_fx` 容器。
- 运行时只在这些容器内生成或复用格子、实体、目标提示、预演对象和短时特效。

## 边界

本变更只调整盘面视图的装配方式，不改变 `BoardState`、旋转、拍击、碰撞和结算规则。
