# 设计：盘面静态视觉预制体化

## D-1：静态视觉与运行时对象分层

预制体中的 `board_root` 负责固定坐标系和视觉层级，静态子节点包括底座、外框、边缘流光、装饰层、网格容器、实体容器和特效挂点。运行时只在容器下生成或复用随关卡变化的网格、实体、异常遮罩、机械臂目标和短时特效。

## D-2：固定外框，网格自适应

外框尺寸固定在预制体中。`FrameArt` 的 RectTransform 完全以 `BoardPage.prefab` 的值为准，`HexBoardView` 只更新其 Sprite 和显示属性，不写入锚点、位置、尺寸、旋转或缩放。`HexBoardView` 根据 `BoardRadius` 计算 `m_CellSize`，只更新网格的格子坐标和实体位置；不再负责创建固定外框对象。

## D-3：实体使用预制体模板

实体模板预制体提供 `RectTransform`、六边形命中面、按钮和视觉挂点；运行时绑定实体数据、图标、类型状态和位置。实例化与复用策略由盘面视图持有，避免把关卡实体固定写入 `BoardPage`。

## D-4：预制体提供容器，运行时填充内容

`board_root` 下固定放置 `board_tiles`、`board_entities`、`board_overlays` 和 `board_fx` 四个容器。容器的顺序由预制体决定，运行时只清理和填充容器内容；这样可以在 Inspector 中直接调整层级，又不会把动态对象的数量和坐标写死。
