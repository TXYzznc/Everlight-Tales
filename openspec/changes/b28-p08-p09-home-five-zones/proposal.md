# b28：家园五区（P4-008 / P4-009）

## 目标
- P4-008 家园场景与五区导航：来客 / 加工 / 收藏 / 保管 / 服务五区导航。

- 新增 `ArchivePanel`（陈列 / 档案区：陈列物列表 + 拥有物五类概览）。
