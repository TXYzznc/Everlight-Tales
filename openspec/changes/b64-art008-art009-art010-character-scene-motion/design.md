# 人物场景与盘面动效设计

## Context

ART-008/009/010，使用 b62样张、首发引用清单和 b63盘面图标。已有背景矩阵和五人物状态定义；已取消 GravitySeat 视觉、立绘呈现跟随当前对话布局，不复活旧样张里的退休节点。

## Goals / Non-Goals

交付首发使用的人物/背景状态和可中断盘面反馈。首发未引用人物差分与14案后置；不把音效混入动效验收，不升级渲染管线或安装新动画依赖。

## Decisions

### 1. 显式状态映射与现有资源复用

| 方案 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 文件名猜状态/地点 | 少配置 | 易错图、错昼夜 | 不采用 |
| 角色/场景稳定键＋显式状态映射 | 可校验并有确定回退 | 需维护清单 | 推荐 |
| 每个页面各自持完整图片 | 独立方便 | 重复资源、状态漂移 | 不采用 |

人物保留 b62列明真实状态ID。按首发实际台词和案件状态选图，未用差分留索引；L01补 hint/manifest/after 三态。缺未知状态走角色已批准默认态并报告诊断，已列首发必需状态缺图则验收失败。UI不因找不到差分而改变案件或时间状态。

背景交付：BG-T01标题/选档、H01外壳、M01地图三种光照、P01准备、B01盘面场景复用、S01结算三种结果、D01舞蹈夜景、D02居所昼夜、O01开场，共P0九组；检查五地点（居所/街区/舞蹈/裁缝/社区）昼夜十图，已合格图片复用。其它P1调查细图与P2分区背景仅补首发清单引用，不扩建全部矩阵。

SceneKey＋时间段＋结果态选图，前景/中景/远景按当前视图支持分层；不以补给来源推断场景。界面控件/文本独立，背景留出现有布局安全区；不因新图重排页面。

### 2. 表现消费结果，不能驱动逻辑

盘面逻辑先产出有顺序的反馈记录，视图消费旋转、咬合、震波、连锁和目标反馈。使用现有动画设施/粒子/材质；优先复用，无需额外第三方依赖。每次播放带页面/尝试世代令牌；关闭、重开、恢复、快进取消旧播放并释放池实例。恢复直接重建当前快照，不重放上一轮奖励动画。

播放完成/跳过最终落到同一视觉状态；无论倍率如何，不能多发结算或解除逻辑中的输入锁。交互恢复由逻辑事务完成＋本次表现收束共同决定；异常取消进入确定的清理路径，不能无限等待已销毁节点。反馈强度、时长和减弱模式集中配置，按样张与试玩调整；回声有可辨识视觉但不创建音频文件。

## Risks / Trade-offs

- 新背景遮住棋盘/文字 → 与现有1080×1920布局叠图对照。
- 多次进入残留粒子/回调 → 连续开关、快进、恢复测试核对池计数和订阅。
- 大量状态制作浪费 → 首发引用清单锁定范围；后置状态不得冒充完成。

## Migration Plan

先人物状态组，再场景状态组，最后动效组，逐组写资源映射与截图；检查GUID/材质引用。回退以完整角色/场景/动效组为单位，保留现有稳定键。b65在正式流程复验，真机帧率/包体留待用户第7项解除暂缓。
