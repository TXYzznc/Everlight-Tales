# 人物场景与盘面动效

状态：整套方案已获开始执行授权，按前置批次顺序待实施。原任务：ART-008、ART-009、ART-010（ART1）。

## Why

已有两张人物图与部分场景图尚不足以覆盖首发对话和昼夜状态；盘面反馈还需要统一的完成、跳过与取消生命周期。

## What Changes

- 按首发实际引用补齐人物状态和 L-01 怪谈三态
- 复用并补齐 P0 背景与五地点昼夜场景
- 完成旋转、咬合、震波和连锁动效，保持逻辑时序独立。

## Capabilities

### New Capabilities

- `narrative-visual-states`: 人物场景状态选择与回退。
- `board-feedback-lifecycle`: 盘面表现播放、跳过、取消与回收。

### Modified Capabilities

无。沿用既有框架工作流与通用 UI 契约，本批新增项目行为/验收契约。

## Impact

人物/场景/动效资源和对应视图；依赖 b63 与 b62 样张；只做首发，十四案、真实音频和渲染管线升级不在范围内。
