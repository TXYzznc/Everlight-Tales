# 变更提案：准备页零件详情与任务概览

## 动机

PreparationPage 当前的盘面预览信息密度低，随机盘面又无法在准备阶段完整预测；可携带零件也只能看到简短提示，拖拽时显示整行卡片会遮挡盘面目标。玩家需要在开始前快速理解维修目标、特殊任务、完成条件和零件的真实数值效果。

## 变更范围

- 在 PreparationPage 中用配置驱动的三段式任务概览替换盘面预览主区域。
- 为可携带零件增加局部长按详情卡片，组合现有 PartConfig 数值与 FormConfig.Description。
- 拖拽零件时只显示跟随指针的零件图片，透明度为 80%。
- 详情卡片作为 PreparationPage 预制体静态节点存在，运行时只更新内容、位置和显示状态。

## 不在范围

- 不增加新的基础形态文案字段。
- 不改变盘面运行规则、结算规则或携带选择数据结构。
- 不保留当前盘面缩略图作为准备页主信息。
