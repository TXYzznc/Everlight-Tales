# 提案：六相旋转与定势 + 拍击结算事务（P1-003、P1-004）

覆盖任务：P1-003、P1-004。

## 目标

在 Board 层实现六相定势盘的两项核心机制：

1. **六相旋转与定势（P1-003）**：内盘六相旋转，左旋／右旋各一个相位并吸附；选定边 = 最低势位 = 重力方向；旋转不改棋子、不触发能力、不累计代价。
2. **拍击结算事务（P1-004，SR-002）**：扣拍数 → 到期效果 → 定势下落 → 碰撞 → FIFO 能力事件队列 → 重力接续（D-067）→ 拍末效果 → 稳定，且一次拍击按序结算、同拍重力持续接续。

## 前置

b05（P1-001 蜂窝格 + P1-002 实体占用层）已完成并验收。

## 验收边界

- 六相位咬合正确：左旋／右旋各一相位，六次旋转回到原位，旋转不移动棋子、不触发能力。
- 一次拍击按序结算：扣拍 → 到期 → 下落 → 碰撞 → FIFO → 接续 → 拍末 → 稳定，事件日志顺序可复现。
- 定势下落：可移动实体沿重力方向滑至边缘或首次碰撞；固定设施不滑落。
- 碰撞：实体移动后受阻产生一次碰撞并触发（占位）；静止相邻不重复触发。
- 重力接续（D-067）：阻挡移除／移开后，同拍内沿当前重力继续下落并接出新碰撞，不消耗额外拍数。
- Board 层仍零引擎依赖（`verify_project_assemblies.py` 通过）。

## 关键决定

- 六相旋转用 `SettleState` 承载（D-094），重力方向 = 对准定势座的相位边。
- 拍击结算事务用 `TapSettlement` 编排（D-095），演算与播放分离，产出确定性事件日志。
- 重力接续（D-067）用批式「下落 → 排空队列 → 重查」循环实现（D-096）；静止相邻不产生新碰撞。
- `BoardState` 增加实体枚举与移除（D-097），供回收／开门／销毁与重力接续。
