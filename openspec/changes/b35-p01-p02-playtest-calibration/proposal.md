# b35：试玩校准（P6-001/P6-002）

## 目标
- P6-001 校准：教学/红鞋/卷帘门——教学三段节奏、红舞鞋三轮目标与时间格、卷帘门拍数/分数/时间格/费用的按盘反馈校准口径。
- P6-002 校准：经济成长节奏——维修费单价、改装支线领奖、形态解锁费区间、回访费的收支节奏校准口径。

## 范围
- `Data/CalibrationConfig.cs`：校准项目录（每项含当前值 + 口径下界/上界 + 类别）。
- `Meta/CalibrationService.cs`：校准口径校验（越界清单 + 全量校验 + 报告）。

## 非目标
- 真实试玩反馈与数值调整（口径先固化，正式调值留试玩后迭代）。
- 正式素材接入（ART2 于 b37 对接）。
