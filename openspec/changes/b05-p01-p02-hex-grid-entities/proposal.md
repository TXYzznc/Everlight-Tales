# 提案：蜂窝格棋盘数据模型 + 棋子实体与占用层（P1-001、P1-002）

覆盖任务：P1-001、P1-002。

## 目标

在 Board 层实现六相定势盘的盘面数据模型：

1. 蜂窝格几何：轴向坐标 (q, r)、六方向 D0–D5、边长 n 分档生成与合法性判定（SR-004、D-088）。
2. 棋子实体基类（零件／设施／任务标记／待维修对象）与占用层：每格单实体、固定设施锁盘面（SR-004）。

## 前置

b04（G0 集成验收）已完成。

## 验收边界

- 各 n 档位（教学 5、试机 5～7、普通 6～8、怪谈 10）总格数与合法格集合生成正确。
- 轴向坐标六方向换算、距离、旋转、反向正确。
- 实体占用：每格最多一个实体；重复 ID 拒绝。
- 移动限制：固定设施不可移动；越界／占用目标拒绝；可移动实体正常移动。
- 地形层与端点标签与实体层共存，不占实体容量。
- Board 层仍零引擎依赖（`verify_project_assemblies.py` 通过）。

## 关键决定

- 网格以「边长 n」参数化（D-091），半径 = n − 1。
- 实体用「类别枚举 + 固定标志」建模（D-092）。
- 盘面状态用「三层模型」（实体占用／地形／端点标签）承载（D-093）。
