# 挑战装配与一局回归设计

## Context

P2-013/P2-014/P2-018 原标记完成，但 [b57](../b57-p2-002-p2-003-challenge-config-tables/tasks.md) 的4.3装配、5.3探针和5.4运行证据尚缺。ChallengeCatalog 已有15条，只有 C-001 可用；现有红鞋规则表 StepsPerTap=1，与部分历史描述每拍3步存在差异。b60 先完成行为，b59 提供恢复入口。

## Goals / Non-Goals

打通 CaseKey→Challenge→Level/Rule 的正式消费链并得到真实关卡证据。P1-021 只追溯已有配置输入，不跨回 G1 批次；不激活其余14案、不添加新入口，不在回归时顺手调难度。

## Decisions

以下均为推荐设计，待用户统一审阅。

| 装配方案 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 保留业务 if 分支 | 改动少 | 配置存在但无权威性 | 不采用 |
| 稳定 RuleId 的显式注册表＋挑战配置 | 类型受控、错误可前置 | 新规则需显式登记 | 推荐 |
| 字符串反射创建任意类型 | 扩展自由 | 拼写/裁剪/运行时失败风险 | 不采用 |

进入正式维修前通过 CaseKey 查 ChallengeCatalog，校验 ReleaseKind/启用条件、唯一关联、LevelKey存在、RuleId已注册。C-001 绑定 L-01/REDSHOE/CR-001，装配器把规则配置与关卡参数注入 RedShoeLevel；不覆盖已有世界档案件实例。配置只读，运行状态由实例持有。未启用 C-002～015 不出现在可玩入口；未知规则或缺引用在装载/进入前失败并带配置键，不能退回默认红鞋。

参数权威顺序：RedShoeTable/Guide/Turn 是专属规则来源，Level/Round 表提供通用轮数和目标，ChallengeTable 只绑定不复制规则参数，CalibrationTable 记录校准范围/结果而非运行时覆写。现有1步作为未经校准的基线保留，并记录与历史3步文本的冲突；b66 用隔离候选对照1/3步，只有明确批准的结果才改主配置。禁止“为了通过”直接改红鞋速度。

### 验证矩阵

| 层次 | 内容 | 证据 |
|---|---|---|
| 配置负例 | 重复案件、缺关卡、未知规则、非法 ExtraData 键/类型/重复键、缺必要数值、禁用挑战 | 失败发生阶段与明确诊断，不进入半初始化盘面 |
| 行为承接 | b60 八障碍八异常相关单测；A003/A007及O003/O005/O007/O008组合 | 种子、参数快照、事件来源轨迹 |
| 三教学 | 每段从正式入口开始、目标、结束转场、零世界耗时 | 实际输入序列与结果 |
| 红鞋 | 三轮、合法奖励选择、目标推进、失败/撤退/成功与 b59恢复 | 不注入分数/Buff；记实际随机奖励与所用重试 |
| 卷帘门 | 正式入口、修复、结算、世界更新 | 一次实际完成与一次中断恢复 |
| 旧档 | 无快照世界档正常加载、C001规则初始化、槽位隔离 | 前后世界值与恢复状态 |

成功路线只证明该路线，不证明所有奖励可通；失败也不推出关卡无解。无头测试、Editor运行分别报告。测试夹具可造异常组合，但不得作为正式入口运行证据。

### b57 移交

3.1b/3.2/3.3/3.4→b60；4.3→本批装配；5.3→本批汇总配置负例＋b60行为证据；5.4编译已完成但正式运行子项→本批；5.5→本批证据索引。5.2 中定向表检查可记录，要求全量 round-trip 无漂移的未完成部分仍属于用户暂缓第8项；不能把 b57 全部勾完或归档成无遗留。

## Risks / Trade-offs

- 双重配置来源 → 在报告列每个有效参数的源表与行键。
- 硬编码通过路线掩盖难度 → 固定回归保留，推广结论交 b66。
- 所有表重生成引入噪声 → 本批只写必要接线和定向验证；历史漂移独列。

## Migration Plan

先装配负例与基线截图，再改正式入口，跑 b60回归后依次三教学/红鞋/卷帘门。写 verification.md 和 b57移交状态；回滚装配代码及对应配置引用成组，保留测试证据。验收是本轮 G2修复复验，不能推导 G6或全量内容完成。
