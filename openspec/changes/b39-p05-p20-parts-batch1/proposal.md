# b39：P-005~P-020 零件行为数值实装（第一批 8 件）

## 目标
把 b27 仅图鉴占位的通用零件接入实际行为与数值。第一批为行为可独立闭环、不依赖未实现怪谈系统（声音/水/负荷/伪装/校准）的 8 件。

## 范围（第一批）
- P-005 弹射簧（反向推进 2 格，遇障发碰撞）
- P-006 分裂铸模（复制邻格零件到六邻格空位，副本不可再作源）
- P-008 吞料炉（吞入移除普通件，产公共维修能量）
- P-009 交换拨叉（原子交换 D0/D3 邻格）
- P-010 旋涡转子（六邻格旋移一位）
- P-011 蓄能飞轮（蓄量 3 满六向射线）
- P-019 磁吸牵引器（D0 射线搜索 + 拉近）
- P-020 接力电池（六邻格补零件能量，电量归零移除）

## 改动
- `Data/PartConfig.cs`：新增 effectScorePerEnergy/pushDistance/rayRange/chargeThreshold 字段 + 注册 8 件。
- `Board/BoardEntity.cs`：新增 Charge（蓄量）与 IsCopy（复制体标记）。
- `Board/BoardState.cs`：新增 AllocateEntityId（铸模复制分配新 ID）。
- `Board/PartAbility.cs`：新增 8 个行为分支。

## 非目标
- P-007/P-012/P-013/P-015/P-016/P-017/P-018（第二批，依赖收纳/信号/水/负荷/伪装/校准状态）。
- 怪谈专属挑战接线（这些零件在挑战中的具体配置留对应内容批）。
