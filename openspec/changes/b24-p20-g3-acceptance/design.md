# 设计：b24 G3 一天闭环验收门

## 1. 验收链路（P3-020）

```
新档(第1天上午)
 → 地图五区注册 + 地点解锁
 → 白天普通供给(≤4)
 → 盘面(卷帘门初盘) → 结算事务(五步+防重) → 世界结算写档(防重)
 → 时间推进 上午→下午→夜晚
 → 夜晚普通供给(≤4) + 调查入口创建红舞鞋怪谈
 → 跨天 深夜→第2天上午
 → 世界存档往返 + 恢复面板(继续/各只一次)
 → 任务三页分组
```

## 2. 关键断言（23 项）

| 环节 | 断言 |
|---|---|
| 新档 | Day=1、Period=Morning、RemainingCells=4 |
| 五区+解锁 | Places.Count=5、home 开局解锁、street 剧情解锁 |
| 四时段 | 上午→下午、下午→夜晚跨段 |
| 昼夜刷新 | 昼夜各 1~4 个普通实例 |
| 怪谈入口 | 调查创建 L-01（调查中） |
| 盘面→结算 | 初盘生成进准备、成功发奖(费>0) |
| 结算事务 | 五步推进时间、防重不重复扣时 |
| 世界结算 | 写档发奖、防重不重复发奖 |
| 跨天 | Day=2、Period=Morning |
| 双存档 | 世界存档往返（五区+案件） |
| 恢复 | 有尝试存档需面板、继续、恢复只一次 |
| 三页 | 事件页白天分组、任务页进行中、怪谈页排序 |

## 3. 第五区补充

`PlaceCatalog.FirstBatch()` 增「community 社区活动中心」（Story 解锁），使地图构成五区：修理铺(家)/街区小店/舞蹈教室/裁缝铺/社区活动中心。

## 4. 层关系

- 本批无新增运行时逻辑，仅 Data 地点目录补一条 + UI 层验收探针。
- 探针位于 UI 层（唯一同时引用 Board/Events/Meta/Data 的业务层），复用 b13～b23 全部服务。

## 已知限制

- 表现层（触控、正式 UI、立绘、音频）与教学自走验收在 G5/G6。
- 成长闭环（G4）自 b25 起。
