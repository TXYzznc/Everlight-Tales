# 障碍与异常完整行为设计

## Context

原任务 P2-002/P2-003，承接 [b57 未完成行为](../b57-p2-002-p2-003-challenge-config-tables/tasks.md)。当前 ObstacleService 有基础扣耐久/切换，AnomalyRegion 缺回声额度和重绘游标；BoardState 单格实体占用不能直接表达“开闸后格内有零件”。两条事件队列分属盘面结算与零件能力，不能靠全局去重抹掉合法碰撞。b58/b59 是前置交付。

## Goals / Non-Goals

使配置参数在完整结算链中可观察、可恢复、可测试。限定项目扩展层；不改 ScriptsBuiltin 框架核心、不开发十四案、不制作音频。SOUND 是逻辑能力信号，不是音效播放。

## Decisions

以下方案已随整套b58～b67获得“开始执行”授权；D-324存档决策继续有效。实施保留现有双队列：Board队列执行能力，Events队列翻译已结算事实用于表现/复现，来源随事实传递，不二次执行能力。

### 1. 保留结算管线，贯通来源标识

| 方案 | 优点 | 代价 | 选择 |
|---|---|---|---|
| 各解释器自行猜测重复事件 | 改动少 | 无法识别爆破链与回声来源，结果依赖调用顺序 | 不采用 |
| 两条现有队列传递统一来源上下文 | 保留职责和 FIFO，能局部限定去重 | 需补齐所有生产和转译点 | 推荐 |
| 重写为统一事件总线 | 单一调度入口 | 跨模块重写，回归面过大 | 不采用 |

每次独立能力根触发生成 RootEventId；一个拍击可有多个根，不能拿 TapId 代替 RootEventId。派生事件继承根，使用唯一 EventId 和 ParentEventId；带 EffectKind、Origin（Original/Echo）、SourceEntityId、发出坐标和方向。去重键为根＋目标＋受限效果，作用域仅当前结算事务，不对所有普通碰撞全局去重。两条队列之间保留标识，不重新生成根。复用事务内集合，结束清空，不在 Update 创建集合。

主效果传播完成后处理该根挂起的回声，再继续既有队列顺序；拍末生长在连锁清空后、最终失败判定前；轮后重绘在下一轮快照前且同轮只执行一次。事务中途不保存，恢复以轮起点重新演算，不保存临时去重集合。

### 2. 固定设施与可移动占用分离

保留普通实体占用表，另设固定设施登记，O-003 闸门和 O-005 夹持座从实体占位移到设施层；稳定 ID 与统一查询仍可被能力命中。入口阻挡同时查询设施和占用者，开闸格可有一个零件，关闸不会覆盖它。夹持状态影响移动资格，释放窗口按完整拍结算递减。Board 渲染按设施→零件→反馈叠放，不复制碰撞目标；机械臂、推移、传送、初始盘面均使用同一阻挡规则。

替代方案：允许单格多个普通实体会改变大量查询契约；开闸时删实体会丢失后续控制目标。设施叠层更局部，但需要专项占用回归。

### 3. 类型参数与实例绑定分开

沿用 ObstacleTable/AnomalyTable 的 ExtraData。给 LevelFixedElementTable 追加可空的 InstanceData 字符串，只保存实例关系（LinkedElementIds、ProtectedElementId、GrowthRootElementId、InitialClampedElementId）；语法复用现有严格参数解析，按设施类型列白名单。引用的是本关固定元素行 ID，由装配器二阶段解析到运行 ID，不把类型表 AttachedPartitions=2 当成两个实体 ID。零表示未绑定；必要关系缺失、重复、悬空、跨关、目标类型错误或非法坐标均在进入前报错。

本批只针对这张表的源 xlsx、schema、txt、cs 做定向一致性验证；不借机修复 Meta 既有漂移。旧行空值保持兼容；只有需要实例关系的配置才强制填写。O-008 绑定数量须与类型配置一致；未配置保护对象不产生保护事故。

### 4. 八种障碍验收契约

| 类型 | 行为与边界 |
|---|---|
| O-001 | 永久隔板不受普通损伤；不可推移、夹持或覆盖 |
| O-002 | 初始耐久来自表；同一爆破根最多扣一次，独立根可再次扣减 |
| O-003 | 初态来自表；同根最多切一次；有占用时记待关闭，空出后关闭；再次合法开信号取消待关闭 |
| O-004 | 输出方向严格读 PassDirection；不硬编码 D1 |
| O-005 | 只夹 AllowTags 允许的普通实体；初始绑定校验；释放后至少经过配置拍数才重新夹持 |
| O-006 | PassDirection 与 ToggleDirection 在控制时互换，不固定假设永远互为反向 |
| O-007 | 每个生长根每拍共享 GrowthPerTap 预算；现存段按稳定 ID、邻格 D0～D5 选空格；新增段本拍不再递归增长；避开端点/占用/非法格；切根仅停长，保留旧段 |
| O-008 | 耐久归零只移除绑定的现存脆裂隔板；按明确保护绑定触发事故；可修复仅恢复存活支柱耐久到上限，不复活已毁实体或隔板 |

### 5. A-003 回声与 A-007 重绘

回声：成功发出的原始 SOUND 源在区域内且额度>0才登记复制。静默或封存而尚未发出不耗额。原传播结束后从原坐标/端口发一个 Echo，Echo 不再被任意回声区复制；额度跨拍保留，合法复位恢复配置额度。重叠同类区仅优先级最高者处理，相同优先级按稳定区域 ID；被选区额度不足不转交低优先区，避免隐含多重额度。只建立 M-010 等延迟发声的来源契约，不补做其未投放玩法。

重绘：区域只接受显式登记的可伪装载体，不扫描所有棋子。按稳定登记序轮转，每轮最多 PerRoundTargets 个合格对象；跳过已满 MaxLayers 的对象，扫描一圈结束，游标确定性前进。只增伪装层，不改真实身份和历史。照明沿已有规则揭露；校准关闭后不再增层，既有层保留。若红鞋 LR-PS-03 提供同一重绘效果，则委托同一执行器和轮次去重，不叠加两次。

其余 A-001/002/004/005/006/008 建逐参数消费矩阵：Priority/Controllable、MaxExpansion、SuppressStoryNodes、StepLength、RechargeAmount、FlipDegrees。A-002 失败传送不计数，扩张不超过配置和候选格；A-008 周期计数触发后重置；只用0表示不适用，不给必需字段偷偷补旧常量。

### 6. 存档、错误和可观测性

b58 快照版本扩展包含设施、待关门、夹持及剩余窗口、封条根关系、附属关系、回声额度、区域 ID、伪装身份/层数/游标/停止状态及轮后已执行标记。恢复先解析 ID 图再校验；旧版本不能无损补齐时走 b58 不兼容备份/无罚重开，不猜测关系。结算日志优先级不变。

输出事件轨迹含根/父/来源与规则结果；检测非法实例关系时阻止进入并给可定位配置键。验收断言规则输出，不依赖截图或日志字串替代状态比较。

## Risks / Trade-offs

实施核对（2026-10-14）：轨道和百叶原来同样被误放入实体占位，随闸门/夹持座采用同一设施登记；入口规则仍各自消费方向参数。夹持基础只接受normal普通件，明确允许task标签的实例才接受可移动任务标记；关键件初始化落在夹持座时按统一进入规则立即夹持。恢复放置不触发进入效果，之后校验双向夹持图。DeferCloseWhenOccupied=false时拒绝占格关闭请求，不覆盖对象。快照及RulesVersion升为3；旧轮起点不能无损解释时依b58降级，世界档保留。

维修参数沿用固定元素表既有RepairPartKinds/RepairRequired/RepairEnergyCost列及REPAIR-SCORE校准项；可修支柱和封条根须显式声明，InstanceData只放关系。维修效果依据该配置扣公共能量和记效果分，满耐久/已停根/已移除不收费或重复记效果。封条根本体作为初始生长段，其它段引用根；每根拍末共享预算，新段只在下一拍参与。段最大耐久单独保存并按SegmentMaxDurability校验，拍末执行序号持久化以拒绝重复钩子。

- 设施分层影响路径与能力命中 → 开闭门、夹持、传送、机械臂和端点混合用例先行。
- 事件标识遗漏 → 针对根跨两条队列及多段传播做反例，同根与独立根都验证。
- 新状态恢复不全 → 同种子恢复前后逐字段状态及事件轨迹比对。
- 修改表结构 → 仅定向生成受影响表，提交证据列出既有漂移，不扩大到暂缓治理。

## Migration Plan

先锁定当前正式关卡基线和快照版本，再来源标识→设施层→障碍→异常→快照→集成。停 Play Mode 后普通编译；结构变更不用 FSR 代替编译。每步有针对性 EditMode 测试，最终用正式入口回归三教学、红鞋、卷帘门；异常组合用测试夹具，不增产品入口。回退代码与配置成组；不兼容快照遵守 b58 降级，保留世界进度。
