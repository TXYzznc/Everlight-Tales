# 设计：b13 盘面内容件批量接入

## D-118：零件与障碍

- **P-004 换向齿轮**（ReversalGear，触发4/容量4/费1/每格8）：有实体入射且能量足够时，耗 1 把来撞实体从当前格沿入射方向顺时针偏转 60°（`HexDirections.Rotate(incoming,1)`）推进 1 格；落点非法耗能不移动；信号无入射不换向不耗能。
- **P-014 铆合钳**（RivetPliers，触发4/无自身能量）：受击或信号时检查 D0 邻格可修复节点，适配且公共维修能量足够时入队 `RepairEffect`（扣公共能量、进度+1、维修效果分由维修对象配置，第一版 20）。
- **耐久障碍**：O-002 脆裂隔板（耐久2）、O-008 承压支柱（耐久3）、O-007 封条（每段耐久1）受「真实物理碰撞」或「爆破冲击」各扣 1，归零移除。碰撞扣耐久在 `TapSettlement.FallAll` 碰撞分支，爆破冲击在 `PartAbility.Coil` 邻格扫描。
- **其余障碍行为**（ObstacleService）：O-001 固定阻挡；O-003 闸门开关切换与进入判定；O-004 轨道输出方向 D1；O-005 夹持锁定/释放；O-006 百叶入口方向判定与 D0↔D3 切换；O-007 拍末生长与切根停长。

## D-119：棋盘异常框架

- `AnomalyRegion`（类型 + 区域格 + 出口格/扩张格 + 运行时状态）注册到 `BoardState.RegisterAnomaly`。
- `AnomalyService` 按类型解释：A-001 局部定势偏转（全局+1）、A-002 裂隙原子传送（计数扩张）、A-004 静默抑制、A-005 沉降方向 D2、A-006 场热/过载/转静默、A-008 拍末反转周期。A-003/A-007 仅登记保留类型。
- 异常与结算管线的实际挂钩（A-005 轮后沉降、A-008 拍末反转整理）留 b15/b16 一局链路接入。

## D-120：特殊目标判定

- `GoalConfig`（GoalKind 到达/保持/顺序 + 锚点标签 + 实体 + 参数）→ `BoardState` 端点标签（锚点→盘面节点映射）。
- `GoalEvaluator.AtLabel` 判定实体是否在锚点；`AnchorGoalState.Tick` 推进：到达一次即达成、保持连续驻留 N 拍、顺序按序到访各锚点。

## 边界

- 本批内容件只落「可配置 + 单点行为」，不接入一局闭环结算顺序（准备页/初盘/存档/结算留 b15/b16）。
