# b36：回归与性能收口（P6-003/P6-004/P6-005）

## 目标
- P6-003 全案回归统计：确定性盘面演算 + 通过率/分数分布聚合。
- P6-004 存档与中断回归：存档往返一致性 + 恢复面板一次性语义。
- P6-005 性能与帧率收口：移动端性能预算口径。

## 范围
- `Board/RegressionService.cs`：盘面确定性演算（同种子同序列同分数）+ 回归报告聚合。
- `Meta/SaveRegressionService.cs`：存档 Capture/Restore 往返一致性校验。
- `Data/PerformanceBudget.cs`：帧率/内存/加载/盘面渲染预算。

## 非目标
- 真实移动端帧率/内存实测（只固化预算口径，实测留发布预热）。
- 关卡求解策略（回归只验确定性演算与稳定性，不验策略通过率）。
