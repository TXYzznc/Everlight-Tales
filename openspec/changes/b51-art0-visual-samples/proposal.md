# b51：ART0 视觉样张（ART-001 UI 视觉规范 + ART-002 六相定势盘样张）

## 背景
程序侧 112 项与占位资源（ART-000）已全部关闭。剩余 15 项正式美术音频任务，本批推进 ART0 视觉样张中程序化可完成的 2 项：UI 视觉规范与六相定势盘视觉样张。二者是 ART1 批量制作（ART-006 零件设施图、ART-007 UI 九宫格）的前置。
