# UI 测试与验收清单

## 结构与资源

- [ ] 每个独立页面只有一个 GF UIForm Prefab，未保留重复视觉结构或无价值专属子 Prefab。
- [ ] 节点命名、层级、SerializeField、资源键和 `prefab-layout.md` 一致。
- [ ] 无 Missing Script、Missing Reference、默认字体、Legacy Text、错误资源路径或整图集误绑定。
- [ ] Image 类型、Sprite Slice、按钮状态、raycastTarget 和 ScrollRect 结构正确。

## 交互与生命周期

- [ ] 打开、关闭、覆盖、恢复、Esc、返回主菜单和异常结束均无残留 overlay 或输入穿透。
- [ ] 默认焦点、手柄导航、键盘确认/取消、鼠标点击走同一业务意图。
- [ ] 加载、空、错误、禁用、超时、重复点击和取消都有可见且可恢复行为。
- [ ] 关闭后不存在晚到回调、重复事件订阅、泄漏对象池 Item 或数据串写。

## 视觉与适配

- [ ] 与确认视觉稿/布局对照，无裁切、重叠、错误锚点、错误轴心或重复节点。
- [ ] 当前 AI 交付在 1920×1080 下的遮罩、HUD、模态框、滚动区和长文本正确。
- [ ] 16:10、21:9 与其他比例由用户后续手动处理；当前不作为 AI 完成门，除非用户明确重新启用。
- [ ] 文字对比度、元素/状态的非颜色提示、焦点状态和最小图标尺寸可读。

## 性能与自动化

- [ ] Profiler 中无由 UI Update、布局循环或列表重建导致的持续 GC/Canvas rebuild 峰值。
- [ ] 页面开关、核心操作、输入层级与 1920×1080 基准场景具备可复跑测试或人工证据。
- [ ] 编译、项目诊断、PlayMode smoke 与项目 UI 锚点/缺失引用检查通过。
