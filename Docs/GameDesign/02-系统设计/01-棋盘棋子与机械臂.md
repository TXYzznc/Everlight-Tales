# 六相定势盘、零件与机械臂 v1.1

> 操作基础沿用已确认方向；具体棋子池、字段与数值未经本轮运行验证。

## 六相定势盘

- 装置由固定底座、可旋转的六边形内盘和底部定势座组成，具有六个合法朝向；旋转不消耗普通拍击次数。
- 玩家用左旋与右旋按钮转动内盘，使目标边对准底部定势座。该边成为本次异常联系的最低势位；外部场景和装置底座不随内盘旋转。
- 拍击生效后，可移动零件沿当前定势方向滑至合法位置，能力移动按事件次序处理；固定设施锁在盘面结构上，不因定势改变而滑动。
- 类型与落点保留随机性。锚点将现场异常联系映射到盘面，连锁改变对应场景。
- 墙体、危险区域、真假标记与方向变化由当前怪谈规则定义。
- 预告、突发变化、隐藏条件均可设计并试玩，不预先设全局体验禁令。

### 装置在世界中的作用

六相定势盘是长明修理铺用于检测和调整异常联系的校准装置。玩家先把锚点接到现场的人、物、通路或设备上，定势盘再把其中可以处理的关系转换成盘内节点。盘面不是现场的缩小模型，也不会把真实人物装进零件；它显示的是“什么正在影响什么，以及这条联系能被怎样推动”。

装置只处理已接入的局部关系。它可以重新安排、分离、接通或封存异常联系，不能凭空逆转所有现实后果，也不代表不同文学怪谈拥有同一个起源。

### 主要部件

| 部件 | 世界内作用 | 游戏表现 |
|---|---|---|
| 固定底座 | 稳定装置并承受反复冲击 | 始终固定，不随盘面旋转 |
| 六边形内盘 | 承载异常关系映射 | 玩家旋转并观察零件、设施与目标标记 |
| 六个相位边 | 提供六种相邻方向和释放方向 | 每次只能有一边与定势座完全咬合；左旋与右旋按钮各转一个相位 |
| 底部定势座 | 把对准的一边设为最低势位 | 高亮当前下落方向并完成方向锁定 |
| 冲击柄与盘底撞锤 | 向内盘发出一次校准震波 | 玩家提交拍击后触发震动、下落和连锁 |
| 现场锚点 | 把人物、物件、线路或空间关系接入装置 | 决定任务目标、出口、障碍与场景反馈 |
| 机械臂 | 在拍击前人工调整一个已映射节点 | 消耗次数搬动一枚允许操作的对象 |

### 一次操作的世界内流程

1. 锚点持续读取现场关系，盘面显示当前节点与异常状态。
2. 玩家用左旋与右旋按钮转动六边形内盘，把选定的一边对准底部定势座。
3. 定势座咬合，六相定势盘建立本次最低势位；此时只是选定方向，零件仍由锁定结构保持原位。
4. 玩家提交拍击，角色压下冲击柄，底座中的撞锤从盘背击中内盘。
5. 校准震波解除可移动节点的锁定，它们沿当前定势方向下落、碰撞并触发零件能力。
6. 连锁结果经锚点回传现场，使对应的灯、门、道路、影子、束缚或异常物状态发生变化。
7. 盘面和现场稳定后，玩家观察结果、领取本拍四选一，再决定下一次定势方向。

“拍击”继续作为操作名称。玩家点击的是拍击命令，角色实际执行的是压下冲击柄，让内置撞锤拍击盘背；不新增另一套“落锤”操作和计数。

### 为什么是六相

六边形内盘的每格拥有六个相邻方向，六个相位边分别对应一种完整的定势方向。盘侧提供左旋与右旋两个按钮，点一下转一个相位并吸附到位；相位切换只通过这两个按钮触发。旋转内盘时，邻接结构、轨道朝向和已经形成的布局一起转向底部定势座，因此玩家是在选择整个既有局面怎样释放，而不是给每枚零件单独指定移动方向。

“六相”是装置结构和维修术语，不是解释世界中所有异常的六种本源。不同案件仍保留各自作品来源、规则和超自然未知。

### 盘面网格与尺寸分级

维修盘是正六边形盘面，内部由紧密排列的正六边形格（蜂窝格）构成。盘面外框视觉尺寸固定，网格数量按边长 n 分级配置：n 为每边格数，总格数 = 3n(n−1)+1；文档中的 n×n 即“每边 n 格”的简写。n 越大单格越小、可容纳对象越多、连锁空间越大，复杂度越高。

| 档位 | 边长 n | 总格数 | 适用内容 | 口径 |
|---|---|---|---|---|
| 教学 | 5 | 61 | S0 工作台三段教学 | 下限，固定（暂定） |
| 试机 | 5～7 | 61～127 | 成长任务 T-G 样机试机 | 范围（暂定） |
| 普通 | 6～8 | 91～169 | 普通维修、临时处置 EV-N | 范围（暂定） |
| 怪谈 | 10 | 271 | 十五案怪谈 | 上限，固定（暂定），统一不分档 |

教学与怪谈是复杂度上下限、大小固定；试机与普通各给一个范围，单事件在范围内自选 n。所有 n 值均为暂定，试玩校准前可调整。六相定势盘的六条相位边即正六边形盘面的六条边；重力方向始终指向当前对准定势座的那条边，盘面随左旋／右旋按钮整体旋转（D-037）。外框固定，n 变化时单格尺寸自适应，保证不同档位在同一屏幕区域内呈现。

现有样张中的 (x, 0) 单行坐标只用于示意同一行对象的相对位置，不是正式坐标系；正式坐标约定与二维网格定位留到实现期、与 n 档定稿一并确定，不在设计期锁死。

### 现场映射例子

- 红舞鞋：节点表示持续运动、穿着者束缚、导流路线和封存端；定势下落是在重新导引失控运动。
- 画壁：节点表示画内外锚点、返回通路和受困者接应关系；连锁逐段接通出口。
- 裂口女：节点表示街口、追逐距离和接力点；改变定势是在安排下一段逃生路线。
- 扫帚：节点表示供水、排水、分裂和停止关系；连锁把失控供给导入可控制的回收路径。

### 2D表现与声音

固定底座和定势座保持在画面底部，六边形内盘以六个离散角度旋转。方向选定时，目标边卡入定势座，出现机械咬合声、边缘灯或刻度亮起；拍击时冲击柄短暂下压，盘框震动，震波由底部向盘内扩散，随后零件开始移动。

现场背景不跟随盘面旋转。盘面连锁通过少量状态切换回传现场，例如灯光亮灭、门缝变化、人物立绘状态、影子偏移、积水高度或广播文字变化。怪谈可以污染刻度、延迟咬合声或制造错误指示，但具体效果必须登记到对应规则。

## 零件与任务标记

当前已设计 [20 种通用零件与 11 种怪谈形态](../04-零件库/00-索引.md)，每项独立成文，具体参数待评阅与试玩。新增蓄能、联络、照明、修复、声响、排水、缓冲、校准、牵引和充电能力。

局前从已解锁内容配携带池，局内随机抽取和落位，现场可补充。M 类怪谈形态附着于指定零件，不额外占格；故事任务对象的可移动、可复制、可吞噬范围由专属挑战明确。

一次拍击内，重力持续接续：阻挡移除或移动后，当前能力连锁结算完，具备下落资格的零件沿当前重力继续滑动并可产生新碰撞。静止贴住同一阻挡不会反复触发；被推开再落回形成的新碰撞会正常触发。固定与夹持保持有效，拍间准备不自动启动重力。依据D-067，具体时序见[共用结算](08-零件挑战共用语义与配装.md#sr-002-碰撞触发与拍击结算)。

任务实体／标记代表红鞋束缚、真实受困者通路、伪装或画中出口。普通零件能力与任务标记叠加规则需逐案明确。高连锁输出、任务达成和故事结果分别记录。

构筑方向保留爆破、增殖、回收、调度和蓄能；它们不是预先选择的固定职业。

## 机械臂

消耗次数将一枚棋子移到任意合法空格。初始次数、补充与异常目标可否搬动由关卡／工具定义；受限制时界面与规则一致。

额外次数可来自阶段补给、成就、加工或奖励。广告补充只是旧有商业化候选，不是当前故事规则或首发必须项。无广告玩家也应能正常完成基础内容。
