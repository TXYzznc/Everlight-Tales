# 盘面与每拍奖励流程 v0.2

> 2026-09-15。本页补完“盘面与每拍奖励”模块：局内界面分区、一次拍击的完整操作循环、连锁播放、拍末结算与失败反馈、机械臂操作、每拍四选一的呈现。共用结算语义见[共用语义与配装](08-零件挑战共用语义与配装.md)，本页只写玩家看到什么、点什么、系统反馈什么。数值与节奏待试玩。

## 这一页解决什么

准备页确认后进入盘面。玩家在这里做的是同一件事重复若干次：看局面、选定势方向、必要时搬一枚零件、拍下去、看连锁、领一次奖励。本页把这套循环固定下来，界面、操作和反馈在同一页写清，避免实现时各自猜测。

## 屏幕分区

竖屏布局，六个区域常驻，不因携带种类多少而变化。

| 区域 | 内容 |
|---|---|
| 顶部左 | 轮次与拍数：第2轮／共3轮，本轮第1／3拍 |
| 顶部中 | 累计分数与目标分：126／140。未达标用中性色，达标后转为高亮，让玩家知道自己是否还差分 |
| 顶部右 | 暂停按钮，进入暂停菜单 |
| 分数下方 | 本轮特殊目标清单，逐项勾选并显示进度，例如“红鞋正在导流 3／6”；本轮没有特殊目标时该行收起 |
| 中部 | 六相定势盘。六边形内盘居中，盘侧是左旋与右旋两个按钮；盘外露出现场背景 |
| 中部两侧 | 现场立绘按状态切换，登场时短暂出现，不长期遮挡盘面 |
| 底部左 | 公共维修能量当前值 |
| 底部中 | 冲击柄，也就是拍击按钮 |
| 底部右 | 机械臂剩余次数 |
| 选中态 | 点任意棋子弹出零件卡：触发条件、自身能量 4／5、每次消耗、得分算法、额外能力、当前加成后的实际数值 |

盘面始终显示全部37格的边界与当前合法格。盘外背景不跟随内盘旋转。

## 一次拍击的操作循环

| 步骤 | 玩家动作 | 系统结果 | 消耗 |
|---|---|---|---|
| 1 | 观察局面，点棋子查看零件卡 | 显示该件的条件、能量与得分算法 | 不消耗 |
| 2 | 选择定势方向 | 内盘旋转、相位边咬合、底座亮起，最低势位建立 | 不耗拍数、不耗时 |
| 3 | 可选：用机械臂搬动一枚零件 | 搬动落定，剩余次数减1 | 不耗拍数 |
| 4 | 点冲击柄拍击 | 扣本轮1次拍数，进入连锁结算 | 1次拍数 |
| 5 | 观看连锁播放 | 按事件次序展开碰撞、触发与效果，飘字与连击计数同步 | 不消耗 |
| 6 | 拍末结算 | 先查失败，再查分数与特殊目标，判断是否过轮 | 不消耗 |
| 7 | 非终局时四选一 | 弹出四个不重复奖励，选择一项并立即生效 | 不消耗 |
| 8 | 进入下一拍或下一轮 | 拍数未用尽继续本轮；额度归零且达标则过轮 | 不消耗 |

选择定势方向和搬动零件都可以在拍击前反复调整，只有按下冲击柄的那一刻，当前方向与位置才被结算。没有“悔拍”。

## 定势方向的操作

盘侧提供左旋与右旋两个按钮，点一下内盘旋转一个相位并吸附到位，每一步旋转都有明确的咬合反馈。相位切换只通过这两个按钮触发。

旋转只改变最低势位，不移动零件，也不触发任何能力。方向选定后盘面给出明确反馈：目标边咬合、底座刻度亮起、当前下落方向在盘外边缘以箭头提示。旋转次数不累计代价，最后一次选择就是本次方向，六个相位之间可以自由来回。

判定的边界：拍击瞬间读取的是当前咬合边。旋转动画未播放完就点拍击时，以玩家最后点到的相位为准，不把半途的过渡角度当成方向。

## 拍击前的预演

拍击前，按当前势位预演每枚棋子第一步会落到哪里：在棋盘上只标出每枚棋子的第一步终点，让玩家不用逐格扫描37个格子自己推。预演同时覆盖重力推动与已登记的移动类特殊规则，例如轨道转向和按规则步进的对象。

预演的计算只走第一步的直接移动：从当前局面出发，按当前势位与移动规则算出每枚会动的棋子停在哪里，被固定设施或其它棋子挡住就停在阻挡前。它不考虑第一步落定之后触发的任何效果，也不预测这些效果带来的推移、碰撞、爆破、分裂或再下落，因此预演结果不会继续展开成整条连锁。

预演的边界写清楚，玩家才敢信它：标出的终点是“如果只看这一步移动”的结果，实际连锁可能把它改掉。连锁的意外感来自真实结算，规则怪谈的紧张来自规则限制，两者都不靠“看不清”制造。玩家想知道更多，可以点开零件卡逐件确认条件和能量。

触屏上的预演随方向变化立即刷新；如果有延迟，宁可晚一点显示，也不要先显示错误的终点。

## 连锁播放

一次拍击的结算在按下冲击柄的瞬间就已经完成，播放只是把结果展开给玩家看。播放是自动进行的，不需要玩家逐步确认。

播放顺序与结算顺序一致，并沿用共用语义的阶段划分：先结算到期效果，再进行本拍基础定势移动与碰撞，随后处理碰撞与效果产生的能力事件，最后执行拍末效果。这一过程中产生的所有事件进入同一个队列，按发生顺序依次取出结算；当前一项结算完并产出新的触发时，新事件接着进入队列尾部，队列中的事件逐一处理到空为止。

- 队列中的一个事件就是一次可读的表现小节：一次碰撞或一次效果作用于它的目标。
- 每取出一个事件就完成它的全部即时结果——移动、触发、计分、对象状态变化——再取下一个，不在中途插入队列外的事件。
- 同一对象在同一事件中只处理一次；静止相邻不重复触发，被推开后重新落回形成的新碰撞作为新事件入列。
- 分数飘字分别标出触发分与效果分，并汇总进顶部累计分；维修效果分在目标旁显示进度变化。
- 连击计数随事件数上升，用于表现。队列长度不产生统一计分倍率。
- 最后一段飘字与顶部累计分变化之后保留短暂停顿，再进入拍末结算，避免玩家看不清自己得了多少分。

## 拍末结算与失败反馈

结算顺序固定：先查即时失败条件，再查其他失败条件，最后查分数与特殊目标。

- 本轮拍数还有剩余时，即使分数已经达标也继续本轮，不提前过轮。
- 额度归零时，累计分数达标且全部特殊目标完成才过轮，否则本关失败。
- 失败界面必须写明原因，不接受只显示“维修失败”：累计分还差多少；哪一项特殊目标未完成，附当前进度；触发了哪一条即时失败条件。
- 失败表现为现场状态变化与对应文案，例如灯光熄灭、障碍增多、机器异响，不使用血腥或怪物表现。
- 过轮时先显示本轮小结（本轮得分、累计分、特殊目标完成情况），再进入轮间四选一。

## 机械臂操作

点机械臂按钮进入搬动选择态，点一枚棋子，再点目标合法空格完成搬动，剩余次数减1。

- 合法目标格高亮；满格、固定设施格与规则禁止的格不可选。
- 不可搬动的对象在选中时给出原因，例如固定设施、任务实体按规则不可搬动，不消耗次数。
- 中途点空白处或返回按钮取消，不消耗次数。
- 搬动不触发零件能力、不产生分数，也不启动重力。
- 次数跨轮保留，不自动补满。

## 每拍四选一

非终局的每拍结束后弹出四个奖励选项，四项互不相同。过轮的那一拍先发普通一次四选一，再发三次轮间四选一，共四次依次选择；终局不发仅供本关使用的奖励。

每张卡显示：

- 奖励类型图标与名称。
- 完整效果文本；可叠加的Buff写明“最多叠加n次”，n读取配置。
- 当前持有层数与上限，例如“已持有2／5”。
- 零件奖励显示具体种类与落点方式，随机落点或玩家选格在卡上标出。
- 来源标注，例如“计量棘轮补给”。

选择的边界：

- 必须选择一项，没有跳过。生成选项前已经移除满层Buff与已持有的不可叠加Buff，池中始终保留足够候选。
- 选择后立即生效。Buff进入持有区并在后续事件中起作用；零件补给按落点方式放置，手动落点进入选格态。
- 盘面已满时仍可选择零件补给，正常结束但不添加，明确提示“盘面已满，本次未添加”。
- 三次轮间四选一连续进行，中间不回到盘面，选择完毕再进入下一轮首拍。
- 可选时点只有当前这一次，不保留到后面补选。

## 零件与对象的状态显示

- 零件卡显示基础值与加成后的实际值，例如“触发分 12（基础10＋精密计量2）”，界面显示实际生效数值。
- 自身能量显示当前／上限；只有维修分支的零件显示所需公共维修能量与目标进度，不显示不存在的能量槽。
- 异化零件在盘面有标记，卡片写明已失去维修效果，其余变化按关卡与条目执行。
- 待维修对象显示维修进度x／y、单次公共能量消耗，以及本次携带中哪些种类可以维修它；准备页已提示过的适配关系在这里可以再确认。
- 公共维修能量的产出、消耗与当前余额在同一处显示，避免玩家把零件能量与公共维修能量混淆。

## 暂停、放弃与恢复

- 暂停菜单包含继续、设置、查看本关规则与目标、放弃本关。
- 查看本关规则与目标显示已取得的全部规则信息、当前轮特殊效果与特殊目标进度，不显示未取得的线索与隐藏规则。
- 放弃本关即撤退：按关配置扣全额时间；怪谈回到维修前状态，等待玩家再次开始维修；普通事件按撤退规则处理。
- 进度按轮存档，异常退出后恢复同一次尝试；存档的具体时点与恢复流程在存档模块中确定，本页只要求恢复后玩家看到的是同一轮、同一盘面与同一资源状态。

## 验收检查

- 玩家在一屏内能看到轮次、拍数、累计分与目标分、特殊目标进度、公共维修能量、机械臂次数。
- 定势方向只通过左旋与右旋两个按钮改变，拍击瞬间读取当前咬合边。
- 拍击前按当前势位只标出每枚将移动棋子的第一步终点，且不预测后续触发效果。
- 连锁播放按事件队列自动依次进行，不改变结算结果。
- 本轮拍数有剩余时不会提前过轮。
- 失败时能读到具体原因，包括分数差额与未完成的特殊目标进度。
- 机械臂取消不消耗次数，不可搬动对象给出原因。
- 四选一四项互不相同、显示真实内容、必须选择且选择后立即生效。
- 满盘选择零件补给时给出明确提示且不添加。
- 盘面已满、能量为零、维修已完成的零件都不会让界面显示错误的可用状态。

## 待试玩

- 第一步终点标记的视觉密度，避免在零件密集时糊成一片。
- 连锁事件播放的单节拍时长与整体节奏，以及连续多拍时的疲劳感。
- 左旋与右旋按钮的吸附反馈强度，是否需要在旋转时给出相位刻度提示。
