# 加工台与形态切换流程 v0.1

> 2026-09-15。本页补完“加工与零件成长”模块：加工台的两个功能、界面结构、形态卡状态、解锁与切换流程、材料口径、与维修准备页的衔接。四种形态机制与费用见[首批改装形态与日常成长](14-首批改装形态与日常成长.md)，本页只写玩家在加工台看到什么、点什么、系统怎么结算。完整配方与经济节奏见[加工配方与经济节奏](25-加工配方与经济节奏.md)；材料体系见[材料与货币](24-材料与货币.md)。

## 加工台的两个功能

加工台位于家园工作／加工台区域，承担两件事：

| 功能 | 玩家动作 | 结果 | 消耗 |
|---|---|---|---|
| 解锁形态 | 选中已有图样的零件，点“加工” | 新形态永久加入该零件的可选形态 | 维修费＋配方要求的材料；图样保留不消耗 |
| 切换形态 | 选中零件，在已解锁形态间点“设为当前使用” | 该零件的当前使用形态立即变更 | 不消耗任何资源 |

解锁改变玩家拥有什么；切换改变玩家默认带什么。两个功能共用同一个界面。

进入加工台、查看与切换都不消耗地图时间（D-021）；只有解锁需要支付费用与材料。

## 界面结构

一屏三段：

| 区域 | 内容 |
|---|---|
| 上方 | 已拥有零件种类横向列表；有可加工形态的种类显示“可加工”角标 |
| 中部 | 选中种类的形态卡横排，包括基础形态与全部已解锁、可加工形态 |
| 下方 | 选中形态的详情与操作按钮：工作方式说明、解锁条件、加工按钮或切换按钮 |

列表只显示已永久拥有的零件种类。M 类奖励若宿主未解锁，按对应奖励规则在取得图样时一并授予宿主（现有口径），因此列表内不会出现缺宿主的图样。

## 形态卡的四种状态

| 状态 | 显示 | 可用操作 |
|---|---|---|
| 已解锁·当前使用 | 高亮，标“当前使用” | 查看详情 |
| 已解锁·非当前使用 | 正常显示 | “设为当前使用”，点击立即生效 |
| 有图样·未解锁 | 标“可加工”，显示维修费与材料需求及持有量 | 条件满足时“加工”可点；不足时按钮置灰并显示还差什么 |
| 未取得图样 | 剪影，显示来源提示 | 不可加工；查看来源 |

“未取得图样”的来源提示写来源怪谈或任务名，例如“红舞鞋 · 力从另一头出来”。已取得但费用或材料不足的卡片同样保留，方便玩家规划。

## 解锁流程（加工）

1. 玩家在任务页或怪谈回访中取得图样。
2. 加工台列表中该零件显示“可加工”角标。
3. 选中形态卡，查看解锁条件：维修费、图样（如配置要求）及所需材料与持有量。
4. 条件满足后点“加工”：一次性支付维修费与材料，图样保留，形态永久解锁。
5. 新解锁的形态自动设为当前使用；玩家可再切回其他形态。

条件不足时：图样与任务完成记录永久保留，没有时限；费用与材料可后补，不需要重做获取任务。

加工是一次性动作：每个形态只需加工一次，重复进入不再收费、不再消耗材料。

## 切换流程（当前使用）

- 在已解锁形态间点击“设为当前使用”，免费、立即生效、不消耗地图时间。
- “当前使用”是该零件在准备页的默认形态：打开维修准备页时，每个种类默认带出加工台设定的当前使用形态。
- 准备页内仍可为本关临时切换形态（D-077），只影响本关，不改变加工台的当前使用。
- 关内不能改选形态，进入维修时固定。

加工台的“当前使用”管日常默认，准备页的临时切换管单关选择，两个入口不冲突。

## 加工消耗与配置口径

加工消耗不做系统强制，由每个形态的配置表定义。材料口径见[材料与货币](24-材料与货币.md)：材料是统称，物资条目是配方里消耗的具体物品，图样和维修费不属于材料。

| 消耗项 | 规则 | 说明 |
|---|---|---|
| 维修费 | 必定消耗 | 唯一货币（金币），每个加工都要支付 |
| 图样 | 可能需要 | 由配置决定；需要时图样作为条件永久保留、不消耗 |
| 材料 | 配置自定义 | 按配方消耗物资条目；首版只有 MT-001～MT-006 六种 |

规则：

- 加工时一次性支付维修费并按配方消耗材料；图样保留不消耗；切换形态不消耗任何资源。
- 物资条目由材料体系限定为 MT-001～MT-006；来源活动给什么、配方要什么，都按条目配置，首版不能用维修费购买材料。
- F类入门形态 P-001-F01 与 P-003-F01 只消耗维修费和图样；F类进阶形态 P-001-F02 与 P-003-F02 消耗普通材料。
- M类怪谈形态按[加工配方与经济节奏](25-加工配方与经济节奏.md)消耗普通材料、定势残晶和指定异常纹样。
- 普通事件的奖励可配置掉落材料；已确认的三个普通维修与三个非盘面小事件当前报酬仍为维修费，是否附加材料在内容配置时决定，不改变已确认的维修费数值。

## 与家园的关系

加工台是家园五类区域中“工作／加工台”的核心功能。07 号文档中“修复普通旧物，研究残件和新工具”的体验由这里承担：加工是研究成果落地的方式，陈列与保管展示加工成果的使用经历。

顾师傅等合作加工服务（外观、布艺等）在后续按各案奖励展开时，复用同一套解锁流程：来源给出图样或材料条件，加工台完成解锁。

## 配置字段

| 字段 | 用途 |
|---|---|
| 形态ID、宿主零件、形态名与图标 | 界面显示 |
| 工作方式说明 | 详情区文本 |
| 解锁条件：维修费、图样ID（可选）、材料清单（MT-001～MT-006 条目） | 加工按钮与条件显示 |
| 是否自动设为当前使用 | 加工完成后的默认行为 |
| 当前使用形态ID | 每个零件种类一条，准备页默认带出 |

## 验收检查

- 加工台同时提供解锁与切换两个功能，切换不消耗资源、不耗时。
- 解锁需要维修费与配置要求的图样及材料全部满足；图样保留不消耗，材料与维修费一次性支付。
- P-001-F01 与 P-003-F01 解锁只消耗维修费与图样；P-001-F02 与 P-003-F02 还需消耗普通材料。
- 条件不足时卡片保留并显示还差什么，图样与任务记录不过期。
- “当前使用”与准备页临时切换的边界清晰：加工台管默认，准备页管本关。
- 关内不能改形态；准备页临时切换不改变加工台的当前使用。
- 未取得图样的形态显示来源提示，不误导玩家。
- 材料不是货币；维修费是唯一金币。

## 试玩校准

- 加工完成后新形态是否自动设为当前使用；当前按“是”配置，待试玩反馈调整。
- 材料的获得量与消耗量平衡，需按[加工配方与经济节奏](25-加工配方与经济节奏.md)和实际事件掉落测试。
