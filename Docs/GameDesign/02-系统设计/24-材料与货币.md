# 材料与货币 v0.1

> 2026-09-16。本页补完第三组“成长闭环”中的经济基础：材料体系、稀有度、来源与用途、怪谈形态材料分层，以及货币口径。加工台的具体界面与操作见[加工台与形态切换流程](22-加工台与形态切换流程.md)，完整消耗配方与经济节奏见[加工配方与经济节奏](25-加工配方与经济节奏.md)。本页只定义材料和钱是什么、从哪来、用来做什么。

## 这一页解决什么

玩家处理事件会得到维修费和材料。维修费是钱，材料是加工素材。以前文档里“材料”和“物资”混用，本页统一为：材料是顶层统称，物资条目是材料下的一件件具体物品。图样是加工条件，保留不消耗；维修费是唯一货币，不属于材料。

## 材料口径

| 词 | 定义 |
|---|---|
| 材料 | 顶层统称，指所有可消耗的加工素材。 |
| 物资条目 | 材料下的每一条具体物品，例如“铜芯线”。配方里配置的消耗对象。 |
| 图样 | 知识／条件，保留不消耗，不属于材料。 |
| 维修费 | 金币，唯一货币，不属于材料。 |

后续文档统一写“解锁形态消耗维修费＋图样（条件）＋材料（按配方消耗物资条目）”。不再把“物资”当作与“材料”并列或相反的概念。

## 首版六种材料

首版只设六种，分两层：四种普通材料来自白天和普通夜晚委托，两种异常材料来自怪谈。这个数量覆盖现有零件的电气、机械、光学、弹性四个主题，同时给怪谈加工一个夜间专属的成长出口。

| ID | 材料 | 稀有度 | 世界观定位 | 来源规则 |
|---|---|---|---|---|
| MT-001 | 铜芯线 | 普通 | 维修时拆下、仍可复用的导线与接点 | 由处理事件的成功结算按内容配置。 |
| MT-002 | 精密齿轮 | 普通 | 仍能正常咬合的传动件与结构件 | 由处理事件的成功结算按内容配置。 |
| MT-003 | 玻璃镜片 | 普通 | 完整可用的灯罩、镜片与透光件 | 由处理事件的成功结算按内容配置。 |
| MT-004 | 校准簧片 | 普通 | 可重新调校的弹性件与敲击件 | 由处理事件的成功结算按内容配置。 |
| MT-005 | 定势残晶 | 精良 | 六相定势盘把异常重新封回后凝结的稳定残留 | 由怪谈相关处理事件的成功结算按关配置。 |
| MT-006 | 异常纹样 | 稀有 | 从已封存异物上拓下的规则纹路 | 由指定怪谈相关处理事件的成功结算按内容配置。 |

定势残晶是所有怪谈共用的异常材料，不按怪谈单独做十五种。异常纹样按来源怪谈细分，见下一节。

## 异常纹样的类型化

异常纹样是一个材料类型，不是单个条目。它的完整标识带来源怪谈，例如“异常纹样·红舞鞋”“异常纹样·画皮”。

规则：

- 不同怪谈掉落的异常纹样互不相同，标识不同、不能互相替代。
- 不是每个怪谈都掉落异常纹样；只有指定怪谈产出。
- 哪些怪谈产出哪种纹样、每种纹样用于哪些怪谈形态，由各怪谈奖励和 M 类怪谈形态配方配置。
- 同一怪谈的纹样可以积累多份，按配方数量消耗。

这样来源怪谈既决定“图样来自哪一案”，也决定“稀有纹样来自哪一案”，材料本身不额外增加十五个独立系统。

## 稀有度只做三档

| 稀有度 | 含义 |
|---|---|
| 普通 | 白天普通委托和部分怪谈就能稳定获得，用于基础加工。 |
| 精良 | 怪谈维修通用产出，用于中阶怪谈形态。 |
| 稀有 | 少数关键怪谈产出，用于高阶怪谈形态的长期目标。 |

首版不引入“史诗”“传说”等更高档位。三档已能区分普通劳动、夜间维修和关键怪谈三类收益。

## 来源与产出规则

材料只由处理事件的结算结果发放，不另外开设采集、合成或经营小游戏。首版不能用维修费购买材料。

每个事件文档在“成功结果与奖励”中单独写明是否产出材料、产出哪一条材料、数量和发放位置；失败、撤退与未处理时是否不给材料，也由该事件结果明确。材料体系页不预先指定某类事件必定掉落某种材料，也不预设掉落数量。

材料的世界观来源必须能由该事件的对象、现场遗留物或异常处理结果解释。例如一项维修完成后留下可复用部件，或异常被稳定后留下定势残晶。事件内容和奖励共同确定来源，不把材料作为脱离内容的随机掉落。

## 材料用途：唯一出口是加工解锁形态

材料只服务加工台解锁形态这一个出口，不进入合成、强化、兑换等第二套消耗系统。

| 层级 | 形态 | 消耗 |
|---|---|---|
| 入门教学层 | P-001-F01、P-003-F01 | 维修费＋图样，不消耗普通材料 |
| 进阶教学层 | P-001-F02、P-003-F02 | 维修费＋图样＋普通材料 |
| 常规怪谈层 | 普通／进阶M类怪谈形态 | 维修费＋图样＋普通材料＋定势残晶 |
| 高阶怪谈层 | 高阶M类怪谈形态 | 维修费＋图样＋更多普通材料＋定势残晶；关键形态再加异常纹样 |

入门形态先把“加工＝花钱解锁”的流程教会玩家。F02 和 M 类让普通材料产生存在感；定势残晶和异常纹样保证夜间怪谈的收益无法用白天劳动替代。

## 形态材料分层规则

逐条配方与费用见[加工配方与经济节奏](25-加工配方与经济节奏.md)。本页只保留分层规则。

| 规则 | 说明 |
|---|---|
| 入门形态不耗普通材料 | P-001-F01 与 P-003-F01 只耗维修费与图样。 |
| 进阶形态耗普通材料 | P-001-F02 与 P-003-F02 消耗 MT-001～MT-004 中的两至三种。 |
| 普通M | 消耗普通材料约4份，加 MT-005 定势残晶1个。 |
| 进阶M | 消耗普通材料约5份，加 MT-005 定势残晶2个。 |
| 高阶M | 消耗普通材料6～8份，加 MT-005 定势残晶3～4个；关键形态再用对应 MT-006 异常纹样。 |
| 图样决定来源唯一性 | 来源怪谈给图样，材料承担消耗；不让每种怪谈都新造一种专属普通材料。 |
| 配方一次性消耗 | 每个形态只加工一次，材料与维修费一次性支付，图样保留。 |

## 货币体系

维修费是唯一货币，用于加工解锁和后续合作服务。图样不是货币，材料不是货币，避免玩家把所有资源都折算成钱后失去选择感。

| 项目 | 规则 |
|---|---|
| 维修费 | 唯一金币，加工解锁必耗；处理事件获得，失败或撤退不发报酬 |
| 图样 | 永久条件，保留不消耗；来源怪谈或任务给 |
| 材料 | 加工素材，一次性消耗；首版不可用维修费购买 |
| 合作服务 | 顾师傅等后续可提供“维修费＋材料换指定材料”的兑换，首版不实现 |

首版不新增第二种货币，不把材料当钱花，也不为加工单独造“加工币”。

## 配置字段

| 字段 | 用途 |
|---|---|
| 材料ID、名称、稀有度、图标 | 界面与加工台显示 |
| 事件结果中的材料ID与数量 | 记录该事件结算发放的材料 |
| 配方ID、形态ID | 关联消耗 |
| 消耗材料条目及数量、维修费、图样ID | 加工条件 |
| 是否可购买 | 首版统一为否 |

## 验收检查

- 材料是顶层统称，物资条目是具体物品，图样和维修费不属于材料。
- 首版只有六种材料：四种普通、一种精良、一种稀有。
- 稀有度只有普通、精良、稀有三档。
- 材料只从处理事件获得，首版不能用维修费购买。
- 材料唯一用途是加工台解锁形态。
- P-001-F01 与 P-003-F01 不耗普通材料；P-001-F02 与 P-003-F02 消耗普通材料；M 类怪谈形态按层级消耗更多普通材料和异常材料。
- 异常纹样按来源怪谈类型化，不同怪谈纹样不通用。
- 维修费是唯一货币，图样保留不消耗。

## 待试玩

- 六种材料是否足够覆盖前期加工，还是需要补充一种结构类普通材料。
- 定势残晶和异常纹样的掉落节奏是否让夜间收益真正区别于白天劳动。
- 三档稀有度在加工台界面上的辨识度。
- 各 M 类怪谈形态配方材料数量与普通事件掉落量的平衡。
