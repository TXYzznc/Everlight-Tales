# 城市地图与昼夜流程 v1.2

白天和夜晚共用槐江市地图，玩家点击地点进入有限背景、立绘和对话。地图包含普通维修、临时处置、居民生活、调查线索与怪谈五类事件，详细玩法、收益和实例见[事件类型](10-地图事件类型与触发.md)。

## 白天与夜晚

白天可开店、拜访、接单、修理、交付、核对物件与参加生活事件；夜晚也有普通维修和居民求助，并非每晚必须处理怪谈。两种时段都能提供怪谈线索及调查入口。采用下文的四时段时间格模型推进；普通事件在白天与夜晚交替时刷新，上午与下午之间、夜晚与深夜之间不重抽整批事件。

任务系统的事件页同步当前地图供给并提供地点定位，实际互动仍在地图发起。主支线和怪谈产生的关键事件不参与普通刷新，具体见[任务系统](11-任务系统.md)。

## 一个地图事件的流程

入口可发现 → 接取／调查 → 处理中 → 本次结果 → 后续／回访。普通维修可独立完成；只有明确的线索结果才引出怪谈。普通订单完成与新怪谈线索分别记账，不把进入下一段故事当成上一单失败。

怪谈在具备批次资格且本案触发调查达成后才建立实例；同批可多个并存，也可没有已触发怪谈。同批无固定先后，未处理线索有主动调查渠道；普通事件和日常生活在其间持续提供内容。

## 有序批次与实际出现

采用B1红鞋 → B2画皮／扫帚／裂口女 → B3猴爪／聂小倩／穿墙／风月／花子 → B4画壁／枕中梦境／道林画像／吹笛／影子 → B5如月站。上一批全部基础故事的夜间目标完成后，下一批才取得触发资格；回访和领奖不阻挡资格。逐案日夜入口见[批次表](../06-怪谈库/01-批次与触发.md)。

同批自由并非整批自动开放到地图，也不是忽略剩余基础怪谈直接进入后批。B4画壁可先完成救援，余下B4案件仍需完成才能取得B5资格；白天修复展与居民回访按剧情继续，和批次计数分开。

## 地点与故事状态

画室、裁缝铺、舞蹈教室、仓库、河岸街区、校舍和家园承载不同事件；地点普通状态与怪谈实例状态区分。如月车站仍从现实末站上的失联报告进入，异常站台不是永久正常城市站点。

已解决实例保留人物获救、设备恢复等结果。档案重玩独立于真实地图；十五案全部完成后可以在已有对象上延伸新再发事件，目前只登记概念，不撤销原来的成功结果。

## 时间推进补充（D-017／D-018，2026-09-09）

一天采用白天两段、夜晚两段。处理事件消耗游戏时间，准备与查看类操作不耗时。事件开始前显示预计耗时，完成或结束本次尝试后统一推进；不根据现实阅读或盘面操作速度扣时。具体容量及跨段结算按下文D-019试配，失败与撤退按D-021统一消耗事件时间。

怪谈永久等待，不因跨日或延迟处理过期。普通事件撤退按失败处理；怪谈撤退恢复维修前状态并等待再次维修。撤退与失败均消耗该事件配置的时间（D-021）。

## 时间格与跨段结算（D-019，2026-09-09）

四时段暂名上午、下午、夜晚、深夜，每段先试4格，一天16格。事件详情显示“预计耗时：N格”和“预计结束：某时段”。短调查等先试1格，普通维修等2格，较长怪谈维修环节3～4格，逐项配置且允许调整。耗时单位属于游戏时间。

剩余不足仍可开始，事件结束后统一结算超出部分。例如夜晚剩1格，完成3格维修后进入深夜且剩2格；结算恰好用完一段时进入下一段。深夜跨日同理，现场与连锁不被切断。只在事件结束后更新地图时段内容，未完成怪谈不消失。

玩家可主动等待到下一时段，不要求做完当前地图所有事件，不额外领取事件奖励。加工、配装、查看类操作继续免费。成功、失败、撤退按该事件配置时间统一结算；怪谈局面复原不返还时间（D-021）。

## 重复普通事件的实例结案（D-022）

非剧情、可无限次出现的普通事件失败或撤退后，本实例以轻量失败反馈收尾并结束；结果保留，同类内容仍能在以后生成新实例。失败不阻断该类事件供给。剧情普通事件有失败分支就进入该分支，没有则提供重试（D-023）；不与怪谈的永久等待／撤退恢复混用。

## 怪谈失败后入口（D-024）

怪谈判定失败与主动撤退均恢复本次维修起点并回到待维修，保留调查和已获得信息。失败有对应反馈，完整事件耗时照常结算；不提前记故事完成、不发通关奖励，不取消以后处理机会。程序中断不走此流程，继续原尝试。

## 开放窗口与当前供给（D-068～D-070）

每个事件配置上午、下午、夜晚、深夜中的一个或多个可开始时段。关键事件错过窗口后保留，下次窗口再次开放；已经开始的事件完整跨段结算。沈遥感谢为上午来店、0格，未领取持续等待；加工、配装、档案查看四时段均免费可用。

进入白天与夜晚各生成4个普通事件，候选不足按实际数量。关键事件另计，普通事件完成不立即补刷；上午转下午、夜晚转深夜只更新开放状态。资料台免费显示当前有资格核实的地点和报告，传送到地图现场处理才消耗调查时间；核实后才创建怪谈。详情见[完整供给配置](15-地图供给与事件开放.md)。
