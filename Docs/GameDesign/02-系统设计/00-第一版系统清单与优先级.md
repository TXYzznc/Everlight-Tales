# 第一版系统清单与优先级

> 2026-09-14。详细设计先做第一版正式内容必须成立的系统，其余十四案回到概要级，作为堆量内容后置。本页是顺序决定，不改动任何已确认玩法。

## 为什么先做系统

新增一案怪谈，等于一份故事、一组规则、一套关卡配置，但它复用的仍是同一套系统。系统没收敛时，每填一案都要跟着改一次；系统定了，填内容才是加法。红舞鞋第一关已经验证过这个做法：它之所以能写完整，是因为把它当成了系统样张，而不是先堆故事。

## 深化顺序

按依赖分成四组，前一组定稿再动后一组。

第一组，一局闭环：准备与配装、盘面与每拍奖励、单关结算与时间推进。目标是让一个普通事件从接取到结束完整跑通，不依赖任何怪谈。

第二组，一天闭环：地图与地点解锁、四时段与刷新、任务系统三页、存档。目标是让玩家的一天能被完整描述、保存，并在打断后恢复。

第三组，成长闭环：加工与零件成长、经济口径、家园。把夜里的收获变成白天的能力和看得见的积累。

第四组，表现与教学：新手教学、界面信息层级、音画与文本清单。前三组确定后再做，避免照着会被改的流程画界面。

## 十四案的处理方式

- 保留：完整故事、来源依据、批次与触发、专属挑战条目、奖励方向。
- 不写：逐关逐轮的拍数与目标分、逐拍演算、对象坐标、初盘随机范围。
- 红舞鞋第一关作为系统样张保留完整配置，用来校准系统；其余案件在系统定稿后按批次套用同一结构。
