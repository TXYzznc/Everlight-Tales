# 城市地图与地点解锁流程 v1.0

> 本页定义一天闭环中的地图界面分区、地点状态与解锁、地点详情、事件标记、地图等待和结算后去向。事件供给、开放时段与刷新口径见[地图供给与事件开放](15-地图供给与事件开放.md)，长期记录见[任务系统](11-任务系统.md)。节点密度与视觉层级在试玩中校准。

## 这一页解决什么

地图回答“现在去哪儿”，任务系统回答“为什么去”。地点是承载事件的城市节点：解锁表示玩家已经知道并能前往，进入后能做什么由该地点当前的事件与开放时段决定。两个问题分开后，地点解锁可以随剧情一次性推进，已有的解锁状态长期保留。

## 地图界面分区

竖屏布局，五个区域常驻。

| 区域 | 内容 |
|---|---|
| 顶部 | 当前时段名、剩余时间格、昼夜状态；等待时显示将进入的下一时段 |
| 地图主区 | 槐江市节点地图，当前跟踪目标带强调边框，家园节点常驻 |
| 左上入口 | 任务系统，带未读角标；打开与关闭不消耗时间 |
| 右上入口 | 长明修理铺快捷返回；任何时段可用 |
| 底部 | 当前跟踪卡片与“等待到下一时段”按钮；没有跟踪目标时显示建议去向 |

地图主区默认居中于当前跟踪目标；没有跟踪目标时居中于修理铺。查看地图、平移、打开地点详情都不消耗事件时间。具体排布按真实操作测试调整。

## 地图视图与操作

- 单指拖动平移。
- 首版使用固定视角，不实现双指缩放。
- 点击节点进入地点详情；点击节点上的事件图标直接进入该事件详情。
- 拖动只改变视图，事件状态与刷新节奏由地图供给规则决定。

## 地点的四种状态

| 状态 | 地图表现 | 点击后 |
|---|---|---|
| 有可处理事项 | 实色节点＋事件类型图标＋数量角标 | 进入地点详情，事件可开始 |
| 已解锁暂无事项 | 实色弱化，无图标 | 进入地点页并显示当前没有可处理事项、已知的下次开放时段 |
| 已知未开放 | 虚线轮廓＋问号 | 显示地点名、已知描述与未开放说明，不显示具体事件内容 |
| 未发现 | 不出现 | 无法点击 |

“已解锁暂无事项”表示玩家现在就能走过去、恰好没有内容；“已知未开放”表示剧情已经提到、条件尚未满足。两者用不同表现区分，方便玩家判断要不要专程跑一趟。

## 解锁来源

每个地点配置一组解锁条件，任一满足即永久解锁。

| 来源 | 说明 | 例子 |
|---|---|---|
| 开局解锁 | 开局即为可用节点 | 长明修理铺 |
| 剧情解锁 | 主线或人物对话正式提到并带玩家前往 | 红舞鞋调查开放舞蹈教室 |
| 调查解锁 | 资料台索引列出该地点，现场核实后写入 | 画皮调查开放裁缝铺 |
| 阶段解锁 | 随玩家阶段的普通事件投放一并出现 | 社区活动中心 |
| 事件解锁 | 处理某个事件后附带认识该地点的常客 | 夜班送还后熟识街区小店 |

解锁是一次性状态，点亮后长期保留。人物暂时不在场只影响具体事件，不改地点状态。

## 首次解锁的表现

节点从线稿点亮为实色，名称浮现，短动画结束后停留在地图上，不用弹窗要求玩家确认。同一批解锁两个以上节点时依次点亮。首次解锁同时把该地点的可用事件写入任务系统的事件页，不额外发一条“去某地看看”的任务。

## 地点详情页

进入地点后显示地点名与一句话描述、当前时段与剩余格数、有限背景与在场人物的立绘或头像、以及该地点当前的事件列表。

每个事件卡显示：

- 名称与类型：维修、处置、生活、调查或怪谈。
- 一句话说明玩家要去做什么。
- 开放时段。
- 预计耗时与预计结束时段。
- 状态：可处理、未到开放时段、前置未满足或已接取进行中。
- 奖励方向。
- 操作按钮：交谈、调查、开始准备或查看。

同一地点的多个事件由玩家选择，不自动强制主线优先。不可用事件保留在列表中并写明已知原因，不用隐藏来简化界面。场景由有限背景、可点击热点与对话表现，不为每个地点制作独立大场景。

## 事件标记

地图主界面用图标、数量角标与跟踪强调表达，完整目标文字留给事件页与地点事件列表。图标按事件类型区分；主线、支线、怪谈等关键事件使用带边框图标，与普通事件区分。普通事件标记“本昼／本夜有效”，关键事件显示其长期来源。

## 地图上的等待

底部“等待到下一时段”按钮把时间推进到下一时段，不处理任何事件，不发放奖励，不额外生成内容。

- 确认前显示将进入哪个时段，以及哪些未处理的普通实例会随昼夜交替退出；不列出未发生的失败。
- 已接取任务、已触发怪谈、关键调查与等待中的回访不因等待消失。
- 等待只推进时间，不重抽当前批次的普通实例，也不重复结算已完成事件。
- 等待期间的免费功能（加工、配装、资料查看、档案馆）照常可用。

## 结算后的去向（D-080已确认）

一关结算后主按钮回到城市地图，不高亮、不自动跟踪，玩家自行选择下一步。

| 舞蹈教室 | S1 | 剧情解锁 | 红舞鞋调查与维修入口 |
| 街区小店 | S1 | 剧情解锁 | 卷帘门、夜班送还与成长任务 |

| 裁缝铺 | S2 | 调查解锁 | 画皮线索与生活内容 |
| 补习班街口 | S2 | 调查解锁 | 裂口女线索 |
| 仓库 | S2～S3 | 剧情解锁 | 隔板、猴爪联络与穿墙术调查 |

## 配置字段

| 字段 | 用途 |
|---|---|
| 地点ID、名称、一句话描述 | 地图与地点页显示 |
| 地图坐标、两档缩放下的标签层级 | 节点布局与可读性 |
| 解锁条件列表与来源类型 | 判定何时点亮 |
| 已知未开放时的描述文案 | 虚线节点与未开放说明 |
| 背景资源、在场人物槽位 | 地点页表现 |
| 承载事件引用 | 地点页事件列表 |
| 家园快捷入口标记 | 修理铺的常驻入口 |
| 节点图标与事件类型图标 | 地图标记 |
| 首次解锁表现与文案 | 点亮动画 |
| 不可用原因文案 | 前置未满足与未到时段 |

## 验收检查

- 未发现地点不出现在地图上；已知未开放节点只显示已知描述。
- 已解锁地点长期保留；人物离开只影响具体事件。
- 查看、缩放、平移、打开详情与等待前的确认都不消耗时间。
- 地图主界面显示图标与角标，完整目标文字在事件页与地点列表查看。
- 同一地点的多个事件由玩家选择进入。
- 等待只推进时间，关键事件与已接取任务继续保留。

## 试玩校准

- 事件图标与数量角标在移动端的可读性。
- 首次解锁动画的时长是否打断连续剧情节拍。
- 地图节点数量增长后，是否需要把同一街区的节点折叠成一个入口。
