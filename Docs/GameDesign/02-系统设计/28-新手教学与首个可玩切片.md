# 新手教学与首个可玩切片 v1.0

> 2026-09。S0 三段教学方向已确认（撞锤→棘轮→线圈＋隔板）；本页补完具体教学流程、每段盘面样张与首个可玩切片。教学是"表现与教学"组的落地，不新增玩法数值。

## 教学要教会什么

玩家离开 S0 时，应能独立完成一次"看盘面 → 旋转定势 → 拍击 → 读连锁 → 用能量维修／拆障"。观察目标是"约 30 秒理解操作、首拍即可读"；这是待试玩验证的观察目标，不是已达成结论。

一次操作链被拆成三步教：

1. 旋转与拍击：左旋／右旋按钮转内盘，把目标边对准定势座，压下冲击柄拍击。
2. 下落与连锁：零件沿当前定势方向下滑、碰撞、接续触发。
3. 能量与目标：连锁产出公共维修能量，用于维修对象或拆障打通通路。

## 三段教学流程

| 段 | 教会什么 | 使用零件与设施 | 通过条件 |
|---|---|---|---|
| 第一段 旋转与碰撞 | 选方向、拍击、看碰撞 | P-001 惯性撞锤 + O-001 固定墙体 | 完成一次移动碰撞（撞锤推动标记或撞到墙） |
| 第二段 能量与维修 | 连锁怎样产出维修能量 | 加 P-002 计量棘轮 + 一个待维修对象 | 棘轮产出公共维修能量并完成一次有效维修（进度 +1、得 20 分） |
| 第三段 爆破与拆障 | 用爆破打通通路 | 加 P-003 爆破线圈 + O-002 脆裂隔板 | 线圈爆破隔板，通路目标标记到位 |

三段可连在同一个工作台场景内，不新增多张背景。每段通过即永久解锁对应零件，按教学段逐件进入供给（D-014）。

### 盘面样张（教学用，坐标可随实现微调）

第一段：H 撞锤在 (0,0)，T 教学标记在 (1,0)，W 固定墙在 (2,0)，重力 D3。玩家旋转使 H 沿重力撞向 T；撞到墙或推动标记都算完成碰撞。

第二段：复用第一段布局，在 T 旁加入待维修对象 O 与棘轮 R。玩家把连锁接到 R，使 R 触发并产出公共维修能量，再让一次有效维修落在 O 上（进度 +1）。

第三段：复用布局，加入脆裂隔板 B 挡在通路前。玩家用线圈 C 对 B 产生爆破，拆除隔板后让目标标记通过校正格。

具体坐标、对象标签、判定阈值与提示文案由关卡配置填写；本页只固定"教什么、按什么顺序、用什么零件"，不把样张坐标当成平衡数值。

## 教学的时间、失败与跳过

- 教学发生在 S0 开局（玩家回城接管店铺、师父离开前留下的工作台引导），不消耗时间格，不进入四时段结算，不配置地图事件。
- 每段是一个小盘面，通过条件宽松；未通过可原地重试，不记失败、不扣资源、不产生失败收尾。
- 教学不配置四选一、Buff 与机械臂惩罚；机械臂的搬动在 S1 红鞋首案由现场教学引入。
- 三段教学之间只按顺序解锁，不设额外前置；已通过段不可回退，教学进度计入世界存档。

## 首个可玩切片

首个可玩切片是"可先实现并运行的第一个垂直切片"，用于在堆量前验证一局闭环，由三部分构成：

| 切片构成 | 验证什么 | 配置状态 |
|---|---|---|
| 三段工作台教学 | 操作可读性、连锁手感、"30 秒理解操作" | 本页流程，盘面待实现 |
| 红舞鞋第一关 | 完整怪谈闭环：准备 → 盘面 → 结算 → 时间 → 地图 | 完整配置已确认（D-051） |
| 卡住的卷帘门 | 可重复普通供给与经济：昼夜刷新、2 格、40 维修费 | 完整配置已确认（D-066） |

选择理由：教学验证操作，红舞鞋验证"怪谈"这条最长闭环，卷帘门验证"可重复普通事件"这条最短闭环。三者跑通后，其余十四案与更多普通事件只是按同一结构堆量。

## 教学与后续投放的衔接

- S0 教学解锁 P-001、P-002、P-003。
- S1 红鞋首案现场引入 P-004 换向齿轮，准备阶段由周衡借出 P-014 铆合钳。
- 红鞋成功后的回店教学永久解锁 P-014，并触发 T-G01 贯通撞锤成长任务。
- 后续零件按[玩家解锁与内容投放](../03-玩家体验/03-玩家解锁与内容投放.md)逐件投放，教学不再为每件新零件重复三段式流程。

## 验收检查

- 玩家离开 S0 能独立完成一次旋转、拍击并读懂连锁结果。
- 三段各自通过即解锁对应零件，并进入后续供给。
- 教学 0 格、可重试、不记失败、不扣资源。
- 首个可玩切片的三部分都能跑通一局闭环，且不互相依赖怪谈奖励。
