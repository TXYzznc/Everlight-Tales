# 计分与零件能量

> v0.1 设计初稿。D-039～D-044为已确认原则；以下具体数值与结算细则为本轮细化初值，尚未经过试玩。每件的完整参数以独立条目为准。

## 玩家看到什么

每个零件显示当前能量／容量，选中后显示触发条件、消耗、得分算法和额外能力。飞轮另显示蓄量，容器另显示储量；这些是对象状态。分数显示在本轮目标区，场景维修能量单独显示在需要消耗它的设备旁。

分数用于本轮基础通过条件；零件能量支付自身效果；维修能量是场景中修复节点的资源。电池只转移零件能量，棘轮、吞料炉和水轮的维修能量产出按各自条目执行。

## 一次触发的结算

1. 执行到该事件时，检查实例存在和触发类型。一次成立的触发立即发放触发分，与能量和效果成功无关。
2. 检查本件自身效果：零件能量足够且条件满足时，支付自身能量并执行，记录实际自身效果分。该分支失败不阻止维修分支。
3. 检查本件已配置的维修效果：目标合法且公共维修能量足够时，只扣公共维修能量并执行，记录实际维修效果分。零件自身能量不影响该分支。
4. 各分支产生的后续事件按队列继续处理。下一次触发重新检查实时资源；同一连锁中补能后可重新执行自身效果。

同次触发先执行自身效果、再检查维修效果，因此本次自身效果明确产出的公共维修能量可以用于本次维修。两分支独立支付，不因另一分支失败而回滚；自身分支使维修目标失效时，按维修执行时的实际目标检查。

触发分＋实际自身效果分＋实际维修效果分构成本次总分。一个零件只产生一次基础触发分，不因具有两个效果分支重复发基础分。未配置维修效果的零件不会自动获得维修能力。

能量不足不会取消触发分，也不会积存等待自动补发的效果。补能本身不是受击，后续仍需新的触发。对象不存在、信号类型不兼容、静止相邻不构成触发。

信号按根ID分别记录触发计分与效果执行：同一根在同一接收件只记一次触发分；缺能时效果未执行，后续再次收到该根可检查效果，但不重发触发分。新的根信号独立计分。

## 能力受阻怎样得分

所有零件都配置触发分，不以能量足够或能力成功为前提。撞锤被触发3次、成功推动2次，若每次触发4分、每次推动1格8分，则共28分。三次都无自身能量，仍得12触发分。

效果分仅按实际完成的效果计算。电池缺少可补目标时仍有触发分，没有补能效果分；维修工具公共储备不足时仍有触发分，没有维修效果分。

## 维修效果分的配置归属

维修效果分由待维修对象配置，第一版所有对象统一为20分。成功执行一次有效维修时，读取该对象的分值并计分；执行维修的零件不配置或覆盖此分值。维修未成功不产生维修效果分。

维修按对象先行设计：对象须声明适配零件、维修进度要求（第一版1～5点）、单次公共能量费用和修复完成后的状态。进度初始0，每次有效维修固定增加1点并立即取得对象配置的20分；达到要求后进入完成状态，再次维修该完成对象不扣公共能量、不增加进度或维修分。开关切换是独立动作，不产生额外切换分。零件改装不影响维修效果；异化零件失去维修效果。准备界面根据本关对象显示需要的适配零件、当前是否携带和是否可借用。


待维修对象的维修配置包含“维修效果分”字段，当前统一填写20。触发分和自身效果分仍由零件条目定义。

## 得分归属与连锁

本拍得分等于各次实际得分相加，连锁长度不附加统一倍率。同一次作用中，一个目标只按该作用的对象去重口径计一次；不同独立爆炸命中同一对象，可以各自得分。移动只记录该能力直接推进的格数，下游零件接力推动归下游自身计分。

爆破线圈起爆后移除，但已经发出的冲击保留来源及本次作用编号，命中分回记该次爆破。尚未执行的起爆取消；已结算的触发分保留，未产生的爆破效果不计分。音叉的端点到达分在信号实际抵达后回记原根声音，桥的转发分属于桥；两者是不同零件的真实效果。

计分随事件结算更新。整条连锁与本拍附加效果结算完毕后，检查失败及目标状态；只有本轮拍击次数耗尽时才判定通过，提前达标继续本轮。分数跨轮继承、跨关清零。

## 容量、蓄量及物品状态

能量补充不得超过当前容量，超出部分留在供能源。胃袋的内部槽位与缓冲囊的负荷容量不被充电增加。飞轮每次受击支付1点能量、增加1蓄量，满3释放；补能不直接增加蓄量。吞料炉使用可补充的零件能量。

缓冲囊被动接收消耗0点，受容量限制；主动排放消耗1点并按真正处置量得分。胃袋收纳和释放各消耗1点。无能量时容器仍保留内容，可以补能后继续处理。

切换模式、查看状态与机械臂搬动不会自动发零件得分。场景另行声明搬动或到达触发时，执行其已登记规则。

## 复制与收纳

铸模复制类型、方向和当前能量（受副本基础容量上限限制），产生新的实例ID和“复制体”标记；该复制体不能再作铸模源。副本刻度、蓄量、本拍触发计数和信号处理记录从0开始，胃袋及缓冲囊副本内容为空；源的内容物与负荷保持原处。

副本不复制实例改装、实例Buff或异化；作用于本关全部某类零件的Buff根据新实例类型正常生效。副本不复制已兑现分数、永久奖励、身份或证据。初始能量继承来源当前量，不因复制补满。

胃袋保存原实例ID、当前能量、方向、蓄量、计数、允许收纳的Buff与异化、信号处理记录；收纳时取消该实例尚未执行的盘面事件，释放后只响应新事件。全局时点与持续时间正常推进，收纳不冻结Buff期限。带任务标记、另一胃袋或故事专属怪谈形态者按原条目不可收纳。缓冲囊被收纳时保留内部负荷与来源，不触发退回；真正移除时才执行负荷退回。

## 公共维修能量

公共维修能量属于当前关的共享储备，关初为0，跨拍和跨轮累计；通过明确产能效果或有记录的现场产出取得。不会因换轮、重试或进入场景自动补满。机制观察样例若从非零余额开始，须注明此前已经完成的产能过程。

当前生产方式：棘轮每次成功执行自身产能效果产生1点；吞料炉每次成功吞料产生2点；排水叶轮每实际排水1单位产生1点。这些产出属于各件自身效果，检查并消耗各自零件能量。能量不足仍有触发分，但不凭触发分自动生产资源。电池补充单件能量，不直接增加公共储备。

维修只消耗公共维修能量。基础铆合钳只配置维修分支，每次修复消耗公共能量2点，不使用自身能量槽。混合型零件可同时具有自身与维修分支，须分别写出条件、消耗、效果及效果分；当前不把维修分支批量赋给全部零件。
