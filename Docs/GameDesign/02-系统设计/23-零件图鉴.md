# 零件图鉴 v0.1

> 2026-09-16。本页补完“零件图鉴”模块：范围、入口、界面结构、条目状态、详情内容与加工台衔接。图鉴是只读参考工具，不承担解锁、切换或升级动作；加工与切换见[加工台与形态切换流程](22-加工台与形态切换流程.md)。数值与文案待试玩。

## 这一页解决什么

玩家在玩了一段时间后，需要一个地方回顾自己有什么零件、每个零件能做什么、还有哪些没拿到。图鉴回答这三个问题，同时提供收集进度感。它和加工台的区别是：加工台能改东西，图鉴只能看。

## 范围与入口

图鉴只收录 P（通用零件）和 M（怪谈形态），共 31 条。O（障碍设施）、A（棋盘异常）属于关卡设施，不进入图鉴；C（怪谈专属挑战）由任务系统怪谈页追踪。材料是消耗品，不进入图鉴。

入口在家园修理铺，一个图鉴按钮。打开后顶部两个标签页：“通用零件”和“怪谈形态”，各自按 ID 排序。31 条一屏滚动可看完，不需要搜索与筛选。

## 界面结构

| 区域 | 内容 |
|---|---|
| 顶部 | 两个标签页：通用零件、怪谈形态 |
| 中部 | 条目网格，每格显示编号、图标或剪影、名称或“？？？” |
| 顶部右 | 收集进度：已拥有 n／31 |

点击条目打开详情页。标签页切换、滚动和打开详情都不消耗地图时间。

## 条目状态

| 状态 | 判定 | 网格显示 | 详情页显示 |
|---|---|---|---|
| 已拥有 | 永久解锁完成；P 类完成教学或委托并进入携带池，M 类图样已取得且加工完成 | 完整图标、名称 | 完整信息，含数值、全部已解锁形态与背景文本 |
| 已知未拥有 | 来源已出现但永久解锁未完成；P 类对应教学或委托已出现，M 类图样已取得 | 剪影、名称 | 来源方向与解锁条件提示，不显示具体数值与形态参数 |
| 完全未知 | 来源尚未出现 | 剪影、“？？？” | 仅显示编号，不给名称或来源 |

“完全未知”的空槽位让玩家知道总共有 31 条、自己收集了多少，本身提供收集驱动。三个状态之间只有正向转换：完全未知 → 已知未拥有 → 已拥有，不倒退。

## 详情页内容

已拥有条目显示：

- 名称、图标与一句话作用。
- 得分与能量配置：触发分、效果分、初始能量与容量、单次消耗、补能方式。
- 全部已解锁形态及各自参数；未解锁形态在详情页按“已知未拥有”处理，只显示来源提示。
- 来源与解锁条件：哪个教学、委托或怪谈回访给的。
- 简短背景文本：这条零件在故事里的定位，一到两句。

已知未拥有条目显示：

- 名称与剪影。
- 来源方向，例如“红舞鞋 · 力从另一头出来”或“第二章穿墙案回访”。
- 不显示具体数值、能量配置和形态参数，避免未取得就提前看到全部设计。

## 与加工台的关系

- 加工台里列出的已拥有零件种类是图鉴 P 类已拥有条目的子集。
- 加工台零件卡提供“查看图鉴”入口，跳转到对应条目详情。
- 图鉴已拥有条目的详情页提供“去加工”按钮，跳回加工台对应零件。
- 两处共用同一套零件与形态配置表，不另建数据源。

## 配置字段

| 字段 | 用途 |
|---|---|
| 条目ID、类别、名称、图标 | 网格与详情显示 |
| 当前状态：完全未知／已知未拥有／已拥有 | 决定显示内容 |
| 来源提示文本 | 已知未拥有与已拥有的来源显示 |
| 完整参数引用 | 已拥有详情页，读取零件与形态配置表 |
| 背景文本 | 已拥有详情页的故事定位 |

图鉴不新增独立数据，条目状态由世界存档中的永久解锁记录推导，参数直接引用零件库、通用零件形态与怪谈形态条目。

## 验收检查

- 图鉴只收录 P 与 M，O／A／C 和材料不出现。
- 已拥有条目显示完整参数与全部已解锁形态。
- 已知未拥有条目只显示名称、剪影与来源方向，不显示具体数值。
- 完全未知条目显示编号和“？？？”，不透露名称与来源。
- 收集进度显示已拥有 n／31，与永久解锁记录一致。
- 图鉴与加工台能互相跳转，共用同一数据源。
- 打开图鉴、滚动和查看详情不消耗地图时间。

## 待试玩

- 31 条在一屏内的浏览密度与标签页切换便利性。
- 完全未知条目的空槽位是否真正产生收集动机，还是让玩家感到信息不足。
- 详情页参数过多时的可读性，是否需要折叠得分与能量区块。
