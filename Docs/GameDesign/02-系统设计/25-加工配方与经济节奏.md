# 加工配方与经济节奏 v0.1

> 2026-09-16。本页集中记录第一版加工经济基准和可加工形态的消耗配方。材料定义见[材料与货币](24-材料与货币.md)，加工台流程见[加工台与形态切换流程](22-加工台与形态切换流程.md)。数值为已确认的试配值，仍需实际试玩校准。

## 经济基准

普通收入按“时间格”统一换算：1格普通小事件成功给20维修费；2格普通维修成功给40维修费。剧情任务、成长任务和怪谈奖励可以在此基础上修正，但不另设第二套价格系统。

| 项目 | 基准 |
|---|---:|
| 1格普通小事件 | 20维修费 |
| 2格普通维修 | 40维修费 |
| 3格中阶维修 | 60维修费 |
| 剧情任务／成长任务 | 40～80维修费 |
| 怪谈单关成功 | 80～120维修费 |

一天有16格。玩家不会全部拿来做普通内容，所以日常实际收入按160～240维修费估算；一周游戏内时间的可支配收入按1200～1600维修费估算。这个规模足够玩家逐步解锁首批内容，又不会一次性买光所有成长目标。

## 加工消耗口径

- 维修费是唯一金币，每次解锁形态必定消耗。
- 图样是永久条件，保留不消耗；来源怪谈或任务给。
- 普通材料、定势残晶、异常纹样按配方一次性消耗。
- 切换已解锁形态不消耗维修费和材料。
- 首版不能用维修费购买材料。
- 每个形态只需加工一次；重复解锁不收费。

F类指通用零件形态。P-001-F01与P-003-F01是入门形态，不消耗普通材料；P-001-F02与P-003-F02开始消耗普通材料。M类指怪谈形态，统一消耗更多普通材料，并根据阶段加入定势残晶，关键形态再加入对应异常纹样。

### 数量规则

- 普通M：普通材料约4份，定势残晶1个。
- 进阶M：普通材料约5份，定势残晶2个。
- 高阶M：普通材料6～8份，定势残晶3～4个。
- 异常纹样只用于5个代表性形态：红舞鞋、画皮、风月宝鉴、道林格雷的画像、如月车站。
- 高阶M的普通材料数量明显高于普通M，形成两到三天的长期目标。

## 支出定位

| 层级 | 单件维修费 | 体验目标 |
|---|---:|---|
| F类入门 | 80～140 | 玩家最早理解“形态改变工作方式” |
| F类进阶 | 120～180 | 早期开始消耗少量普通材料 |
| 普通M | 240～280 | 一到两天内可获得 |
| 进阶M | 300～320 | 一到两天的稳定目标 |
| 高阶M | 340～480 | 后期长期目标 |

首版不追求玩家很快买齐全部形态；应让玩家先买第一个，再逐步遇到下一个有分量的选择。

## 事件配置边界

本页只定义收入基准和形态消耗，不单独配置任何具体事件的奖励。每项维修费、普通材料、定势残晶与异常纹样的实际产出，必须在对应事件的完整设计中与故事内容、触发条件、地点、开放时段、前置条件、耗时、交互或盘面、成功失败结果一起配置。

## 试玩观察

- 160～240维修费／天的实际节奏是否让玩家感到有事可做但不臃肿。
- 普通M配方是否在完成后不久即可解锁，而不是长期卡钱。
- 高阶M的普通材料数量是否造成重复刷同一种事件。
- 异常纹样来源与5个代表形态是否足够清晰。
- 每个配方是否真正对应玩家会想使用的形态，而不是单纯作为收费门槛。
