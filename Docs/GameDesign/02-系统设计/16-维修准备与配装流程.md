# 维修准备与配装流程 v0.2

> 2026-09-15。本页补完“准备与配装”模块：从现场开始维修到进入第一轮的完整流程、准备页分区、关卡预览与初盘生成。携带 6 种（D-063）、6 枚初盘与关键件占名额（D-064）、关键件固定工作位置与其余随机落位（D-065）、机械臂初始 2 次已在此前确认；预览只显示固定内容、携带的选择与替换操作、每次重新配装按 D-077 落实；初盘固定与随机混合生成按 D-080 修订。数值与配置待试玩。

## 这一页解决什么

玩家在地图现场选择一处可维修的事件后，先经过准备，再进入盘面。准备阶段回答三个问题：

1. 这次要修什么，现场需要哪些作用？
2. 我携带哪 6 种零件，各用哪个形态？
3. 这次的固定条件是什么，值不值得现在开始？

准备、预览、切换形态、取消和查看资料都不消耗地图时间（D-021）。开始维修后按该事件配置结算耗时，成功、失败、撤退同价。

## 完整流程

| 步骤 | 玩家动作 | 系统结果 | 耗时 |
|---|---|---|---|
| 1 | 在地图现场选择开始维修 | 打开准备页；载入本关模板与已固定的实例内容 | 0 |
| 2 | 阅读关卡信息 | 显示耗时、轮数、每轮拍数、累计目标分、特殊效果与特殊目标、待处理对象与建议适配零件 | 0 |
| 3 | 点“查看关卡预览” | 弹出预览层，用 RawImage 渲染该轮真实关卡画面；可切换轮次、可返回 | 0 |
| 4 | 在左栏选择携带种类，在右栏确认携带 | 右栏最多 6 种；只显示本关固定内容的预览不随携带选择变化 | 0 |
| 5 | 点确认 | 冻结携带集合、形态与初盘，进入第一轮 | 0；开始后按事件配置结算 |
| 6 | 返回地图 | 放弃本次准备；不扣时间、不记失败、不改变已固定的实例内容 | 0 |

每次进入准备页都重新配装，只自动选入本关关键件，其余槽位留给玩家选择；同一事件在同一时段内反复进出也不带入上一次的选择。

## 准备页的三个区

### 关卡信息区

显示本次事件的全部已知条件，避免玩家靠记忆做决定：

- 事件名称、地点、委托人或来源。
- 一句话目标。
- 预计耗时与预计结束时段。
- 本关轮数、每轮拍数与累计目标分。
- 每轮的特殊效果与特殊目标摘要，可展开逐轮查看。
- 需要处理的对象，以及建议的适配零件与作用。
- 现场可借用的种类与形态。
- 本次可能异化的零件提示。

### 携带选择区

分左右两栏，玩家始终能同时看到“我有什么”和“我带什么”。

左栏“全部可用零件”列出本关可选择的全部种类，来源为已永久拥有的种类加上现场可借用的种类，按种类去重：

- 种类名、图标与一句话作用。
- 该种类本次锁定的形态；存在多个已解锁形态时可在卡上切换。
- 本关适配标记，例如“用于维修封存匣铆合端”。
- 本次可能发生异化的种类，在卡片右上角显示“异化”标签。
- 已被选入右栏的种类显示勾选与选中序号。

右栏“本次携带”给出 6 个槽位，每槽显示种类、锁定形态与作用，并有移除按钮。底部显示“已选 4／6”与未满足的关键件提示。

加入与替换的操作按数量分两种状态：

| 右栏状态 | 点击种类卡 | 拖动种类卡 |
|---|---|---|
| 未满 6 种 | 按序号补入第一个空槽位 | 拖到空槽位放入该槽；拖到已占用槽位替换该槽 |
| 已满 6 种 | 不生效，并提示需要替换 | 拖到某个槽位替换该槽种类 |

点击只负责补空位，不改变已有槽位的种类。拖动到已占用槽位即为替换，两种状态下都可用；移除通过槽位上的移除按钮完成。确认前可以任意调整，调整不消耗时间。

携带判定沿用既有口径：可用种类数 N 不足 6 时全部携带，超过时选满 6 种；同种不同形态不占额外名额；携带池决定本关随机补给能抽到哪些种类，不决定盘面实体数量。

### 预览区

“查看关卡预览”按钮打开预览层。预览层包含：

- 轮次标签，逐轮切换，默认停在第一轮；带特殊目标的轮次在标签上标点。
- 中部 RawImage，渲染当前轮的真实关卡画面。
- 底部当前轮的拍数、累计目标分、特殊效果与特殊目标文字。
- 返回按钮，关闭预览层回到准备页，携带选择保持不变。

不看预览也能直接确认，预览不是强制步骤。

## 关卡预览

预览面板用 RawImage 显示 RenderTexture，由实际关卡的预制体与渲染管线渲染，不带交互。预览是只读展示：不产生游戏状态、不消耗时间、不触发事件、不推进随机数、不改变携带选择。

预览只显示本关固定不变的内容，也就是这一盘无论携带什么都会存在的东西；随机生成的部分不进入预览：

| 预览项 | 第一轮 | 后续轮 |
|---|---|---|
| 盘面形状、边界与合法格 | 显示 | 显示 |
| 固定地形、轨道、出口与危险格 | 显示 | 显示该轮配置后的状态 |
| 障碍、设施与现场装置 | 显示 | 显示 |
| 需维护的对象与任务标记 | 显示初始状态 | 显示该轮新增或启用的对象 |
| 固定配置的零件与工作位置 | 显示 | 显示 |
| 轮数、每轮拍数、累计目标分 | 显示 | 显示 |
| 本轮特殊效果与特殊目标文字 | 显示 | 显示 |
| 随机生成的非关键件及其落位 | 不显示 | 不显示 |
| 未取得的线索、隐藏规则与隐藏阶段 | 不显示 | 不显示 |
| 连锁结束后的实际局面 | 不展示 | 不展示 |

预览因此与携带选择无关：改携带不会改变预览画面，预览也不会泄露这一盘会抽到哪些随机件。

## 初盘生成

初盘由关卡配置定义固定与随机的混合方式（D-080）：每种元素（地形、障碍、设施、零件、维修对象、挑战等）由关卡设计时单独指定固定或随机，没有按类型统一划分。

固定元素每次进入维修时不变，包括关卡指定的规则、地形、轨道出口、障碍与设施、固定配置的零件与工作位置、需维护对象等；预览只显示这些固定内容。

随机元素每次进入维修时重新生成，包括关卡标记为随机的地形、挑战、零件、维修对象位置等；预览不显示随机部分，玩家无法从预览得知随机内容在局内的样子。

随机部分的生成顺序：

1. 放置任务对象、设施与关键件到配置的工作位置（如有关键件则固定放置）。
2. 在剩余名额内从携带池等权有放回抽取种类。
3. 落点从当前合法空实体格等概率抽取，落位后移出空格集合。
4. 允许重复种类、允许挡路。

确认入场后，本次生成的初盘作为该次尝试的存档内容保存，按轮存档恢复同一次维修。取消准备不改变实例，也不保留临时查看结果；下次进入时随机部分重新生成。

## 借用、形态与异化

借用：

- 关卡声明本次可借用的种类与形态，借用计入 6 种上限。
- 缺少关键类型时，准备页给出提示与一键加入。
- 已满 6 种时按替换流程处理，不产生第 7 种。
- 借用只对本关生效；借用件进入本关携带池并可被随机补给抽到，不进入永久收藏。

形态：

- 打开准备页时，每个种类默认带出加工台设定的“当前使用”形态（D-079）。
- 已解锁形态在准备页可为本关临时切换，不耗时、不收费；切换只影响本关，不改变加工台的当前使用。
- 进入维修时固定本关形态，关内不能改选形态。
- 关键件使用玩家锁定的形态，不暗中改回基础形态；其他形态是否仍满足本关目标由关卡配置决定。
- 未解锁形态不出现在可选项中。

异化：

- 本次可能发生异化的种类按关卡配置标记，卡片右上角显示“异化”。
- 标签只说明存在变化可能，不提前给出具体结果。
- 异化零件失去维修效果；其余变化与触发时点按关卡与条目执行。

## 入场状态与取消

进入第一轮时：分数 0、公共维修能量 0、机械臂按本关配置（首批普通维修与既有关卡为 2 次）、无 Buff、盘面为本关初盘。携带池与锁定形态随之固定，关内四选一补给只从携带池抽取。

取消准备：返回地图、不扣时间、不记失败、不影响该实例已固定的模板与抽取状态，也不保留本次的携带选择。已经确认入场并开始维修后，不再回到准备页；失败或撤退后按关规则重新配装并重试。

## 配置字段

关卡需要能在配置中表达以下内容：

| 字段 | 用途 |
|---|---|
| 轮数、每轮拍数、每轮累计目标分 | 关卡信息区与预览底部 |
| 每轮特殊效果文本 | 影响玩法，不是目标 |
| 每轮特殊目标文本与判定 | 显示在目标分数下方 |
| 待处理对象、适配零件与建议 | 关卡信息区与适配标记 |
| 现场可借用种类与形态 | 左栏可选项与关键件提示 |
| 每种元素的固定或随机标记 | 决定预览内容与局内生成行为 |
| 关键件种类、形态要求、工作位置 | 初盘第一步与预览 |
| 随机元素的候选池、抽法与落位规则 | 局内生成，不进入预览 |
| 本次可异化种类 | 卡片标签与局内变化 |
| 预览各轮渲染内容 | 预览层的固定盘面与地形状态 |

## 验收检查

- 玩家能在准备页看到耗时、轮次、拍数、目标分与全部已知的轮内条件。
- 携带区同时显示全部可用种类与已选携带，并明确本关适配与借用来源。
- 未满 6 种时点击与拖动都能加入，满 6 种时点击不生效、拖动可以替换。
- 关键件缺失时能借用并计入 6 种上限，不产生第 7 种。
- 每次进入准备页都只自动选入关键件，不沿用上一次的携带记录。
- 预览用真实关卡画面渲染，按轮切换，返回后准备页状态不变。
- 预览只显示固定内容，随机非关键件与落位不出现在预览中。
- 预览不显示未取得的线索、隐藏规则与连锁后的实际局面。
- 确认入场后，本次尝试的初盘按轮存档保存；取消准备或未确认前反复进出准备页，随机元素每次重新生成。
- 确认后携带、形态与初盘冻结，关内不能改选形态或携带池。
- 取消准备不消耗时间、不记失败、不改变已固定内容。
- 固定初盘关卡不因本页规则被改成随机。
