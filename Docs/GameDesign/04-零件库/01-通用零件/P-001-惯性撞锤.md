## 得分与能量配置

| 字段 | 设计初值 |
|---|---|
| 初始能量／容量 | 2／2 |
| 单次消耗 | 1点 |
| 补能 | 接力电池可补至容量；同一连锁中补能后，后续触发重新检查 |
| 触发分 | 每次成立的触发得4分，不消耗能量；能量不足或效果受阻仍获得。 |
| 效果分 | 每实际推动1格得8效果分。 |

例：本件被触发3次，其中1次能量不足，仍累计12触发分；另将实际成功效果按本表算法加分。

触发分先独立结算，自身效果按零件能量检查，维修效果按公共维修能量检查；只有成功的效果取得对应效果分。特殊目标另行判定。详细结算口径见[计分与零件能量](../../02-系统设计/12-计分与零件能量.md)。

## 玩家面对的选择

用机械臂把它放到一串零件的起点；也可以保留惰性撞锤作为挡块。贴在一起不等于不断触发，必须发生新的有效撞击。

## 触发与效果

作为可移动实体占一格。被移动实体撞击时先获得触发分；自身能量足够则消耗1点，将来撞实体沿入射反方向尝试推移1格。无合法落点仍消耗此次能量，但不产生位移或效果分；只推动该对象，不推动整排。来自爆破等其他对象效果的触发仍获得触发分；没有实体撞击来向时不执行推移、不消耗自身能量。

本条完整参数登记于规则库的 [PR-001](../../02-系统设计/04-怪谈规则库.md#pr-001-惯性撞锤) 条目，调整判定同步其摘要。普通碰撞、信号、修复、校准不互相冒充。

## 状态、移动与持续

初始及容量 2 点零件能量；耗尽后保留惰性实体，仍能阻挡和被推动，可经充电恢复。

未单列的移动和同拍顺序按 [SR-002](../../02-系统设计/04-怪谈规则库.md#sr-002-碰撞触发与拍击结算)、[SR-004](../../02-系统设计/04-怪谈规则库.md#sr-004-占用层方向与任务接口)；跨拍／跨阶段按 [SR-005](../../02-系统设计/04-怪谈规则库.md#sr-005-持续状态与合法阶段转换)。

## 试配参数与最小验证

默认充能 2、推距 1。安排一次有效碰撞和一次被墙堵住的碰撞，分别检查位移及充能消耗；再让两件静止接触，确认没有新事件。

在半径3空盘中保留相关物件与目标，按描述施加一次碰撞或信号即可观察本项。正式关卡的合法路径与经济仍须单独验证。

## 一次具体操作

在直线通道中让撞锤撞向有空余退位格的爆破线圈 P-003。只有线圈因这次碰撞获得触发事件；它在执行时的位置爆破，邻件接收爆破效果后再分别被触发。撞锤不会因主动撞出这一击而自动执行推移。

## 改装形态的共用判定

> 以下两种形态的工作方式与当前机制配置已确认（D-060），待实际试玩；获取任务和价格已确认（D-061），见本文件末尾获取表。都保留基础撞锤4触发分、每实际推动1格8效果分，以及2/2自身能量、每次自身效果消耗1点。维修能力与基础形态一致，本件没有维修分支。

只有被实体撞击时才取得入射方向d，d表示来撞实体指向撞锤的移动方向。来自爆破等没有实体入射的触发仍获得触发分，但不执行这两种形态的推动，也不消耗自身能量。零件方向随内盘坐标，不增加形态之外的转向操作。

有合法实体入射且自身能量足够时，先支付1点，再执行该形态的推动；无可推动目标或落点受阻也消耗该点。推动固定设施或不接受普通推移的任务对象无效。只对被该形态选中的对象发起移动，不额外推动来撞实体，不隐式推进整排。

## 改装形态 P-001-F01：贯通撞锤

| 字段 | 设计初值 |
|---|---|
| 最早玩家阶段 | S1，红舞鞋完成后的形态教学候选 |
| 工作方式 | 把输入侧的撞击传给输出侧对象 |
| 作用对象 | 撞锤沿入射方向d的相邻格中的实体 |
| 输出 | 该对象沿d尝试移动1格；来撞实体留在碰撞停止格 |
| 能量与计分 | 2/2；每次自身效果消耗1；本件触发4分、实际推动每格8分 |
| 无对象或对象固定 | 不产生移动或效果分，已支付的自身能量不退还 |
| 获得与切换 | 获取任务及费用见本文件末尾配置；解锁后局外免费切换，入场固定 |

**例子：让后面的零件接着撞。**

A位于(-1,0)，贯通撞锤H位于(0,0)，棘轮B位于(1,0)，棘轮C位于(2,0)。A向D0撞H，只有H因这次碰撞触发；H再让B向D0移动。由于C占位，B留在(1,0)，C被撞并触发，B不会因为主动撞C而触发。H本次得4触发分、0位移效果分；若C有自身能量，C另得10触发分并产能1。

若(2,0)为空，B成功移入，H得4+8分；B仅被移动，没有因此自动取得触发分。若输出侧没有B，则本次不能把A直接传送到另一侧。

基础形态适合让来撞对象折返；贯通形态适合连接撞锤前后的两段布局。玩家需要在输出侧安排对象，形成“输入—传力—接力”的链条。

## 改装形态 P-001-F02：横推撞锤

| 字段 | 设计初值 |
|---|---|
| 最早玩家阶段 | S2，街区形态教学候选 |
| 工作方式 | 把一侧输入拆成两路向外推动 |
| 作用对象 | 撞锤相邻方向(d+1)和(d-1)的两个实体，方向编号按模6计算 |
| 输出 | 各自沿所在邻接方向尝试移动1格 |
| 能量与计分 | 2/2；两路合计支付1点自身能量；本件触发4分，每路实际推动每格8分 |
| 缺少一路 | 有对象的一路照常执行，不要求凑齐两路 |
| 获得与切换 | 获取任务及费用见本文件末尾配置；解锁后局外免费切换，入场固定 |

A从D0撞到(0,0)的横推撞锤。H选取D1位置(1,-1)的B，以及D5位置(0,1)的C：B向(2,-2)移动，C向(0,2)移动。两处都空时，H共得4+8+8=20分；能量只消耗1点。

若C被固定，B仍可移动，本件得4+8分。B或C向占用格尝试移动时，对该被撞对象产生碰撞触发；来撞方不自动触发。

**两路的结算顺序：**H处理自身效果时记录两路目标ID与所在格，按d+1、d-1依次把移动请求加入FIFO队列。执行某一路时，如果目标已经离开记录格或已不存在，该路取消，不临时选择替身。由某路产生的碰撞触发排到队尾，既有另一条移动请求先执行。每条移动请求按实际执行位置检查路径和目标。

这让一次输入有机会启动两侧的零件；它不自动替两个对象各发一次触发事件，连锁仍须由实际碰撞或其他效果接续。

## 两种撞锤形态与Buff、保存

- BF-003提高本件每实际推动一格的效果分，BF-016提高每条输出的移动上限；具体Buff上限按Buff库配置。两条输出也只按各自真实移动距离计分。
- 多格推动逐格前进，遇第一个阻挡停止并产生对应碰撞，撞锤不会自行推动阻挡后的整排。
- 形态ID与能量随本关保存；补给生成采用本关已固定形态。收纳、复制按共用规则处理，复制保留形态但不重复取得解锁。
- 图像可复用撞锤主体：贯通形态画贯穿轴，横推形态画两根侧向推杆，触发时高亮实际输出方向。
