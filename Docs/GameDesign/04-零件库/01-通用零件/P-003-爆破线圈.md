## 得分与能量配置

| 字段 | 设计初值 |
|---|---|
| 初始能量／容量 | 1／1 |
| 单次消耗 | 1点 |
| 补能 | 接力电池可补至容量；同一连锁中补能后，后续触发重新检查 |
| 触发分 | 每次成立的触发得6分，不消耗能量；能量不足或效果受阻仍获得。 |
| 效果分 | 每个实际接受本次爆破冲击的不同对象得6效果分。 |

例：本件被触发3次，其中1次能量不足，仍累计18触发分；另将实际成功效果按本表算法加分。

触发分先独立结算，自身效果按零件能量检查，维修效果按公共维修能量检查；只有成功的效果取得对应效果分。特殊目标另行判定。详细结算口径见[计分与零件能量](../../02-系统设计/12-计分与零件能量.md)。

## 玩家面对的选择

一拍炸开隔板和相邻能力件；在扫帚案选择劈分装配后，可把敌对供给源越炸越多，转而利用水动力。

## 触发与效果

可移动实体占一格。新受击且有充能时，先支付1点零件能量并标记已起爆，向执行时六个邻格各发送一次 1 强度的冲击，再移除自身。邻格目标按方向 D0～D5 入队；冲击造成受击及可破坏障碍的损伤，不直接推移。普通任务标记只接收其声明接受的标签。基础线圈不带劈分、照明或封存标签；C-009 装配可赋予劈分标签。

本条完整参数登记于规则库的 [PR-003](../../02-系统设计/04-怪谈规则库.md#pr-003-爆破线圈) 条目，调整判定同步其摘要。普通碰撞、信号、修复、校准不互相冒充。

## 状态、移动与持续

单次消耗型，起爆后本体移除；待执行事件若本体已被回收则取消，不从旧坐标爆炸。

未单列的移动和同拍顺序按 [SR-002](../../02-系统设计/04-怪谈规则库.md#sr-002-碰撞触发与拍击结算)、[SR-004](../../02-系统设计/04-怪谈规则库.md#sr-004-占用层方向与任务接口)；跨拍／跨阶段按 [SR-005](../../02-系统设计/04-怪谈规则库.md#sr-005-持续状态与合法阶段转换)。

## 试配参数与最小验证

半径 1、强度 1。检查只命中六邻格，同一目标每次爆炸一次；普通版本击中扫帚不应擅自执行劈分。

在半径3空盘中保留相关物件与目标，按描述施加一次碰撞或信号即可观察本项。正式关卡的合法路径与经济仍须单独验证。

## 一次具体操作

线圈邻接 O-002 脆裂隔板与另一枚线圈。第一炸让隔板由 2 耐久降为 1，第二炸移除隔板，后续定势下落使上游零件进入新缺口。

## 改装形态 P-003-F01：轴向线圈

> 工作方式与当前机制配置已确认（D-060），待实际试玩。最早S2已确认（D-061）；获取任务和费用已确认（D-061），见本文件末尾获取表。本件基础版没有维修分支，改装也不增加维修分支。

| 字段 | 设计初值 |
|---|---|
| 初始能量／容量 | 1／1 |
| 触发与支付 | 受碰撞或其他可触发效果时取得6触发分；自身能量足够则消耗1点并发出冲击 |
| 作用范围 | 当前位置沿D0、D3各一条最长2格射线 |
| 遮挡 | 每条射线命中第一个实体便停止；接受冲击则发送强度1冲击，拒收也会遮挡 |
| 效果分 | 每个实际接受本次冲击的不同对象6分 |
| 生命周期 | 支付后标记起爆、发送两路冲击，再移除本体；已发出的冲击仍按其来源结算 |
| 方向 | 随内盘坐标固定，不免费单独旋转零件 |

处理自身效果时根据实时位置扫描两路，按D0、D3记录命中目标并入队，冲击执行时目标已不存在则取消。能量不足时仍有触发分，不发射、不移除本体。基础能力没有穿透或沿射线经过多个实体的伤害。

线圈在(0,0)，(1,0)为空，(2,0)有棘轮；(-1,0)有可破坏隔板。线圈触发后，D0穿过空格命中棘轮，D3命中隔板即停：线圈自身得6触发分+12效果分；棘轮另按自身条件取得触发分及产能。相邻但不在这条轴线上的对象不被波及。

与基础六邻格爆破相比，轴向线圈适合沿通道接力，也能让某些邻接对象避开冲击。BF-004作用于实际命中对象的效果分。未来改变范围的Buff须声明对射线长度还是邻格范围生效。

## 改装形态 P-003-F02：定时线圈

> 工作方式与当前机制配置已确认（D-060），待实际试玩。最早S2已确认（D-061）；核心选择是在这一拍预埋下一拍的连锁起点，获取任务和费用已确认（D-061），见本文件末尾获取表。

| 字段 | 设计初值 |
|---|---|
| 初始能量／容量 | 1／1 |
| 未启动时受触发 | 先得6触发分；能量至少1时支付1点，进入“待爆”，记录到期拍为当前拍+1 |
| 启动时效果分 | 0；尚未发生爆破 |
| 待爆时再次受触发 | 每次仍得6触发分；保留既定到期拍，不重复支付、提前爆破或累积多次爆炸 |
| 到期效果 | 下一拍扣除拍击额度后、基础定势下落前，在本件实时位置向六邻格发送强度1冲击 |
| 爆破计分 | 每个实际接受冲击的不同对象6效果分；到期结算不再自动发一次触发分 |
| 爆破支付 | 使用启动时已支付的能量，不再次检查或消耗自身能量 |
| 移除 | 爆破发出后移除本体，后续能力队列仍结算 |
| 维修能力 | 与基础版一致，没有维修分支 |

### 一次跨拍准备

第1拍，A撞到定时线圈T：T得6触发分、能量1→0，亮起“下一拍爆破”标记，周围零件此时不接收爆破。

本拍结束后玩家选择补给，在下一拍准备时可用机械臂移动T，或把希望触发的零件布置在T周围。第2拍提交后，T先在移动后的格子爆破，再进行普通定势下落。

若爆破只命中两枚有能量的棘轮，T本次得12效果分；两枚棘轮各得10触发分并各产公共能量1。这段完整示例为第1拍6分、第2拍32分，共38分；第2拍后续定势碰撞产生的得分另算。

如果第1拍T先后被触发3次，本拍仍得18触发分，但只安排一次下一拍爆破。第2拍的到期执行是已支付效果的后续执行，不是一条无能量触发的新效果。

### 待爆期间与轮次

- 待爆实体继续占格，可受普通推移或机械臂搬动；移动不会自动引爆或重新计时。再次补能不清除待爆状态，也不安排第二次爆破。
- 本关使用连续拍序号，换轮不重置到期拍。第1轮末拍启动，可在第2轮首拍爆破，玩家可先利用轮间补给布置。
- 最后一轮最后一拍启动时，本关结束便移除临时状态，不补发额外拍击或爆破。选中实体和拍前预览提示“本关剩余拍击不足，启动后无法等到爆破”。
- 一拍开始时，先扣1次拍击额度，记录当前场上已到期的定时线圈ID，按稳定ID升序加入队列。各到期爆破及其FIFO连锁结算完，再按本关规则建立基础下落顺序。刚被这一波触发并启动的新定时线圈到期拍是当前拍+1，不加入本拍到期名单。
- 到期爆破引发即时失败时，按共用失败优先级结束本关，不继续基础下落；拍击次数已正常消耗。
- 起爆前被吞噬、回收或错误销毁，取消该实体的待爆效果，已支付能量不退还。已发出的爆破事件保留来源，不依赖本体继续存在。
- 收纳保留原实体的待爆状态与到期拍。到期时不在场上就不执行；之后释放到盘面，在首次拍击开始时检查已到期状态并执行，释放操作本身不引爆。
- 复制得到相同形态及源当前能量，但新副本处于未启动状态，不复制已支付的待爆事件；需要自身能量足够并重新受触发才能启动。
- 若到期时位于抑制主动能力的静默区，保留待爆状态与已支付记录；之后首次不受抑制的拍击开始时执行。离开静默区的移动不即时引爆。
- 轮存档记录实体ID、形态、能量、待爆状态、到期拍和当前拍序号，恢复不会再次支付启动费用或重复已执行的爆破。

### 计分与表现

BF-004在真正爆破时按当前有效配置提高每个对象效果分；爆破前取得的相关Buff可影响这次输出。其他触发分Buff照常作用于各次受触发。定时线圈的等待不会产生自动触发分。

启动时线圈亮起短引线与“下一拍”图标，机械臂移动时图标跟随实体；拍前高亮预计爆破范围。到期后仍因静默或收纳等待时，显示对应状态。资源上复用基础线圈、六向爆破和一个状态叠层。

玩家用基础线圈追求本拍立刻连锁，用定时线圈安排下一拍的起爆位置和先后顺序。两种形态共享爆破能力，通过时机改变具体用法。
