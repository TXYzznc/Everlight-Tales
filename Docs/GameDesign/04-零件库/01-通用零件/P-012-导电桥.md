## 得分与能量配置

| 字段 | 设计初值 |
|---|---|
| 初始能量／容量 | 4／4 |
| 单次消耗 | 1点 |
| 补能 | 接力电池可补至容量；同一连锁中补能后，后续触发重新检查 |
| 触发分 | 每次成立的触发得4分，不消耗能量；能量不足或效果受阻仍获得。 |
| 效果分 | 成功主动转发一次得8效果分。 |

例：本件被触发3次，其中1次能量不足，仍累计12触发分；另将实际成功效果按本表算法加分。

触发分先独立结算，自身效果按零件能量检查，维修效果按公共维修能量检查；只有成功的效果取得对应效果分。特殊目标另行判定。详细结算口径见[计分与零件能量](../../02-系统设计/12-计分与零件能量.md)。

## 玩家面对的选择

摆成一条可靠通信线，或接入多个分支让一击同时激活远端设备。旋转整盘不改变桥相对端口，搬动会改变线路。

## 触发与效果

可移动实体占一格，具有 D0、D3 两个信号端口；相邻兼容端口组成信号边，机械位置改变后重新计算。接收带根信号 ID 的脉冲时，先检查仍有兼容的已接通邻端，再支付1点零件能量并转发，同一根信号对同一桥只转发一次；触发分另按同一根信号在本桥首次成立的触发计一次，能量不足也记该触发分，不因环路重复发放。没有可发送邻端时不消耗、不记为已转发；后续再次收到同根信号时可重新检查。能量不足同样不占用成功转发记录。电路连通判定只需桥存在和端口匹配，不消耗充能，空能桥仍可维持静态联络。

本条完整参数登记于规则库的 [PR-012](../../02-系统设计/04-怪谈规则库.md#pr-012-导电桥) 条目，调整判定同步其摘要。普通碰撞、信号、修复、校准不互相冒充。

## 状态、移动与持续

初始及容量4点零件能量；静态线路跨拍保留。通用充电可恢复零件能量。

未单列的移动和同拍顺序按 [SR-002](../../02-系统设计/04-怪谈规则库.md#sr-002-碰撞触发与拍击结算)、[SR-004](../../02-系统设计/04-怪谈规则库.md#sr-004-占用层方向与任务接口)；跨拍／跨阶段按 [SR-005](../../02-系统设计/04-怪谈规则库.md#sr-005-持续状态与合法阶段转换)。

## 试配参数与最小验证

充能 4。环形回路中的一次根信号每桥只转发一次；两次独立根信号可各触发，零充能桥仍可作为 LR-KS-01 的静态连通边。

在半径3空盘中保留相关物件与目标，按描述施加一次碰撞或信号即可观察本项。正式关卡的合法路径与经济仍须单独验证。

## 一次具体操作

用两枚桥把 P-015 的声音接到画外呼应点；静态保持联络与主动发送呼应是两种可观察行为。

## 2D 表现与资源

两端铜接点与发光连线，静态线路和活动脉冲用不同亮度。

使用零件基础图形、状态叠层、数字／图标及短动画；任务对象代表现场联系，不要求角色字面缩小成棋子。具体资源数量按美术拆单，不自动折算为每件一个全新场景。

## 待试玩观察

观察本项是否形成预期选择、是否能从操作预测或解释结果、与其他条目叠加是否改变事件次序。充能、容量、范围和压力可调；未经试玩，不将当前参数视为固定平衡。
