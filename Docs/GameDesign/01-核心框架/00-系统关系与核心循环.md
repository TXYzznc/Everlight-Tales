# 系统关系与核心循环 v1.0

阅读提示：本页说明玩家循环；具体零件按需查组合示例与单项文档。精简候选尚未替换现有能力。

> 双主线、事件时间与失败后续已确认；具体拍击数、事件时长、形态解锁频率与逐案阶段划分仍待设计或试玩。

## 主循环

白天或夜晚先从任务系统查看当前事件、主支线与已触发怪谈 → 定位到城市地图对应地点 → 选择维修、处置、生活、调查或怪谈 → 完成相应目标并取得事件结果 → 获得材料／报酬、更新任务、关系与线索 → 回到家园加工整备或继续走访。

任务系统分为事件、任务和怪谈三个页面。事件页索引当前地图事件但不能直接处理；任务页记录主线与现场接受的成长支线并负责领取任务奖励；怪谈页记录案件阶段，奖励由对应人物后续交付。普通事件按昼夜交替刷新，任务和怪谈的关键事件持续保留。详见[任务系统](../02-系统设计/11-任务系统.md)。

怪谈支路：取得本批资格 → 日夜具体事件引出本案调查 → 确认触发 → 完成完整故事目标 → 按ID计入本批完成。本批全部完成才开放后批资格，资格不自动刷新新案；回访与领奖独立继续。夜间可以只有普通事件而没有怪谈。

白天有独立目标：重开店铺、建立合作、主持共同修复、完成修复展。夜晚追查异常与画中失踪，最终救回师父。并非每个白天事件都必须引出怪谈。

## 一次拍击

观察盘面、已知规则与阶段目标 → 旋转六边形内盘选择定势方向 → 可消耗机械臂自由搬动 → 压下冲击柄完成拍击 → 定势下落与能力连锁 → 规则事件与阶段响应 → 查看场景和任务状态。

棋盘操作对应现场连接，人物标记可代表其通路或束缚，不要求真实人物字面变成零件。规则可在拍击前、移动中、触发时、连锁结束或轮后生效；按规则库条目区分。

连锁期间是否允许特殊交互由关卡明确，不再全局规定所有规则变化必须结算后发生。通常新拍击在当前事件结算后提交，特殊交互属于独立草案。

## 拍击、轮、关与完整怪谈（D-029）

- 一次拍击：提交方向，完成一次运动与连锁。
- 一轮游戏：一关内部的一个维修阶段，由若干次拍击完成相应阶段目标；不单独扣地图时间，不作为失败重试起点。
- 一关游戏：一次独立维修事件，通常是一个晚上能够完成的连续现场处理，可包含多轮。每关独立配置耗时；成功、失败、撤退均结算本关完整时间。
- 一个怪谈：从线索到最终解决的完整故事。通常核心维修为一关；若故事需要第一晚维修后继续寻找线索、在后续日期再次维修，则分为多关。每关分别记录成功，全部必要关卡及最终故事目标完成后才记整案完成。

“一个晚上”描述通常的内容跨度，不增加夜尽强制失败或截止时间；既有跨时段完成、怪谈永久等待继续有效。单关失败后隔天重试仍是同一关，不因日期变化成为多关。

每关失败或撤退后，从该关第一轮重新开始；此前成功关卡与已取得调查信息保留。关内已过轮次不自动保留为重试点。异常退出或关闭游戏按轮存档恢复同一次尝试，不作为失败；恢复位置由轮存档记录确定。

关间调查若为独立事件，按自身配置耗时；准备、加工、配装、查看已有资料不耗时。整案耗时为实际处理的各次事件耗时之和。轮数、每轮拍击数、轮间补给和盘面继承的具体配置依各案设计，不由术语对应自动固定。

## 每轮配置与通过条件（D-031）

每关明确轮数，每轮分别配置以下内容：

| 项目 | 是否必需 | 含义 |
|---|---|---|
| 拍击次数 | 必需 | 本轮完成目标可使用的拍击额度 |
| 目标分数 | 必需 | 本轮基础通过要求 |
| 特殊效果 | 可无 | 改变棋盘的规则、对象行为或局面，不作为待完成目标 |
| 特殊目标 | 可无 | 需要额外达成的具体条件，例如让指定对象按要求到达指定格子 |

本轮必须用完配置的拍击次数，最后一拍结算后累计分数达标且全部特殊目标完成才通过；没有特殊目标时也须用完拍数。分数跨轮继承、跨关清零。特殊效果继续按其规则影响玩法，不增加一项“完成效果”的目标。

目标区先显示分数要求；有特殊目标时，逐项显示在目标分数下方，并呈现完成状态。没有特殊目标时不显示该列表。

拍击次数内仅分数达标、或仅特殊目标完成，都不能通过有特殊目标的轮；额度用尽仍未同时满足则未通过，失败重试沿用按关规则。最后一次允许拍击产生的有效结果应计入本轮判定，不能仅因拍击额度扣到零而提前否定其结果。

特殊目标是到达即完成、需保持某状态还是要求其他顺序，由该目标明文定义。本条不自动决定同拍多种终局的优先级，不改异常退出的存档粒度。既有十五案需逐轮映射效果、目标和分数；各轮分数与拍击额度由关卡配置明确填写。

## 构筑与恢复

同一关维修持续演变，分数与棋盘状态跨轮继承；换轮更新特殊效果、特殊目标与拍击额度。永久收集、知识与已完成剧情和本局Buff、异化状态分别记录。

失败与撤退按下表处理；每次均消耗事件配置的完整时间。怪谈恢复到本次开始维修前，已完成调查与已获得信息保留；本次尚未结案的内部阶段回退，已正式完成的独立维修保留。

| 事件 | 失败／撤退后的结果 |
|---|---|
| 可重复、无剧情关联的普通事件 | 展示轻量失败收尾，结束本实例；同类事件以后可再次出现 |
| 剧情相关普通事件 | 已设计失败分支则进入分支，否则提供重试；具体失败分支须单列 |
| 怪谈 | 展示对应反馈，恢复本次维修起点，永久保留入口等待重试；本次不计完成、不发通关奖励 |

关闭程序等中断按轮存档恢复同一次尝试，不作为撤退或重复扣时。存档与轮间奖励的具体先后、外带消耗品与重试随机条件仍待设计。详见[事件结果](../02-系统设计/10-地图事件类型与触发.md)。

## 长期循环

完成各批基础故事 → 新工具、加工关系、零件与收藏 → 普通地图事件与档案重玩持续提供体验 → 十五个基础案全部完成 → 以后可基于既有对象再发新事件（本轮仅概念）。跨对象组合、固定种子、排名和分享仍为后续候选。

现实地图的新事件与档案重放区分，避免已获救人物无说明地反复失踪。时长参考见[节奏与长期内容](../03-玩家体验/01-移动端节奏与长期内容.md)。


## 零件挑战接入（D-013）

本关准备时携带min(拥有种类数,上限)种零件；旋转／搬动／拍击形成连锁，每拍完成后四选一，进入下一轮获得三次四选一。分数与棋盘跨轮继承，地图故事结果按关卡与案件成功分别保存。具体试配见[共用语义与配装](../02-系统设计/08-零件挑战共用语义与配装.md)，关键选择见[六个组合推演](../02-系统设计/09-零件挑战组合与验证场景.md)。当前规则登记为 53 条 LR，另有 6 条 SR、20 条 PR、15 条 MR、8 条 OR、8 条 AR、15 条 CR，加 6 条地图投放 ER，合计 131 条。单案爆破劈分等能力标签不能自动套用到其他案件。
