# EV-D02 邻里帮忙找物

## 1. 基本资料

| 字段 | 配置 |
|---|---|
| 事件类型 | EV-03 居民生活，可重复普通事件，非盘面热点调查 |
| 一句话目的 | 帮刚收完活动用品的居民在门口找到遗落钥匙，避免她折返家中取备用钥匙 |
| 地点与地图标记 | 社区活动中心门口；失物标记 |
| 关联人物与表现 | 普通居民；复用活动中心门口背景、居民头像、长椅、伞架、告示栏三个热点与夜间灯光层 |
| 关联记录 | 不创建任务或怪谈档案；不计入普通作业成功数 |

这是一次普通遗失物处理。钥匙、地点线索和居民反馈只属于本事件实例，不把生活委托伪装为怪谈，也不生成永久背包道具。

## 2. 出现、开放与持续规则

| 字段 | 配置 |
|---|---|
| 最早出现 | S1，玩家已可独立出门，社区活动中心地点已解锁 |
| 普通供给 | 白天权重1，夜晚权重1；每一昼或夜最多生成一个本事件实例 |
| 可开始时段 | 上午、下午、夜晚；深夜不开始。夜晚实例进入深夜后显示本段已错过，等待下一次昼夜交替退出 |
| 前置与排斥 | 普通居民和活动中心门口未被关键剧情占用；若同一地点的关键事件使用该人物，本模板不进入当前候选池 |
| 可重复规则 | 成功、失败或撤退后本实例结束；以后可在普通供给中生成新实例 |
| 玩家可见信息 | 事件页显示居民遗失钥匙、社区活动中心门口、预计1格、成功报酬20维修费；地图定位到居民与失物区域 |

未处理实例在下一次昼夜交替时退出普通供给，不算失败。深夜不能开始，是该地点工作人员与居民离场的表现；它不会把已经接受的关键剧情步骤一并关闭。

## 3. 处理步骤

| 步骤 | 玩家操作与内容 | 时间与状态 |
|---|---|---:|
| 询问描述 | 居民说明刚收伞时，将钥匙和纸巾一起放下 | 0格。玩家可以在此取消，不开始处理 |
| 查看地点 | 在同一背景查看长椅、伞架、告示栏三个热点；每处可反复查看，不限制次数 | 第一次进入热点调查即开始本事件；查看不逐次扣时，时间在成功或撤退结算时统一扣1格 |
| 找到钥匙 | 首版钥匙固定在伞架旁；长椅显示旧报纸，告示栏显示活动海报 | 取得事件钥匙后开启交还按钮；答案在实例创建时固定，不随点击改变 |
| 交还钥匙 | 回到居民对话并交还钥匙 | 成功时本次处理结算1格 |

玩家未找到钥匙时不能误点交还结束。可以继续查看、查看已看过的线索，或主动撤退。没有维修盘、分数、拍击、战斗或额外关系数值。

## 4. 结果与奖励

| 结果 | 达成与时间 | 状态变化 | 奖励与发放 | 收尾表现 |
|---|---|---|---|---|
| 成功 | 找到本实例钥匙并交还；结算1格 | 本实例结束并从地图和事件页移除 | 现场立即获得20维修费。报酬来自居民原本准备的找回酬谢 | 就在我放伞的地方啊。多亏你，我不用回家再拿一趟备用钥匙了。 |
| 失败 | 本事件不配置错误提交。没有找到钥匙时不能提交，玩家仍可继续调查或撤退 | 无 | 无 | 无 |
| 撤退 | 在交还前离开；结算1格 | 本实例结束；事件钥匙清除，不影响居民、地点或后续供给 | 无 | 我再问问失物招领处。谢谢你陪我找。 |

中断游戏时保存已查看热点、事件钥匙和实例答案。已完成、撤退或昼夜替换后的实例均不会重新发放奖励。

## 5. 变体与表现边界

首版为固定的伞架答案，用来确保第一次看到热点交互时信息足够直接。后续可把钥匙改到长椅或告示栏，但每种变体都必须同时改写居民描述、热点文字和对象摆放，并在实例创建时固定。变体不额外制造关系系统、物品收集系统或怪谈线索。
