# EV-N03 货架后的隔板

## 1. 基本资料

| 字段 | 配置 |
|---|---|
| 事件类型 | EV-02 临时处置，可重复普通事件 |
| 一句话目的 | 拆除仓库货架后变形卡住的隔板，重新打通取货通道 |
| 地点与地图标记 | 仓库；临时处置工具标记 |
| 关联人物与表现 | 仓库店员；复用仓库背景、隔板遮挡与通道打开两层状态、店员头像和两段短对白 |
| 关联记录 | 普通作业成功数；不创建任务或怪谈档案 |

隔板变形后挡住了货架后的货箱。六相定势盘映射隔板和货架结构的受力连接；爆破线圈在盘面上的冲击对应现场的定势拆障，而不是在仓库中使用现实炸药。

## 2. 出现、开放与持续规则

| 字段 | 配置 |
|---|---|
| 最早出现 | S2，仓库地点解锁后 |
| 普通供给 | 白天权重2，夜晚权重2；同一昼或夜最多生成一个本事件实例 |
| 可开始时段 | 上午、下午、夜晚、深夜 |
| 前置条件 | 已完成S0开店教学中的爆破线圈和脆裂隔板演示；不要求解锁任一线圈改装形态 |
| 可重复规则 | 成功、失败、撤退后本实例结束；以后可作为新的普通供给重新出现 |
| 玩家可见信息 | 事件页显示仓库取货通道被隔板挡住、预计2格、四时段可处理；地图定位到仓库 |

## 3. 处理步骤

| 步骤 | 玩家操作与内容 | 时间 |
|---|---|---:|
| 查看通道 | 店员指出被挡住的货箱和变形隔板，玩家确认可拆除的受力点 | 0格 |
| 准备维修 | 选择至多6种零件和形态；可查看固定盘面预览 | 0格 |
| 六相定势盘处置 | 对隔板造成两次独立有效冲击，拆通通路并达到目标分 | 2格，于结算时一次性扣除 |

### 维修关 EV-N03-R01

| 字段 | 配置 |
|---|---|
| 轮次与拍击 | 1轮，3拍；前2拍后各一次四选一，按[共用配置](01-共用配置.md)执行 |
| 分数目标 | 累计40分；分数跨拍保留 |
| 特殊效果 | 无额外轮效果；隔板拆除后，因阻挡消失而腾出的通路会在同一拍继续结算基础下落 |
| 特殊目标 | 脆裂隔板W耐久降至0并被移除 |
| 固定预览内容 | W脆裂隔板在(1,0)，P-003爆破线圈X在(0,0)，P-001惯性撞锤H在(-1,0)。X与H均为关键件，计入初盘6枚普通零件 |
| 随机内容 | 其余4枚普通零件的种类与合法落点；两次局内奖励候选 |
| 初始资源 | 机械臂2次，分数0，公共维修能量0，无Buff |

| 对象 | 坐标与规则 | 完成后的状态 |
|---|---|---|
| W O-002脆裂隔板 | (1,0)；固定，耐久2；每次新的物理碰撞或独立爆破冲击耐久-1，同一次爆破只扣1次 | 耐久为0时移除，通道打开 |
| X 爆破线圈 | (0,0)；关键件；成功触发后对相邻对象施加爆破冲击并按命中对象得效果分 | 能量耗尽后仍可作为盘面实体参与移动和受击 |

固定示例可选D0：X先沿D0撞击W，造成一次物理耐久损伤；H随后沿D0撞击X，使X起爆并对W造成第二次独立爆破冲击，W耐久归零并移除。核心拆障不依赖随机齿轮或奖励抽取。第2、3拍以及两次局内奖励用于让随机零件组织得分；隔板和线圈移除后，腾空的通路允许相关实体在同拍继续下落。

## 4. 结果与奖励

| 结果 | 达成与时间 | 状态变化 | 奖励与发放 | 收尾表现 |
|---|---|---|---|---|
| 成功 | 第3拍后累计至少40分，且W已移除；结算2格 | 仓库通道打开；普通作业成功数+1；本实例结束 | 现场立即获得40维修费、MT-004校准簧片×1。店员从拆下的隔板减震支架中留下仍可校准复用的一枚簧片 | 通了！箱子可以直接拉出来，不用把整排架子都搬开。 |
| 失败 | 用完3拍后分数或拆除目标未达成；结算2格 | 本实例结束，隔板和货箱维持阻挡状态 | 无 | 这批货先从另一侧取，隔板留给下一班处理。 |
| 撤退 | 在本关内主动撤退；结算2格 | 本实例结束，盘面和局内奖励清除 | 无 | 这批货先从另一侧取，隔板留给下一班处理。 |

## 5. 表现与验证

隔板第一次受损显示裂缝叠层，耐久归零时播放固定件松脱、隔板被取下和货箱通道露出的短演出。夜间只更换仓库照明与称呼，不新增专属场景资源。

需验证玩家是否能读出物理碰撞和爆破冲击都能消耗隔板耐久、拆除后同拍续滑的结果是否容易理解，以及40分目标是否与拆障后剩余得分空间匹配。
