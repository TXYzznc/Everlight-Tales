# EV-I01 修复记录核对

## 1. 基本资料

| 字段 | 配置 |
|---|---|
| 事件类型 | EV-04 普通调查，可重复普通事件，非盘面信息核验 |
| 一句话目的 | 比对旧设备照片和登记卡，修正一条抄错的设备特征，让委托人能取回正确物件 |
| 地点与地图标记 | 长明修理铺资料台；档案标记 |
| 关联人物与表现 | 书面留言的普通委托人；复用资料台背景、收音机照片、登记卡与三个可选字段，无需新增人物立绘 |
| 关联记录 | 不创建任务或怪谈档案；不计入普通作业成功数 |

这是为后续取件做的普通资料工作。它与玩家免费查看自己已取得的档案不同，也不会污染怪谈档案、解锁推理系统或成为任何主线唯一入口。

## 2. 出现、开放与持续规则

| 字段 | 配置 |
|---|---|
| 最早出现 | S1，修理铺资料台已开放 |
| 普通供给 | 白天权重1，夜晚权重1；每一昼或夜最多生成一个本事件实例 |
| 可开始时段 | 上午、下午、夜晚、深夜 |
| 前置与排斥 | 资料台未被不可中断的主线演出占用；书面委托可以在无人到店时处理，因此不依赖某位NPC在场 |
| 可重复规则 | 成功、失败或撤退后本实例结束；以后可作为新的普通供给重新出现 |
| 玩家可见信息 | 事件页显示核对旧设备登记、长明修理铺资料台、预计1格、成功报酬20维修费；地图定位到资料台 |

未处理实例在下一次昼夜交替时退出普通供给，不算失败。资料台的免费查档功能始终可用；只有开始这份委托的照片核对，才会进入事件计时。

## 3. 处理步骤

| 步骤 | 玩家操作与内容 | 时间与状态 |
|---|---|---:|
| 阅读委托 | 查看旧设备照片、登记卡和报酬说明 | 0格。玩家可退出，不开始处理 |
| 比对字段 | 照片显示收音机左侧调音旋钮、右下角缺角、三个拨杆；登记卡将调音旋钮误写为右侧 | 第一次修改候选字段即开始本事件；反复查看图片和修改选择不逐次耗时 |
| 提交修正 | 选择调音旋钮位置，并将其改为左侧 | 正确或错误提交都会在本次结算1格；提交前可自由更改 |

首版只要求找出一处不符。右下角缺角与三个拨杆是正确的干扰信息，帮助玩家理解这是基于可见证据的核对，而不是猜谜。没有盘面、分数、拍击或独立信誉值。

## 4. 结果与奖励

| 结果 | 达成与时间 | 状态变化 | 奖励与发放 | 收尾表现 |
|---|---|---|---|---|
| 成功 | 提交左侧调音旋钮；结算1格 | 本实例结束并从地图和事件页移除；本次登记卡标记为已修正 | 现场立即获得20维修费。报酬来自书面委托附带的核对费用 | 委托人回信：原来是抄反了。这样就能对上那一台，多谢你帮忙核实。 |
| 失败 | 提交右下角缺角或三个拨杆；结算1格 | 本实例结束；该次委托记录为未核对成功，不影响玩家正式档案或其它事件 | 无 | 这处和照片还对不上，我再请原保管人确认。 |
| 撤退 | 在提交前离开；结算1格 | 本实例结束；未提交的修改不保存 | 无 | 我先把登记卡留在这里，等核对清楚再说。 |

中断游戏时保存实例照片、登记卡、当前选择和已否提交状态。已提交后的结果与奖励只结算一次，不因恢复存档重复发放。

## 5. 变体与表现边界

首版照片、文字和答案固定。后续可替换旋钮位置、缺角位置或拨杆数量，但每个变体必须同步提供对应图片、登记文字和正确答案，并在实例创建时固定。普通核对绝不从玩家已解决怪谈中抽取真实规则或隐藏答案。
