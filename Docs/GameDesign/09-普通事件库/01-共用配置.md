# 首批普通维修共用配置

本页只记录三件普通维修共同使用的准备、随机、局内奖励与结算规则。每件事件自身文档负责定义地点、人物、出现条件、盘面对象、轮次、结果和永久奖励。

## 准备与初盘

- 单关可携带至多6种通用零件；已拥有和现场借用种类去重后由玩家选择。每种零件进入本关前固定为一种形态。
- 每次事件初盘均为6枚普通零件，任务对象与地形设施不计入该数量。先放置任务对象、固定设施和关键件，再从携带池随机抽取其余零件并落到合法空格。
- 关键件类型、数量与初始工作位置由事件明确提供。其余件允许重复种类、允许挡住路线；玩家可在准备后用初始2次机械臂调整。
- 随机种类从本关携带池等权有放回抽取；随机位置从当前合法空实体格等权抽取。事件实例在创建时保存抽取结果，反复查看准备页不会重新抽取。
- 关键种类未拥有时可以现场借用，借用也占用1个携带种类位置；借用品在结算后收回，不减少玩家永久收藏。

## 局内奖励

第1拍与第2拍全部连锁结束后各展示一次四选一；第3拍结算本关，不再展示局内奖励。每次从本事件已配置的候选中无放回展示4个不同选项，选中后下一次重新抽取。

三件首批普通维修使用相同的局内候选构成：

| 候选 | 条件与效果 | 局内处理 |
|---|---|---|
| 已携带零件补给 | 本关每种已携带零件各可作为1枚候选，显示其进入本关时锁定的形态 | 玩家选定后添加1枚；P-002与P-014由玩家选合法空格，其余在合法空格随机落位；满盘时仍可选但实际添加0枚 |
| 机械臂补给 | 始终可出现 | 本关机械臂次数+1，立即生效 |
| BF-001 棘轮加分 | 本关携带P-002且BF-001未满5层时可出现 | 场上所有P-002触发分+2，可叠加，最多5层 |

局内补给、机械臂与Buff只在当前维修关有效。维修费和材料属于事件结算奖励，在各事件的成功结果中单独配置。

## 时间、结果与重复出现

三件事件都为一关一轮3拍，整次处理耗时2格。准备、配装、关卡预览和在地图上定位不耗时；确认开始维修后，无论成功、失败或撤退，均在结算时一次性推进2格。

- 成功：立即发放该事件写明的永久奖励，计入一次普通作业成功数，本实例从事件页和地图移除。
- 失败或撤退：本实例以轻量现场收尾结束，不发报酬或材料，不扣已有资源，也不产生永久负面状态；同模板可在之后的普通供给中再次出现。
- 未处理：在下一次昼夜交替时退出当前普通供给，不算失败，不播放失败对白。
- 中断：关闭或异常退出恢复同一维修尝试，不结算时间、奖励或结果。

第一版的同模板重复实例保留任务布局，重新生成非关键件、其落点和两次局内奖励。之后若增加布局变体，必须为变体单独配置目标分、特殊目标、固定与随机元素及验证路线。
