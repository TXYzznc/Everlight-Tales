# EV-D01 夜班送还

## 1. 基本资料

| 字段 | 配置 |
|---|---|
| 事件类型 | EV-03 居民生活，可重复普通事件，非盘面交付 |
| 一句话目的 | 将合作工坊已经修好的收音机送到夜班店员手中，让他在空荡的夜班里重新听到正常的广播 |
| 地点与地图标记 | 街区小店；包裹标记 |
| 关联人物与表现 | 夜班店员；复用小店夜景、收音机包裹图标、店员头像与两段短对白。试听时播放普通广播短音效 |
| 关联记录 | 不创建任务或怪谈档案；不计入普通作业成功数 |

收音机是本事件临时交付物。合作工坊已经完成维修，玩家获得的是代送委托；它不会进入永久零件、材料或收藏库存。

## 2. 出现、开放与持续规则

| 字段 | 配置 |
|---|---|
| 最早出现 | S1，玩家已可独立出门，街区小店地点已解锁 |
| 普通供给 | 夜晚权重1，白天权重0；每一夜最多生成一个本事件实例 |
| 可开始时段 | 夜晚、深夜。夜晚刷新后生成的实例在深夜仍可处理 |
| 前置与排斥 | 夜班店员可在小店接待；若该人物被关键剧情占用，本模板不进入本夜候选池 |
| 可重复规则 | 成功、失败或撤退后本实例结束；同一模板可在之后的夜晚供给中生成新的收件人或收音机版本 |
| 玩家可见信息 | 事件页显示代送收音机、街区小店、预计1格、夜晚与深夜可处理、成功报酬20维修费；地图定位到店员所在柜台 |

未处理实例在下一次昼夜交替时退出普通供给，不算失败，不播放失败对白。进入深夜后若仍未处理，它不关闭；这是让夜班内容在同一夜内有完整处理窗口，而不是额外延长普通事件刷新周期。

## 3. 处理步骤

| 步骤 | 玩家操作与内容 | 时间与状态 |
|---|---|---:|
| 接取包裹 | 在小店柜台与店员确认收件人；事件包裹进入本实例的已接取状态 | 0格。取消对话不开始事件，不消耗时间 |
| 交付选择 | 选择直接交接，或先听店员试播收音机。直接交接以一句简短寒暄结束；试听播放一段普通夜间广播，并补充店员的夜班近况 | 交互不单独扣时，两个选择不改变报酬、关系值或后续剧情 |
| 确认交付 | 将包裹交给登记的店员 | 成功时本次处理结算1格 |

本事件没有六相定势盘、盘面准备、分数、拍击或局内奖励。玩家可以在未确认交付前撤退；此时包裹退回合作工坊的事件记录，不产生永久物品变动。

## 4. 结果与奖励

| 结果 | 达成与时间 | 状态变化 | 奖励与发放 | 收尾表现 |
|---|---|---|---|---|
| 成功 | 向本实例登记的夜班店员确认交付；结算1格 | 本实例结束并从地图和事件页移除；收音机状态变为已交付 | 现场立即获得20维修费。报酬来自合作工坊预付的代送费 | 店员拧两下旋钮：这就对了，夜里有点人声，店里没那么空。代送的钱收好。试听路线额外播放正常广播片段 |
| 失败 | 本事件没有错误操作导致的失败分支 | 无 | 无 | 无 |
| 撤退 | 在确认交付前离开；结算1格 | 本实例结束；包裹退回委托方；不扣永久资源 | 无 | 先放回工坊吧，等有空再送。我今晚听店里的旧音箱。 |

中断游戏时保存本实例、已接取包裹和已选择的试听状态；未提交交付前不结算时间或报酬，已提交结果不重复结算。

## 5. 变体与表现边界

首版固定使用夜班店员和普通广播。后续重复实例可替换为其他已配置收件人或普通设备，但必须同时配置人物、对话和地点，不能在运行时把关键剧情人物临时替换进来。任何能够引向怪谈的异常广播必须做成独立剧情或调查事件，不能混入本模板。
