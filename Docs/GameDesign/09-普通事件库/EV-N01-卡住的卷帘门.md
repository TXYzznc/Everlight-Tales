# EV-N01 卡住的卷帘门

## 1. 基本资料

| 字段 | 配置 |
|---|---|
| 事件类型 | EV-01 普通维修，可重复普通事件 |
| 一句话目的 | 帮街区小店把滑出定位槽的卷帘门轴推回校正位置，让店员能正常搬货或关店 |
| 地点与地图标记 | 街区小店；普通维修扳手标记 |
| 关联人物与表现 | 街区小店店员；复用小店背景、卷帘门故障与开启两层状态、店员头像和两段短对白 |
| 关联记录 | 普通作业成功数；不创建任务或怪谈档案 |

门轴没有损坏，只是长期受力后滑出定位槽。六相定势盘映射门轴、传动箱和校正位置之间的受力关系；盘面目标完成时，现场表现为卷帘门重新卡回轨道。

## 2. 出现、开放与持续规则

| 字段 | 配置 |
|---|---|
| 最早出现 | S1，完成红舞鞋后的首次回店交谈，并解锁街区小店 |
| 普通供给 | 白天权重3，夜晚权重3；同一昼或夜最多生成一个本事件实例 |
| 可开始时段 | 上午、下午、夜晚、深夜 |
| 前置与借用 | P-001、P-002、P-003、P-004已按S1投放；P-014未永久拥有时可在准备页借用，并计入6种携带上限 |
| 可重复规则 | 成功、失败、撤退后本实例结束；以后可作为新的普通供给重新出现 |
| 玩家可见信息 | 事件页显示小店卷帘门卡住、预计2格、四时段可处理；地图定位到街区小店 |

## 3. 处理步骤

| 步骤 | 玩家操作与内容 | 时间 |
|---|---|---:|
| 现场查看 | 店员指出门轴偏离定位槽，玩家查看门轴与传动箱 | 0格 |
| 准备维修 | 选择至多6种零件、形态和借用件；可查看固定盘面预览 | 0格 |
| 六相定势盘维修 | 在一关一轮内完成分数与门轴校正目标 | 2格，于结算时一次性扣除 |

### 维修关 EV-N01-R01

| 字段 | 配置 |
|---|---|
| 轮次与拍击 | 1轮，3拍；前2拍后各一次四选一，按[共用配置](01-共用配置.md)执行 |
| 分数目标 | 累计30分；分数跨拍保留 |
| 特殊效果 | 无额外轮效果；按当前定势方向进行基础下落与连锁 |
| 特殊目标 | 门轴联系标记B必须由普通推移效果首次进入校正格G；机械臂直接放入G不计完成 |
| 固定预览内容 | W传动箱外壳在(-1,0)，B门轴联系标记在(1,0)，G校正格在(2,0)，关键P-001惯性撞锤H在(0,0) |
| 随机内容 | 其余5枚普通零件的种类与合法落点；两次局内奖励候选 |
| 初始资源 | 机械臂2次，分数0，公共维修能量0，无Buff |

| 对象 | 坐标与规则 | 完成后的状态 |
|---|---|---|
| B 门轴联系标记 | (1,0)；受基础定势、普通推移和机械臂影响；不接受冲击、复制或吞噬 | 被普通推移送入G后锁定，停止移动与重复判定 |
| W O-001固定墙体 | (-1,0)；传动箱外壳，固定且不可破坏 | 保持不变 |
| G 校正格 | (2,0)；地形层，不占实体层 | B进入后显示门轴已校正 |

参考路线可选D3：第1拍由B撞到H后，H将B推入G；第2、3拍继续触发棘轮或其它得分零件，使累计分达到30。路线只用于验证固定示例，随机初盘、不同形态与不同旋转方向允许形成其它解法。

## 4. 结果与奖励

| 结果 | 达成与时间 | 状态变化 | 奖励与发放 | 收尾表现 |
|---|---|---|---|---|
| 成功 | 第3拍后累计至少30分，且B已校正；结算2格 | 门显示开启或关严状态；普通作业成功数+1；本实例结束 | 现场立即获得40维修费、MT-002精密齿轮×1。齿轮来自店员交付的旧门维护盒中未使用的备用传动件 | 白天：这回对上槽了。等会儿进货，总算不用一箱箱绕后门。夜晚：能关严了，我也能收工了。 |
| 失败 | 用完3拍后分数或目标未达成；结算2格 | 本实例结束，门保留检修牌 | 无 | 先这样吧，我从侧门进出，明天再安排检修。 |
| 撤退 | 在本关内主动撤退；结算2格 | 本实例结束，盘面和局内奖励清除 | 无 | 先这样吧，我从侧门进出，明天再安排检修。 |

## 5. 表现与验证

完成时切换卷帘门开启或闭合的状态层，并播放金属卡入槽位的短音效。失败和撤退只保留检修牌，不把门表现为已修好。

需用固定示例、不同携带形态、随机余件和局内奖励组合验证：目标是否可读、随机局面是否存在合理操作空间，以及30分目标与2格耗时是否匹配。
