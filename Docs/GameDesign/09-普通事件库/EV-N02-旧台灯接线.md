# EV-N02 旧台灯接线

## 1. 基本资料

| 字段 | 配置 |
|---|---|
| 事件类型 | EV-01 普通维修，可重复普通事件 |
| 一句话目的 | 为居民的旧台灯重新固定松脱接线端，使它恢复照明 |
| 地点与地图标记 | 长明修理铺；普通维修扳手标记 |
| 关联人物与表现 | 到店居民；复用修理铺接待区、熄灭与点亮的台灯状态、居民头像和两段短对白 |
| 关联记录 | 普通作业成功数；不创建任务或怪谈档案 |

灯罩、开关和灯泡都仍可使用，问题只在接线端松脱。玩家要先组织公共维修能量，再触发铆合钳把能量实际用在接线端上；点亮台灯后仍要完成本轮剩余拍击并达到目标分。

## 2. 出现、开放与持续规则

| 字段 | 配置 |
|---|---|
| 最早出现 | S1，红舞鞋完成后，长明修理铺恢复日间接待 |
| 普通供给 | 白天权重3，夜晚权重0；同一白天最多生成一个本事件实例 |
| 可开始时段 | 上午、下午；夜晚出现的普通供给不包含本事件 |
| 前置与借用 | P-002计量棘轮作为关键产能件；P-014铆合钳未永久拥有时可借用，并计入6种携带上限 |
| 可重复规则 | 成功、失败、撤退后本实例结束；以后可作为新的白天普通供给重新出现 |
| 玩家可见信息 | 事件页显示旧台灯接线松脱、预计2格、仅上午与下午可处理；地图定位到修理铺 |

## 3. 处理步骤

| 步骤 | 玩家操作与内容 | 时间 |
|---|---|---:|
| 接待与查看 | 居民说明台灯忽明忽暗，玩家检查接线端和备用线材 | 0格 |
| 准备维修 | 选择至多6种零件、形态和借用件；可查看固定盘面预览 | 0格 |
| 六相定势盘维修 | 先产出公共维修能量，再完成接线端维修并达到分数目标 | 2格，于结算时一次性扣除 |

### 维修关 EV-N02-R01

| 字段 | 配置 |
|---|---|
| 轮次与拍击 | 1轮，3拍；前2拍后各一次四选一，按[共用配置](01-共用配置.md)执行 |
| 分数目标 | 累计60分；分数跨拍保留 |
| 特殊效果 | 无额外轮效果；公共维修能量跨拍保留，成功维修时才消耗 |
| 特殊目标 | 接线端L维修进度达到1／1 |
| 固定预览内容 | L接线端在(2,1)，P-002计量棘轮E在(1,2)，P-003爆破线圈X在(0,2)，P-001惯性撞锤H在(-1,2)，P-014铆合钳C在(1,1)。这四枚关键件均计入初盘6枚普通零件 |
| 随机内容 | 其余2枚普通零件的种类与合法落点；两次局内奖励候选 |
| 初始资源 | 机械臂2次，分数0，公共维修能量0，无Buff |

| 对象 | 坐标与规则 | 完成后的状态 |
|---|---|---|
| L 接线端 | (2,1)；固定，维修进度0／1；只接受P-014的适配维修请求，普通碰撞和爆破不增加进度 | 完成后台灯常亮，不再接受维修或维修计分 |
| C 铆合钳 | (1,1)；被触发时检查D0邻格L；公共维修能量至少2时，消耗2并使L进度+1，立即获得20维修效果分 | 已修好L时仍可获得触发分，但不重复耗能或取得维修效果分 |

固定示例可选D0。E位于D0边缘，X先沿D0撞击E，使E第一次产出公共维修能量；H随后撞击X，X起爆并冲击E与C。E第二次产能后公共维修能量达到2，C在同一爆破事件中检查D0邻格L并完成维修。该固定过程已产生62分：E两次触发20分、X触发6分与命中E、C的12效果分、C触发4分与接线端维修20分。因此2枚随机零件、后续拍击和两次局内奖励用于改变追分路线，而不是补齐核心维修条件。其它旋转、机械臂或形态组合仍允许形成其它解法。

## 4. 结果与奖励

| 结果 | 达成与时间 | 状态变化 | 奖励与发放 | 收尾表现 |
|---|---|---|---|---|
| 成功 | 第3拍后累计至少60分，且L维修进度为1／1；结算2格 | 台灯状态切为常亮；普通作业成功数+1；本实例结束 | 现场立即获得40维修费、MT-001铜芯线×1。居民将接线时剩下的一段合格备用线交给维修铺回收 | 还是这盏灯照着舒服。谢谢，今晚总算能把那几页书看完。 |
| 失败 | 用完3拍后分数或维修目标未达成；结算2格 | 本实例结束，台灯保持熄灭并放回检修箱 | 无 | 我先用备用灯，这盏放回检修箱吧。 |
| 撤退 | 在本关内主动撤退；结算2格 | 本实例结束，盘面和局内奖励清除 | 无 | 我先用备用灯，这盏放回检修箱吧。 |

## 5. 表现与验证

维修成功时，铆合钳闭合、接线端亮起，随后台灯从局部闪烁变为稳定暖光。公共维修能量不足时，钳口停在接线端前并显示能量不足提示。

需验证公共能量先后顺序是否清楚、60分目标是否要求玩家在完成维修后仍继续组织连锁，以及借用铆合钳是否能让首次玩家理解维修接口。
