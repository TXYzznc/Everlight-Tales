# L-02 画皮：现实原作与传说背景

> 本文的“现实”指现实世界中存在的文学作品、流传版本及相关记录，不是声称超自然情节真实发生。核对日期：2026-09-08。文学情节用本次自行组织的中文转述，传说注明版本；解释性观点单独标示。

## 一、现实中的原篇

《画皮》出自蒲松龄《聊斋志异》。原篇围绕王生、他的妻子陈氏、披皮鬼物与道士展开。今天常见的爱情化影视改编会增加大量人物动机；本文采用原篇，不把那些再创作当成蒲松龄原文。[《聊斋志异》第一卷《画皮》](https://zh.wikisource.org/wiki/聊齋志異/第01卷#畫皮)

## 二、王生把陌生女子藏进家中

王生在路上遇到美貌女子，听她诉说受欺负、逃离原处的经历，便把她带回并私下安置。他受到美貌和对方说辞吸引，没有充分核实身份，也没有认真听从妻子的劝阻。

他随后遇到道士。道士看出他身上带着邪气，王生起初不信，回家后却看到可怕真相：屋里的存在并不是他所认识的女子，而是在处理一张人皮的狰狞鬼物。它把皮整理、描画，再披到身上，便恢复成美丽女子的外观。

画皮在这里不是现代意义的化妆或整形，而是一层可以离身、被制作并再次披上的外表；外表与行动主体分离，构成故事最鲜明的画面。

## 三、保护未能阻止报复

王生向道士求助，得到暂时保护的办法。但鬼物发现阻碍后并没有自动消散，而是愤怒地破坏防护，进入屋内，杀害王生并取走他的心。

道士随后追查鬼物的去向。它可以再用其他面貌躲藏，直到被识破、击败，其依附的人皮也被收拾。原篇由此说明“知道她是假的”和“已经处理掉危险”并非同一件事，识破之后的行动仍然可能失败。

这部分的暴力是原作情节，本背景文档只概述因果，不据此要求游戏制作写实的开膛画面。

## 四、陈氏为救丈夫承受屈辱

鬼物被处理，并不意味着王生自然复活。陈氏继续求救，道士指向另一位看起来疯癫、肮脏的乞者。她为了丈夫承受辱骂和羞辱，并吞下对方给出的污物。

返回家中面对王生尸身时，陈氏悲痛呕出一个心状之物。它进入王生胸中，伤口逐渐恢复，王生最终苏醒。原篇的救援并不是由最像仙人的人物轻易完成，而落在她的坚持以及一个外观最不值得相信的人身上。

故事末尾的议论回到人的愚昧：把妖物当作美人，把忠告当作胡言，也让无辜的妻子替自己的迷恋承担沉重代价。[原篇及篇末议论](https://zh.wikisource.org/wiki/聊齋志異/第01卷#畫皮)

## 五、原作中可以确定与不能混入的内容

可以确定的关键链条是：美貌诱惑、私下藏匿、看见绘皮披皮、求助、防护失效、王生遭害、鬼物被降伏、妻子求取复生。不能把某部电影里的妖怪爱情、姐妹关系或牺牲规则反写成原篇设定。

以下属于本次解读：原作的可怕不仅是皮下面有怪物，还在于人依据愿望选择相信什么。美貌与丑陋都不是可靠的善恶检验，真正的结果取决于行为和所承担的后果。

槐江市的顾师傅、新助手、裁缝铺、照明与真假出口是游戏改写。游戏采用披皮伪装与捕食的原作特征，改为保护仍然活着的人；不要求先让顾师傅经历王生的死亡，也不把妻子的受辱复生过程换皮照搬成维修步骤。
