# L02-E01 调查：橱窗里借来的脸

## 事件定位

L-02 通过两个时段不同、结果相同的调查入口创建。玩家只需要完成其中一个；另一个不再作为阻塞步骤，而是转为补充对话。这样白天与夜晚各自能自然引出怪谈，也不要求玩家为了进入维修先重复处理同一条信息。

| 字段 | 配置 |
|---|---|
| 怪谈阶段 | 未触发 → 调查 → 待维修 |
| 前置 | B2 资格已取得；裁缝铺地点已开放。 |
| 地点 | 裁缝铺。 |
| 时间消耗 | 每次处理 1 格；成功、答错与撤退都消耗 1 格。 |
| 盘面 | 无。本步骤是现场观察与对话，不进入六相定势盘。 |
| 失败处理 | 不创建失败分支；本次处理结束，入口保留至下个开放时段重试。 |

## EV-L02-01 橱窗里借来的脸

| 字段 | 配置 |
|---|---|
| 开放 | 上午、下午。 |
| 地图显示 | 裁缝铺橱窗的灯忽明忽暗；事件页显示“裁缝铺橱窗检查”。 |
| 处理过程 | 玩家检查灯座、代表作袖口和助手整理过的三件衣物；顾师傅说明自己习惯用左手拇指顶针补内侧针脚，助手却把三件衣物都缝成同一种整齐的外观。 |
| 正确推进 | 选择“相同的针脚不是顾师傅的习惯”，记录线索〈拇指顶针的补痕〉，创建 L-02 档案。 |
| 错误推进 | 顾师傅认为只是新手手法生硬；本次事件结束，下一次白天可重试。 |
| 撤退 | 玩家暂时离开橱窗；本次事件结束，下一次白天可重试。 |

成功后，裁缝铺夜间地图标记变为“后间求助”，怪谈页显示 `L-02 画皮：前往夜间维修（1/1）`。夜间调查入口改为补充对话：它可让玩家听到顾师傅被困的声音，但不再消耗怪谈推进次数。

## EV-L02-02 后间的三张脸

| 字段 | 配置 |
|---|---|
| 开放 | 夜晚、深夜。 |
| 地图显示 | 裁缝铺门缝透出不稳定的白光；事件页显示“裁缝铺后间求助”。 |
| 处理过程 | 玩家在门口听见三个相同的声音分别要求开门、关灯、把人带走。检查橱窗倒影、屏风内侧和后间门锁后，发现三处脸部反光完全一致，只有一道衣袖上的旧补痕不在倒影中。 |
| 正确推进 | 选择“先恢复照明，再分开处理”，记录线索〈不在倒影里的补痕〉，创建 L-02 档案与维修入口。 |
| 错误推进 | 某个声音催促玩家立刻带它离开；玩家没有开门，本次事件结束，下一次夜晚可重试。 |
| 撤退 | 玩家离开店门；本次事件结束，下一次夜晚可重试。 |

成功后，白天入口改为补充对话：顾师傅的熟客可补充代表作的来历，不再要求再次处理。怪谈页显示 `L-02 画皮：前往夜间维修（1/1）`。
