# 修复展筹备

> S2主线分组。社区合作邀请、三个项目自由顺序、步骤耗时、各40维修费奖励与失败重试已确认；本页定义邀请事件和三个任务如何进入任务页。

任务页在“主线”下显示“修复展筹备”分组，包含T-M02《把旧物照亮》、T-M03《写下物件的来处》和T-M04《让旧声音响起来》。分组用于展示共同进度，不单独设置可领取奖励。

## EV-TMX-01 接下修复展邀请

| 字段 | 配置 |
|---|---|
| 事件类型 | 地图交互，主线任务组入口 |
| 地点与人物 | 长明修理铺／社区工作人员 |
| 出现条件 | S2已开启；修理铺日间接待恢复；修复展尚未建立 |
| 开放时段 | 上午、下午；长期保留，错过窗口等待下一个白天窗口 |
| 玩家可见信息 | 事件页显示“社区的修复展邀请”、1格、将开放三项长期任务 |
| 任务与地图关系 | 接受前不显示三个项目；接受后创建T-M02、T-M03、T-M04，并分别生成各自地图事件 |
| 并存规则 | 不占昼夜普通事件名额；可与修理铺的普通维修事件同时显示 |

社区希望把居民仍在使用、但带着修补痕迹的旧物放进店内展示区。玩家确认腾出展示区后，工作人员交付展示灯、两份物件记录和播放机资料；这些是任务对象，不进入永久库存。

| 结果 | 时间 | 状态变化与奖励 |
|---|---:|---|
| 接受 | 1格 | 建立修复展筹备分组；创建T-M02、T-M03、T-M04；展示区由封闭状态改为施工状态；无货币或材料 |
| 撤退 | 1格 | 工作人员留下邀请；入口长期保留，下次白天可重试；无奖励 |
| 中断 | 0格 | 保留未确认对话，不推进时间 |

## 三项任务与总进度

| 任务 | 地图处理步骤 | 任务完成结果 | 任务页奖励 |
|---|---|---|---|
| [T-M02 把旧物照亮](T-M02-把旧物照亮.md) | 展示区维修2格 | 展示灯常亮，展示区照明状态开启 | 40维修费 |
| [T-M03 写下物件的来处](T-M03-写下物件的来处.md) | 两次走访，各1格 | 照片与物件说明卡出现 | 40维修费 |
| [T-M04 让旧声音响起来](T-M04-让旧声音响起来.md) | 资料核对1格＋播放机维修2格 | 店内开放两段居民录音试听 | 40维修费 |

三项可任意交错处理。首次无失败完成共消耗7格，加上邀请事件为8格；重试只增加失败步骤的完整耗时。每项任务完成即更新店内状态，不等待任务页领奖。三项全部完成后，分组显示“具备办展条件”；周衡回归后的正式办展作为画壁主线收尾处理，不在此处提前创建事件。

## 共用失败、领奖与表现规则

三个项目均没有剧情失败分支。失败或撤退消耗当前步骤的完整时间，只重试当前步骤；已完成步骤保留。任务页奖励在各自任务完成后出现，领取不消耗时间、只可领取一次；现场不再重复发放相同报酬或材料。

店内只增加现有展示区的照明层、两张说明卡和一个播放按钮。项目不使用展览等级、客流、满意度或新的经营数值。
