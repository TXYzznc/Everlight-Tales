# T-M01 画里的敲击

> 主线任务。周衡失联的发现方式、开放时段与1格调查已确认；本页把该调查收束为可直接配置的地图事件。

## 任务资料

| 字段 | 配置 |
|---|---|
| 任务类型 | 主线调查 |
| 任务出现 | L-01红舞鞋首次维修成功后的回店教学完成；周衡离店前往收藏馆后自动写入任务页 |
| 任务页名称与目标 | 画里的敲击；去收藏馆确认周衡的去向 |
| 关联事件 | EV-TM01-01 收藏馆修复室调查 |
| 完成条件 | 完成EV-TM01-01，确认周衡与一名搬运工被困画内 |
| 任务结果 | 创建T-M05《画面原来的路》，记录旧照片线索；不直接发放维修费、材料或图样 |
| 持续规则 | 长期保留；不占普通事件名额，不因昼夜刷新退出 |

本任务的直接回报是把“师父暂时离店”变为可验证的事实，并打开画壁主线的两条证据链。它不在任务页设置领奖按钮，避免主线调查在没有可解释物资来源时额外发放货币。

## EV-TM01-01 收藏馆修复室调查

### 基本资料

| 字段 | 配置 |
|---|---|
| 事件类型 | 地图调查，T-M01唯一处理步骤 |
| 地点与地图标记 | 收藏馆／修复室门口；资料放大镜标记 |
| 人物与表现 | 陆宁在门外等待；复用修复室背景、陆宁半身立绘、工具包、施工记录和画中人影三个热点 |
| 开放时段 | 上午、下午；夜间与深夜在事件页显示“收藏馆白天开放” |
| 前置与并存 | T-M01已创建且未完成；可与同地点普通事件并存。陆宁被画壁后续事件占用时，本事件已完成，不再生成冲突入口 |
| 玩家可见信息 | 事件页显示“收藏馆的敲击声”、1格、无物资报酬、推进主线；任务页显示当前目标和白天开放提示 |

### 处理内容

| 步骤 | 玩家操作 | 时间与状态 |
|---|---|---:|
| 与陆宁交谈 | 得知周衡进入修复室后没有出来；查看已知任务说明 | 0格 |
| 查看三个证据 | 自由点击工具包、施工记录、画面人影；三个均须查看，阅读与反复查看免费 | 计入本次调查 |
| 回应敲击 | 画中人影先敲出“短、短、长”三拍。玩家从三种节奏按钮中选择相同节奏回应；正确后画中人影改为周衡惯用的敲击手势 | 计入本次调查 |
| 提交判断 | 向陆宁确认“画内有人仍能回应”，结束调查 | 成功时结算1格 |

工具包说明周衡没有正常收工；施工记录显示修复前后编号不一致；画中人影提供尚存联系。正确回应不要求玩家记住外部资料，节奏在当前交互内可随时重听。

### 结果与时间结算

| 结果 | 时间 | 状态变化与反馈 | 奖励 |
|---|---:|---|---|
| 成功 | 1格 | 写入“周衡失联”“旧图编号不一致”“画内存在回应”三条主线记录；创建T-M05并使旧照片调查可处理 | 线索与后续任务入口 |
| 错误提交 | 1格 | 陆宁说回应没有接上，画中人影恢复静止；本步骤保留，可在下一次白天重试 | 无 |
| 撤退 | 1格 | 离开修复室，三个已查看热点不保存为完成；本步骤保留，可重试 | 无 |
| 中断 | 0格 | 保存当前热点阅读与未提交的节奏选择；不推进时间，不重复随机 | 无 |

成功、错误提交和撤退都属于一次已开始的事件处理，按统一规则消耗本步骤完整1格。任务完成后，事件页移除EV-TM01-01，任务页显示“已确认周衡下落”，不再显示领奖按钮。

## 与画壁的衔接

T-M01只建立早期联络，不提前创建L-04画壁的夜间维修。T-M05完成旧照片与流转证据后，任务记录改为“接应资料齐备”；B4资格与L-04的正式触发条件满足时，这两条已完成记录直接作为画壁准备条件，不要求重做调查。

## 表现范围

画中不制作可自由行走的场景。用画面人影从静止到回应、一次敲击音效、陆宁的对话状态变化完成结果表现。
