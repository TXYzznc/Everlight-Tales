# T-M04 让旧声音响起来

> 修复展项目之一。先核对居民录音的标签，再通过六相定势盘修好播放机接线，使两段普通访谈能在店内试听。

## 任务资料

| 字段 | 配置 |
|---|---|
| 任务类型 | 主线项目／调查＋下盘维修 |
| 创建条件 | EV-TMX-01《接下修复展邀请》成功后 |
| 任务页名称与目标 | 让旧声音响起来；核对资料并修好播放机 |
| 关联事件 | EV-TM04-01 录音资料核对；EV-TM04-R01 播放机接线 |
| 完成条件 | 资料核对与播放机接线均成功，必须按顺序处理 |
| 开放与持续 | 两个步骤均在修理铺上午、下午开放，长期保留；夜间显示下次白天开放 |
| 领奖 | 任务页领取40维修费一次 |
| 世界变化 | 修理铺展示区开放两段居民录音的免费试听 |

## EV-TM04-01 录音资料核对

| 字段 | 配置 |
|---|---|
| 交互内容 | 查看录音标签、重复试听两段片段、为当前片段选择正确标题后提交 |
| 正确配对 | 第一段“修理铺旧招牌的来历”；第二段“街坊修过的收音机” |
| 错误结果 | 标签与试听不符，工作人员请玩家重新核对 |
| 耗时 | 成功、错误提交、撤退均1格；试听、查看和提交前改选免费 |
| 成功变化 | 记录“录音资料已核对”，开放EV-TM04-R01；无现场货币或材料 |
| 重试 | 错误或撤退后仅重试本步骤，播放机维修尚未开放 |

两段录音是修复展普通访谈，不提供怪谈线索，也不写入怪谈档案。

## EV-TM04-R01 播放机接线

| 字段 | 配置 |
|---|---|
| 事件类型 | 剧情下盘维修 |
| 地点与表现 | 修理铺展示区；播放机由杂音状态切换为清晰人声状态 |
| 前置 | EV-TM04-01已成功 |
| 处理耗时 | 成功、失败、撤退均2格；准备、配装与预览0格 |
| 固定与随机盘面 | 完整复用EV-N02：固定音频接线端、P-002计量棘轮、P-003爆破线圈、P-001惯性撞锤与P-014铆合钳；这4枚关键件计入初盘6枚，其余2枚普通零件与两次局内奖励候选按EV-N02配置随机生成 |
| 关卡规则 | 一关一轮3拍，累计目标60分；特殊目标为音频接线端维修进度达到1／1；公共维修能量初始0、机械臂2次、携带上限6种 |
| 永久结算差异 | 不发放EV-N02的40维修费或铜芯线；局内奖励仅对本关有效 |

| 结果 | 时间 | 状态变化与奖励 |
|---|---:|---|
| 成功 | 2格 | 播放机可用，展示区立即开放试听；T-M04变为可领奖；无现场永久奖励 |
| 失败或撤退 | 2格 | 资料核对状态保留，仅重试播放机关卡；无奖励 |
| 中断 | 0格 | 恢复本次维修尝试轮存档，不重复扣时或生成奖励 |

## 领奖与同步

任务页领取40维修费后，状态变为“已领奖”。玩家可随时免费试听两段录音，不消耗时间，不产生额外任务或材料。
