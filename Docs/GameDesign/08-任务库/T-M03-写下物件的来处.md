# T-M03 写下物件的来处

> 修复展项目之一。两位居民分别提供一件旧物的来历；玩家通过观察与对话写出正确说明，使展览内容和“修好以后仍继续被使用”的主题成立。

## 任务资料

| 字段 | 配置 |
|---|---|
| 任务类型 | 主线项目／非下盘调查 |
| 创建条件 | EV-TMX-01《接下修复展邀请》成功后 |
| 任务页名称与目标 | 写下物件的来处；完成两张说明卡 |
| 关联事件 | EV-TM03-01 沈遥的排练照片；EV-TM03-02 林岑的旧书挡 |
| 完成条件 | 两个事件均成功；处理顺序自由 |
| 开放与持续 | 两个事件均在上午、下午开放，长期保留；夜间显示下次白天开放 |
| 领奖 | 两张说明卡完成后，任务页领取40维修费一次 |
| 世界变化 | 修理铺展示区出现照片与说明卡，可免费查看 |

## EV-TM03-01 沈遥的排练照片

| 字段 | 配置 |
|---|---|
| 地点与人物 | 舞蹈教室／沈遥；复用沈遥立绘、排练照片、节拍器小图与两段对白 |
| 玩家目标 | 从照片和讲述中选择说明卡标题 |
| 正确提交 | “几代老师共用的节拍器” |
| 干扰选项 | “沈遥刚买的第一只节拍器” |
| 处理耗时 | 成功、错误提交、撤退均1格 |
| 成功结果 | 保存沈遥说明卡，任务进度1／2；无现场货币或材料 |
| 失败与撤退 | 沈遥指出标题和照片不符；本步骤恢复可处理，林岑步骤及已完成进度保留 |

玩家可反复查看照片、听讲述并修改尚未提交的选择；提交后才结算。已从红舞鞋获得的纪念物不参与本事件，不重复赠送。

## EV-TM03-02 林岑的旧书挡

| 字段 | 配置 |
|---|---|
| 地点与人物 | 书店／林岑；复用林岑立绘、书挡、修补照片和两段对白 |
| 玩家目标 | 从书挡和修补照片中选择说明卡标题 |
| 正确提交 | “保留修补痕迹的旧书挡” |
| 干扰选项 | “未经修复的原样书挡” |
| 处理耗时 | 成功、错误提交、撤退均1格 |
| 成功结果 | 保存林岑说明卡，任务进度1／2；无现场货币或材料 |
| 失败与撤退 | 林岑指出记录不符；本步骤恢复可处理，沈遥步骤及已完成进度保留 |

书挡是展览借用物，不进入零件、材料或收藏库存。查看和改选不另耗时，提交后才结算本次1格。

## 完成、领奖与同步

两个事件成功后，展示区立即出现对应照片与说明卡，T-M03变为可领奖。任务页领取40维修费后记录“已领奖”，两张说明卡保持可查看。错误提交、撤退和中断不会产生永久负面状态；中断保留尚未提交的当前选择，不推进时间。
