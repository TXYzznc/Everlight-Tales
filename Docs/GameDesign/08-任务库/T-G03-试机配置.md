# T-G03 试机：穿过空腔

> v0.1试机配置已确认（D-062），待实际试玩。玩家阶段S2；任务条件与加工费用已确认D-061。本关采用[试机共用配置](01-试机共用配置.md)的棋盘、下落、初始资源、奖励、耗时与重试规则。

## 目标与初盘

一关一轮，3拍，累计目标20分；下方同时显示特殊目标进度0/1。达到目标后仍用完拍数。

指定样机X发出的轴向射线越过首格空格(1,0)，在第二格命中K并被K接受，锁定目标。按射线来源、穿越格及命中距离判定；其他线圈直接炸到K、填入中间实体导致射线被截断均不能代替。K变为开启状态并留在原格。

所有初始对象均在S2本任务现场出现并提供借用；以下为完整实体及地形清单，其余格为空。

|---|---|---|---|

## 玩家看到的变化

展柜背景保留可见空腔；盘面在X与锁扣之间显示两格长度的细导向虚线。射线经过空格、撞开远端锁扣，反向射线同时触发来撞齿轮，体现范围与连锁收益。

中间被补给零件占住时提示“射线被首个实体截住”。夹持座在X移除后空闲；第一拍X移除后，A继续进入座子(0,0)并被夹住，实际停在(0,0)，随后不再自动下落。

特殊目标完成后界面打勾；最后一拍同时检查分数和打勾状态。失败只重试本关，恢复初盘及目标记录；不消耗已领取的永久图样。成功台词与任务领奖见[隔着空隙传过去](T-G03-隔着空隙传过去.md)。
