# T-M02 把旧物照亮

> 修复展项目之一。展示灯维修使用已确认的台灯教学关结构，任务结果和永久奖励按本任务单独结算。

## 任务资料

| 字段 | 配置 |
|---|---|
| 任务类型 | 主线项目／下盘维修 |
| 创建条件 | EV-TMX-01《接下修复展邀请》成功后 |
| 任务页名称与目标 | 把旧物照亮；修好展示区旧灯 |
| 关联事件 | EV-TM02-R01 展示灯接线 |
| 地点与开放 | 长明修理铺展示区；上午、下午；长期保留 |
| 完成条件 | EV-TM02-R01成功 |
| 领奖 | 任务页领取40维修费一次；领取不耗时 |
| 世界变化 | 展示区照明常亮，日后可免费查看展品 |

## EV-TM02-R01 展示灯接线

| 字段 | 配置 |
|---|---|
| 事件类型 | 剧情下盘维修 |
| 地点与表现 | 修理铺展示区；复用台灯维修背景、熄灭／点亮状态与工作人员对白，任务对象显示为展示灯接线端 |
| 前置与并存 | T-M02已创建且未完成；与其它修理铺事件并存。已开始维修可跨时段完成；未开始时夜间显示白天开放 |
| 处理耗时 | 成功、失败、撤退均2格；准备、配装和关卡预览0格 |
| 固定与随机盘面 | 完整复用EV-N02：固定接线端L、P-002计量棘轮、P-003爆破线圈、P-001惯性撞锤与P-014铆合钳；这4枚关键件计入初盘6枚，其余2枚普通零件与两次局内奖励候选按EV-N02配置随机生成 |
| 关卡规则 | 一关一轮3拍，累计目标60分；特殊目标为接线端维修进度达到1／1；公共维修能量初始0，机械臂2次，携带上限6种 |
| 永久结算差异 | 不发放EV-N02的40维修费或铜芯线；局内奖励仍仅在本关有效 |

玩家先用计量棘轮积累公共维修能量，再触发铆合钳修好接线端。展示灯亮起后，仍须用完本轮3拍并满足60分才通过，避免“点亮即跳关”绕过完整连锁过程。

| 结果 | 时间 | 状态变化与奖励 |
|---|---:|---|
| 成功 | 2格 | 展示灯点亮，T-M02变为可领奖；展示区立即显示照明状态；无现场永久奖励 |
| 失败 | 2格 | 灯仍闪烁；任务保留，下次从本关初态重试；无奖励 |
| 撤退 | 2格 | 工作人员暂用临时灯；任务保留，下次从本关初态重试；无奖励 |
| 中断 | 0格 | 恢复同一次维修尝试的轮存档，不重复扣时或生成奖励 |

## 领奖与表现

任务页领取40维修费后，状态为“已领奖”；展示灯保持点亮，反复查看展示区和已完成对白免费。失败不引入展示区损坏、信誉或资源惩罚。
