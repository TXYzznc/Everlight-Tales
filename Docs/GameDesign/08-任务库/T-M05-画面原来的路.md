# T-M05 画面原来的路

> 主线证据任务。它把T-M01获得的异常回应转化为可用于画壁救援的结构依据；旧照片与构件流转两项证据均落实为独立地图调查。

## 任务资料

| 字段 | 配置 |
|---|---|
| 任务类型 | 主线调查 |
| 创建条件 | T-M01《画里的敲击》成功后 |
| 任务页名称与目标 | 画面原来的路；找到旧照片并核对构件流转 |
| 关联事件 | EV-TM05-01 旧照片调查；EV-TM05-02 运输记录核对；EV-TM05-03 许渡账本交接（替代EV-TM05-02的证据来源） |
| 完成条件 | 旧照片证据与任一流转证据均已取得 |
| 任务结果 | 自动生成“画面结构对照图”，写入L-04画壁的接应准备条件；不设置维修费、材料或图样奖励 |
| 持续规则 | 长期保留；未开放的证据在任务页显示已知开放条件，不因昼夜刷新消失 |

这项任务的回报是明确“旧出口在哪里、哪两块构件被错接、从哪里仍能接到画中回应”。它不设置额外资源奖励，因为证据本身直接改变后续画壁关的已知固定信息与可用准备条件。

## EV-TM05-01 旧照片调查

| 字段 | 配置 |
|---|---|
| 地点与人物 | 书店／林岑；复用地方展览册、旧照片与当前画面并排图 |
| 开放时段 | 上午、下午；T-M05创建后长期可处理 |
| 玩家操作 | 查看桥头、招牌、画边三个热点，再选择发生通路变化的位置 |
| 正确提交 | “桥头通向画边的小路被接到街道中央” |
| 干扰信息 | 招牌褪色、路人姿势变化；可查看但不是道路结论 |
| 耗时 | 成功、错误提交、撤退均1格；查看与提交前改选免费 |
| 成功结果 | 写入旧出口和道路错接记录；无现场资源奖励 |
| 重试 | 错误或撤退后保留任务，下一次从本调查重新处理 |

画面必须以明显的连线差异呈现道路变更，不把正确性建立在辨识极小像素或猜作者意图上。

## 流转证据：两条入口，共用一个进度

任务页把第二项目标显示为“核对构件流转（0／1）”。以下任一事件成功都将其设为1／1，另一个入口转为可选补充对话，不再给予第二份任务进度或资源。

### EV-TM05-02 运输记录核对

| 字段 | 配置 |
|---|---|
| 地点与人物 | 收藏馆／陆宁；旧清单、运输编号和现有拼装记录三个文件热点 |
| 开放条件 | S3已开启，且流转证据尚未由许渡账本取得 |
| 开放时段 | 上午、下午；满足条件后长期保留 |
| 玩家操作 | 按运输编号将两块构件与现有拼装位置配对后提交 |
| 正确提交 | 确认两块构件在运输后交换位置，导致出口与街道中央错接 |
| 耗时 | 成功、错误提交、撤退均1格 |
| 成功结果 | 写入流转证据；陆宁承认曾注意到画面变化却沿用错误拼装；无现场资源奖励 |
| 重试 | 错误或撤退后保留本步骤；旧照片证据保留 |

### EV-TM05-03 许渡账本交接

| 字段 | 配置 |
|---|---|
| 地点与人物 | 许渡的二手仓库／许渡 |
| 开放条件 | L-03猴爪完成后，许渡的回访事件已出现，且流转证据尚未取得 |
| 开放时段 | 上午、下午；回访长期保留，错过窗口等待下个白天窗口 |
| 玩家操作 | 查看许渡主动交出的账本，选择“记录画作构件的转手批次”作为需要抄录的条目 |
| 正确结果 | 账本给出与运输记录相同的两块构件交换事实 |
| 耗时 | 成功、错误提交、撤退均1格 |
| 成功结果 | 写入流转证据；EV-TM05-02改为收藏馆补充对话；无现场资源奖励 |
| 重试 | 错误或撤退后保留本步骤；旧照片证据保留 |

许渡账本是猴爪结案后的人物回访内容之一。它提供替代证据，避免玩家必须等待S3或重复完成同一条信息；它不改变L-03的奖励归属。

## 完成与画壁衔接

两项目标满足后，系统自动生成结构对照图，T-M05状态变为“资料齐备”。对照图免费可查看，标明旧出口、错接位置和可回应区域；它不消耗、不可出售，也不进入材料或收藏库存。

| 结果 | 时间 | 状态变化与奖励 |
|---|---:|---|
| 任一调查成功 | 1格 | 保存对应证据，更新任务进度；无资源奖励 |
| 两类证据齐备 | 已包含在第二次成功结算中 | 自动生成结构对照图，写入L-04接应准备条件；无领奖按钮 |
| 错误提交或撤退 | 当前步骤完整1格 | 当前步骤可重试，另一项已完成证据保留 |
| 中断 | 0格 | 保存当前未提交选择，不推进时间或重复结算 |

T-M05不额外改变B4资格。即使资料提前齐备，也只在B4资格与画壁本案其他触发条件满足后开放正式救援；资料不会失效，也不需要重复取得。
