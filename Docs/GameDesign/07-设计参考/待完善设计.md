# 设计细化清单

本页区分已确认设计、待评阅方案、尚未设计和主动暂缓。设计确认不等于实际实现或试玩通过。[设计决定](设计决定.md)记录已确认内容。

## 已确认，可以进入实现与试玩

- 触发分、自身效果分、维修效果分独立结算；公共维修能量由效果产出；修复进度1～5，每次有效维修+1、对象计20分。
- 用完本轮拍数且累计分数和特殊目标达标才过轮；分数及盘面跨轮继承，跨关独立；怪谈失败保留此前成功关。
- 四选一同池抽四个不同奖励；满层Buff退出候选；零件奖励持续可抽；Buff筛选作用于场上符合条件的对象。
- 零件永久拥有，改装改变工作方式；已解锁形态局外自由切换、入场固定；异化零件失去维修效果。
- 红舞鞋第一关完整配置（D-051）；四种F类形态、获取任务和试机（D-060～D-062）；加工经济与F类、M类完整配方（D-083～D-084）。
- 携带上限6种（D-063）；首批普通维修6枚初盘，关键件占名额，其余随机抽取（D-064）；关键件固定起点、其余随机落位，机械臂初始2次（D-065）。
- 准备页三段结构、两栏携带（未满点击或拖动，满时拖动替换）、只显示固定内容的RawImage关卡预览；每次重新配装，初盘固定与随机混合、每种元素由关卡配置单独指定（D-077、D-080）。详见[维修准备与配装流程](../02-系统设计/16-维修准备与配装流程.md)。
- 一拍循环、第一步预演、事件队列自动播放与左旋右旋双按钮，见[盘面与每拍奖励流程](../02-系统设计/17-盘面与每拍奖励流程.md)（D-078）；播放节拍与预演标记密度待试玩。
- 加工台双功能（解锁消耗维修费与配置材料、切换免费）、当前使用与材料口径，见[加工台与形态切换流程](../02-系统设计/22-加工台与形态切换流程.md)（D-079）。
- 零件图鉴只收录P＋M，条目分已拥有、已知未拥有、完全未知三态；与加工台共用数据源并可跳转，查看不耗时，见[零件图鉴](../02-系统设计/23-零件图鉴.md)（D-081）。
- 六种材料、稀有度三档、来源与用途、维修费唯一货币口径，见[材料与货币](../02-系统设计/24-材料与货币.md)（D-082）。
- 统一事件管理架构定稿（[27](../02-系统设计/27-统一事件管理架构.md)）、新手教学 S0 流程与首个可玩切片（[28](../02-系统设计/28-新手教学与首个可玩切片.md)）、家园陈列／档案重放／拥有物列表、[失败分支索引](失败分支索引.md)、[音画与文本素材清单](音画与文本素材清单.md)均已成文。

20种通用零件已写入具体数值和行为，不再整体标成“未设计”；各条具体参数仍须按其状态评阅、与关卡配套测试。首批20项Buff已有条目和叠加初值，共用规则确认不代表所有上限已确认。

## 主动暂缓

异化暂不全量展开；十五案后再发仅保留概念。净化零件、零件合并及专用工具改成现场装置的范围继续暂缓；灯泵可搬、轨道与出口固定保持已确认状态。日周挑战、赛季、商业化和皮肤上线范围不自动成为首发必做。
