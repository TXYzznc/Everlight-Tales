# 名词表 v1.0

> 以当前文学怪谈双主线为准。时间为测试参考，不写入术语定义。

| 名词 | 当前定义 |
|---|---|
| 白天主线 | 修理铺生活、客户合作、手艺与家园成长，最终完成共同修复展并接手店铺。 |
| 夜晚主线 | 地图异常处理、文学怪谈经历、画中调查与救援。 |
| 异物 | 在游戏城市中具有已知作品或传说对象特征的异常物件或依附物；空间／遭遇型异常不强制物件化。 |
| 怪谈实例 | 某个地点、人物和状态下发生的一次完整异常事件；不是一个孤立规则。 |
| 原作对象 | 已有文学／虚构作品中的物件或存在；D-011 扩展至有明确版本来源的都市传说对象。 |
| 来源 ID | SRC-01～SRC-15，指向档案中的作品／传说版本及核对入口；日本三案注明整理来源。 |
| 怪谈 ID | L-01～L-15，原四案已确认，新增十一案已确认。 |
| 六相定势盘 | 通过现场锚点把异常联系映射为六边形零件结构的校准装置，具有六个合法定势方向。 |
| 定势 | 六相定势盘把当前对准定势座的方向设为异常联系的最低势位；可移动节点在拍击后沿该方向下落。 |
| 拍击 | 提交当前定势方向；角色压下冲击柄，使盘底撞锤发出校准震波并触发一次定势下落与连锁处理。 |
| 机械臂 | 消耗次数把一枚棋子搬到任意合法空格；合法性受已装配规则明确约束。 |
| 任务标记 | 表示受困者通路、异常联系、锚点或出口状态；不一定是人物字面变成棋子。 |
| 一轮游戏／关内维修阶段 | 一关内部的一段目标，由若干拍击推进；不独立扣时或设失败重试点。 |
| 一关游戏 | 一次独立维修事件，通常一晚完成，可含多轮；独立耗时，失败／撤退从本关第一轮重试。 |
| 单关／多关怪谈 | 一次连续维修解决的通常为单关；需跨日继续调查并再次维修的故事为多关，前关成功独立保留。 |
| 一次作业／维修行动 | 对一关的本次尝试，从开始维修到成功、失败或撤退；重试仍是该关的新尝试。 |
| 每轮目标分数 | 本关累计分数门槛；用完本轮拍数后与特殊目标共同判定，跨关清零。 |
| 零件得分效果 | 每种零件均具备的基础效果；各自定义得分算法、触发条件和结算规则，部分零件还具备得分之外的能力。 |
| 连锁收益 | 连续触发中各零件与明示效果产生的实际收益；分数逐次累计，当前不按连锁长度追加统一倍率。 |
| 每轮特殊效果 | 影响棋盘规则或对象行为，可无；不是待完成的目标。 |
| 每轮特殊目标 | 可选的额外过轮要求；有则全部完成，并列在目标分数下方。 |
| 维修能量 | 当前关的公共资源，须通过明确方式产出，供已配置的维修效果消耗；与各枚零件的自身能量分开记录。 |
| 零件能量 | 单枚零件用于执行自身效果的能量，逐次检查与消耗。能量不足仍有触发分，维修效果独立使用公共维修能量。 |
| 规则库 | 包含明确归属、时点、效果及解除方式的当前规则登记来源，单关专属规则也入库。 |
| 当前规则 ID | LR-RS、PS、MP、WP、NX、LS、FM、ZJ、SA、DG、PP、SH、KO、HN、KS 共十五组，53 条文学机械表达，另有 SR 6 条、PR 20 条、MR 15 条、OR 8 条、AR 8 条、CR 15 条共 72 条共用与条目判定，加 6 条地图投放 ER，合计 131 条待试玩。 |
| 基础装配 | CB-RS-01 等，规定阶段引用、参数需求及终局条件。 |
| 规则改写 | 改变特定零件／关系或已登记规则的局内效果，需明确覆盖范围。 |
| 升压协议 | 玩家主动添加危险条件换取挑战表现收益的候选方式。 |
| 家园 | 长明修理铺的生活、加工、收藏与合作空间。 |
| 封存 | 将危险联系隔离并记录受控状态；不等于异物变为普通安全装饰。 |
| 档案重放 | 重玩已完成事件，和现实地图上新发生的剧情实例分开。 |
| 设计基线 | 已确认的故事与产品方向；不表示已经制作或通过试玩。 |
| 工作名 | 为文档沟通统一使用的名称，商业标题／最终命名可以另行确认。 |

## 零件与挑战编号

| 编号 | 定义 |
|---|---|
| P-001～P-020 | 通用零件，能进入携带池的能力载体。 |
| M-001～M-015 | 附着在指定零件上的怪谈形态，本身不额外占格。 |
| O-001～O-008 | 障碍和设施，塑造通路、阻挡与可操作结构。 |
| A-001～A-008 | 棋盘异常，改变区域、方向、时序或盘面演变。 |
| C-001～C-015 | 十五案的具体挑战配置，连接故事目标、任务对象与零件能力；不是另外十五个故事。 |
| SR／PR／MR／OR／AR／CR | 共用、通用零件形态、怪谈形态、障碍、异常、专属挑战的判定登记；与原 LR 共同构成规则库。 |

挑战描述玩家要处理的局面，规则描述该局面如何判定。两者通过编号关联，不把所有内容混作规则清单。

## 地图事件与批次

| 名词 | 定义 |
|---|---|
| 地图事件 | 白天或夜晚可参与的维修、处置、生活、调查或怪谈事件。 |
| 普通事件实例 | 昼夜刷新时生成的一次具体城市事件；处理后结束，未处理则在下一次昼夜交替时退出，不算失败。 |
| 任务系统 | 由事件、任务、怪谈三个页面组成的统一信息入口；可以查看、跟踪和定位，实际事件仍在地图现场处理。 |
| 任务 | 已触发主线或已在现场接受的成长支线记录；可包含多个步骤，完成后在任务页领取奖励。 |
| 怪谈记录 | 已正式触发怪谈的案件进度视图，显示线索、关卡与当前阶段；奖励由对应人物后续交付。 |
| 怪谈事件 | 具有完整故事且较具挑战的事件类型，由具体日夜事件引出。 |
| B批次资格 | 前批基础案完成后允许后批被触发的条件，不是整批刷新。 |
| S玩家阶段 | 零件和挑战首次学习的进度参考，区别于B内容批次。 |
| 基础案完成 | 按L-ID记录夜间故事目标首次成功，独立于领奖回访。 |
| 怪谈再发 | 十五案完成后的既有对象新遭遇概念，目前无续篇规则。 |

ER-001～006登记事件投放规则；独立故事见[怪谈库](../06-怪谈库/00-索引.md)。

## 配装、奖励与中断恢复（D-032）

通用零件形态与怪谈形态均指满足条件并付费解锁的形态，局外自由切换、入场固定；异化指意料之外的变异，仅统一失去维修效果，其他变化逐项设计；Buff指局内奖励效果。每关携带种类数为min(拥有种类数,携带上限)，拍后四选一、换轮三次四选一。分数与盘面跨轮继承。正常失败／撤退按关重试，异常退出／关闭按轮存档恢复同次尝试；恢复资源取自轮存档。

| 名称 | 含义 |
|---|---|
| 触发分 | 每次成立的触发获得的基础分，与自身或公共能量是否充足无关。 |
| 效果分 | 自身效果或维修效果成功执行后取得的分数；自身效果分由零件定义，维修效果分由待维修对象配置，第一版统一20分。 |

维修进度：待维修对象的0／需求值状态，需求暂定1～5；每次有效维修+1并立即按对象计20分，完成后进入明示状态。通用零件形态与怪谈形态不影响维修，异化零件失去维修效果。开关切换不额外加分。
