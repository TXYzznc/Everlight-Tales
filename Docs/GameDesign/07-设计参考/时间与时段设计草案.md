# 时间与时段设计

## 已确认的时间规则

一天四时段，白天两段、夜晚两段；每段4格、每日16格为试配。处理事件才耗时，开始前显示预计耗时与结束时段。成功、失败、撤退统一消耗事件时间；准备、加工、配装和查看免费。

事件可以跨时段完整结束，深夜也可跨到次日上午；玩家可主动等待。怪谈永久等待。每关独立计时，各轮通过不额外扣地图时间。

## 时段内容草案

按D-068逐事件配置开放时段，关键事件错过后等待下一窗口；下表为内容侧重，具体地点与候选见[地图供给配置](../02-系统设计/15-地图供给与事件开放.md)。

| 时段 | 主要功能 | 内容与表现 |
|---|---|---|
| 上午 | 接单、加工整备、接收回访 | 到店客户、沈遥上午感谢（0格）、当天订单；可外出处理已有事务 |
| 下午 | 城市走访、合作与调查 | 工匠合作、学校社区事务、收藏馆记录、普通维修、修复展活动；可回店加工 |
| 夜晚 | 夜间生活、现场调查与怪谈处理 | 夜班商店、居民下班后求助、街区设备处置；有资格并完成调查的怪谈可维修 |
| 深夜 | 特殊夜间内容、继续维修与回店整备 | 末班交通、关店后的场所状态、夜班人员事件；已触发怪谈可继续选择，不统一增加难度 |

## 事件耗时试配

短调查或交付剧情1格、普通维修或临时处置2格、较长维修关卡3～4格；各事件单独配置。具体关卡数值待填写。

## 普通供给与调查（已确认）

D-069：白天4个、夜晚4个普通事件，候选不足则少于4；关键事件另计，做完不补刷。上午／下午共用白天一批，夜晚／深夜共用夜间一批，仅更新事件开放状态。

D-070：资料台免费列当前有资格核实的地点与简短报告；玩家到地图现场处理调查才推进并耗时。关键调查和已获线索保留，不能因跨时段回到未发现状态。
