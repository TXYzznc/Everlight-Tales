# 精简候选与三案对照

已确认精简方向，以及灯泵可由机械臂搬动、轨道出口固定。下面的装置充能、来水触发、零件合并等仍是候选，尚未替换现有规则；用户完整阅读后再决定。本页保留玩法和取舍，不构成新的提问。

## 三案对照：红鞋、画皮、扫帚（候选，未迁移规则）

D-026已确认实际精简方向。本节是可以评阅的玩法对照，不是已验证的关卡布局。正文仅使用已有零件与现场装置，不增加新的玩家分类系统；改变之处明确列出。

### 三案共同的操作

旋转盘面、用机械臂调整可移动对象、拍击。撞击提供推移／触发，转向组织路线，爆破触发周围并开路；玩家学会传导后可将激活送到远处。红鞋首案不因此提前加入传导教学。得分与其他已学零件照常参与，不把示例三四件写成关卡只能使用的名单。

现场灯与泵的试配行为统一为“受到一次有效受击或兼容传导激活，工作一次”。灯执行现有去一层伪装，泵执行现有单次排水。它们由现场配置提供。候选中的灯泵由有效激活驱动；触发是否接得上、位置与既有目标压力构成选择，次数与强度通过试玩调整。该简化不是把全游戏所有零件充能删除。

已确认移动性（D-027）：现场灯、泵可用机械臂搬到明确合法的位置；固定导流轨、接应口、封存口保持固定。灯和泵不受基础定势自动滑动，以免每拍把刚布置好的现场设备全部带走；若将来某装置需要自由滑动，应单列可见特征。此移动约定已确认，不继承全部普通棋子属性。

### 红舞鞋：保留原来的运动解法，删去不必要的旁支

| 项目 | 候选设计 |
| --- | --- |
| 目标 | 分离沈遥与红鞋，再封存鞋 |
| 核心现场 | 持续运动的鞋、导流位置、固定转向轨、封存口 |
| 主要选择 | 用导向／推移反复经过导流，分离后送入封存 |
| 首次学习 | 首次完整例子只突出已有推移、转向及导流；传导、音叉、蓄能等不为凑共同名单提前加入 |

一段操作：先通过方向与机械臂把普通零件安排成接力路线，让鞋经过导流位置；固定轨道带它转回，玩家下一拍继续利用这条路线。分离目标达成后重新安排后续方向，将鞋送到封存口。不是让鞋一直绕圈就算通关，也不靠触发一只通用机器替代救人过程。

红鞋本身已经较集中，不能为了“精简三案”反而改掉其最有辨识度的运动玩法。首遇实际启用数量仍依旧投放规则。

### 画皮：专用照明零件变成现场灯

原案目标保持：辨认顾师傅与画皮，并分别送往救援口、封存口。


一段操作：把撞击零件送向灯，灯亮起，附近对象露出真实特征；后续转向把已辨认对象送往正确方向。若爆点同时邻接灯与脆裂隔板，爆破可以一边打开路线，一边经灯完成照明；爆炸本身没有直接去伪装能力。远处另一盏灯可在传导能力解锁后接入同一条链。

玩家的选择从“还缺一只照明工具／电池”转为“先让哪盏灯亮、照到谁、怎样接上后面的分流”。交换与旋涡仍是后续高级组合候选，不作为此精简例子的必要学习。P-013与P-020的去留待评阅。

### 扫帚：专用排水零件变成现场泵

原案目标保持：所有扫帚回到停止架，水位降到安全范围；爆破劈分会增加后续供水，仍是可反用的风险。


一段操作：用撞击与转向安排连续触发，让泵工作；爆破开路时可能劈分扫帚，下次来水会更多。若爆点靠近泵，可在本次爆破中同时触发排水，再利用后续接力处理新增压力。接好远端传导后，玩家能够同时驱动另一侧设备。水排下去仍未结案，还须把扫帚逐个送回停止架。


### 保留、减少与代价

保留：故事、十五案数量、首遇解锁分段、随机落位、机械臂、持续演变、已确认时间与失败规则。

减少：此三案示例中的专用携带工具、独立设备充能、首遇不需要的高级组合说明。能力的使用方式以“连锁触发现场工作”复用，但红鞋持续运动和扫帚劈分等怪谈特征仍独立存在。

代价：现场提供装置会减少一部分局外携带选择，具体效果与操作体验需评阅。

### 已确认的移动性

D-027确认灯泵可搬，轨道和出口固定；灯泵不随基础定势滑动，使用已有机械臂。

### 装置工作方式候选（已暂缓，读完后再讨论）

推荐三案试配中的灯与泵统一采用：每收到一次有效撞击／爆破受击或兼容传导激活，执行一次工作，工作机会由有效激活决定。灯去一层伪装，泵先试排2单位水；已有核心零件的使用次数不因此取消。搬动装置只是调整位置，不自动算一次激活。

来水只增加水位，不自动驱动泵；排水必须接到玩家组织的连锁上。泵没有水时不产生排水收益，已有怪谈失败阈值和扫帚停止目标保留。激活机会取决于连锁触发，不是无操作持续工作，也不另加统一的每拍一次限制。

这会实质删除此两种现场装置的独立续航管理，并减少原来的来水自驱动玩法。取舍已经明示，尚待用户确认；不扩展为全游戏工具无限使用。




## 优先阅读：概念精简建议（待评阅）

用户已确认精简方向及三案装置移动性；下面具体合并与能力改动仍为待评阅候选。其余未决设计见[待完善设计](待完善设计.md)，不要求逐项立即做决定。已有十五个故事不因精简而删除，规则库和单项文档仍保留。

### 1．最明显的复杂度来源

20种通用零件中，后半部分加入了照明、铆合、声音、排水、缓冲、校准、牵引、补能等能力。加上15个怪谈形态、16个障碍／区域、15个专属挑战，读者需不断切换新词。66份条目不是66种必学系统，但当前展示使这种区别不清。

尤其P-013／014／015／016／018承担具体作业用途；每个案件增加一个专用工具，容易变成识别目标后寻找对应工具，而不是把熟悉零件组合成解法。此为设计风险与精简切入点，不声称已经通过试玩证明。

### 2．先用少量核心零件，再由场景改变用途

每种零件均具备自己的得分效果；额外能力的精简候选包括撞击、爆破、转向、复制、收纳、蓄能、传导。这里的7类额外能力用于展示精简思路，不是确认清单或以后不得新增的上限。剩余条目逐项判断合并、作为改装或留待后续，不直接删除。

| 现有设计 | 精简候选 | 实际改变 |
|---|---|---|
| P-013照明棱镜作为通用携带零件 | 画皮现场提供可被连锁驱动的灯 | 灯由现场提供；通过触发次数、位置与传导路线控制照明 |
| P-015叩击音叉作为通用携带零件 | 花子／吹笛现场提供铃、敲击器或声源 | 撞击或传导触发现场声音；需几次、作用于谁由怪谈定义 |
| P-016排水叶轮作为通用携带零件 | 扫帚现场提供泵 | 同一套连锁驱动排水，水与扫帚继续保持本案特征 |
| P-014铆合钳、P-018校准探针各自作为通用工具 | 合并为“驱动现场作业装置”的交互方式 | 修复和校准依然有不同故事效果，但不各增加一种必须收藏配装的专用工具；实际触发条件需重新写清 |
| 零件能量 | 显示当前量／容量及本次消耗 | 按零件条目支付与补能；蓄量、内容容量按各自作用显示 |
| 15个怪谈形态分别引入专用玩法 | 优先改造玩家已用过的核心零件 | 例如回声奖励让传导件延迟再发一次，不另增一套必须学习的携带工具；原效果变更需明确对照 |

现场装置不要求全部固定，也可以由机械臂调整位置；具体条目明确可移动性。把工具移到现场会减少出门配装的一部分自由，换来通用零件更大的复用范围，不能说这是无代价整理。独立功能确实形成有趣选择的工具仍可保留。

### 3．用同一组零件展现两种怪谈

画皮：撞击触发现场灯，照出身份；转向把目标送向不同出口；爆破可打开通路，也能触发附近灯；传导使远端灯加入同一条链。

扫帚：同样的撞击和传导驱动泵；转向改变零件路径，形成重复触发；爆破在本案仍有劈分扫帚的特殊后果，更多扫帚带来更多水，再利用蓄能组织一次集中处理。

两案保留识别／分流与供水／排水的区别。重点是重复利用已学行为，不把水、身份、愿望或所有怪谈压力强行合成一种“异常值”。这些示例是新的装配建议，不代表现有爆破已经具备照明或排水标签。

### 4．事件与挑战在主阅读层简化

玩家地图重点区分普通事件与怪谈；普通事件内部的维修、调查、对话、交付是具体内容或图标说明，不要求玩家先学习五个系统。后台仍需记录是否关联剧情、可否重复和失败分支，执行已确认三类失败结果，不增加新的进度货币或玩家分类。

障碍、危险区域和怪谈专属挑战都作为“这关现场有什么”呈现；独立文档仍在，设计者不必先记O/A/C分类才读懂案例。批次是怪谈出现顺序，S阶段只保留给内容作者标注解锁，不向玩家叠加一条新的升级线。
