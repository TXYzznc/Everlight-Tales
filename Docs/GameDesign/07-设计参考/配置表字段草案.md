# 配置表字段草案（草案，非冻结）

> **声明**：本文件为**草案**，非冻结口径。首批字段清单仅供 G0 基线占位参考，最终字段以各归属任务为准；本文件不构成与《第一版开发任务表》并行的权威副本。

## 归属说明

每类字段标注最终归属任务 ID；关卡类字段明确归属 `P1-021`（关卡盘面配置表）。「已建骨架」列反映 b02（P0-005）已落地的表骨架字段，供对照核对。

## 事件模板（归属：G1 事件任务）

| 字段 | 含义 | 已建骨架（EventTable） |
|---|---|---|
| 触发条件 | 事件触发的判定条件 | 无（待补） |
| 权重 | 事件抽取时的权重 | 无（待补） |
| 效果引用 | 事件触发的效果引用 | 无（待补） |
| 文本引用 | 事件展示文本引用 | 无（待补） |

> 骨架现状：EventTable 已有 `Name`／`EventType`（事件类型）／`TimeCost`（完成后消耗时间格），与上列草案字段口径不同，最终以 G1 事件任务为准。
