# C-001 红鞋强制运动与分离

> S1／B1，v0.2；首案关卡设计已确认（D-051），数值待实际试玩验证。

本挑战属于L-01红舞鞋：玩家借持续运动制造连锁，导流解除沈遥的束缚，修复封存装置后收容红鞋。由开店教学后的日间节拍器委托或夜间助手求助触发。

## 规则与对象

- RS是规则步进任务实体，不随基础定势下落；接受普通推移与机械臂。机械臂摆入导流格不加进度，规则步进实际经过才计数。
- 每拍3步，导流6次分离人物；分离前受阻束缚+1，达到6失败。
- 唯一待维修对象BOX要求2点进度；适配P-014，每次消耗公共能量2、进度+1、当次+20。完成后保持修好状态。
- 第三轮启用入口并解锁右轨切换，切换不加分；合法交付停止鞋的运动，仍继续普通连锁和剩余拍击。

## 完整首案配置

采用1关3轮、每轮3拍，累计分数30／100／170。第一轮导流至少3次；第二轮分离且BOX维修2/2；第三轮封存。每轮必须用完拍击次数。

初盘、全部坐标、补给、对象状态、逐拍账目、失败与回访统一记录在[第一关：停不下来的排练](../../06-怪谈库/L-01-红舞鞋/03-第一关-停不下来的排练.md)，该文档是本挑战首案装配的配置来源。

首次使用P-001～004和借用P-014。P-005、P-011、P-015属于后续构筑候选，不是首案前置。轨道采用O-004；可选返场LR-RS-05首案不启用。

## 表现与边界

分离时切换沈遥坐下立绘，修复时逐点亮铆钉，封存时播放短震动和匣内闷响。导流、维修、切换、交付分别反馈。分离与封存不单独发维修分；只有有效维修BOX逐次得20分。

普通爆破不能销毁人物或红鞋。分离前束缚到6、必要对象错误丢失、末拍分数或目标不满足均失败；从本关第一轮重试，调查保留。
