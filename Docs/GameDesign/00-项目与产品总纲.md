# 产品总纲 v1.0

> 更新：2026-09-10。双主线、主要故事、任务系统与流程决定已确认；零件、关卡参数和新增详细文本仍按各页状态评阅。阅读入口见[目录](目录.md)。

## 一句话

白天经营修理与加工旧物的店，建立关系、收集并强化零件；夜晚从城市地图前往文学怪谈现场，通过六边形的六相定势盘制造随机应变与爽感连锁、处理异常，再把成果带回第二天的生活。

## 玩家与世界

玩家回到槐江市代管长明修理铺，先通过普通维修认识居民，再处理他们遇到的异物。师父周衡在画作修复期间失联，玩家沿线索进入画壁，完成救援并正式接手店铺。人名地名按当前工作名使用，商业标题未定。

保留已有作品对象的核心特征，改写当代人物和事件。最初确认的四个对象为红舞鞋、画皮、猴爪、画壁；D-011 新增十一案设计后，当前内容库共 15 案，含裂口女、花子、如月车站三条日本都市传说；城市与人物是游戏原创连接框架。异常保留超自然未知，不采用维护网故障或所有物品履行旧职责作为统一解释。

## 体验支柱

1. 连锁爽感与随机应变：六方向旋转、拍击、有限机械臂，让局面形成可利用的连锁。
2. 完整怪谈：每案有作品依据、故事、挑战目的、解决结果与奖励，玩法推进事件。
3. 昼夜双主线：白天有独立生活和成长，夜晚有调查与异常处理，两者互相改变。
4. 收集与强化：家园积累物件、知识、工具、零件和合作服务；后续加入皮肤奖励。
5. 持续挑战：基础故事成立后，再用规则变体、局内Buff与异化、高分和难度组合增加重玩。

## 当前边界

- 纯 2D，移动端优先；地图点击地点，以有限背景、立绘状态、对话、音效及少量动画呈现。
- 不依赖 3D 场景、实时物理或实时 PvP。
- 第一版怪谈必须有已知文学／虚构作品对象来源；单关规则也统一入库。
- 已采用白天两段、夜晚两段的时间格框架；每段4格、每日16格为试配起点。处理事件才耗时，查看、加工、配装与盘面操作不额外扣时；普通事件在昼夜交替时刷新，具体供给数量、权重和逐项时长待设计。
- 事件开始前显示预计耗时，成功、失败、撤退均消耗本事件完整时间；允许跨时段结束，怪谈永久等待。现实游玩分钟数仅供节奏测试。
- 最初四案和后来新增十一案的主要故事均已确认；实际首个投放批次仅红舞鞋，最小试玩子集、商业首发完整清单、上线节奏另定。


## 内容制作顺序

完整故事与原作对象 → 昼夜目标与结果 → 规则入库和关卡装配 → 小规模试玩 → 校准机制和数值 → 验证变体与组合 → 扩展内容。

## 深化顺序（D-076，2026-09-14）

第一版正式内容必须成立的系统先详细设计，怪谈属于堆量内容。十四案保留完整故事、来源、批次触发、专属挑战与奖励方向，逐关逐轮配置在系统定稿后按批补。顺序与清单见[第一版系统清单与优先级](02-系统设计/00-第一版系统清单与优先级.md)。

## 设计验收与试玩问题

玩家应能说明自己在救谁／处理什么、操作改变了什么、带回什么，以及为什么想继续。试玩再验证拍击可读性、连锁爽感、规则压力、节奏与重玩意愿。原“30 秒理解操作”等作为观察目标，不当作已达成结论。

## 零件与挑战深化（2026-09-08）

D-013 已确认共用零件＋自由异化、局前配装＋现场补充、持续演变。现已交付 [零件库](04-零件库/00-索引.md)与[挑战库](05-挑战库/00-索引.md)，共 62 个独立条目；具体效果与数值为待评阅草案，不代表全部首发或试玩通过。玩家通过多次拍击塑造通路、积累能量、调整危险，再把连锁转成对应案件的救援、断联或封存结果。

## 地图事件与基础怪谈批次（D-015）

地图有普通维修、临时处置、居民生活、调查线索和怪谈五类。怪谈较具挑战，与完整故事关联；普通夜间事件允许玩家在无怪谈的夜晚继续维修、收集和生活。十五份独立故事见[怪谈库](06-怪谈库/00-索引.md)。

五批依次获得触发资格，同批依日夜事件自由触发，可多个并存或零个活跃。本批全部夜间故事目标完成后才能进入下一批资格，回访领奖独立；全部十五案完成后的再发仅保留概念。详见[地图事件](02-系统设计/10-地图事件类型与触发.md)和[批次表](06-怪谈库/01-批次与触发.md)。

## 任务系统（D-034／D-035）

任务系统分为事件、任务和怪谈三个页面。事件页索引当前城市事件并定位地图；任务页记录主线和现场接受的成长支线，完成后从页面领取奖励；怪谈页记录已触发案件的阶段和进度，奖励由对应人物后续交付。普通事件随昼夜交替刷新，任务与怪谈关键事件持续保留。详见[任务系统](02-系统设计/11-任务系统.md)。
