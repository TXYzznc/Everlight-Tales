# 背景资源命名、提示词与接入验收 v0.1

## 1. 目录与命名

背景统一放在 `Assets/Game/Sprites/场景/`，按内容域分目录：

```text
Assets/Game/Sprites/场景/
├── 标题/                 # BG-T01
├── 主页/                 # BG-H01~H07
├── 地图/                 # BG-M01~M02
├── 局内/                 # BG-SC-*（地点昼夜母版）
├── 对话/                 # BG-D01~D05
├── 调查/                 # BG-I01~I05
└── 序章/                 # BG-O01
```

文件名使用 `bg_<区域>_<语义>_<状态>@1080x1920.png`，例如：

- `bg_title_workshop-night@1080x1920.png`
- `bg_home_shell-day@1080x1920.png`
- `bg_dialogue_dance-night@1080x1920.png`
- `bg_investigate_dance_anomaly@1080x1920.png`

前景层使用同一主名加后缀：`_far`、`_mid`、`_fx`；不要在文件名中写个人电脑路径或日期。

## 2. 出图提示词模板

**正向模板**

```text
Everlight Tales, urban ghost-story picture-book game background, [地点与时间],
vertical 9:16 composition, layered far/mid/foreground, paper grain and gouache texture,
cinematic rim light, restrained palette of navy blue and warm copper, clear low-frequency
center for UI readability, no text, no logo, no characters unless specified, no UI widgets,
clean silhouette, mobile game background, high readability at thumbnail size.
```

**异常模板**

```text
Keep the same camera, architecture and prop positions as the normal background.
Add one localized supernatural disturbance: [裂纹/镜面错位/红色反光/幽青雾].
The anomaly occupies less than 15 percent of the frame and stays away from text-safe zones.
```

**负向约束**

```text
no words, no letters, no numbers, no watermark, no UI, no buttons, no card frames,
no random extra doors, no duplicated props, no floating anatomy, no excessive bloom,
no full-screen purple tint, no photorealistic noise, no landscape crop.
```

## 3. Unity 接入验收

- [ ] Sprite 路径落在 `Assets/Game/Sprites/场景/`，Prefab 不引用 `Docs/`、`outputs/` 或绝对路径。
- [ ] 1080×1920 竖屏截图中 SafeArea、Header、Content、Footer、Overlay 均能按页面文档叠放。
- [ ] 日/夜或异常变体的远景透视与母版一致，切换时不会改变地点锚点。
- [ ] 背景本身没有文本和交互图形；所有 UI 由 Prefab 负责。
- [ ] 270×480 缩略图可辨认地点、时段和异常主焦点。
- [ ] 在 100% 与 70% 透明度的遮罩下，页面文字和主按钮均通过可读性检查。
- [ ] 资源导入无 Mipmap、无 Repeat、无透明洞；前景层按需要使用 RGBA。
- [ ] 变体与页面资源表、`UIFormalSpriteCatalog` 或后续场景资源配置完成一对一登记。
