# 界面背景资源矩阵 v0.1

> 资源 ID 是设计追踪 ID，不等同 Unity 资产 GUID。每行是一个界面入口的背景契约；“复用/变体”表示复用同一地点母版后只重绘镜头、时段或前景层。

## 2. 局内地点背景母版

现有 `Assets/Game/Sprites/场景/局内/` 的 10 张昼夜图是地点识别基线，重绘时保持下列锚点不变：

| 地点 | 母版 ID | 必须保留的识别物 | 重绘重点 |
|---|---|---|---|
| 长明修理铺 | `BG-SC-HOME-D/N` | 工作台、常明灯、工具墙 | 暖铜灯晕、油污纸面、夜间窗外冷蓝 |
| 舞蹈教室 | `BG-SC-DANCE-D/N` | 镜墙、节拍器、鞋柜、木地板 | 夜间红舞鞋的朱砂反光；镜面不要反射 UI |
| 街区小店 | `BG-SC-STREET-D/N` | 卷帘门、货架、街灯 | 白天生活杂物；夜间湿地反光与远处车灯 |
| 裁缝铺 | `BG-SC-TAILOR-D/N` | 缝纫机、布料墙、人体模特 | 线、针、布料作为中景节奏；危险状态只加局部红线 |
| 社区活动中心 | `BG-SC-COMMUNITY-D/N` | 公告栏、折叠椅、活动器材 | 白天青绿色生活感；夜间空旷和荧光灯闪烁 |

## 3. 资源拆单与验收顺序

- P0 首批：`BG-T01`、`BG-H01`、`BG-M01`、`BG-P01`、`BG-B01`、`BG-S01`、`BG-D01`（舞蹈教室夜）、`BG-D02`（修理铺昼/夜）、`BG-O01`，共 9 个母版/变体组。
- P1 第二批：5 个地点昼夜重绘、`BG-M02`、`BG-I01~I05`、`BG-D03~D05`。
- P2 第三批：任务、家园五区、服务/来客、资料台、存档和弹窗的复用层与氛围层。
- 每批先交 270×480 缩略图拼板，再交 1080×1920 正式图；缩略图未通过不得进入全尺寸精修。
