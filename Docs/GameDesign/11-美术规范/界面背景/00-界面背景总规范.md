# 界面背景总规范 v0.1

> 目的：为 Everlight Tales 的每个可见界面指定可制作、可接入、可验收的背景方案，替换纯色占位，同时保证 1080×1920 移动端信息可读。本文与 `界面设计文档/界面/00-界面设计总规范.md` 配套；它只定义背景视觉，不改 UI 节点层级或业务规则。
>
> 本轮基线：仓库已有 10 张局内地点昼夜图（尺寸约 941×1672），以及标题页、主页壳、准备页、对话页等文档中的背景占位描述。正式背景统一导出为 1080×1920；现有局内图在重绘时保留地点识别元素，不直接拉伸交付。

## 1. 总体方向

采用“都市怪谈绘本”作为统一视觉语言：现实空间使用冷灰蓝纸面与旧物材质，人物和灯光使用暖铜、朱砂作视觉锚点，怪谈介入时用冷紫与少量幽青切入。背景需要让玩家先读出“我在哪里、现在是什么时段、哪里发生了异常”，再读 UI 文本。

背景不是一张铺满细节的插画。每张背景按三个可独立调整的层制作：

1. **远景层**：建筑、墙面、街道或室内大结构；对比度最低，负责地点识别。
2. **中景层**：工作台、镜子、货架、灯具、门框等叙事物件；提供视觉动线，但避开文字安全区。
3. **前景氛围层**：纸张颗粒、尘埃、灯晕、异常裂纹、窗影或轻雾；可独立叠加、裁切和淡入淡出。

每张图应保留 10% 左右的可裁切边缘，不把重要物件贴到屏幕边缘。禁止把标题、按钮、数值、任务文案烘焙进背景。

## 2. 画布、导出和安全区

| 项目 | 规范 |
|---|---|
| 工作画布 | 2160×3840（2×绘制），竖屏 9:16 |
| Unity 导出 | PNG，1080×1920，RGB；需要透明前景层时另出 RGBA |
| 导入 | `Texture Type=Sprite`、`Sprite Mode=Single`、`Alpha Is Transparency=On`、`Mip Map=Off`、`Wrap=Clamp` |
| 色彩 | sRGB；不得在导出时叠加 UI 颜色滤镜 |
| 顶部安全区 | y=0~220：只放低对比远景或留白，避免标题和时段条争抢 |
| 中部信息区 | y=300~1450：按页面布局表留出文字和列表可读区域 |
| 底部安全区 | y=1540~1920：优先放暗部、地面或低频纹理，供主按钮和弹窗叠放 |
| 对话立绘区 | x=80~1000，按左右立绘挂点预留连续暗部，不放高频线条 |

## 3. 色彩与对比

| 用途 | 主色 | 允许的面积与对比 |
|---|---|---|
| 现实冷底 | `#111A26`、`#243142` | 60%~75%；保证 UI 白字有足够对比 |
| 常明灯/希望 | `#D99B53`、`#E8C47A` | 5%~15%；只做灯、金属边、重要道具高光 |
| 生活/安全 | `#5BB6A6` | 3%~8%；用于白天植物、玻璃、修复完成后的轻色 |
| 怪谈异常 | `#8C6AD2`、`#B35AD0` | 3%~10%；必须附着在异常对象上，不能把全屏染紫 |
| 危险/失控 | `#B54845` | 小于 5%；用于红舞鞋、警示、破损边缘 |
| 文字承载暗部 | `#05080D`，不透明度 72%~92% | 仅作为局部渐变或遮罩，不做整页纯色底 |

背景的最高亮度不超过标题或当前 CTA 的 85%。在缩略图（270×480）下，背景应能辨认地点轮廓，但不能抢过标题、角色脸和当前操作目标。

## 4. 动态处理

- 白天/夜晚优先制作独立底图，不依赖运行时整体染色；同一地点的道具位置、镜头高度和构图锚点保持一致。
- 叙事异常使用前景层或局部遮罩切换，避免替换整张背景造成空间跳变。
- 对话页允许 0.5~1.0 秒的前景雾、灯晕或纸屑循环；循环不能改变可点击区域的边缘。
- 暂停、设置、恢复和全局弹窗复用当前页面背景，叠加 `#05080D` 55%~85% 遮罩与轻微高斯模糊，不再制作一张孤立的纯黑背景。

## 5. 风格检查清单

- [ ] 远景、中景、前景三层可单独隐藏或调暗。
- [ ] 1080×1920 截图下标题、正文、列表和主按钮均可读。
- [ ] 背景没有烘焙文字、按钮、数值或任务状态。
- [ ] 同一地点的昼/夜版本保持镜头、透视和关键物件一致。
- [ ] 怪谈色只出现在异常源、反射、裂纹或局部光晕上。
- [ ] 通过 270×480 缩略图检查后，地点和时段仍可辨认。
- [ ] 文件名、目录和导入设置符合 `03-背景资源命名与接入.md`。

## 6. 制作顺序

1. P0：标题页、主页壳、城市地图、准备页、盘面、结算、对话、序章。
2. P1：五个地图地点昼/夜重绘与地点详情/事件页的镜头变体。
3. P2：任务三页、家园五区、图鉴/资料台、来客/服务、调查、暂停/设置/恢复。
4. P3：15 案怪谈的异常前景层和特殊场景过渡。

先锁 P0 的一套色彩和纸面材质，再批量复制到 P1~P3。若 P0 的缩略图读不出层级，后续资源全部暂停扩展。
