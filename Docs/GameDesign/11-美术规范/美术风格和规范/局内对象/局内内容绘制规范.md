# 局内对象 · 内容绘制规范（图形化硬边数字厚涂）

> 状态：草案（待样张验证）
> 适用范围：**局内对象**——盘面棋子/零件/形态/障碍/异常/待维修对象/对话 NPC 等
> 风格参考：《无畏契约》角色立绘的可迁移绘画语言，见《通用视觉风格分析与生图提示词.md》

## 1. 风格定位

**图形化硬边数字厚涂（graphic hard-edge digital painting）**：以清晰大形为基础，用经过设计的
几何色面组织体积与明暗，结合受控色彩、锐利有变化的边缘、少量顺形体的数字厚涂笔触，
形成兼具空间感与二维绘画感的风格化商业游戏插画。

- **写实度**：形体与光照逻辑可信，表面纹理高度概括。
- **图形化程度**：中高，大色面和几何切面显著，但避免机械低多边形拼贴。
- **完成度**：成熟、干净的商业概念插画；保留绘画感，不做照片抛光。

> **明确：不是马克笔手绘。** 马克笔（重笔触/勾线/飞白）已改为局外海报方向；局内对象用数字厚涂的
> 硬边分面语言，不靠均匀黑描边、不靠噪点颗粒。

## 2. 核心规则（7 条）

1. **受控色盘**：先定 2~4 个主色群，强调色少量；暗部做受控色相偏移（偏冷蓝/灰紫），亮部干净。
2. **大形先行**：先剪影 → 后结构 → 最后细节；几何切面服从实际结构，不随机三角化。
3. **硬边明暗**：亮/中/暗三层，宽阔连续色面，硬边为主；明暗边界贴合真实转折。
4. **材质靠形状与反光**：金属=窄亮反光面、玻璃=高明度透色+边缘反光、布料=宽色面+折线；不靠照片贴图。
5. **笔触**：平整大面 + 少量顺形体方向的数字厚涂；不靠随机碎块/噪点冒充厚涂。
6. **边缘由色差建立**：不用统一等宽黑描边；外轮廓硬、次要边缘软/失边。
7. **细节密度**：焦点精细，非重点区域概括；小尺寸资产进一步压缩色阶与切面。

## 3. 项目配色（套进本风格，替换参考图的青绿/灰蓝）

| 色群 | 色值 | 用途 |
|---|---|---|
| 暖铜（主） | `#E0A858` / `#C88A3A` / `#9A6424` | 机械、零件、暖面 |
| 冷紫（强调/异常） | `#A86AC8` / `#8650A6` | 异常、怪谈、破损光 |
| 深灰蓝（暗部/底） | `#171A20` / `#262B34` | 暗面、背景、中性 |
| 纸白（高光） | `#E8EAF0` | 亮部高光 |

## 4. 与卡纸锚点的关系

所有局内对象统一披一张**卡纸衬底**作为锚点（shader 实时生成）：内容轮廓外扩一圈 + 纸色纸纹 + 投影。
**内容图只画本体、透明背景**，不画卡纸、不画投影。内容风格与卡纸锚点解耦：内容用硬边厚涂，卡纸是统一容器。
