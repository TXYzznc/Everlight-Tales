# 局内对象 · 内容绘制规范（干净清新马克笔）

> 状态：草案（待样张验证）
> 适用范围：**局内对象**——盘面棋子/零件/形态/障碍/异常/待维修对象/对话 NPC 等
> 注意：本规范与 `../马克笔风格规范.md`（局外·海报/立绘/大图）**分开**，两者定位不同。

## 1. 定位：局内 vs 局外

| 维度 | 局内对象（本规范） | 局外（海报/立绘/大图） |
|---|---|---|
| 尺寸 | 小、会动、数量多 | 大、静态、氛围型 |
| 需求 | 清晰、干净、可辨识、强统一 | 氛围、笔触、质感 |
| 锚点 | 卡纸衬底（shader 统一外扩） | 无（靠整体氛围统一） |

## 2. 内容绘制：干净清新马克笔

保留马克笔的纸感与手绘温暖，但相比局外，多两条硬要求：

1. **线条干净**：勾线利落、一笔到位，无飞白乱线、无毛躁；深褐墨线（非纯黑），粗细一致或轻微变化。
2. **质感清新**：色彩明快通透，叠色 1~2 层（不超过 3 层），不叠出脏色、不厚重。

### 语言规则

| 规则 | 说明 |
|---|---|
| 线条干净 | 利落勾线，无毛躁飞白 |
| 色彩清新 | 明快通透，叠色 ≤3 层 |
| 色块明确 | 主色 + 1~2 辅色 + 高光，边界清晰（小尺寸可读） |
| 纸白高光 | 高光用纸白**实色**（禁止透明像素，见通用规范） |
| 淡纸纹 | 轻纸纹保留手绘感，但无重笔触 |
| 异常破格 | 怪谈/破损处允许冷紫发光，但同样干净（非脏晕染） |

## 3. 卡纸锚点（shader 实现，概述）

所有局内对象统一披一张**卡纸衬底**作为锚点——由 shader 实时生成：

- 内容轮廓**向外放大一圈**，填充卡纸材质（纸色 + 纸纹 + 厚度切面 + 投影）。
- 形状**跟随每个对象的内容轮廓**（零件是零件形、NPC 是人形、怪谈物是舞鞋形），因此适用于所有类型对象。
- 参数（外扩宽度、纸色、纸纹、投影）全局统一，改一处全项目一起变。

> 卡纸由 shader 实现，美术**只画内容本体**（透明背景）。具体 shader 参数待技术验证后固化。

## 4. 与局外马克笔的区别（一句话）

局外马克笔靠**重笔触 + 飞白 + 多叠色**做氛围；局内靠**干净线条 + 清新色彩**做清晰，再靠**卡纸**做统一。
