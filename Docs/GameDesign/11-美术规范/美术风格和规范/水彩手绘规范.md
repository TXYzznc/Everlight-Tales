# 水彩手绘风格规范

> 状态：候选（待样张对比）
> 适用范围：全部手绘类美术资源（棋子/零件/形态/障碍/异常/场景/立绘/UI 手绘素材）

## 1. 风格定位

**水彩手绘**，湿画法晕染，承载「熟悉之物陌生化」——暖铜秩序 × 冷紫混沌。
水彩的颜料渗透/晕染天然契合"异常侵蚀"：冷紫像颜料一样从物件裂缝渗入、晕开，
是四种候选里"异常"表现力最强的一种。

## 2. 水彩语言规则（所有素材统一遵守）

### 规则 1 · 纸纹 + 纸白高光
粗纹水彩纸质感；高光/亮部靠纸白（**实色，不透明**，见《马克笔风格规范》第四条通用约定），禁止透明像素。

### 规则 2 · 湿画晕染
颜色边缘有柔和的晕开与水痕（bloom / backrun），明暗靠透明叠色，不用硬边缘。

### 规则 3 · 透明叠色
暖铜走 **赭石 → 熟褐 → 镉橙**，冷紫走 **紫 → 蓝紫 → 靛蓝**，色彩透明、互相渗透。

### 规则 4 · 边缘干笔
物件轮廓用干笔/枯笔（dry brush）画断续的水痕边，不要太实；留出"手"的痕迹。

### 规则 5 · 异常破格
异常侵蚀处允许最重的晕染与冷紫扩散——水彩的"颜料渗入"就是陌生化本身，是唯一可以大幅晕开的区域。

## 3. 定调样张（半侵蚀座钟）

- 左半暖铜：赭石/熟褐水彩晕染，干笔勾齿轮，纸白留高光。
- 右半冷紫异常：紫/蓝紫湿画晕开，颜料从裂缝"渗"出来，边缘留水痕/backrun。
- 交界：冷暖颜料互相渗透的湿痕带。
- 氛围：比马克笔更"湿、软、诗意"，恐怖感更"渗人"。

## 5. 对比马克笔

| 维度 | 水彩 | 马克笔 |
|---|---|---|
| 异常表现 | 最强（颜料渗入） | 强（荧光破格） |
| 精密机械感 | 较弱 | 强（笔触力度） |
| 数字化稳定性 | 易脏灰、叠色难控 | 稳定 |
| 气质 | 诗意、湿润、渗人 | 温暖、利落、温柔 |
