# 铜版画蚀刻排线风格规范

> 状态：候选（待样张对比）
> 适用范围：全部手绘类美术资源（棋子/零件/形态/障碍/异常/场景/立绘/UI 手绘素材）

## 1. 风格定位

**铜版画 / 蚀刻（etching / engraving）**，用细密平行排线（hatching / cross-hatching）
塑造明暗与体积，金属感、精密感最强，古典厚重。契合"精密机械"的极致表达。

## 2. 排线语言规则（所有素材统一遵守）

### 规则 1 · 单色墨线主骨架
主体用墨黑/深褐排线；明暗**完全靠排线密度**（疏=亮、密=暗），不靠平涂上色。

### 规则 2 · 排线方向随形体
齿轮用同心/放射排线，平面用单向平行排线，转折处交叉排线（cross-hatching）。

### 规则 3 · 纸白为高光
最亮处纸白（**实色**），靠排线密度渐变过渡到暗部；禁止透明像素留白。

### 规则 4 · 金属质感分墨
黄铜件用暖褐墨排线，钢件用冷灰墨排线；可加"飞尘法 aquatint"的颗粒底做灰面。

### 规则 5 · 异常破格
异常侵蚀处排线**扭曲、断裂、搅乱**（秩序崩溃），冷紫作为"唯一的一抹色"（油墨渗漏/套色版画的第二色）。

## 3. 定调样张（半侵蚀座钟）

- 左半暖铜：细密同心排线画齿轮、罗马数字，暖褐墨。
- 右半冷紫异常：排线扭曲断裂，冷紫油墨渗漏，表盘数字融化。
- 氛围：冷硬、古典、精密——秩序被搅乱的那一瞬间极有冲击。

## 4. 参考作品

- 丢勒《忧郁 I》的排线（古典铜版画）。
- 蚀刻版画、木刻版画。
- 博物学插图（机械/钟表铜版画）。

## 5. 对比马克笔

| 维度 | 铜版画排线 | 马克笔 |
|---|---|---|
| 精密机械感 | 最强 | 强 |
| 手作温度 | 弱（冷硬古典） | 强 |
| 异常表现 | 强（秩序崩溃的排线） | 强 |
| 气质 | 冷硬、厚重、精密 | 温暖、利落、温柔 |
