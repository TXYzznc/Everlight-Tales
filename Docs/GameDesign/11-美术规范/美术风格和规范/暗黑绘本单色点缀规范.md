# 暗黑绘本单色点缀风格规范

> 状态：候选（待样张对比）
> 适用范围：全部手绘类美术资源（棋子/零件/形态/障碍/异常/场景/立绘/UI 手绘素材）

## 1. 风格定位

**暗黑绘本 / 单色点缀**（参考《Gris》《LIMBO》《Inside》的极简负空间），
大面积纸白留白 + 单一墨色 + 一个强调色，靠构图与负空间营造情绪，氛围高级、克制。

## 2. 语言规则（所有素材统一遵守）

### 规则 1 · 大面积负空间
纸白占画面 60% 以上，物件只占小部分，靠留白制造孤独/不安。

### 规则 2 · 单一墨色主骨架
墨黑/深灰勾轮廓 + 局部排线/平涂，不用多彩。

### 规则 3 · 一个强调色
全图只用**一个**强调色（冷紫异常 或 暖铜），只点缀在关键处；其余全部墨色。

### 规则 4 · 纸白为高光与空间
纸白是核心表现手段（**实色**）；禁止透明像素留白。

### 规则 5 · 异常破格
异常侵蚀是**全图唯一有颜色的地方**——冷紫从裂缝渗出，其余全部墨色。"颜色只属于异常"是这个风格最有力的一笔。

## 3. 定调样张（半侵蚀座钟）

- 大面积纸白背景，座钟墨黑/深灰勾轮廓，暖铜用极少量的暖褐点缀。
- 右半异常侵蚀：唯一浓烈的冷紫从裂缝渗出，其余全是墨线。
- 氛围：极简、高级、孤独——"颜色只属于异常"。

## 4. 参考作品

- 《Gris》《LIMBO》《Inside》的极简负空间。
- 单色绘本 + 点缀色插画。

## 5. 对比马克笔

| 维度 | 暗黑绘本 | 马克笔 |
|---|---|---|
| 氛围/高级感 | 最强 | 中 |
| 信息密度 | 弱（图鉴量大时单调） | 强 |
| 内容量大适配 | 弱 | 强 |
| 气质 | 极简、孤独、高级 | 温暖、利落、温柔 |
