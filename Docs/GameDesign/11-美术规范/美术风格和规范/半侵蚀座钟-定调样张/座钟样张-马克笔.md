# 半侵蚀座钟 · 定调样张（马克笔手绘）

> 用途：拿去生成一张效果图，对照下方验收要点判断风格是否达标。
> 对应规范：`../马克笔风格规范.md`

## 1. 内容设计

- **主体**：一台老式黄铜座钟（mantel clock），正面，居中构图。
- **左半（秩序）**：精密完好——黄铜齿轮、罗马数字表盘、拉丝金属质感，暖铜色。
- **右半（异常）**：被侵蚀——金属起皱剥落、表盘数字融化下淌、裂缝渗出冷紫色藤蔓状纹样，微微发光。
- **交界**：一道斜向侵蚀边界，冷暖光在此过渡。
- **光影**：左侧暖黄光，右侧冷紫幽光。
- **点睛**：侵蚀区的时针扭成不自然的角度。
- **氛围**：安静、不安——"不是坏了，是活着，而且不对"；温柔画风画诡异内容。

## 2. 中文提示词（可直接复制）

> 马克笔手绘插画。一台老式黄铜座钟的正面特写，居中构图。左半边精密完好：黄铜齿轮、罗马数字表盘、拉丝金属质感。右半边被异常侵蚀：金属起皱剥落、表盘数字融化往下淌、裂缝里渗出冷紫色藤蔓状纹样并微微发光。酒精马克笔叠色质感：暖铜用黄→橙→棕叠色，冷紫用紫→蓝紫叠色；深褐色针管笔勾线，笔触可见，淡米黄纸纹颗粒底。左侧暖黄光、右侧冷紫幽光，交界处冷暖光过渡。侵蚀区的时针扭曲成不自然的角度。安静、不安的氛围，温柔画风画诡异内容。

## 5. 验收要点

- [ ] 手绘质感（笔触/纸纹可见），非数字平涂
- [ ] 冷暖分明：左暖铜、右冷紫
- [ ] 异常处"发光破格"（全图唯一发光处）
- [ ] 温柔画风 × 诡异内容的反差感
- [ ] 高光为实色，无透明洞
