# 半侵蚀座钟 · 定调样张（暗黑绘本单色点缀）

> 用途：拿去生成一张效果图，对照下方验收要点判断风格是否达标。
> 对应规范：`../暗黑绘本单色点缀规范.md`

## 1. 内容设计

- **主体**：一台老式黄铜座钟（mantel clock），正面，居中偏下。
- **背景**：大面积纸白留白（占画面 60% 以上），负空间构图。
- **左半（秩序）**：墨黑/深灰勾轮廓 + 局部排线，暖褐极少点缀黄铜齿轮与罗马数字表盘。
- **右半（异常）**：金属轮廓扭曲、表盘数字融化，裂缝渗出**全图唯一的浓烈冷紫**（其余全部墨色）。
- **点睛**：侵蚀区的时针扭曲。
- **氛围**：极简、孤独、高级——"颜色只属于异常"。

## 2. 中文提示词（可直接复制）

> 极简暗黑绘本插画，单色点缀风格。大面积留白的纸白背景（占画面 60% 以上）。一台老式黄铜座钟的正面，居中偏下，用墨黑/深灰勾轮廓加局部排线，暖褐极少点缀黄铜齿轮与罗马数字表盘。右半边被异常侵蚀：金属轮廓扭曲、表盘数字融化，裂缝渗出全图唯一的浓烈冷紫色（其余全部墨色）。负空间构图，纸白为高光，孤独、安静、高级的不安氛围。

## 5. 验收要点

- [ ] 大面积纸白负空间（60%+）
- [ ] 墨黑/深灰单色主骨架
- [ ] 冷紫是唯一浓烈的彩色（其余全部墨色）
- [ ] 极简、孤独、高级的构图
- [ ] 纸白高光（实色），无透明洞
