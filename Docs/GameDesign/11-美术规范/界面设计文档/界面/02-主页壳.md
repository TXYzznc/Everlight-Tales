# 02 · 主页壳

> 对应脚本：`Assets/Game/Scripts/EverlightTales/UI/MainPageShell.cs`、`SafeAreaFitter.cs`
> 对应预制体：`Assets/Game/Prefabs/UI/MainPageShell.prefab`（无契约文件，数值取自预制体 YAML）
> 承载方式：预制体（UIForm，`UIViews.MainPageShell`）

---

## 1. 界面概述

游戏的主容器。**它不是一张独立界面，而是四个页签内容的共同外壳**——
顶部功能区 + 中间内容区 + 底部四页签栏，内容区由地图 / 任务 / 家园 / 工作台四块轮换填充。

- 打开入口：标题页选档后 / 序章结束后
- 内容区实际内容：`MapPanel` / `JournalPanel` / `HomePanel`（家园与工作台共用同一实例的不同分区）
- 安全区：`SafeAreaFitter` 把 `SafeArea` 节点适配到 `Screen.safeArea`

## 2. 布局规格（基准 1080×1920）

```
┌──────────────────────────────────────────┐ y=0
│ ← 返回      Everlight Tales               │  TopBar 高 140
├──────────────────────────────────────────┤ y=140
│                                          │
│                                          │
│           内容区 Content                  │  Content: y 偏移 +10, 高 = 屏高 − 300
│     （地图 / 任务 / 家园 / 工作台）        │  即 y ∈ [150, 1770]
│                                          │
│                                          │
├──────────────────────────────────────────┤ y=1760
│   地图  │  任务  │  家园  │  工作台        │  TabBar 高 160
└──────────────────────────────────────────┘ y=1920
```

| 控件 | 尺寸 | 状态 | 视觉变化 |
|---|---|---|---|
| 返回按钮 | 200×80 | `normal` / `hover` / `pressed` / `disabled` | 同 `SHR-022`；hover 时描边转暖铜 |

## 8. 验收要点

- [ ] 顶部条与底部条视觉对称，像同一套材质的上下夹板
- [ ] 四个页签等宽，图标在同一水平线上，文字基线对齐
- [ ] 选中页签的三重表达（文字变亮 + 图标升温 + 暖铜指示条）同时出现，不冲突
- [ ] 内容区左右各留 40px，不与屏幕边缘贴死
- [ ] 底部条高度足以容纳手势条安全区（SafeAreaFitter 会再内缩，设计时按最坏情况考虑）
- [ ] 页签 `hover` 与 `active` 可区分：hover 只提亮，active 一定带暖铜指示条
