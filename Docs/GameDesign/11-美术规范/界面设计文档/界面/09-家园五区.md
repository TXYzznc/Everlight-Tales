> 对应脚本：`Assets/Game/Scripts/EverlightTales/UI/HomePanel.cs`

> 策划出处：`02-系统设计/07-家园收集强化与奖励.md`、`03-玩家体验/02-昼夜双主线剧情.md`

## 1. 界面概述

家园是玩家在「白天经营」这条主线上的据点，也是所有**非盘面功能**的集合入口。

五个区（`ZoneNames`）：**来客 / 加工 / 收藏 / 保管 / 服务**

| 区 | 索引 | 承载 | 详情文档 |
|---|---|---|---|
| 来客 | 0 | 沈遥感谢领取 + 当天到店委托 + 改装支线入口 | 本文档 §2.2 + `13-来客区.md` |
| 加工 | 1 | 复用 `WorkbenchPanel` | `10-加工台.md` |
| 收藏 | 2 | 复用 `CodexPanel`（默认落在此区） | `11-图鉴与资料台.md` |
| 保管 | 3 | 复用 `ArchivePanel` | `12-保管区与材料背包.md` |
| 服务 | 4 | 复用 `ServicePanel` | `14-服务区.md` |

> **主页壳 Tab 2 与 Tab 3 都进入本界面**：
> Tab 2 → `ShowZone(2)`（收藏），Tab 3 → `ShowZone(1)`（加工）。
> 因此家园的五个区共用一个实例，**切换页签不会重建面板**（避免状态不同步）。

```

│                                          │
│            content_area                  │  五区内容容器
│   （由各子面板填充，见各自文档）           │  y 偏移 -48, 高 = 内容高 − 96
```

### 2.1 五区导航条

| 元素 | 锚点 | 位置 | 尺寸 | 颜色 |
|---|---|---|---|---|
| home_top 底 | min(0,1) max(1,1) pivot(0.5,1) | (0,0) | (0,96) | `UIFactory.BgDark` ≈ `#1A1F29` @92% |
| 五区按钮 | — | `(-380 + i·190, -24)` | (180,56) | 选中 `ButtonGreen`(0.26,0.52,0.34) ≈ `#428557` / 未选 `ButtonBlue`(0.30,0.42,0.55) ≈ `#4D6B8C` |
| 按钮文字 | — | 居中 | 字号 26 | `#FFFFFF` |

**按钮横向布局计算**：`buttonWidth = 190`；`startX = -190 × (5−1) × 0.5 = -380`；
第 i 个按钮 x = `-380 + i × 190`，按钮实际宽 `190 − 10 = 180`（间距 10）。
五按钮总宽 `5 × 190 = 950`，居中在 1080 宽内（左右各留 65）。

## 10. Prefab 制作契约（文档确认后执行）

> 本节只描述 Prefab 制作，不生成效果图。Assets/Test 中对应的 Image 仅用于 1080×1920 PlayMode 对照验收；运行时禁止把整张对照图挂到页面上。

### 10.1 页面根节点与布局基准

| 项目 | 约束 |
|---|---|
| 设计分辨率 | 1080×1920 竖屏；Canvas Scaler 使用 Scale With Screen Size；SafeArea 内缩 |
| 页面根节点 | UIForm → SafeArea → 背景/固定层/内容层/弹窗层 |
| 对照图 | 仅用于截图对照，不作为 Prefab 子节点或运行时资源 |

### 10.2 节点树与节点职责

页面必须包含 SafeArea、Background、Header、Content、Footer、Overlay。Background 位于最底层并只绑定正式背景；Header 顶部 Stretch，包含标题、返回和状态条；Content 位于 Header 与 Footer 之间，列表只保留动态容器；Footer 底部 Stretch，按钮同一基线；Overlay 覆盖 SafeArea，默认隐藏并负责弹窗、Toast、Loading。

### 10.3 逐节点设计表

| 节点名 | 父节点 | 锚点/尺寸 | 组件职责 | 正式资源路径 | 状态 |
|---|---|---|---|---|---|
| Txt_Title | Header | 左上；距左48、距上32；高64 | TMP 页面标题 | 无；项目字体材质 | 始终显示 |
| Btn_Back | Header | 右上；48×48 触控区 | Button 返回上级 | 本页资源表指定 ICO-* | 可用/禁用 |
| ScrollViewport | Content | 四边 Stretch | Mask 裁切内容 | 无 | 超出时滚动 |
| ContentRoot | ScrollViewport | 顶部 Stretch | LayoutGroup 承载运行时 Item | 无 | 只含动态实例 |
| Btn_Primary | Footer | 底部居中 | Button 主流程动作 | Assets/Game/Sprites/UI/控件/SHR-021-*主按钮.png | normal/hover/pressed/disabled |
| Btn_Secondary | Footer | 与主按钮同基线 | Button 次流程动作 | Assets/Game/Sprites/UI/控件/SHR-022-*次按钮.png | normal/hover/pressed/disabled |
| Overlay | 页面根节点 | Stretch | CanvasGroup 阻挡输入 | SHR-041/042/002，按页面资源表 | 默认隐藏 |

### 10.4 UIItem 模板与动态创建

页面 Prefab 只保存模板引用字段和动态容器，不保存重复 Item 实例。每种重复对象在 Assets/Game/Prefabs/UI/Item/<ItemName>.prefab 独立制作，根节点挂 Item 脚本和 GF UIItemObject；图标、标题、详情、数值/操作的相对关系固定。页面打开、刷新或切换分类时从对象池创建，关闭或切换页面时回收，空列表显示 Empty 节点。Item 只负责视图绑定、状态切换和事件转发。

### 10.5 正式资源接入规则

1. 每条资源必须解析为 Assets/Game/Sprites/UI 下的实际文件。
2. SHR 九宫格使用 Image.Type.Sliced；图标使用 preserveAspect。
3. 控件状态按文件名后缀绑定；缺失状态按资源表回退。
4. 资源缺失、节点缺失、节点重复或引用对照图均记入差异表。

### 10.6 制作与验收顺序

1. 按节点树创建固定节点并设置 1080×1920 锚点。
2. 按资源表绑定正式 Sprite、字体和控件状态。
