# 04 · 地点详情与事件卡

> 对应脚本：`Assets/Game/Scripts/EverlightTales/UI/MapPanel.cs`（`BuildPlacePanel` / `UpdatePlacePanel` / `AddEventEntry`）
> 承载方式：程序化构建，作为城市地图底部的常驻面板 + `GlobalUI.Confirm` 弹窗
> 说明：本界面与「03 城市地图」是同一个页签内的上下两层，此处单独成文是因为
> **地点信息层与事件确认层是玩家做决策的地方**，美术上需要单独出效果图。

---

## 1. 界面概述

玩家点地图节点后，底部面板变成该地点的详情；点面板内的事件卡，弹出确认弹窗（事件详情页）。
这两层共同回答三个问题：**这是哪／这里有什么／我现在要不要做**。

- 触发：`OnNodeClicked(placeId)` → `UpdatePlacePanel()`
- 事件卡来源：硬编码的卷帘门（home 地点）+ `WorldSession.Supply` 中该地点的普通供给
- 交互结果：点事件卡 → `GlobalUI.Confirm(名称, 详情, 开始, 取消)` → 开始则进准备页

## 6. 交互控件状态

| 控件 | 尺寸 | 状态 | 视觉变化 |
|---|---|---|---|
| 事件卡 | 1000×56 | `normal` / `hover` / `pressed` / `disabled` | normal 底 `#2E3640`；hover 底抬到 `#3A4350` + 左侧类型色条加宽到 12px；pressed 底压到 `#262D36`；disabled 整体 50% 透明、类型色条去饱和 |
| 等待按钮 | 360×52 | `normal` / `hover` / `pressed` / `disabled` | 同 `SHR-022` 次按钮；`disabled` 用于时段已到深夜（无可推进） |
| 弹窗确认按钮 | 基准 160×64（弹窗内两按钮等宽） | `normal` / `hover` / `pressed` / `disabled` | 用 `SHR-021` 主按钮（确认）与 `SHR-022` 次按钮（取消） |
| 地点名（无交互） | — | — | 无状态 |

> **按钮顺序与宽度**：`DialogView` 的按钮由 `m_Buttons` 数组决定数量（1 个或 2 个）。
> 单按钮时（`ShowDialog`）应居中且占满可用宽度；双按钮时左右等分。
> 设计时须同时给出「单按钮」与「双按钮」两种排版的效果示意。

## 8. 验收要点

- [ ] 地点名 → 描述 → 事件卡 → 按钮 的层级在缩略图下成立
- [ ] 事件卡的「名称 22 / 元信息 16」字号差足够，不会读成一段
- [ ] 类型色条颜色与 `EventKind` 一一对应，六种可区分
- [ ] 弹窗正文的多行信息（说明/前置/奖励）有明确分行感，不糊成一片
- [ ] 单按钮弹窗与双按钮弹窗都做了排版（且按钮宽度合理，不出现半宽悬空）
- [ ] 遮罩透明度足够压暗背景但不至于看不见上下文
- [ ] 事件卡 disabled 态与 normal 态一眼可分
