## 1. 界面概述

### 1.1 暂停菜单（盘面内）

四个动作（`PauseAction`）：

| 按钮 | 行为 | 备注 |
|---|---|---|
| **继续** | 关闭菜单 | |
| **设置** | 打开设置界面（`UIViews.Settings`） | |
| **规则** | 弹窗展示本关规则与目标 | 只显示已取得的规则信息 |
| **放弃** | 撤退流程：确认弹窗 → 按撤退结算 → 结算页 | **建议改用危险按钮** |

- 打开入口：盘面页右上角「暂停」按钮
- 背景：半透明深色遮罩，**点背景可关闭**（等同继续）

### 1.2 设置界面

两个音量滑块 + 关闭按钮：

| 控件 | 数据 | 持久化 |
|---|---|---|
| 音乐音量 | `SettingsService.MusicVolume` | `PlayerPrefs["et.settings.music"]` |
| 音效音量 | `SettingsService.SfxVolume` | `PlayerPrefs["et.settings.sfx"]` |
| 关闭 | 走框架关闭流程 | — |

- 打开入口：暂停菜单「设置」/ 服务区「设置」
- 数据应用：`GameAudio.SetMusicVolume` / `SetSoundVolume`

**数值文案**：`Mathf.RoundToInt(volume × 100) + "%"`，如「80%」。

> **滑块结构要点**：`Sld_Music` 自身的 Image 是**轨道底**（`#2F3540`），
> `Fill_Music` 是**已填充部分**（暖铜），`Handle_Music` 是**滑块**（纸白）。
> 三者是三个独立 Image，**需要三套素材**（轨道 / 填充 / 滑块），
> 且滑块的尺寸是 24×56（窄长条），不是常见的圆形。

## 6. 交互控件状态

| 控件 | 尺寸 | 状态 | 视觉变化 |
|---|---|---|---|
| 暂停菜单按钮 ×4 | 320×72 | `normal` / `hover` / `pressed` / `disabled` | normal 底 `#4D6B8C`；hover 亮度 +10% + 左缘 3px 暖铜；pressed 下沉 2px。**「放弃」单独一套危险色** |
| 滑块把手 | 24×56 | `normal` / `hover` / `pressed` / `disabled` | normal 纸白 `#F0F2F4`；hover 加 1px 暖铜描边 + 左右各伸出 2px；pressed 中央凹槽加深 + 亮度 −10% |

> **滑块把手的形态是本界面的一个具体决策点**：契约给出的尺寸是 24×56（竖向窄条，高大于宽）。
> 设计上应保持这个比例——它像一枚**可以左右推动的金属推钮**，符合「工装面板」的语义，
> 而不是移动端常见的圆形滑块。

## 8. 验收要点

- [ ] 暂停菜单四按钮等宽等距，「放弃」与其余三个视觉可区分（危险语义）
- [ ] 遮罩 85% 足够压暗盘面，但仍能隐约看见棋盘（表达「暂停」而非「离开」）
- [ ] 设置两块面板视觉同族，只有标题与数值不同
- [ ] 滑块轨道 / 填充 / 把手三者的视觉关系清楚（哪段是已填充、哪里能拖）
- [ ] 把手是竖向窄条（24×56），不是圆形；hover 与 pressed 状态明确
- [ ] 数值「80%」用等宽数字，拖动时不抖动
- [ ] 关闭按钮位置统一在左下，与准备页的「返回」按钮位置一致
- [ ] 两块面板之间的间距（260）明显大于面板内元素间距，分组清楚
- [ ] 设置的视觉语言与「18 全局弹窗」的对话框同族（同一套金属板语言）
