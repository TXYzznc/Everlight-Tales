# Everlight Tales 界面 Prefab 制作总规范

> 版本：2026-09-30 · 适用：本目录下 01～20 页面文档。本文是预制体制作契约，不生成效果图。

## 1. 画布与坐标

- 正式基准为竖屏 `1080×1920`；Canvas Scaler 使用 Scale With Screen Size。
- SafeArea 四边默认内缩 40px；顶部和底部系统安全区由运行时继续处理。
- 基础网格为 8px，常用间距 16/24/32/40px；触控区不小于 48×48px。
- 所有页面截图必须使用 1080×1920；`Assets/Test` 中页面对象名包含 `Image` 的图片只作对照，不进入运行时 Prefab。

## 2. 正式资源硬约束

1. 唯一运行时素材源为 `Assets/Game/Sprites/UI`，文档中的每条资源都必须对应实际文件。
2. 九宫格资源使用 `Image.Type.Sliced`，保持四角和边框厚度。
3. 控件按文件名后缀绑定 normal/hover/pressed/disabled/active/selected 状态；缺少状态时按页面文档记录回退。
4. 图标保持原始轮廓和比例，不用截图、非项目正式资源路径或临时色块替代。
5. 资源、节点、状态和布局必须能从页面文档反向定位。

## 3. 页面层级与状态

标准层级：`UIForm` → `SafeArea` → `Background` → `Header` → `Content` → `Footer` → `Overlay`。页面 Prefab 不嵌入整张对照图，不保存重复 Item 实例。

每个可交互节点至少记录 normal、hover、pressed、disabled；页签、地点节点、卡片另记录 active/selected/locked/empty。状态优先通过正式素材切换，其次使用颜色、透明度和文本补充。

## 4. 每页文档必须包含

页面职责与入口、UIForm/Prefab、1080×1920 布局表、节点树、逐节点父子关系、锚点和尺寸、组件职责、正式资源路径、状态矩阵、文本字号、交互流程、UIItem 模板、动态容器、创建/回收生命周期、Prefab 接入要点、验收清单。

## 5. Item 页面统一规则

从 `ArchivePage` 到 `WorkbenchPage` 的 Item 类型、动态容器和资源绑定见 `21-界面Item与节点接入规范.md`。各页面文档的第 10 节是具体执行表，优先于旧版占位描述。

重复对象必须拆成独立 Item Prefab、脚本和 GF UIItemObject 包装类。页面只持有模板引用和容器引用，刷新时回收对象池，再按数据顺序生成；Item 内部完成素材、文本、状态和按钮绑定，页面脚本只负责数据映射和回调。

## 6. 验收

- 节点层级、父子关系、布局锚点与文档一致。
- 所有 Sprite、字体和状态资源来自 `Assets/Game/Sprites/UI`。
- 动态 Item 能创建、刷新、回收，空态和禁用态可验证。
- PlayMode 使用 1080×1920 截图与 `Assets/Test` 对照，截图命名为 `<Prefab>-1080x1920-<state>.png`。
- 文档确认前不修改页面 Prefab、Item Prefab 或领域业务规则。
