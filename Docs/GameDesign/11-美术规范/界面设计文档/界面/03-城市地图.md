> 对应脚本：`Assets/Game/Scripts/EverlightTales/UI/MapPanel.cs`、`CityMapView.cs`、`TimePeriodBar.cs`

## 1. 界面概述

游戏的主界面（默认页签）。玩家在这里看时间、看城市、选地点、点事件、等待下一个时段。
是「一天闭环」的操作中枢：**时段条告诉我们现在几点 → 地图告诉我们能去哪 → 地点面板告诉我们能做什么**。

- 打开入口：主页壳默认页签（Tab 0）
- 数据来源：`WorldSession.Time`（TimeState）、`WorldSession.World.Map`（MapState）、`WorldSession.Supply`
- 交互结果：点地点节点 → 显示地点详情；点事件卡 → 确认弹窗 → 进准备页；点等待 → 推进时段

> **地图是固定视角单指拖动平移**（D-080，不做双指缩放）。节点用「世界坐标 × Scale + 视口偏移」定位，
> 拖动时整体平移。设计时要考虑节点可能在拖动后移出可视区，**需要一层隐约的边缘提示或地块纹理**让玩家感知地图还能拖。

## 8. 验收要点

- [ ] 时段条的四格能一眼看出「现在走到哪一格」，且白昼/夜晚有明确色调差异
- [ ] 地点节点在缩略图尺寸下仍可区分身份（不靠文字）
- [ ] 「未发现」的节点确实不出现，且地图上该区域不能出现明显空缺（底图要能自然承接）
- [ ] 节点之间的相对位置与 §2 坐标表一致（修理铺在右上方、裁缝铺与社区在右侧）
- [ ] 地点详情面板与地图区有清晰分界（1px 刻线或明度落差）
- [ ] 事件卡内两行文字（名称 22 / 元信息 16）层级明确
- [ ] 地图拖动后不出现空白露底
