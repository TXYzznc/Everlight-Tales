## 1. 界面概述

新档首进时全屏播放的**序章字幕**。按时间自动推进（`OpeningSequence.Advance(deltaTime)`），
可随时跳过；播完后按钮文字由「跳过」变为「开始」。播完即落盘（`OpeningDone = true`），
后续进入走「继续」跳过序章。

- 触发条件：`session.IsNewGame && !session.OpeningDone`
- 结束：点按钮 → `Finish()` → 回调 → 自毁

**叙事背景**：主角（玩家，无名徒弟）回城代管长明修理铺；师父周衡下落不明。
序章负责交代这件事，并把玩家送进城市地图。

### 2.2 字幕文案规则

```
有说话人：「{Speaker}：{Text}」
无说话人：「{Text}」            ← 旁白
序列结束：「」                   ← 字幕清空
```

### 2.3 按钮文案变化

| 时机 | 文案 |
|---|---|
| 序列播放中 | 「跳过」 |
| 序列播完 | 「开始」 |

> **按钮语义的切换**：同一按钮在播放中是「跳过」（次级、不鼓励），
> 播完后是「开始」（主级、鼓励点击）。**设计上应为这两种语义出两套按钮视觉**，
> 而不仅仅是文字替换。

## 6. 交互控件状态

| 控件 | 尺寸 | 状态 | 视觉变化 |
|---|---|---|---|
| **跳过按钮**（播放中） | 260×56 | `normal` / `hover` / `pressed` | 低调：透明底 + 1px `#A8B0BC` 描边 + 灰字；hover 描边转白；pressed 底 10% 白 |
| **开始按钮**（播完后） | 260×56 | `normal` / `hover` / `pressed` | 醒目：暖铜实底 `#E0A858` + 深色字 `#171A20` + 外发光；hover 外发光 +30%；pressed 亮度 −15% |
| 字幕 | 940×140 | `fade-in` / `show` / `fade-out` | 由程序淡入淡出，无素材需求 |
| 全屏（可点跳过，建议） | 全屏 | `pressed` | 可选：点任意处快进到下一段 |

> **「跳过」到「开始」的状态切换**是序章的唯一交互反馈，必须两套视觉——
> 让玩家明白「现在可以开始了」，而不是继续被动地看。

## 8. 验收要点

- [ ] 三张序章插画在叙事上连贯：夜街（外）→ 铺内（人不在）→ 晨光（接手）
- [ ] 每张插画都有一个清晰的暖光点，冷紫只在边缘出现
- [ ] 字幕在插画上可读（有底衬），且不遮挡插画的关键叙事元素
- [ ] 「跳过」按钮足够低调，不诱导玩家跳过；「开始」按钮足够醒目
- [ ] 两个按钮尺寸与位置完全一致，只有视觉不同（便于程序切换）
- [ ] 周衡在序章中**不正面出现**或仅以背影/遗留物出现（他是「下落不明」的师父）
- [ ] 玩家视角不画玩家的脸（第一人称，可画手部特写）
- [ ] 常明灯光晕的造型与标题页、家园背景里的灯保持一致（同一盏灯）
