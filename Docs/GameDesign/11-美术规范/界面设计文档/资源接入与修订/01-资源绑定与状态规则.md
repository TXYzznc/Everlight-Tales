# UI 资源绑定与状态规则

> 设计日期：2026-10-08。当前为规则设计，不代表 Prefab、脚本或素材导入已完成修改。
> 保留已确认的 `ListRowItem` 统一方案及五种专用 Item；本规则不改变业务状态、解锁条件、奖励内容和输入规则。

## 决策检查点

### 检查点 1：第 1～2 轮已确认

1. **功能图标优先**：地点、材料、事件类型与关键业务状态必须有明确的图标用途；装饰素材按必要性选用，不为消耗素材增加节点。
2. **主图标＋小状态徽标**：列表主图标为 48×48，表达类型或对象；可选状态徽标为 24×24，表达当前业务状态，同时保留状态文字。扩展现有通用 `ListRowItem`，不恢复独立业务行 Prefab。

### 检查点 2：第 3～4 轮已确认

3. **短提示与确认弹窗分开**：四种 `SHR-041` 用作自动消失、不阻挡输入的短提示；需要确认、选择或阅读后处理的信息继续使用 `DialogView`。此决定修改现有 `ShowToast` 的表现边界，但不改变确认弹窗的业务行为。
4. **纳入全部正式素材**：UI 外 61 张正式素材纳入绑定规则，覆盖列表缩略图、盘面表现、调查对象与人物立绘；59 张 Placeholder 仅作为开发回退。素材接入不新增玩法、怪谈投放或解锁条件。

以下具体数值、资源用途和状态优先级由上述四轮决定及已有业务规则推导；没有现存业务对象的素材明确预留。

## 2. 通用显示与状态规则

### 2.1 图标层级

| 位置 | 显示框 | 职责 |
|---|---|---|
| 主导航图标 | 48×48 | 识别当前入口；保留文字 |
| 页面标题/分区标题图标 | 32×32 | 识别页面或区块；不单独成为按钮 |
| 列表主图标 | 48×48 | 事件类型或具体对象 |
| 列表状态徽标 | 24×24 | 只补充业务状态，必须同时显示状态文字 |
| 筛选图标、费用/时间图标 | 32×32 | 与筛选文字或数值相邻 |
| 地图建筑图 | 160×160 | 识别地点，位于 200×200 节点内 |
| 详情对象图 | 128×128 | 识别材料、零件、形态；正文说明效果 |

图标 `Image.Type=Simple`、`preserveAspect=true`、`raycastTarget=false`。48×48 是交互目标的最小尺寸；24×24 状态徽标没有独立点击行为。不得用状态徽标作为唯一信息，24px 不可辨时仍能读到相邻状态文字。

### 2.2 着色

- ICO-001～016 为单色功能图：普通文字/图标 `#E8EAF0`，暖铜选中底上改为 `#171A20`，禁用 `#6E7684`；不通过把白图整体染灰表达全部业务含义。
- ICO-021～030、041～046、051～062、地点图及正式对象缩略图自带语义色：`Image.color=white`，不叠加全局暖铜/紫色 Tint。业务禁用不取消已知对象的识别能力；仅文字弱化。未知/锁定由对应图与文字表达。
- 语义文字：可处理/可领奖 `#E0A858`，进行中 `#5A9EB8`，完成/解决 `#5AB878`，待回访/异化 `#A86AC8`，未到/错过/禁用 `#6E7684`。源图已包含不同灰度时不再次压暗。

### 2.3 三种状态分别绑定

1. **业务状态**决定状态图和文字，例如“可处理”；由页面读取业务模型后传入。
2. **选择状态**决定卡片/列表/页签底图，例如当前选中条目；不能把键盘焦点当作持久选中。
3. **输入状态**决定 normal/hover/pressed/disabled；禁用优先于按下，持久选中的页签在 hover/pressed 时仍保持 active。

类型图与状态图独立。状态徽标只放一个；重要性、异化、关键件等属性另有指定位置，不抢占状态位置。所有 Bind、取消选择、分类切换和真正回收都必须清除旧 Sprite、Tint、文字、显隐、徽标与回调。

## 5. ListRowItem 与 16 类业务行

保留标题单行 64、非空副文本 96 的两种高度。主图标、状态徽标、编号、右值、操作按钮各自可选，隐藏后释放空间。状态徽标放在右侧状态文字之前；主图标上的 `StateFrame` 继续只表示对象收集/选中状态。

新增的 StatusGroup 持有独立状态文字，不占用原 `RightText` 数值位；字段分别绑定。相应结构与尺寸以 prefab-layout.md 为准，主图增至48、Action命中高度增至48。通用行64/96不变；Carry专用候选为容纳48px图与按钮，目标高度调整为144/172（无/有提示）。

## 7. 地图与时间状态

### 7.1 地点映射

`home`→ICO-071 长明修理铺；`street`→ICO-072 街区小店；`dance`→ICO-073 舞蹈教室；`tailor`→ICO-074 裁缝铺；`community`→ICO-075 社区活动中心。使用实际文件中的“长明”，不改为“常明”。

| 地点状态 | 建筑图 | 选择表现 | 点击 |
|---|---|---|---|
| 未发现 | 整个节点隐藏 | 不保留选择/角标 | 不可点击 |
| KnownLocked 未选中 | known_locked | 无 | 保留既有详情查看，进入操作禁用 |
| KnownLocked 选中 | 仍为 known_locked | 独立 SHR-046-selected 选择框 | 只查看锁定原因，不显示 unlocked/selected 建筑 |
| Unlocked 未选中 | unlocked | 无 | 查看地点 |
| Unlocked 选中 | selected | 不再叠第二层选择框 | 查看并按原资格进入 |

每个 `MapNodeItem` 根保留透明命中区，新增 `Img_Place`；不再把 SHR-003 当作建筑本体。标签显示地名，锁定原因在地点详情显示。未选中不压暗 unlocked 图；known_locked 已含灰度，不再叠 0.5 Alpha。

地点有可处理事件时用独立 `SHR-043-alert` 角标＋数量，数值来自现有 `HasActionable/EventCount` 或页面已有权威查询。选择和事件角标可并存。无数据不显示角标；不把 KnownLocked 标成可进入。地图拖拽、节点坐标、缩放和点击监听沿用原契约。

### 7.2 四时段

四格表示 Morning/Afternoon/Night/DeepNight，**不是**当前时段剩余的四个行动格。当前格由 `time.Period` 选出；昼夜由 `TimePeriod.IsDaylight` 判断。

- 白昼当前格：SHR-036-day-active；白昼其它格：day-idle。

## 10. 短提示、弹窗与加载

### 10.1 短提示

四类分别使用 SHR-041-info/success/warning/danger：信息（说明/状态变动）、成功（保存/领取/加工成功的短结果）、警告（条件不足、当前操作不可执行）、错误（操作失败且需说明原因）。需要阅读奖励明细时仍可弹结果详情，不把明细裁成一条提示。

- 一条最多两行、每行省略；完整复杂原因转入现有详情/弹窗。
- info/success 持续 2.5 秒；warning/danger 持续 4 秒；淡入/淡出各 0.15 秒，使用不受暂停影响的 UI 时间。
- 最多同时 3 条，间距 12；同类同文在 1 秒内合并并刷新停留时间，重复次数显示为“×N”；其余排队最多 10 条，满时先丢弃最早info/success；若全部为warning/danger，新danger替换最早warning（无warning则替换最早danger），新warning替换最早warning（无warning则丢弃新warning），新info/success直接丢弃。剩余消息保持原顺序；已展示消息不被截短。
- 位于可用内容底边上方 24，避开主壳页签栏与盘面操作区；宽度为内容区宽减 96、最大 960，高度 80/112。布局使用页面提供的底部占用边界，不能固定在全屏底部 4% 覆盖按钮。
- 所有背景/文字 `raycastTarget=false`，CanvasGroup `blocksRaycasts=false, interactable=false`；无全屏遮罩、无确认按钮。页面切换时短提示留在全局层，不重复生成 DialogView。

### 10.2 操作弹窗与 Loading

退出、删除、撤退、放弃恢复、奖励选择及必须阅读后确认的内容继续使用 DialogView/现有专用流程。背景 SHR-002；单个推进动作 SHR-021，取消 SHR-022，破坏性确认 SHR-024。按原业务处理按钮，不改变“点击遮罩关闭”或返回键行为。

Loading 保留原流程的输入阻挡，底层纯色遮罩＋居中 SHR-042（192×192）＋“加载中…”；关闭必须由原加载生命周期驱动，不能当 Toast 自动消失。网络/资源错误不得留下永久加载遮罩。

FeedbackPage 是反馈填写/提交页，继续用真实输入节点和 Btn_Submit；不把页面换成 Toast。提交结果才按短提示/操作弹窗规则显示。

## 13. 导入、切片与资源目录

1. 保持实际资源路径与 GUID。素材编号是语义键；静态 Prefab 引用 Sprite，动态目录序列化 Sprite 引用。一个 key 对应唯一图；存在于目录不等于已使用。
2. 九宫格/按钮/页签等可拉伸图必须有非零且正确的 Sprite Border；仅把 Image 设为 Sliced 不算验收通过。当前 SHR-021～030 共 37 张 Border=0，实施时须处理。
3. 同族状态先统一画布、透明边距、轮廓原点和切片位置；当前图片尺寸不齐，不能分别 SetNativeSize 造成点击/选中时跳动。归一化后保留文件名/GUID，不改 RectTransform 来迁就每态大小。
4. 采用批次文档的标准尺寸和 border；对现有较大源图按参考尺寸比例换算，L/B/R/T 分轴换算并向上取整。切线必须包住完整包角、铆钉等不应拉伸的结构，超出参考 border 时向外调整四态共同切线并登记；不能机械沿用“16px”切掉角件。切片记录包含最终源尺寸、四条 border、验证最小/最大显示尺寸和截图。
5. 图标/对象图不九宫格拉伸；保留源图比例。SHR-032 填充用水平 Filled，端部被裁切影响识别时按原进度组件分离端帽，不改数据值。
6. 全屏纯色遮罩 StretchAll；SHR-042 装饰图 Simple 保比例；SHR-041 提示底板 Sliced。装饰背景与输入阻挡层分开。
7. 不依赖运行时 `AssetDatabase`；不将正式图复制到另一目录制造第二份素材源。新增目录键覆盖全部需要动态切换的状态，Editor Binder 与运行时刷新共同验证。

## 14. 实施顺序与验收

先处理显式语义目录与切片，再扩展通用行/五种专用 Item，随后接地图与时间、准备页、其它页面、Toast/Loading，最后接盘面与人物。各阶段先核对目标资源路径与节点，再做运行截图。

- 全量清单必须每图一个判定：必须、条件、可选、预留、开发回退；没有“可能到处使用”。预留有具体理由，条件有具体触发式。
- 20 个现有页面 Prefab＋6 个 Item 的角色绑定全部可追溯；新增全局提示组件单独记录，不因此把原统计伪称为已实现。
- 验证至少包括：事件四状态、任务三状态、案件七状态、五地点三图及锁定选择、昼夜跨日、六槽空/已填/拖入、五来源材料与未知来源、所有页签选中/hover/禁用、三类空态、四类短提示与 Loading。
- 对象池回归：丰富行→纯标题→另一业务行，旧主图/状态/框/右值/回调不残留；分类隐藏后再显示，按钮仍有效。
- 实际运行按 720×1280、1080×1920、1080×2340、2160×3840 竖屏核对 SafeArea、触控区、滚动与文字省略；颜色按红绿、蓝黄、灰阶查看，图形与文字仍能区分状态。
- 页签快速切换、刷新/重开、拖拽取消、暂停中提示计时、重复 Toast、Loading 失败退出均需运行验证。
- 图标/对象在 32px 检查主体辨识，24px 状态徽标检查不遮挡文字且信息有文字冗余；若实际不清楚，在既定徽标框内换简化表达或补图，不扩大所有行高。
- 检查真正调用/显示、静态 GUID 引用、目录登记三种证据分别记录。静态核对完成不代表 PlayMode 已验收。

本轮只完成设计与文件一致性检查；所有 Unity 实施与运行验收任务在 OpenSpec 中保持未完成。
