### 6.2 状态素材、Shader、动画和粒子的配合

#### 图层顺序（从后到前）

场景背景 → 棋盘投影 → 机械底座 → 普通格/边界墙格 → 异常区域 → 已有棋子 → 格子选中/机械臂提示 → 盘框及其流光 → 定势座/方向箭头 → 短促粒子 → HUD/操作控件/弹窗。

背景与投影不随棋盘坐标旋转；底座、格子、墙格、棋子、盘框和定势座对齐盘面旋转。形态图只替换实体图层，不能移动或重新生成整个盘面。动态节点不盖住暂停/弹窗，装饰Image不接收射线。

#### 状态表

| 状态 | 素材选择 | Shader与动画 | 粒子/叠加边界 |
|---|---|---|---|
| 普通格 | normal | 基础材质，保持低对比 | 无常驻粒子 |
| 悬停格 | hover，保留几何母版 | 80～120ms过渡，边缘光感轻微增强 | 不全格变亮，不遮棋子 |
| 选中格 | selected | 120ms过渡，0.9～1.2s轻呼吸；不缩放格子 | 刻点和边线来自PNG，不重复画第二圈 |
| 机械臂源 | selected＋工具青源选择覆盖 | 单一独立源轮廓层，在搬运模式显示 | 不把棋子染成整块青色，不增加源图状态副本 |
| 机械臂合法目标 | normal＋target覆盖 | 冷紫虚线层轻呼吸，透明中心；当前合法结果决定显示 | 不替代异常底纹，不改变可搬动资格 |
| 不合法目标/禁用 | normal，隐藏target | 如有必要短暂暗灰拒绝提示 | 不仅凭贴图宣布合法/非法 |
| 旋转中 | 原素材＋流光遮罩 | 沿盘框周向扫光，强度跟随已有旋转速度，停止时衰减 | 不用六张旋转帧替代真实盘面旋转 |
| 当前定势座 | active＋独立箭头，其它五座normal | 切相时交叉过渡，箭头绑定真实GravityDirection | 不六座同时点亮，不据按钮点击次数猜方向 |
| 拍击/碰撞 | 原素材＋火花 | 复用既有震动/冲击环，Shader局部短脉冲 | 火花寿命约0.18～0.35s，小规模池化爆发，遮罩内播放 |
| 连锁 | 原素材 | 复用连击脉冲与得分飘字，环在棋子周围扩散 | 不新增手绘数字/连击字样需求，不让底格持续变色 |

以上时长为视觉参数，不改变拍数、时间消耗、触发顺序或结算。切换/关闭/池复用时清除旧材质参数、旧状态图和残留粒子。

#### Shader约束（技术制作，不由生图AI输出代码）

- 场景使用基础色/低强度色调和局部灯光参数；已选昼夜差分不再全图叠乘暖铜/冷紫。异常气氛只在边缘受控出现，中央棋盘区域保持清晰。
- 格子材质使用RGBA主贴图和局部状态遮罩；沿几何六边形及棋盘边界裁切，保留uGUI Mask/RectMask2D、Canvas裁切与Alpha混合支持。不能把正方形Sprite外框当作格子边界。
- 盘框Shader使用流光遮罩、周向位置和强度参数；光带严格限于盘框环带，不对背景整屏Bloom。底座投影是唯一的整体投影来源，PNG不再烘焙第二层影子。

### 6.3 场景、时段、几何与回退规则

1. 关卡表现配置明确选择SceneKey：home、street、dance、tailor、community。进入局内时读取既有时段快照：Morning/Afternoon→day，Night/DeepNight→night；本关保持该背景，不因视觉动画推进世界时间。
2. 关卡没有明确场景时沿用当前深色纯色回退并记录缺配；有明确SceneKey但PNG未交付时同样回退，不能用修理铺冒充舞蹈教室。场景选择不写入玩法存档，不更改供应或地点解锁。
3. 点顶六边形的功能格宽√3R、高2R，格子中心、实体0.72缩放及墙裁切保持现有几何。大的boardRadius统一适配可用视口，正常/墙格和全部覆盖层用相同尺度；PreviewBoardView与HexBoardView共用素材与裁切规则。
4. 原六方向轴向偏移依次为D0=(1,0)、D1=(1,-1)、D2=(0,-1)、D3=(-1,0)、D4=(-1,1)、D5=(0,1)。依当前AxialToPixel换算的局部方向角依次为0°、-60°、-120°、180°、120°、60°。
5. 六份定势座放在对应六边的边心方向，局部朝右母版按上述角度旋转；当前重力座叠active和箭头。再叠加原盘面旋转后，激活箭头指向屏幕下方。不要按“屏幕固定六点”与“盘内方向”混用编号。
6. BG使用不透明普通背景层，棋盘图使用Simple与preserveAspect，Image基础乘色白；材质只在指定通道调色。墙格使用真实裁切，状态覆盖不另外扩大输入区域。

### 6.4 贴图参考线与运行验收

格子贴图对齐仍由原六边形几何决定。贴图源半径60px与功能格半径R的换算为Image正方形边长`128×R/60`，原命中区仍为宽`√3R`、高`2R`；渲染必须通过功能格几何遮罩/裁切，不能用扩大后的矩形Image接收输入。墙格按原大六边形六半平面裁切贴图，不能只裁程序底色而让墙图漏到盘外。

将源图参考半径680对应当前`OutlineRadius=2×(boardRadius+1)×CellSize`。盘框/遮罩Image边长为`1456×OutlineRadius/680`，底座为`1500×OutlineRadius/680`，不能直接把不同源画布拉成相同宽高。整盘再按可用视口统一缩放，保持格子、盘框、底座、定势座和输入映射一致；不按固定boardRadius烘焙整张棋盘。
