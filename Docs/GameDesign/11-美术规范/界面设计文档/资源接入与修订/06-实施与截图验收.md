# 正式资源实施与截图验收

日期：2026-10-08。Unity 2022.3.62f3c1，Windows Editor。范围是本项目 UI 资源接入及实际截图问题修正；未修改 `ScriptsBuiltin` 框架核心，未改变玩法数值与内容投放。

## 交付与绑定

- 26 个 UI Prefab 保留原 GUID；增加资源目录、通用行状态组、专用 Item 图层与页面绑定。
- 正式目录共 474 个语义键，对应保留的 215 张正式 PNG。59 张 Placeholder 继续作为开发回退。
- 新增 ICO-063、ICO-064、ICO-057-generic 已使用用户交付图；五来源纹样与四张热点图保留用户替换的 PNG/GUID。
- 八张新增/纹样图实际源文件为 1254×1254，Unity 最大导入尺寸为 128；不是声称母版文件已经变成 128×128。
- SHR-027-badge、SHR-047 在全 Assets 依赖检查为零后，经 AssetDatabase 删除 PNG/meta。五项预留资源仍保留；未为了覆盖率放入无对应功能的页面。
- 图标保持 Simple、preserveAspect；可伸缩背景使用九宫格与校正后的 Border。短提示使用独立非阻塞 Toast，确认操作保留 DialogView。

JSON 保留 `design_baseline_evidence`，新增逐文件 `implementation_evidence`：实际文件、GUID、Prefab 直接引用与目录键。运行时查表的对象不会全部出现在 Prefab 的直接 Sprite 引用中；反之，进入目录也不代表业务入口已在截图中出现。

## 运行证据与重现

工具菜单位于 `Game Framework/EverlightTales/UI/正式资源规则/`。

1. 停止 Play Mode 后执行“接入全部”“验证资产”。迁移脚本用于保留组件绑定；相关旧生成器已接入同一迁移，避免恢复旧页签和旧 Item。
2. “准备运行验收”后进入 Play Mode，Game 视图保持可见。20 页依次打开并截图。
3. “验证导航视觉状态”通过主导航进入子页、状态切换、模拟 SafeArea、四类 Toast、确认、Loading、人物与奖励展示。
4. “验证特殊条目”复查携带条目的点击/拖放/形态/池复用及热点坐标/重复点击/重建；“验证运行组件”复查通用行复用及 Toast 队列和生命周期。

本地完整截图与日志位于 `Library/FormalResourceValidation/`。本轮计入通过的是 `1080x1920` 目录的 20 页与 32 类导航/反馈状态；`assets.txt`、`runtime.txt`、`visual-states.txt` 分别对应静态引用、运行组件、导航状态。精选截图保存在本目录“验收截图”中。

其他尺寸目录中的早期截图不计入通过：文件名虽包含目标尺寸，实际 Game 视图仍是 1080×1920。用户已要求不再处理此项，停止扩展多尺寸工具；没有用这些文件宣称完成四分辨率验证。

## 仍需区分的边界

- SHR-021～030 的 37 张源 PNG 画布仍有族内尺寸差异（大多 1～7 像素，025 图标按钮更明显）。本次用固定控件尺寸与 Border 消除控件整体伸缩，**未重绘、归一化源 PNG**；源图内部装饰的一致性不能据此宣称完成。详细后续需求见 04 文档，任务 1.2 保持未完成。
- 玩家/沈遥使用精确身份绑定，周衡及未知身份隐藏；当前维修事件配置没有人物身份字段，不能为 Board 的人物槽猜测演员。序章和独立对话支持精确绑定，Board 人物内容投放仍由后续配置决定。
- 多尺寸验收未完成；SafeArea 仅为 Editor 模拟。灰阶和小图辨识做了辅助检查，未完成色盲用户、真实设备、系统字体缩放或刘海设备认证。
- “TMP 未溢出”不能证明两个组件没有重叠，故保留截图人工复查。长列表受 ScrollRect 裁切属于正常滚动；准备槽位的简略描述保留省略号，完整信息由条目详情承载。
- 测试采用内存数据，奖励只注入展示快照，未调用正式结算保存；没有用本轮测试覆盖真实存档恢复业务。未完整经过的业务入口不标为端到端通过，OpenSpec 未完成项保留。
