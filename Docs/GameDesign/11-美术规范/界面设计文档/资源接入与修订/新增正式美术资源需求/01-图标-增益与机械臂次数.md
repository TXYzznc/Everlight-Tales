## 2. 本批的造型规范

| 项 | 规范 |
|---|---|
| 源图尺寸 | 128×128，透明背景 PNG |
| 图形占比 | 外接框约占画布 **78%**（四周留安全边；本批图形多为小徽标，留白略多于功能图标） |
| 笔画粗细 | **统一 9px**（比功能图标的 10px 略细，因为本批多是「标识」而非「操作」） |
| 圆角 | 笔画端头与转折处统一**半径 3px** |
| 视角 | 一律**正面平视** |
| 语义色用量 | 语义色占图形面积 **不超过 40%**，其余为深灰蓝金属与纸白高光 |

### 语义色分配（本批的统一约定，**不要混用**）

| 语义色 | 用途 | 出现在 |
|---|---|---|
| 暖铜 `#E0A858` | 「可以推进 / 有收益」 | ICO-021 可处理、ICO-025 可领奖、ICO-030 关键件 |
| 工具青 `#5A9EB8` | 「正在进行 / 中性信息」 | ICO-022 进行中 |
| 成功绿 `#5AB878` | 「已经完成」 | ICO-026 已完成、ICO-027 已解决 |
| 冷紫 `#A86AC8` | 「怪谈 / 异常 / 未解」 | ICO-028 待回访、ICO-029 异化、ICO-045 怪谈 |
| 灰 `#6E7684` / 暗灰 `#4A4E56` | 「未到 / 失效 / 错过」 | ICO-023、ICO-024 |

> **暖铜 = 可以去做，冷紫 = 还没解决**——这是本项目最常被误解的一对，务必按上表分配。

上表“出现在”列记录原批次编号。本批补充两项主体配色：ICO-063箭头使用工具青#5A9EB8；ICO-064铰链使用暖铜#E0A858。两项均遵守相同的语义色面积和金属基调规则。

## 4. 逐项画面主体

### ICO-063 · 增益

```text
单项画面主体：ICO-063，表达“增益奖励类别”。
画一枚六角机械铭牌，轮廓克制，底板深灰蓝金属。
中央只有一根工具青#5A9EB8的粗向上箭头，箭头尖与竖杆为连续实心形。
箭头独立于边框，与内框至少留8px间距，不增加第二个箭头。
不把铭牌画成星形或齿轮，不画裂纹眼睛、扳手、礼盒、货币或光柱。
不将数值、层数或增益名称画入主体。
```

表示“这是一项增益”，名称、效果、层数用图外文字表达。不能用来表示异化、可处理、完成、关键件或材料，也不能作为所有奖励的通用图。

### ICO-064 · 机械臂次数

```text
单项画面主体：ICO-064，表达“机械臂可用次数/次数奖励”。
画一只两节机械臂：左下方形底座，两个圆形铰链连接两节臂杆，肘部明显弯折。
末端向右上伸出打开的双爪，两个爪指分离且各有机械转折，间隙至少10px。
底座和臂杆为深灰蓝金属，铰链窄环点暖铜#E0A858，不将整臂涂黄。
底座、两个关节和双爪明确，不加细电线或小螺母阵列。
不能画成开口扳手，不加入时钟、沙漏、旋转箭头、按键符号或次数数字。
```

表示机械臂可用次数，增加或剩余数量用图外文字表达。不表示耗时、行动格、旋转次数、通用移动，不替代控制器按键符号。
