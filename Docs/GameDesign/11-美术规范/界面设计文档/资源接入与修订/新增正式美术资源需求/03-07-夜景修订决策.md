# 03–07 局内背景夜景修订决策

## 已确认边界

- 第一轮：夜景包含明确可见的异常细节，可使用无光源微光、错位倒影和不合理阴影；不出现怪物。
- 第二轮：昼夜保持镜头、房间结构、主要陈设位置、裁切与中央留白一致；允许局部异常变化，不要求倒影与阴影逐像素相同。
- 长明修理铺为家园相关背景，表达神秘感；街区小店、舞蹈教室、裁缝铺、社区活动中心表达副本的诡谲感。

## 术语

- **神秘感**：熟悉且可亲近的空间存在未被解释的秘密，让人产生探索欲。
- **诡谲感**：熟悉环境中出现可见但无法合理解释的关系，让人产生不安。
- **静态异常细节**：直接画入夜版背景的局部反常现象，不依赖运行时特效才能辨认。

## 第三轮确认与落地

- 允许关联剧情，在背景细节中体现伏笔与线索；不把它们限定为纯常态氛围。
- 舞蹈教室关联红舞鞋，裁缝铺关联画皮，社区活动中心关联魔法师学徒的扫帚；依据各案现有基础怪谈文档。
- 家园与街区小店的局部细节为美术伏笔提案，不据此新增故事事实或强行绑定案件。
- 已统一更新五份文档的夜景提示词、同族规格、制作顺序、素材用途与验收。维持一处主要异常与一处辅助伏笔；静态异常直接画入夜版，动态特效另行叠加。
- 伏笔不代替事件进度、可交互证据或结案状态；本次仅两张昼夜图，不新增剧情状态图。

## 修改范围

只修订 03–07 五份背景制作文档中的夜景方向及相互关联的制作、用途、验收规则；保留昼版、资源编号、输出路径、尺寸和通用绘画语言。不生成图片，不修改代码或运行时表现。本次为局部美术文档修订，不建立 OpenSpec change。

## 2026-10-09 氛围增强与输入流程修订

- 用户反馈独立夜景稿的神秘与诡谲不足，要求增强整体氛围；沿用此前三轮确认的无怪物、主体构图固定、可关联剧情边界。
- 五份独立夜景文档改为“完整文档 + 对应白天图片”的图像编辑流程，白天图是唯一构图母版，取消无参考图从零生成的分支。
- 氛围从微小异常提升为整体大色群、冷暖光域、暗部纵深、中等尺度异常与呼应伏笔；允许指定边缘区域的稀薄静态空气色面。中央留白与主体结构继续保持。
- 增加约25%缩图辨识、与白天图结构对照的验收标准。具体强度与制作流程以五份独立夜景文档为本次出图要求，原昼夜合并文档保留为此前版本记录。

## 2026-10-09 允许新增故事小物品

- 用户明确允许增加诡异且与故事相关的物品，继续禁止怪物。
- 白天图仍固定建筑、镜头和原有主要陈设；每幅允许新增1件故事小物品及最多1件配件，原图已有同类物品时优先改造。
- 家园采用旧黄铜零件匣，街区采用异常倒影的钥匙，教室采用停止的节拍器与红缎带，裁缝铺采用双层针脚样片与旧线，活动中心采用空桶与反常水痕。
- 物品的具体摆放与超自然表现为美术伏笔，不自动新增剧情事实、互动任务或结案状态。
