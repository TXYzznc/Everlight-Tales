## 1. 固定模块（每项提示词都要接在后面，逐字复用）

### A · UI 视觉语言

```
一款竖屏手机游戏的界面设计，2D 数字绘制，成熟的商业游戏 UI 完成度。
整体基调：深夜仍在营业的老式精密修理铺——黄铜工具的秩序感与门外未知之物的侵蚀感同处一框。
克制的低饱和深色底，靠局部暖光与冷光建立层次；不使用大面积高亮、不糖果色、不卡通描边，
不使用拟真照片贴图、玻璃拟态、霓虹赛博或扁平极简白底风格。
面板与控件用「薄金属板 + 蚀刻线 + 轻微内阴影」构成，边缘清晰、拐角圆润但克制（圆角半径小），
有实体感与触感，像一块被反复使用的工装面板。避免：厚塑料质感、浮雕过多、廉价渐变、立体投影过重。
```

### B · 色彩体系

```
以深色为绝对主体，具体色值：最底背景 #171A20，页面背景 #1E2229，
面板底 #262B34，卡片底与悬停 #2F3540，分隔线与描边 #3E4652，
主文本 #E8EAF0，次文本 #A8B0BC，弱文本与禁用 #6E7684。
强调色两支：暖铜 #E0A858（主按钮、高亮、当前选中、金属暖面），
冷紫 #A86AC8（怪谈、异常、待处理、警示性的神秘感）。
辅助功能色：工具青 #5A9EB8（次级强调、链接）、成功 #5AB878、危险 #D05A5A、警告 #D8A858。
暖铜与冷紫是画面唯一的两处「光」，其余全部压在深灰蓝的中低明度区间；
暖冷面积比大致 3:1，暖为主、冷为异。禁止大面积高饱和与多色并列竞争。
```

### C · 材质与光影

```
光源假定来自画面内的灯具与屏幕本身：左上偏暖的方向光，边缘有极轻微的冷紫反射光。
金属件强调转折面与窄亮反光带，不画照片级反射；布料与纸张用大面平涂加少量褶皱折线。
面板高光只在边缘 1~2px 处出现，形成薄金属收边；阴影短、硬、贴合结构，不做长投影与浓重 AO。
所有发光元素（指示灯、符文、异常侵蚀）用有限的光晕，光晕不超过元素自身尺寸的 1.5 倍。
整体干净、层次分明，从缩略图能读出分区，放大能看见刻线与铆钉的细节安排。
```

### D · 细节与统一性

```
统一全画面的圆角尺度、描边宽度（1~2px）、刻线间距与图标笔画粗细；
功能图标用统一线宽与统一圆角，风格一致，可成套使用；
同类控件在所有界面中保持同一种视觉语言，不因界面不同而改变造型。
焦点区域（主按钮、当前选中页签、提示信息）才允许更高对比与更精细的细节，
次要区域概括处理。不得让某一区域突然变成其他画风、摄影写实或手绘涂鸦。
```

## 2. 本批的硬性约束（九宫格素材专属，比风格更重要）

九宫格素材会被 Unity 按 border **切四角、拉伸四边与中心**。违反下列任一条，
拉伸后就会出现条纹、断层或糊边：

| 约束 | 说明 |
|---|---|
| **必须在源尺寸画布内居中绘制** | 四角与四边结构完整可切，不要把图形贴到画布边缘之外 |
| **中心与四边中段必须是低对比纯色或极弱纹理** | 这是被拉伸的区域；任何图案、渐变方向性、高光带都会被拉成条纹 |
| **禁止向外的投影、外发光、外扩描边** | 边角处的向外投影在拉伸后变成沿着边的一条平行色带 |
| **四角结构要「闭合」** | 角上的包角/铆钉/刻线必须完整落在 border 区域内，不能跨过 border 线 |
| **不画文字** | 文字由程序用 TMP 渲染；素材只是「容器」 |
| **透明背景** | 除遮罩类（SHR-008）外全部透明背景 PNG |

## 4. 出图批次建议

本批 10 张量不大，可按下面的顺序分 **2 次**出，保证每次质量：

| 次序 | 内容 | 说明 |
|---|---|---|
| 第 1 次 | SHR-001 面板、SHR-002 对话框、SHR-006 顶部条（2 版）、SHR-007 页签栏 | 先出**单态**的 5 张，确立「薄金属板」这套基础语言；后面所有控件都以这几张的圆角、收边宽度、铆钉大小为基准 |
| 第 2 次 | SHR-003 卡片（5 态）、SHR-004 槽位（3 态）、SHR-005 列表行（3 态） | 多状态族，一次性连贯完成，确保各态外轮廓严格一致 |

> SHR-008 不入批，程序填色即可。

**关键做法**：出第 1 次时，从 5 张里挑最满意的一张作为「基准板」，
第 2 次出图时把它一起喂给 AI 作为风格参考——这样卡片的收边与面板才会是同一套。

## 5. 本批验收要点

- [ ] 5 张单态容器摆在一起时，**圆角半径、收边宽度、铆钉尺寸是同一套**（不是 5 种风格）
- [ ] 「暖铜刻线」在面板/对话框/顶部条/页签栏上的粗细与亮度一致
- [ ] 所有素材在中心与四边中段是**纯色**，横向/纵向拉伸 10 倍后不出现条纹
- [ ] 没有向外的投影或外发光（外扩不超过 4px，且只在 `slot highlight` 允许）
- [ ] 多状态族（卡片 5 态 / 槽位 3 态 / 列表行 3 态）各态**画布尺寸与外轮廓逐像素一致**
- [ ] 全部透明背景、无文字、无真实内容图标
- [ ] 源图尺寸严格等于清单值（Unity 按 border 切图，尺寸错会导致切分错位）
- [ ] 导出后按 §3 表格的文件名命名，放入 `Assets/Game/Sprites/UI/九宫格/`
