## 1. 固定模块（逐字复用）

### 图标视觉语言（固定）

```
一款竖屏手机游戏的地图地点节点图标，2D 数字绘制，成套的精密工装风格。
图标是**地点标识**：每个图标画一座建筑或场所的正面平视剪影，
用实心块面 + 少量硬边笔触表现结构，不画照片级细节、不画透视纵深。
整体压在中低明度，主体用深灰蓝金属色阶（#3E4652 / #2F3540 / #262B34），
只允许**一处**暖铜 #E0A858 的高光点（每座建筑都有一盏灯，这是本套图标共同的记号）。
背景完全透明，形状之外不画任何东西。
不使用渐变、不使用投影（外扩）、不使用外发光。
缩到 44px（地图节点实际显示尺寸）仍然一眼能认出是哪座建筑，这是本批唯一的硬标准。
```

## 2. 本批的造型规范

| 项 | 规范 |
|---|---|
| 源图尺寸 | 128×128，透明背景 PNG |
| **实际显示尺寸** | **44×44**（地图节点）。所有细节必须在这个尺寸下成立 |
| 图形占比 | 外接框约占画布 **85%**（节点很小，要占满才看得见） |
| 视角 | 一律**正面平视**，不画等距/透视 |
| 底座 | 五座建筑**共用一个圆形或六边形的地基轮廓**（宽度一致），让它们在地图上排列时高度感统一 |
| 灯 | 每座建筑有且只有**一处**暖铜高光点（窗/灯/招牌），面积不超过图形的 6% |

### 状态与出图数量（**先看这里，避免多出图**）

原始清单列了四态，但 `undiscovered`（未发现）**在地图上根本不渲染**（`CityMapView` 跳过未发现节点），
因此**不需要出图**。实际只需 3 态：

| 状态 | 是否出图 | 说明 |
|---|---|---|
| `undiscovered` 未发现 | **不出图** | 程序不渲染该节点 |
| `known_locked` 已知未解锁 | 出图 | 虚线灰描边、无内部细节（像一张未完成的草图） |
| `unlocked` 已解锁 | 出图 | 实色、完整细节、暖铜灯光点亮 |
| `selected` 已选中 | 出图 | 与 unlocked 同曝光，外面加一圈高亮环 |

**本批 2 个地点 × 3 态 = 6 个素材**（另 3 个地点在 `08-图标-地图地点.md`）。

> **`known_locked` 与 `selected` 的做法**：都从 `unlocked` **同形派生**——
> `known_locked` 整体降为灰 `#6E7684`、轮廓改虚线、去掉内部细节与暖光；
> `selected` 保持建筑本体不变、外面加一圈 2px 暖铜高亮环。

> **与 `08` 篇的成套性**：本批两座建筑必须与 08 篇的三座（修理铺/街区/舞蹈教室）
> 保持同一套视觉语言（同一视角、同一地基宽度、同一明度区间、同一处暖灯记号）。
> 出图时建议把 08 篇已出的任意一张作为风格参考一起喂给 AI。
