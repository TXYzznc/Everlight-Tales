## 1. 固定模块（逐字复用）

### 图标视觉语言（固定）

```
一款竖屏手机游戏的地图地点节点图标，2D 数字绘制，成套的精密工装风格。
图标是**地点标识**：每个图标画一座建筑或场所的正面平视剪影，
用实心块面 + 少量硬边笔触表现结构，不画照片级细节、不画透视纵深。
整体压在中低明度，主体用深灰蓝金属色阶（#3E4652 / #2F3540 / #262B34），
只允许**一处**暖铜 #E0A858 的高光点（每座建筑都有一盏灯，这是本套图标共同的记号）。
背景完全透明，形状之外不画任何东西。
不使用渐变、不使用投影（外扩）、不使用外发光。
缩到 44px（地图节点实际显示尺寸）仍然一眼能认出是哪座建筑，这是本批唯一的硬标准。
```

## 2. 本批的造型规范

| 项 | 规范 |
|---|---|
| 源图尺寸 | 128×128，透明背景 PNG |
| **实际显示尺寸** | **44×44**（地图节点）。所有细节必须在这个尺寸下成立 |
| 图形占比 | 外接框约占画布 **85%**（节点很小，要占满才看得见） |
| 视角 | 一律**正面平视**，不画等距/透视 |
| 底座 | 五座建筑**共用一个圆形或六边形的地基轮廓**（宽度一致），让它们在地图上排列时高度感统一 |
| 灯 | 每座建筑有且只有**一处**暖铜高光点（窗/灯/招牌），面积不超过图形的 6% |

### 状态与出图数量（**先看这里，避免多出图**）

原始清单列了四态，但 `undiscovered`（未发现）**在地图上根本不渲染**（`CityMapView` 跳过未发现节点），
因此**不需要出图**。实际只需 3 态：

| 状态 | 是否出图 | 说明 |
|---|---|---|
| `undiscovered` 未发现 | **不出图** | 程序不渲染该节点 |
| `known_locked` 已知未解锁 | 出图 | 虚线灰描边、无内部细节（像一张未完成的草图） |
| `unlocked` 已解锁 | 出图 | 实色、完整细节、暖铜灯光点亮 |
| `selected` 已选中 | 出图 | 与 unlocked 同曝光，外面加一圈高亮环 |

**本批 3 个地点 × 3 态 = 9 个素材**（另 2 个地点在 `09-图标-地图地点.md`）。

> **`known_locked` 与 `selected` 的做法**：都从 `unlocked` **同形派生**——
> `known_locked` 整体降为灰 `#6E7684`、轮廓改虚线、去掉内部细节与暖光；
> `selected` 保持建筑本体不变、外面加一圈 2px 暖铜高亮环。
> 这样玩家能看出「这里有个地方，但还看不清 / 这个正在选中」，而不是看到陌生图形。

## 3. 逐项提示词（每个地点 × 3 态 = 每个状态一个编号）

### ICO-071-unlocked · 长明修理铺（home，已解锁）

文件 `ico_place_home_unlocked@128x128.png`。

一座带灯的小铺面，正面平视：一个方形铺面（左右两根立柱、上方一道横梁），
铺面中央是一道卷起一半的卷帘门（可见横向卷帘棱纹，向上卷起露出下方黑口）；
横梁中央悬挂一盏吊灯——灯罩梯形、下方一个小圆点，**这是本图唯一的暖铜高光点**，
可带极窄暖色光晕（不超过 4px）。整体是五座建筑中最亮、最暖和的一座（玩家的家）。透明背景。

### ICO-071-known_locked · 长明修理铺（home，已知未解锁）

文件 `ico_place_home_known_locked@128x128.png`。

与 ICO-071-unlocked 完全相同的形状与尺寸（铺面轮廓、卷帘门、吊灯位置逐像素一致）。
唯一区别：整体降为灰 #6E7684，轮廓改为虚线（短划线），去掉内部次要细节与暖铜灯光
（像一张未完成的草图，玩家能看出「这里有个地方，但还看不清」）。透明背景。

### ICO-071-selected · 长明修理铺（home，已选中）

文件 `ico_place_home_selected@128x128.png`。

与 ICO-071-unlocked 完全相同的形状与尺寸（建筑本体逐像素一致）。
唯一区别：在建筑本体外面加一圈 2px 的暖铜 #E0A858 高亮环（环外可带极窄光晕，不超过 4px）。透明背景。

## 4. 本批验收要点

- [ ] **本批 9 个素材，每个有唯一编号（`ICO-xxx-状态`）、一段独立提示词、一张独立交付文件**
- [ ] **三座建筑并排放在地图上是成套的**：同一视角、同一地基宽度、同一明度区间
- [ ] 三座建筑**高度与宽度有区分**（铺面窄、舞蹈教室高、街区小店居中），能靠轮廓认出
- [ ] 每座建筑有且只有**一处暖铜高光点**（这是全批共同的记号）
- [ ] 三座建筑的**视觉重量接近**，没有一座明显比其它密或空
- [ ] `ICO-073 舞蹈教室` 的冷紫只在鞋与鞋带上，面积不超过 8%，细看才发现
- [ ] 每个地点的 `known_locked` / `selected` 与 `unlocked` **形状完全一致**，只有灰+虚线 / 外环的差异
- [ ] 缩到 **44×44**（实际显示尺寸）仍能认出是哪座建筑——这是本批最硬的验收项
- [ ] `undiscovered` 态**没有出图**（程序不渲染，不需要）
- [ ] 全部 128×128 透明背景 PNG，放入 `Assets/Game/Sprites/UI/图标/地点/`
