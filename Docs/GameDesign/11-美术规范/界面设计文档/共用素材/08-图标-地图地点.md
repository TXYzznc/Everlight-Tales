# 共用素材 08 · 图标 - 地图地点节点

> 本批交付：**5 项 / 源图 15 张**（3 个可见状态 × 5 个地点）
> **本文件自包含，可直接整份喂给生图 AI。**
> 覆盖编号：`ICO-071` ~ `ICO-075`

## 1. 固定模块（逐字复用）

### 图标视觉语言（固定）

```
一款竖屏手机游戏的地图地点节点图标，2D 数字绘制，成套的精密工装风格。
图标是**地点标识**：每个图标画一座建筑或场所的正面平视剪影，
用实心块面 + 少量硬边笔触表现结构，不画照片级细节、不画透视纵深。
整体压在中低明度，主体用深灰蓝金属色阶（#3E4652 / #2F3540 / #262B34），
只允许**一处**暖铜 #E0A858 的高光点（每座建筑都有一盏灯，这是本套图标共同的记号）。
背景完全透明，形状之外不画任何东西。
不使用渐变、不使用投影（外扩）、不使用外发光。
缩到 44px（地图节点实际显示尺寸）仍然一眼能认出是哪座建筑，这是本批唯一的硬标准。
```

## 2. 本批的造型规范

| 项 | 规范 |
|---|---|
| 源图尺寸 | 128×128，透明背景 PNG |
| **实际显示尺寸** | **44×44**（地图节点）。所有细节必须在这个尺寸下成立 |
| 图形占比 | 外接框约占画布 **85%**（节点很小，要占满才看得见） |
| 视角 | 一律**正面平视**，不画等距/透视 |
| 底座 | 五座建筑**共用一个圆形或六边形的地基轮廓**（宽度一致），让它们在地图上排列时高度感统一 |
| 灯 | 每座建筑有且只有**一处**暖铜高光点（窗/灯/招牌），面积不超过图形的 6% |

### 状态与出图数量（**先看这里，避免多出图**）

原始清单列了四态，但 `undiscovered`（未发现）**在地图上根本不渲染**（`CityMapView` 跳过未发现节点），
因此**不需要出图**。实际只需 3 态：

| 状态 | 是否出图 | 说明 |
|---|---|---|
| `undiscovered` 未发现 | **不出图** | 程序不渲染该节点 |
| `known_locked` 已知未解锁 | 出图 | 虚线灰描边、无内部细节（像一张未完成的草图） |
| `unlocked` 已解锁 | 出图 | 实色、完整细节、暖铜灯光点亮 |
| `selected` 已选中 | 出图 | 与 unlocked 同曝光，外面加一圈高亮环 |

**5 个地点 × 3 态 = 15 张。**

> **`known_locked` 的做法**：与 `unlocked` **同形**，但整体降为灰 `#6E7684`、
> 轮廓改为**虚线**（短划线）、去掉内部次要细节与暖铜灯光。
> 这样玩家能看出「这里有个地方，但还看不清」，而不是看到一个陌生图形。

## 3. 逐项画面主体

> 每项出**三态**：`unlocked`（实色完整）/ `known_locked`（虚线灰，同形缩略）/ `selected`（= unlocked + 外环）。

### ICO-071 · 长明修理铺（`home`）

一座带灯的小铺面。正面平视：一个方形的铺面（左右两根立柱、上方一道横梁），
铺面中央是一道卷起一半的卷帘门（可见横向的卷帘棱纹，向上卷起露出下方黑口）；
横梁中央悬挂一盏**吊灯**——灯罩是梯形，下方一个小圆点，**这是本图唯一的暖铜高光点**，
可以带极窄的暖色光晕（不超过 4px）。
整体是五座建筑中**最亮、最暖和的一座**（它是玩家的家）。

### ICO-072 · 街区小店（`street`）

一座带招牌的店面。正面平视：一个略窄的方形铺面，
上方有一块横向的**突出招牌**（招牌板 + 两根支撑斜杆），招牌面上有两道横向的刻线（表示字）；
下方是一道半开的卷帘门或一扇玻璃门，门内透出**一小片暖铜色**（唯一高光点）。

### ICO-073 · 舞蹈教室（`dance`）

一间舞蹈教室的外立面。正面平视：一个较高的方形立面，
上半部是一排**大面积的竖向窗格**（三到四格，玻璃用深色，其中一格有暖铜色反光——唯一高光点）；
立面外侧斜靠着一根**把杆**（一根横向的细杆 + 两个支柱），
在把杆下方悬挂着一双**舞鞋的剪影**——鞋尖朝下、两根鞋带垂下，
**务必在鞋的轮廓与鞋带上带极淡的冷紫 #A86AC8**（不超过图形 8% 面积），暗示这里的异常。

> **ICO-073 是五张里唯一带冷紫的一张**，因为舞蹈教室是红舞鞋怪谈的发生地。
> 冷紫必须克制到「细看才发现」，不能变成一张紫色图标。

### ICO-074 · 裁缝铺（`tailor`）

一间裁缝铺。正面平视：一个较矮的方形立面，上方一块小招牌，
下半部是一扇橱窗；立面外挂着一把**大剪刀的剪影**（两片交叉的刃 + 两个环形手柄），
旁边立着一个**线轴**（竖立的圆柱 + 缠绕的线层纹）。
高光点在招牌的一角或橱窗内（暖铜，唯一高光点）。

### ICO-075 · 社区活动中心（`community`）

一栋公共建筑。正面平视：一个**较宽、较低**的方形建筑（比其它四座更宽更扁，体现「公共设施」），
中央是一扇双开的门（两条竖缝把门分成两扇），
门左侧墙面上挂着一块**公告板**（矩形板 + 板上几道横向刻线），
门右侧是一张**长椅**（横向座板 + 两根支腿）。
高光点在门口的灯或公告板一角（暖铜，唯一高光点）。

## 4. 出图批次建议

15 张分 **3 次**：

| 次序 | 内容 | 说明 |
|---|---|---|
| 第 1 次 | ICO-071 长明修理铺 · 先只出 `unlocked` 一张 | 定「建筑剪影 + 一处暖灯」这套语言。这是玩家的家，造型最需要打磨 |
| 第 2 次 | ICO-072 ~ ICO-075 的 `unlocked`（4 张） | 带第 1 次的图作参考，保证五座建筑的**宽度感与高度层次**成套 |
| 第 3 次 | 全部 5 个地点的 `known_locked` + `selected`（10 张） | 由已有图派生，不重新设计形状 |

> **`known_locked` 与 `selected` 不要独立设计**——必须从 `unlocked` 派生，
> 否则三态形状不一致，切换时地图上会「跳一下」。
>
> **第 3 次的正确做法**：把该地点的 `unlocked` 图喂给 AI，指令为
> 「保持这张图的形状与尺寸完全不变，把整体改为灰 #6E7684、轮廓改虚线、去掉内部细节与暖光」。

## 5. 本批验收要点

- [ ] **五座建筑并排放在地图上是成套的**：同一视角、同一地基宽度、同一明度区间
- [ ] 五座建筑的**高度与宽度有区分**（铺面窄、活动中心宽扁、舞蹈教室高），在地图上能靠轮廓认出
- [ ] 每座建筑有且只有**一处暖铜高光点**（这是全批共同的记号）
- [ ] 五座建筑的**视觉重量接近**，没有一座明显比其它密或空
- [ ] `ICO-073 舞蹈教室` 的冷紫只在鞋与鞋带上，面积不超过 8%，细看才发现
- [ ] `known_locked` 与 `unlocked` **形状完全一致**，只有灰色 + 虚线 + 去细节的差异
- [ ] `selected` = `unlocked` + 外环，建筑本体逐像素一致
- [ ] 缩到 **44×44**（实际显示尺寸）仍能认出是哪座建筑——这是本批最硬的验收项
- [ ] `undiscovered` 态**没有出图**（程序不渲染，不需要）
- [ ] 全部 128×128 透明背景 PNG，放入 `Assets/Game/Sprites/UI/图标/地点/`
