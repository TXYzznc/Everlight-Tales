## 1. 固定模块（逐字复用）

### 图标视觉语言（固定）

```
一款竖屏手机游戏的资源物品图标，2D 数字绘制，成套的精密工装风格。
图标是**彩色单态图**：物体用其自身的材质颜色表现（铜是铜色、玻璃是淡青、晶体是冷紫），
但一律低饱和、压在深色金属的基调里，不允许出现糖果色或高饱和塑料色。
背景完全透明，形状之外不画任何东西。
造型语言：物体是**被用过很多年的老件**——有轻微的磨损棱、边缘收得干净、
用大面平涂加少量硬边笔触画出体积，不画照片级反射。
用**实心块面**画，不是描边线稿；端头与转折处小圆角。
不使用投影（外扩），不使用外发光（材质自发光允许极窄，不超过 4px）。
缩到 48px 仍然一眼能认出是什么，这是本批唯一的硬标准。
```

## 2. 本批的造型规范

| 项 | 规范 |
|---|---|
| 源图尺寸 | 128×128，透明背景 PNG |
| 图形占比 | 外接框约占画布 **82%**（物品类图标要占得满一点，才认得出是什么） |
| 笔画/块面 | 主体用块面；内部的刻线、纹路统一 **4px** |
| 视角 | 一律**正面平视**或**略微俯视 15°**（物品类允许小俯角以显示体积），全批统一 |
| 光 | 光从左上来，左上缘亮、右下缘暗，暗部不超过物体自身尺寸的 15% |

### 稀有度的表达方式（重要）

材料分三档稀有度：普通 / 精良 / 稀有。**本批图标本身不承担稀有度表达**——
图标只画「这是什么材料」，稀有度由程序在图标外加**角标**（`SCR-12-06` 铜/银/紫三档小角标）表示。

> 理由：若图标同时表达材质与稀有度，两套信息会互相干扰；
> 而且同一材料在不同界面可能以不同强调程度出现，把稀有度做进图标就改不动了。

但**材质本身的自然差异可以保留**：铜是暖铜色、玻璃是淡青白、定势残晶是冷紫（它本身就是稀有物）。

## 3. 逐项画面主体

### ICO-051 · 维修费（唯一货币）

一枚黄铜币。正面平视的圆形铜币，币面中央压印一枚小齿轮（六齿），齿轮外围一圈细密的内刻线（币缘齿纹）。币面整体暖铜 `#E0A858`，左上缘一道纸白窄高光，币缘下侧压暗到 `#9A6424`。**这是全局唯一的货币图标，造型要最讲究、最容易被记住。**

### ICO-052 · 铜芯线（MT-001）

一段盘绕的铜线。三到四圈松散的线圈（正面可见的椭圆环叠压），线头从右上翘出并略微弯折；线体呈暖铜色，每一圈的左上缘有窄高光、右下缘压暗，形成圆线的体积。

### ICO-053 · 精密齿轮（MT-002）

一枚小齿轮。八齿齿轮正面平视，齿形短而密（比 `ICO-012 设置` 的齿轮更精巧），中央是圆形轴孔（镂空），轴孔外围一圈加强环；齿轮面为钢灰色 `#8A9098`，齿顶有窄亮高光。

### ICO-054 · 玻璃镜片（MT-003）

一枚圆形玻璃镜片。正面平视的圆片，边缘有一圈窄的倒角环（亮）；镜片本体是淡青白色半透明感（用极淡的 `#C8D8E0` 到 `#8AA0B0` 的层次表达厚度，**不要用透明像素**），镜面左上有一道细长的斜亮反光条。**不要画成闪光的宝石**——它是打磨过的镜片，光是细而长的，不是星芒。

### ICO-055 · 校准簧片（MT-004）

一片弯折的薄金属片。一条窄长的金属带在中间折成一个钝角（约 120°），两端各有一个极小的圆孔；片的正面为浅钢灰 `#9AA2AA`，折角处的上缘有一条亮线、下缘压暗。

### ICO-056 · 定势残晶（MT-005，精良）

一枚六棱晶体。竖向的六棱柱，顶面是一个菱形（表示能看到顶面），柱身有两个可见侧面（左面亮、右面暗）；晶体内部**透出冷紫 `#A86AC8` 的内发光**（集中在柱心偏下，宽度不超过柱宽的 40%），柱体边缘是半透明的冷紫灰。整体要「脆、通透、有点危险」。

### ICO-057 · 异常纹样（MT-006，稀有）**× 5 个变体**

五张同族图标：**同一枚徽章的底座，中央的侵蚀纹路各不相同。**

**共用底座**：一个圆角方形的小金属牌（深灰蓝 `#262B34`，四边 1px 收边），
牌面中央是**冷紫 `#A86AC8` 的侵蚀纹路**（由细线构成，像裂痕、藤蔓或笔迹），
纹路从牌面中心向外扩散但不触边（四周留约 12% 的边距）。

| 变体 | 来源怪谈 | 纹路的形态 |
|---|---|---|
| `redshoe` | 红舞鞋 | 两条相互缠绕的鞋带形曲线，一上一下交错，末端各有一个小圆环 |
| `paintedskin` | 画皮 | 一道从中央向外翻卷的薄片形（像剥落的皮），边缘呈锯齿状 |
| `mirror` | 风月宝鉴 | 一个不闭合的圆环，缺口朝右下，环内有几道放射状短线（像裂纹） |
| `portrait` | 道林格雷的画像 | 一个方框轮廓，框内有几笔斜向的涂抹线（像被划掉的画） |
| `station` | 如月车站 | 两条平行的水平线（像铁轨）向画面上方汇聚，汇聚点有一个小圆 |

> 这五个纹路**必须一眼可分**，因为材料背包里 `异常纹样·红舞鞋` 与 `异常纹样·画皮` 是两条不通用
> 的独立库存。玩家必须能扫一眼图标就知道自己手里是哪一种，不能靠读文字区分。

### ICO-058 · 图样（Blueprint）

一卷图纸。一个从右侧卷起的纸卷（可见卷心的螺旋口），左侧展开一小段纸面，纸面上用极细的线画出两三道工程技术图的线（一道横线 + 一个圆 + 一条斜线）；纸张是米白 `#E0DCC8` 的老纸色，卷心处压暗。

### ICO-059 · 材料（通用）

一个通用材料袋。一个束口的布袋（袋身略鼓，袋口用一道绳结扎紧），袋身是深棕灰的粗布色 `#5A5048`，袋口绳结为暖铜色小绳；袋身正面有一小块补丁（不同深浅的方形色块）表示用了很久。

### ICO-060 · 零件（通用）

一枚通用零件。正面平视的八齿齿轮，中央轴孔镂空，齿轮面为暖铜 `#E0A858`，齿顶与轴孔内缘有窄亮高光；整体比 `ICO-053 精密齿轮` 更粗壮、更朴素（齿更宽、更少）。

### ICO-061 · 形态（通用）

零件 + 冷紫变形叠加。以 `ICO-060 通用零件` 为基础形状，在其**右上半部叠加一层冷紫 `#A86AC8` 的半透明侵蚀层**（边缘呈不规则的侵蚀轮廓，像金属被异化了一半），侵蚀层上有两三道极细的冷紫裂纹。传达「同一个零件、被怪谈改写过」。

### ICO-062 · 时间格（TimeCost）

小方格 + 半个沙漏。一个圆角方框（深灰蓝金属），框内是一个沙漏的简化形：上下两个相对的三角形，中间一条细颈，**上三角里填满沙（暖铜色小点密集）、下三角空着**——表示「时间要被消耗掉」。方框的右下角略微开口。

## 4. 出图批次建议

16 张分 **4 次**：

| 次序 | 内容 | 说明 |
|---|---|---|
| 第 1 次 | ICO-051 维修费 + ICO-062 时间格 | 两个「通用量」图标（货币与时间），最先出，造型语言会被后面沿用 |
| 第 2 次 | ICO-052 ~ ICO-055（4 种普通材料） | 四个普通材料一起出，保证四者的**体量感一致**（不能铜线很细、镜片很大） |
| 第 3 次 | ICO-056 定势残晶 + ICO-058 图样 + ICO-059 材料袋 | 精良/稀有物 + 通用件 |
| 第 4 次 | ICO-057 五个变体 | 五张同族图标，**必须一次出完**，保证底座完全一致 |
| 第 5 次 | ICO-060 通用零件 + ICO-061 形态 | 后者的形状依赖前者，一起出 |

> **ICO-057 的五个变体是最容易失败的一项**：五张图标只有中央纹路不同，
> 底座必须逐像素一致。建议先出 `redshoe` 一张作为底座基准，
> 其余四张**以第一张为参考图**生成（只换中央纹路），不要五张独立描述生成。

## 5. 本批验收要点

- [ ] **16 张图标并排放在一起是成套的**：块面处理方式、光源方向、图形占比一致
- [ ] 全部物品有「被用过很多年的老件」的质感，不是崭新的商品图标
- [ ] 没有出现高饱和的塑料色或糖果色
- [ ] **图标本身不承担稀有度表达**——稀有度由程序加角标，图标只画「这是什么」
- [ ] `ICO-054 玻璃镜片` 的反光是**细长的斜亮条**，不是星芒/闪光效果；镜片是半透明感而非透明像素
- [ ] `ICO-056 定势残晶` 的内部冷紫发光不超过柱宽 40%，没有变成发光宝石
- [ ] `ICO-057` 五个变体**底座逐像素一致**，只有中央纹路不同，且五者一眼可分
- [ ] `ICO-061 形态` 的形状明显是 `ICO-060 通用零件` 的变体（同一个零件的异化版）
- [ ] `ICO-052` ~ `ICO-055` 四种普通材料的**体量感一致**（在图标框内占据的面积接近）
- [ ] 缩到 **48px** 仍能辨认；`ICO-057` 的五个变体在 48px 下仍能区分
- [ ] 全部 128×128 透明背景 PNG，放入 `Assets/Game/Sprites/UI/图标/`
