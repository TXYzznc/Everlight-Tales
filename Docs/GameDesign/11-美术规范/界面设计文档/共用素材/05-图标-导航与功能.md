## 2. 本批的技术前提（**必须先理解，否则整批要重画**）

### 2.1 为什么必须是单色

导航与功能图标出现在**会变色的容器**里：

| 场景 | 图标需要呈现的颜色 |
|---|---|
| 页签 · 未选中 | 纸白 `#E8EAF0` |
| 页签 · **已选中** | **深色 `#171A20`**（选中态页签是暖铜 `#E0A858` 实底） |
| 图标按钮 · normal | 纸白 |
| 图标按钮 · hover | 暖铜 `#E0A858` |
| 图标按钮 · pressed | 暖铜压暗 `#C88A3A` |
| 图标按钮 · disabled | 灰 `#6E7684` |

一套图标要覆盖 6 种颜色语境。**若图标本身画成彩色，选中态（暖铜底）上就会糊成一片。**

因此本批 16 个图标**一律画成纸白单色**，由程序用 `Image.color` 上色，一套图自动适配全部状态。
这比每个状态各画一张省 5/6 工作量，也是唯一不会出错的做法。

> 这与原始清单中给某些图标标注颜色（如「家园：暖灯是唯一暖光点」）不一致，**以本文件为准**：
> 那盏灯改用**形状**表达（灯的轮廓 + 镂空灯罩），不靠颜色。

### 2.2 统一造型规范

| 项 | 规范 |
|---|---|
| 源图尺寸 | 128×128，透明背景 PNG |
| 图形占比 | 外接框约占画布 **80%**（四周各留 10% 安全边） |
| 笔画粗细 | **统一 10px**（128 画布上）。这是全批最重要的统一项 |
| 圆角 | 笔画端头与转折处统一**半径 3px** |
| 视角 | 一律**正面平视**，无透视、无倾斜、无投影方向 |
| 光 | 不画光源方向（单色，靠形状而非光影表达） |

> **先出一个基准图标定线宽**（建议先出 `ICO-012 设置`——齿轮最容易判断线宽是否合适），
> 确认后再批量出其余 15 个。**不要一次把 16 个全出了再回头改线宽。**

## 3. 逐项画面主体

### ICO-001 · 地图

折叠的城市地图 + 一枚定位针。地图是摊开一半的油纸地图，可见两三条折痕、边缘略微卷起；一枚黄铜大头针斜插在地图偏右上的位置，针头是圆帽形。地图占画布约 85%，大头针压在图上。

### ICO-002 · 任务

一块夹板清单。木质或金属的方板，顶部一个圆环卡箍（可透视的镂空圆环），板面刻画两行横向刻线代表条目。整体轮廓方正略竖长。

### ICO-003 · 家园

一座带灯的屋顶。三角形的屋顶（屋脊在顶部中央），屋顶下方是一个小方窗；窗内画一盏**吊灯的轮廓**（梯形灯罩 + 下方一个小圆点），灯罩用镂空与实心对比表现——**靠形状表达「这是唯一亮着的东西」**，不靠颜色。

### ICO-004 · 工作台

台钳 + 扳手。画面左侧是固定在工作台边缘的台钳（两个对合的分块 + 一根横螺杆），右侧是一把开口扳手斜靠。两者在底部由一条短横线（工作台面）连成一体。

### ICO-005 · 事件

一张便签纸 + 一枚铃铛。便签是一张略微歪斜的小方纸（一角微卷），右上角叠着一枚小铃铛（钟形轮廓 + 顶部的环）。

### ICO-006 · 怪谈

半睁的眼睛。一只横向的杏仁形眼眶，其中上眼睑压下一半（遮住瞳孔的上半部），瞳孔是一个小圆孔。整体要克制、像一个刻在金属上的符号，**不要画成恐怖的眼睛**（无血丝、无睫毛、无写实眼白）。

### ICO-007 · 图鉴

翻开的书 + 一枚零件。书是摊开的两页（左右两片略微上扬的弧形页片，中间一条书脊竖线），书页上叠着一枚小齿轮（八齿）。

### ICO-008 · 保管

木箱 + 封条。一个正面平视的方形储物箱，箱盖与箱体之间有一条横向接缝，接缝上贴着一条十字交叉的封条（两条窄带）。

### ICO-009 · 资料台

档案夹 + 放大镜。一个竖立的档案夹（矩形 + 顶部一个半圆的提环），右下角叠着一枚放大镜（圆环 + 短手柄），镜片用镂空表示。

### ICO-010 · 来客

一扇门 + 门铃。一扇带小窗的矩形门（右侧一个圆点门把手），门框右侧墙上挂着一枚圆形的门铃按钮，按钮外围有一圈细环。

### ICO-011 · 服务

齿轮 + 对话气泡。左下是一个六齿或八齿的齿轮，右上叠着一个圆角矩形的对话气泡（气泡左下角有一个小三角尾巴）。

### ICO-012 · 设置

一枚六齿黄铜齿轮。粗壮的六齿（齿宽与齿距相等），中央是一个圆形的镂空轴孔，轴孔外围一圈略窄的环形加强筋。**这是本批的线宽基准图标**，笔画定为 10px。

### ICO-013 · 暂停

金属双竖杠。两根等宽等高的竖向圆角矩形并排，间距约为单根宽度的 0.8 倍，两端的圆角半径与全批一致。

### ICO-014 · 返回

左向箭头。一根横向的粗箭头指向左侧，箭头的左端是三角形的箭头尖；箭头的右端有一小段向上的短折（表示「退回」的拐弯），整体轮廓方正。箭头只画一个，不画双箭头。

### ICO-015 · 关闭

圆角叉。两根等长等宽的斜杠呈 X 形交叉，四端都是圆角端头；交叉点处两根斜杠融合成一个实心的小方块。整体外接框为正方形。

### ICO-016 · 等待时段

老式怀表 + 月牙。一只圆形怀表（外圈粗环 + 顶部一个小的环形提钮），表盘中央用镂空刻出时针与分针（指向约 10 点 10 分方向的短刻线）；怀表的右下角叠着一个极小的月牙（缺口朝右上）。

## 4. 出图批次建议

16 个图标分 **4 次**，每次 4 个：

| 次序 | 内容 | 说明 |
|---|---|---|
| 第 1 次 | ICO-001 地图、ICO-002 任务、ICO-003 家园、ICO-004 工作台 | 四个导航页签图标（同一排显示，必须成套） |
| 第 2 次 | ICO-005 事件、ICO-006 怪谈、ICO-007 图鉴、ICO-008 保管 | 页签与分区图标 |
| 第 3 次 | ICO-009 资料台、ICO-010 来客、ICO-011 服务、ICO-013 暂停 | 分区与操作 |
| 第 4 次 | ICO-014 返回、ICO-015 关闭、ICO-016 等待时段、ICO-012 设置 | 纯操作图标 |

> **第 1 次的四个图标会并排显示在主页壳底部页签栏上**，
> 因此它们的**视觉重量必须接近**（不要地图很密、任务很空）。
> 出完第 1 次后把四张并排缩到 48px 看一眼，重量不均就重出。

## 5. 本批验收要点

- [ ] **16 个图标并排放在一起时是成套的**：笔画粗细、圆角大小、图形占比、留白完全一致
- [ ] 全部是**纸白单色**（#E8EAF0 及其亮暗层次），没有出现彩色或多色
- [ ] 没有一个图标是「描边线稿」画法（全部是实心笔画 + 镂空）
- [ ] 缩到 **48px** 仍能一眼辨认出是什么——逐张验证，认不出的重画
- [ ] 图形外接框约占画布 80%，四周有均匀安全边
- [ ] 视角全部是正面平视，没有透视、倾斜或投影方向
- [ ] ICO-003「家园」用**形状**表达「唯一亮着的灯」，没有靠明暗或颜色
- [ ] ICO-006「怪谈」克制如刻纹符号，不是恐怖写实眼睛
- [ ] 第 1 次的四个导航图标并排时**视觉重量接近**
- [ ] 全部 128×128 透明背景 PNG，放入 `Assets/Game/Sprites/UI/图标/`
- [ ] 交付时同时说明「这些图是单色待上色的」——避免程序侧误当彩色图直接用
