## 1. 固定模块（每个素材提示词都要接在后面，逐字复用）

### UI 视觉语言

```
一款竖屏手机游戏的界面设计，2D 数字绘制，成熟的商业游戏 UI 完成度。
整体基调：深夜仍在营业的老式精密修理铺——黄铜工具的秩序感与门外未知之物的侵蚀感同处一框。
克制的低饱和深色底，靠局部暖光与冷光建立层次；不使用大面积高亮、不糖果色、不卡通描边，
不使用拟真照片贴图、玻璃拟态、霓虹赛博或扁平极简白底风格。
面板与控件用「薄金属板 + 蚀刻线 + 轻微内阴影」构成，边缘清晰、拐角圆润但克制（圆角半径小），
有实体感与触感，像一块被反复使用的工装面板。避免：厚塑料质感、浮雕过多、廉价渐变、立体投影过重。
```

### 色彩体系

```
以深色为绝对主体，具体色值：最底背景 #171A20，页面背景 #1E2229，
面板底 #262B34，卡片底与悬停 #2F3540，分隔线与描边 #3E4652，
主文本 #E8EAF0，次文本 #A8B0BC，弱文本与禁用 #6E7684。
强调色两支：暖铜 #E0A858（主按钮、高亮、当前选中、金属暖面），
冷紫 #A86AC8（怪谈、异常、待处理、警示性的神秘感）。
辅助功能色：工具青 #5A9EB8（次级强调、链接）、成功 #5AB878、危险 #D05A5A、警告 #D8A858。
暖铜与冷紫是画面唯一的两处「光」，其余全部压在深灰蓝的中低明度区间；
暖冷面积比大致 3:1，暖为主、冷为异。禁止大面积高饱和与多色并列竞争。
```

### 材质与光影

```
光源假定来自画面内的灯具与屏幕本身：左上偏暖的方向光，边缘有极轻微的冷紫反射光。
金属件强调转折面与窄亮反光带，不画照片级反射；布料与纸张用大面平涂加少量褶皱折线。
面板高光只在边缘 1~2px 处出现，形成薄金属收边；阴影短、硬、贴合结构，不做长投影与浓重 AO。
所有发光元素（指示灯、符文、异常侵蚀）用有限的光晕，光晕不超过元素自身尺寸的 1.5 倍。
整体干净、层次分明，从缩略图能读出分区，放大能看见刻线与铆钉的细节安排。
```

### 细节与统一性

```
统一全画面的圆角尺度、描边宽度（1~2px）、刻线间距与图标笔画粗细；
功能图标用统一线宽与统一圆角，风格一致，可成套使用；
同类控件在所有界面中保持同一种视觉语言，不因界面不同而改变造型。
焦点区域（主按钮、当前选中页签、提示信息）才允许更高对比与更精细的细节，
次要区域概括处理。不得让某一区域突然变成其他画风、摄影写实或手绘涂鸦。
```

## 2. 本批的核心原则：**先出母版，再换色派生**

按钮族是「母版 + 派生」的典型。**最大的风险是让 AI 分别设计四个按钮**，
结果得到四种圆角、四种收边、四种厚度的「看起来差不多的按钮」——这是 UI 不统一的主要来源。

正确做法：

```
第 1 步  出「基础按钮形状」—— 只定义形状，不定义色彩语义
         （外形轮廓、圆角半径、收边宽度、内阴影、高光位置、刻线）
第 2 步  用同一个形状，只换色彩语义，派生 4 个变体：
         主按钮（暖铜实底） / 次按钮（深灰描边） / 危险按钮（低饱和红） / 一键补充（暖铜亮底）
第 3 步  每个变体各出 4 个状态（normal/hover/pressed/disabled），
         每个状态一个唯一编号、一段完整提示词、一张独立交付文件
```

**基础按钮形状描述（下文所有按钮状态提示词中的「形状部分」都指它，出图时保持逐像素一致）：**

> 圆角矩形按钮，圆角半径约 8px，上下左右对称。四边一圈 1px 浅色收边线，
> 收边线内侧距边 4px 处一道极淡内阴影形成厚度，上缘内侧一道 1~2px 窄亮高光线（左上光源），
> 下缘内侧一道对应暗线。板面中央完全平整纯色，无图案无横向渐变。
> 四角在 border 8px 范围内干净收口。透明背景，不画文字，不向外投影。

### 九宫格约束

| 约束 | 说明 |
|---|---|
| 源图尺寸 | 大按钮 256×128，小按钮 256×64，页签 256×64，筛选片 128×64，图标按钮 128×128 |
| border | 一律 8（图标按钮 16，一键补充 12） |
| 中心与四边中段 | 必须是**低对比纯色**，被拉伸区域不得有图案或横向渐变 |
| 外扩 | **禁止向外投影/外发光**，拉伸后会变成沿边的平行色带 |
| 文字 | 不画。按钮上的文字由程序用 TMP 渲染，素材只是「空壳」 |

## 4. 出图批次建议

本批 37 个素材分 **6 次**（先出母版作过程参考，不交付）：

| 次序 | 内容 | 张数 | 说明 |
|---|---|---|---|
| 第 0 次 | 母版按钮形状 | 1（过程参考，不交付） | **只出形状不定色**，挑最满意的保留为基准 |
| 第 1 次 | SHR-025 图标按钮 4 态 | 4 | 方形族，复用面最广（15 界面），先出 |
| 第 2 次 | SHR-021 主按钮 4 态 + SHR-022 次按钮 4 态 | 8 | 带母版一起喂，只换色 |
| 第 3 次 | SHR-024 危险 4 态 + SHR-030 一键补充 4 态 + SHR-023 小按钮 4 态 | 12 | 派生完成，收口按钮族 |
| 第 4 次 | SHR-026 页签3 3 态 + SHR-027 页签4 4 态 | 7 | 页签族（同形状宽度版） |
| 第 5 次 | SHR-028 页签5 3 态 + SHR-029 筛选片 3 态 | 6 | 收口页签与筛选 |

> **每个多态族内部出图顺序**：先出 `normal` 定形状，再把 normal 的图作为参考图，
> 逐个生成 hover/pressed/disabled/active，指令为「保持形状与尺寸完全一致，只改颜色/明暗」。
> 每次出图都把上一次成果一起喂进去作参考，这是保证「同一套圆角与收边」的唯一可靠办法。

## 5. 本批验收要点

- [ ] **本批 37 个素材，每个有唯一编号（`SHR-xxx-状态`）、一段独立提示词、一张独立交付文件**
- [ ] **所有按钮共用同一个外形轮廓**——叠在一起看，圆角、收边宽度、高光位置、内阴影完全重合，只有颜色不同
- [ ] 四个按钮变体的**视觉权重排序清晰**：一键补充 > 主按钮 > 危险按钮 > 次按钮
- [ ] 主按钮「亮面」、次按钮「亮边」（hover 时次按钮是描边转青，不是板面变亮）——两者强调方式不同
- [ ] 危险按钮是**低饱和**的工装红，不是鲜红
- [ ] 图标按钮中央 56×56 完全干净（要被功能图标覆盖，不能有底色花纹）
- [ ] 页签三族同族：3/4/5 页版本形状、圆角、分隔刻线完全一致，只有宽度不同
- [ ] 页签 `active` 是暖铜实底；筛选片 `active` 是工具青实底——**两者不能撞色**
- [ ] 小按钮（行内）细节比大按钮更概括，没有糊成一团的铆钉与多重收边
- [ ] 每个多态族的各态**画布尺寸与外轮廓逐像素一致**（切换时不跳变）
- [ ] 全部透明背景、无文字、无图标、无向外投影/发光
- [ ] 文件按 `<部件>_<状态>` 命名，放入 `Assets/Game/Sprites/UI/控件/`
