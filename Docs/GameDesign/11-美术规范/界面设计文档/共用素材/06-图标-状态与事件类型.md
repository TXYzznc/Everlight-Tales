## 1. 固定模块（逐字复用）

### 图标视觉语言（固定）

```
一款竖屏手机游戏的 UI 状态图标，2D 数字绘制，成套的精密工装风格。
图标是**彩色单态图**：允许使用指定的语义色，但整体必须克制、低饱和，
除语义色外其余部分一律用深灰蓝金属（#3E4652 / #2F3540 / #262B34）与纸白 #E8EAF0 高光构成。
背景完全透明，形状之外不画任何东西。
造型语言：由黄铜工装件的几何形状构成——圆角矩形、圆柱、齿轮、卡箍、刻线、封条；
用**均匀的实心笔画**画成，不是描边线稿；笔画端头与转折处一律小圆角。
不使用渐变、不使用投影、不使用外发光（语义色允许极窄的内发光，不超过 3px）。
```

## 2. 本批的造型规范

| 项 | 规范 |
|---|---|
| 源图尺寸 | 128×128，透明背景 PNG |
| 图形占比 | 外接框约占画布 **78%**（四周留安全边；本批图形多为小徽标，留白略多于功能图标） |
| 笔画粗细 | **统一 9px**（比功能图标的 10px 略细，因为本批多是「标识」而非「操作」） |
| 圆角 | 笔画端头与转折处统一**半径 3px** |
| 视角 | 一律**正面平视** |
| 语义色用量 | 语义色占图形面积 **不超过 40%**，其余为深灰蓝金属与纸白高光 |

### 语义色分配（本批的统一约定，**不要混用**）

| 语义色 | 用途 | 出现在 |
|---|---|---|
| 暖铜 `#E0A858` | 「可以推进 / 有收益」 | ICO-021 可处理、ICO-025 可领奖、ICO-030 关键件 |
| 工具青 `#5A9EB8` | 「正在进行 / 中性信息」 | ICO-022 进行中 |
| 成功绿 `#5AB878` | 「已经完成」 | ICO-026 已完成、ICO-027 已解决 |
| 冷紫 `#A86AC8` | 「怪谈 / 异常 / 未解」 | ICO-028 待回访、ICO-029 异化、ICO-045 怪谈 |
| 灰 `#6E7684` / 暗灰 `#4A4E56` | 「未到 / 失效 / 错过」 | ICO-023、ICO-024 |

> **暖铜 = 可以去做，冷紫 = 还没解决**——这是本项目最常被误解的一对，务必按上表分配。

## 3. 逐项画面主体

### 3.1 状态图标

**ICO-021 · 可处理** — 一枚实心小圆徽章。圆形底盘（深灰蓝金属环，宽 8px）内部是一个**暖铜色实心圆点**，占内径的 70%，圆点上有一小片纸白高光。整体像一枚镶嵌的指示灯。语义色：暖铜。

**ICO-022 · 进行中** — 半环箭头。一个圆环被切掉右上约 90° 的弧段，切口两端各有一个小箭头尖，形成「正在转动的循环」；环体深灰蓝金属，**切口处的那段弧与两端的箭头尖用工具青**。语义色：工具青。

**ICO-023 · 未到开放时段** — 闭合的钟。圆形钟面 + 顶部一个小环提钮，钟面上刻出时针与分针（未连通到边缘，表示「还没开始」）；整体**全用灰 #6E7684**，不点任何语义色。语义色：灰。

**ICO-024 · 本段已错过** — 破损的钟。与 ICO-023 相同的钟形，但钟面右上方有一块**缺口**（像被磕掉一角），时针分针略歪；整体用**暗灰 #4A4E56**，比 ICO-023 更暗一档。语义色：暗灰。

> ICO-023 与 ICO-024 必须**同形**（只在缺口与明度上有差异），这样玩家能读出「同一个钟，只是破了」。

**ICO-025 · 可领奖** — 张开的手托着一枚小礼盒。下方是一只简化的手掌（四指并拢的托盘形），掌心上放一个小方盒，盒盖半开，**盒内透出一小片暖铜光**（不超过 3px 的内发光）。语义色：暖铜。

**ICO-026 · 已完成** — 勾选方框。一个圆角方框，框内是一条粗的对勾（从框的左下偏中起笔，向右下再向右上）；方框为深灰蓝金属，**对勾与方框的内缘为成功绿**。语义色：成功绿。

**ICO-027 · 已解决** — 闭合的封条。一条横向的封条（窄带）贴在一个矩形的接缝上，封条中央有一个**圆形压印**（表示已盖章结案）；封条为深灰蓝，**压印为成功绿**。语义色：成功绿。

**ICO-028 · 待回访** — 回旋箭头。一根向右弯折后又绕回的粗箭头（U 形回转），箭头尖指向左侧，形成「要回去」的动势；**箭头本体用冷紫**，尾部一小段为深灰蓝。语义色：冷紫。

**ICO-029 · 异化** — 裂纹三角警示。一个等腰三角形（顶点朝上）的金属牌，牌面上有一道从顶点向下延伸并分叉的**裂纹**；三角形描边为深灰蓝，**裂纹用冷紫**并带极窄冷紫内发光。语义色：冷紫。

**ICO-030 · 关键件** — 星形铆钉。一枚正面平视的铆钉，中心是一个圆的压印，外围是六角或八角形的金属座；**铆钉的顶面用暖铜**，六角座的六个角略外凸形成星形轮廓。语义色：暖铜。

### 3.2 事件类型图标

> 这六个承载**不同信息，不能合并或互相替代**。六者必须同族：同一线宽、同一图形占比、同一视角。

**ICO-041 · 维修** — 一把开口扳手。竖向放置，开口朝上偏左，手柄向下逐渐收窄，手柄末端有一个小圆孔。

**ICO-042 · 处置** — 一把扫帚斜放。扫帚杆从左下到右上，扫帚头在右上（由几束平行短线组成的梯形），柄端有一小段手握的加粗。

**ICO-043 · 生活** — 一只茶杯配托盘。正面平视的圆口茶杯（杯口一个横向椭圆、杯身梯形、右侧一个环形杯柄），下方是一个扁平的托盘；杯口上方有两道极短的弧线表示热气。

**ICO-044 · 调查** — 一枚放大镜。圆形镜框（宽 9px 的粗环）+ 镜片用镂空表示，右下角一根短粗手柄（斜向 45°）；镜框内可以有一条极短的斜亮线表示镜面反光。

**ICO-045 · 怪谈** — 冷紫眼形符号。与 `ICO-006 怪谈` 同族的眼睛形状（杏仁形眼眶、上眼睑压下一半），但**眼睑与瞳孔用冷紫 #A86AC8**，外框为深灰蓝。两者是同族但用途不同：ICO-006 是页签标识（单色），ICO-045 是事件类型标识（彩色）。

**ICO-046 · 全部** — 九宫格小点阵。三行三列共九个等大的实心小圆点，间距均匀，外接框为正方形；**左上角的三个点用暖铜**，其余六个点为深灰蓝——暗示「全部里也分主次」。

## 4. 出图批次建议

16 个图标分 **3 次**：

| 次序 | 内容 | 说明 |
|---|---|---|
| 第 1 次 | ICO-021 ~ ICO-026（6 个） | 六个「正向」状态图标，语义色为暖铜/青/绿 |
| 第 2 次 | ICO-027 ~ ICO-030（4 个） | 收尾状态，含两个冷紫 |
| 第 3 次 | ICO-041 ~ ICO-046（6 个） | 六个事件类型图标，**必须一次出完**——它们会并排显示在任务页的筛选条上 |

> **第 3 次是重点**：六个类型图标并排出现在同一排筛选片上，
> 只要有一个的线宽或图形占比不同，整排就会看出「不合群」。出完后并排缩到 32px 检查一次。

## 5. 本批验收要点

- [ ] **16 个图标并排放在一起是成套的**：笔画粗细、圆角大小、图形占比、留白一致
- [ ] 语义色严格按 §2 的分配表使用：**暖铜 = 可以去做，冷紫 = 还没解决**，没有混用
- [ ] 语义色占图形面积不超过 40%，其余是深灰蓝金属与纸白高光——整体仍是「深色金属件 + 一点色」
- [ ] 没有出现满色填充的图标（不是彩色的扁平 App 图标）
- [ ] **ICO-023 与 ICO-024 同形**，只在缺口与明度上有差异（能读出「同一个钟，破了」）
- [ ] ICO-045 与 ICO-006 是**同族但不同用**：045 彩色（事件类型）、006 单色（页签）
- [ ] ICO-041 ~ ICO-046 六个事件类型图标**线宽与图形占比完全统一**，并排时像一套
- [ ] 缩到 **32px** 仍能辨认（本批图标常用在列表行内，尺寸比功能图标小）
- [ ] 图形外接框约占画布 78%，四周有均匀安全边
- [ ] 全部 128×128 透明背景 PNG，放入 `Assets/Game/Sprites/UI/图标/`
- [ ] 交付时标注每张对应的语义色，便于程序侧核对
