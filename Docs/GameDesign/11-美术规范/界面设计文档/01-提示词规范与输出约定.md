# 提示词规范与输出约定

> 用途：为「界面效果图」「界面 UI 素材」「交互控件多状态素材」三类产物定义统一的提示词骨架、
> 尺寸规范、命名规范与交付要求。**所有界面文档的提示词都按本文件的结构书写。**
> 依据：`美术风格和规范/局内对象/提示词结构规范.md`（盘面棋子类沿用其 8 模块）、
> `UI视觉规范.md`（色板/字号/九宫格）、`美术素材清单与资源目录.md`（目录/命名/导入设置）。

---

## 1. 三类产物的差异（先分清，避免出图方向错）

| | ① 界面效果图 | ② 界面素材 | ③ 交互控件多状态素材 |
|---|---|---|---|
| 是什么 | 一整屏的完成态画面 | 屏内可复用的图片部件 | 一个控件在若干交互状态下的图片 |
| 内容 | 背景 + 全部面板 + 全部文字 + 全部图标 | **只画部件本体，不画文字、不带背景** | 同左，但每个状态一张 |
| 尺寸 | 1080×1920 | 按清单 | 按清单（同控件各状态尺寸必须一致） |
| 是否切图 | 不切，仅作视觉参考与验收依据 | 需要，需按九宫格/图标规范切 | 需要，按状态切 |
| 透明背景 | 否 | **是**（图标/九宫格/控件全体） | **是** |
| 文字 | 画出来（用于评估排版密度） | **不画**（文字由程序用 TMP 渲染） | **不画** |

> **关键约定：所有 UI 素材都不含文字，也不含真实内容的图标（如具体零件图）。**
> 文字与真实内容由程序运行时填充；美术只交付「容器」与「通用图形」。

## 2. UI 素材提示词骨架（六模块）

界面效果图与 UI 素材共用同一套骨架，模块 2/4/5/6 是**全项目逐字复用**的固定模块，
只有模块 1（主体需求）与模块 3（布局骨架）按界面/部件填写。

### 模块 1 · 主体与画面需求（每个界面/部件不同）

写清：这是什么界面/部件、屏幕方向与基准分辨率、画面内有哪些区域、玩家的视线落点在哪、
这一屏要传达什么情绪。**不要**写与视觉无关的玩法规则。

### 模块 2 · UI 视觉语言（固定，逐字复用）

```
一款竖屏手机游戏的界面设计，2D 数字绘制，成熟的商业游戏 UI 完成度。
整体基调：深夜仍在营业的老式精密修理铺——黄铜工具的秩序感与门外未知之物的侵蚀感同处一框。
克制的低饱和深色底，靠局部暖光与冷光建立层次；不使用大面积高亮、不糖果色、不卡通描边，
不使用拟真照片贴图、玻璃拟态、霓虹赛博或扁平极简白底风格。
面板与控件用「薄金属板 + 蚀刻线 + 轻微内阴影」构成，边缘清晰、拐角圆润但克制（圆角半径小），
有实体感与触感，像一块被反复使用的工装面板。避免：厚塑料质感、浮雕过多、廉价渐变、立体投影过重。
```

### 模块 3 · 布局骨架（每个界面不同）

用**从上到下的区域列表**描述画面分区，并给出各区域所占高度比例或像素（取自本套文档各界面「布局规格」）。
写明：哪些区域是常驻的、哪些是弹层、视线的第一落点在哪。

### 模块 4 · 色彩体系（固定，可微调对象配色）

```
以深色为绝对主体，具体色值：最底背景 #171A20，页面背景 #1E2229，
面板底 #262B34，卡片底与悬停 #2F3540，分隔线与描边 #3E4652，
主文本 #E8EAF0，次文本 #A8B0BC，弱文本与禁用 #6E7684。
强调色两支：暖铜 #E0A858（主按钮、高亮、当前选中、金属暖面），
冷紫 #A86AC8（怪谈、异常、待处理、警示性的神秘感）。
辅助功能色：工具青 #5A9EB8（次级强调、链接）、成功 #5AB878、危险 #D05A5A、警告 #D8A858。
暖铜与冷紫是画面唯一的两处「光」，其余全部压在深灰蓝的中低明度区间；
暖冷面积比大致 3:1，暖为主、冷为异。禁止大面积高饱和与多色并列竞争。
```

### 模块 5 · 材质与光影（固定）

```
光源假定来自画面内的灯具与屏幕本身：左上偏暖的方向光，边缘有极轻微的冷紫反射光。
金属件强调转折面与窄亮反光带，不画照片级反射；布料与纸张用大面平涂加少量褶皱折线。
面板高光只在边缘 1~2px 处出现，形成薄金属收边；阴影短、硬、贴合结构，不做长投影与浓重 AO。
所有发光元素（指示灯、符文、异常侵蚀）用有限的光晕，光晕不超过元素自身尺寸的 1.5 倍。
整体干净、层次分明，从缩略图能读出分区，放大能看见刻线与铆钉的细节安排。
```

### 模块 6 · 细节与统一性（固定）

```
统一全画面的圆角尺度、描边宽度（1~2px）、刻线间距与图标笔画粗细；
功能图标用统一线宽与统一圆角，风格一致，可成套使用；
同类控件在所有界面中保持同一种视觉语言，不因界面不同而改变造型。
焦点区域（主按钮、当前选中页签、提示信息）才允许更高对比与更精细的细节，
次要区域概括处理。不得让某一区域突然变成其他画风、摄影写实或手绘涂鸦。
```

## 3. 尺寸与九宫格规范

### 3.1 九宫格（拉伸类部件）

| 部件 | 源图尺寸 | border（上下左右同值） | 备注 |
|---|---|---|---|
| 面板 panel | 512×512 | 16px | 四角保持、四边拉伸、中心平铺 |
| 对话框 dialog | 512×512 | 20px | 角更大 |
| 按钮 button | 256×128 | 8px | 左右角 + 上下边 |
| 页签 tab | 256×64 | 8px | 单行 |
| 卡片 card | 256×256 | 12px | 列表卡片、事件卡 |
| 槽位 slot | 256×256 | 12px | 携带槽 / 奖励槽 |

> 出图时**必须在 512×512（或指定源尺寸）画布内居中绘制**，四角与四边结构完整可切；
> 拉伸区（中心与四边中段）必须是**低对比纯色或极弱纹理**，避免拉伸后出现明显形变。

### 3.2 控件与图标

| 类别 | 尺寸 | 说明 |
|---|---|---|
| 主/次按钮 | 240×64（源图 256×128 九宫格） | 需要 normal/hover/pressed/disabled 四态 |
| 页签 | 200×56 | 需要 active/normal/hover 三态 |
| 图标按钮（返回/关闭/暂停/设置） | 128×128 | 需要 normal/hover/pressed/disabled 四态 |
| 功能图标 | 128×128 | 单态（无交互，仅标识） |
| 状态徽标 / 角标 | 64×64 | 单态（形状底 + 由程序填数字） |
| 进度条 / 滑块 | 320×16（源图 320×32 九宫格横条） | 轨道 idle/fill 两段；滑块 normal/hover/pressed 三态 |
| 装饰元素（铆钉/刻线/边角件） | 64×64 | 单态，可镜像复用 |

### 3.3 效果图与半身类

| 类别 | 尺寸 |
|---|---|
| 界面效果图 | 1080×1920 |
| 盘面现场立绘（盘面两侧挂点 200×360 → 建议出图） | 600×1080，透明背景 |
| 对话立绘（挂点 420×680 → 建议出图） | 840×1360，透明背景 |
| 对话背景 / 调查场景底图 | 1080×1920 |
| 序章底图 | 1080×1920 |

## 4. 交互状态规范（重点）

> 用户明确要求：**可交互对象必须按状态出图**。效果图是静态的，看不到悬停与按下。

### 4.1 状态集合（按控件类型）

| 控件类型 | 必须的状态 | 可选状态 |
|---|---|---|
| 主按钮 / 次按钮 | `normal` 正常 · `hover` 悬停 · `pressed` 按下 · `disabled` 禁用 | `selected` 选中 |
| 图标按钮 | `normal` · `hover` · `pressed` · `disabled` | — |
| 页签 | `normal` 未选中 · `active` 当前选中 | `hover` · `badge` 带角标 |
| 卡片（可点击列表项） | `normal` · `hover` · `pressed` · `disabled`（不可用） | `selected` 选中 · `tracked` 被跟踪 |
| 槽位（携带/奖励） | `empty` 空槽 · `filled` 已放入 | `highlight` 拖拽目标高亮 |
| 滑块 | 轨道 `idle` / `track` · 滑块 `normal` / `hover` / `pressed` | — |
| 六边格（盘面） | `normal` · `wall` · `hover` · `selected` | `target` 机械臂合法目标 |
| 盘面棋子 | `normal` · `selected` | `preview` 预演 ghost · `hit` 被撞环 |
| 复选框 / 勾选标记 | `unchecked` · `checked` | — |

### 4.2 状态视觉变化规则（统一，避免每处重新约定）

| 状态 | 变化方式 |
|---|---|
| `hover` 悬停 | 整体亮度 +8~12%，或在底部/内圈增加一条 1px 暖铜内描边；**不改变尺寸** |
| `pressed` 按下 | 整体亮度 −10~15%，主色由 `#E0A858` 压低到 `#C88A3A`，内阴影加重 1px；**不改变尺寸** |
| `disabled` 禁用 | 去饱和至灰（明度不变），主文本与图标改用 `#6E7684`，整体不透明度 55% |
| `selected` 选中 | 外圈 2px 暖铜描边 + 内部底色抬到 `#2F3540`；可选左上角一枚小指示三角 |
| `highlight` 高亮 | 外圈 2px 冷紫虚线或不连续描边，用于拖拽目标与合法落点 |

> **所有状态图的画布尺寸、元素外轮廓位置必须完全一致**，只允许内部明暗/描边/色彩变化。
> 这样程序切换 sprite 时不会产生位移跳动。

### 4.3 提示词写法（状态变体）

不要为每个状态各写一篇长提示词。写法是：**基础提示词 + 状态后缀句**。

示例（主按钮）：

```
base  = 【模块1：一个暖铜色游戏主按钮，圆角矩形九宫格，256×128 源图，无文字，透明背景】
        + 模块 2~6
normal  = base + "以最亮的暖铜 #E0A858 作为面，上缘一道 2px 更亮的收边高光。"
hover   = base + "与 normal 完全相同的形状与尺寸，整体亮度提高约 10%，上缘收边高光加宽到 3px，"
                 "下缘增加一道 1px 暖铜内描边。"
pressed = base + "与 normal 完全相同的形状与尺寸，面压暗到 #C88A3A，内阴影加重，"
                 "上缘高光几乎消失，呈被按下去的凹陷感。"
disabled= base + "与 normal 完全相同的形状与尺寸，整体去饱和成中性灰，明度不变，"
                 "不透明度约 55%，无暖铜高光。"
```

## 5. 文件命名与交付

### 5.1 命名规则

- 界面素材：`<界面英文简称>_<部件>_<状态>@<尺寸>.png`
  例：`titlescreen_btn_primary_normal@256x128.png`
- 共用素材：`shared_<部件>_<状态>@<尺寸>.png`
  例：`shared_panel@512x512.png`、`shared_tab_active@256x64.png`
- 图标：`ico_<语义>@128x128.png`（语义用英文小写，见 `共用素材/05`~`08` 的图标表）
- 效果图：`ui_<界面英文简称>_mockup@1080x1920.png`
- 状态后缀固定用：`normal` / `hover` / `pressed` / `disabled` / `active` / `selected` /
  `empty` / `filled` / `highlight` / `wall` / `target`

> 入库到 Unity 时的**目录与中文名**遵循 `美术素材清单与资源目录.md`：
> 目录用中文（`Sprites/UI/九宫格/`、`Sprites/UI/控件/`、`Sprites/UI/图标/`），
> 文件名可用中文语义。**交付时（外部出图阶段）用上面的英文规范命名，入库时再改中文名。**

### 5.2 交付包结构

```
delivery/
├── 00_效果图/            ui_<界面>_mockup@1080x1920.png
├── 01_共用素材/          shared_*.png
├── 02_界面素材/<界面>/    <界面>_*.png
├── 03_图标/              ico_*.png
└── manifest.csv          编号,文件,尺寸,状态,归属界面,用途
```

### 5.3 导入设置（入库时，由程序侧统一处理）

- `textureType = Sprite`、`spriteMode = Single`、`alphaIsTransparency = 1`、`mipMap = 0`、`wrap = Clamp`
- `maxTextureSize`：盘面棋子 256 / UI 按钮页签图标 256 / UI 面板与对话框 512 / 立绘与背景 1024~2048
- 九宫格：需在 Unity 中设置 Sprite 的 Border（见 §3.1），**出图时保证四边可切**
- 手绘「留白高光」若出现，必须用纸白 `#E8EAF0` 实色填充，**禁止 alpha=0 透明洞**

## 6. 通用验收要点（所有产物）

- [ ] 色板严格落在规定的色值区间内，暖铜与冷紫面积比约 3:1
- [ ] 无文字（UI 素材），无真实内容图标，透明背景干净、无白边残留
- [ ] 同类控件造型一致，圆角/描边/刻线尺度统一
- [ ] 同一控件的多状态图**尺寸与外轮廓完全一致**，仅明暗/描边/色彩变化
- [ ] 九宫格四角结构完整，中心与四边中段为低对比区，拉伸不形变
- [ ] 缩略图尺寸下能读出层次，放大能看见刻线细节
- [ ] 无照片贴图、无玻璃拟态、无霓虹赛博、无糖果色、无卡通描边
- [ ] 图标成套：统一线宽、统一圆角、统一视觉重量
