## 一、这套文档解决什么

程序/客户端阶段已把全部界面做到「功能正确、结构正确、布局正确」，界面内资源用程序化色块占位。
现在需要美术按本目录逐界面产出三类产物：

| 产物 | 数量口径 | 提示词位置 | 交付格式 |
|---|---|---|---|
| **① 界面效果图** | 每个界面 1~3 张（含关键弹窗态） | 各界面文档「§ 界面效果图提示词」 | PNG 1080×1920 |
| **② 界面所需全部美术素材** | 按各界面「专属素材清单」+ 共用素材批次文档 | 各界面文档「§ 专属素材清单」+ `共用素材/01`~`08` | 按清单逐项出图 |
| **③ 可交互控件的多状态素材** | 按各界面「交互控件状态」表 | 各界面文档「§ 交互控件状态」+ `01-提示词规范与输出约定.md` | 每状态一张，命名带状态后缀 |

> **效果图是静态的，素材不是。** 效果图只需要表达「这一屏长什么样」；
> 而按钮、页签、槽位、卡片、滑块这些可交互对象，**必须按状态分别出图**，
> 因为悬停/按下/禁用/选中在静态效果图里看不出来。

### 为什么共用素材要拆成 8 个文档

共用素材原先是**一个 447 行、81 个条目**的文件。两个问题：

1. **条目太多，一次性出图质量低**——一次让 AI 画 80 多个互不相关的部件，它会把注意力平摊，
   结果每个都不够好，也难以保证「这一批是成套的」。
2. **原文件只有清单没有提示词**——它写的是「编号 / 尺寸 / 状态 / 文件名 / 被谁引用」，
   等于一份物料表。AI 只能从「用途：图鉴行、账目行」这种一行字去猜画什么。

拆分后每个批次文档：

- **量可控**：7~16 项 / 10~36 张，一次出图能画完并画好
- **自包含**：内嵌固定风格模块（视觉语言 / 色彩 / 材质 / 统一性 / 反向提示词），
  整份喂给生图 AI 即可，不必再额外粘贴风格文本
- **有画面描述**：每一项都写了「画面主体」长什么样，而不是只给一句用途
- **有状态后缀句**：多状态控件给出「在主体描述之后追加哪一句」，保证各态同形
- **有出图批次建议**：把本批再切成几次，以及每次出完要自检什么

> 拆分只改了「怎么出图」，**没有改动任何编号**——`界面/01`~`20` 里已有的
> 「引用 `SHR-021` 主按钮」这类引用全部照旧有效。

## 三、每份界面文档的固定结构

所有界面文档使用同一套章节，便于批量交接：

| 章节 | 内容 | 给谁看 |
|---|---|---|
| 1. 界面概述 | 所属层、承载方式、脚本、打开入口、出现时机 | 双方 |
| 2. 布局规格 | 1080×1920 基准下的区域划分 + **代码里的真实数值** | 美术（决定画面骨架） |
| 3. 元素清单 | 每个元素的类型/尺寸/位置/文字/字号/颜色 | 美术 + 程序（后续替换） |
| 4. 界面效果图提示词 | 中文 + 英文，直接可粘贴 | 出图 |
| 5. 专属素材清单 | 本界面独有的素材（编号/名称/尺寸/状态数/文件名） | 出图 + 入库 |
| 6. 交互控件状态 | 本界面每个可交互对象需要哪几个状态 | 出图 |
| 7. 引用的共用素材 | 只写编号，定义在 `共用素材/01`~`08` | 出图 |
| 8. 验收要点 | 可勾选 | 验收 |

## 四、怎么用（推荐顺序）

1. **先读** `01-提示词规范与输出约定.md`，确定提示词骨架、尺寸规范、命名规范。
2. **再读** `00-共用素材与引用规则.md`，了解共用策略、编号规则与出图优先级；
   然后**按 `共用素材/01` ~ `08` 顺序逐批出图**——它们被 8 个以上界面引用，
   先做能立刻复用，避免各界面重复出图。
3. **然后按界面顺序**逐份出效果图 → 专属素材 → 交互状态。
   建议顺序与程序实现优先级一致：**标题页 → 主页壳 → 城市地图 → 地点/事件 → 任务三页 →
   准备页 → 盘面 → 结算 → 家园五区 → 叙事层 → 弹窗/设置/恢复**。
4. 入库时按 `美术素材清单与资源目录.md` 的目录结构落到 `Assets/Game/Sprites/` 与 `Assets/Game/Font/`。

## 五、总体视觉基调（所有界面共用）

- **项目代号**：常明奇谭（非正式名，仅代号；不要从名字推导风格）。
- **画面核心**：「物件怪谈」——熟悉之物被陌生化；**暖铜秩序 × 冷紫混沌**同框。
- **双主轴配色**：暖铜 `#E0A858` 为主，冷紫 `#A86AC8` 为强调，深灰蓝 `#171A20` 打底，纸白 `#E8EAF0` 提亮。
- **界面气质**：一间深夜仍亮着常明灯的修理铺——精密黄铜的秩序感 + 门外怪谈的冷紫侵蚀感。
  克制、低饱和、大面积深色，强调光与影的反差；不使用大面积高亮、糖果色或卡通描边。
- **字体**：思源黑体（标题 Bold / 正文 Regular）+ 等宽数字（计分/拍数/能量/费用，避免跳动时宽度抖动）。

完整色板与字号层级见 `11-美术规范/UI视觉规范.md`；盘面专属规范见 `11-美术规范/盘面视觉规范.md`。

## 七、维护约定

- 本文档集是**界面美术需求**的唯一入口；界面布局若被程序改动，需同步更新对应界面文档的「布局规格」。
- 共用素材只在 `共用素材/01`~`08` 定义一次（提示词在各批次文档内）；界面文档只引用编号，**不重复定义提示词**。
- 新增编号规则：共用 `SHR-` 前缀、界面专属 `SCR-<界面号>-` 前缀、图标 `ICO-` 前缀。
- 素材交付后，在对应界面文档的清单表「状态」列标记为已交付。
