### 命名与导入约定

- 目录命名：**中文**（`盘面/零件/`、`怪谈/L01_红舞鞋/`、`场景/修理铺/`），怪谈立绘保留 `L01_` 编号前缀对应批次与怪谈库编号；
  例外：`Audio/` 用英文 `SFX`/`BGM`/`Voice`。
- 文件命名：**编号前缀 + 中文语义**（`p001_惯性撞锤` / `m001_护送扣` / `o001_固定墙体` / `a001_局部定势偏转` /
  `shenyao_紧绷起舞` / `workshop_night`），既便于程序按编号引用，又便于美术识别。
- 音频文件命名：**中文**（如 `咬合音效.wav` / `红舞鞋_紧张变奏.ogg` / `沈遥_求助.wav`），放在 SFX/BGM/Voice 对应目录。
- 导入设置（b50）：textureType=Sprite、spriteMode=Single、alphaIsTransparency=1、mipMap=0、wrap=Clamp；
  maxTextureSize 按用途：盘面棋子 128、UI 按钮/页签 256、UI 面板/对话框 512、立绘/背景 1024~2048。
- 手绘「留白高光」必须用纸白实色（不透明）填充，禁止 alpha=0 透明洞（用户 2026-09-22 纠正）。
