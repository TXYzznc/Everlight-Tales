# UI 视觉规范与控件样张（草案）

> 状态：草案（待视觉方向确认）。本规范定义 UI 的色板、字体、九宫格与控件基线，
> 供 ART-001 样张与 ART-007 九宫格批量制作依据；正式资源到位后逐项替换占位。

## 1. 视觉基调

「机械铜暖 + 怪谈冷紫」双主轴，深灰蓝为底，强调光与影的反差——白天是修理铺的
暖铜与工具青，夜晚与怪谈是冷紫与异常品红。整体克制的低饱和，避免大面积高亮。

## 3. 字体

| 层级 | 字体 | 字号 | 行高 | 用途 |
|---|---|---|---|---|
| H1 | Noto Sans SC / 思源黑体 Bold | 36 | 48 | 页面大标题 |
| H2 | 同上 Bold | 28 | 38 | 区块标题 |
| H3 | 同上 Bold | 22 | 30 | 卡片标题 |
| Body | Noto Sans SC Regular | 18 | 26 | 正文 |
| Caption | 同上 Regular | 14 | 20 | 辅助说明 |
| Number | 等宽（DIN/思源等宽） | 20 | 26 | 分数、拍数、能量、费用 |

> 数字优先等宽字体，避免计分/计数跳动时宽度抖动。字体资源待 ART-007 集成时落地。

## 4. 九宫格参数

| 控件 | 源图建议 | 边框(border) | 说明 |
|---|---|---|---|
| 面板 panel | 512×512 | 16px | 四角保持、四边拉伸、中心平铺 |
| 对话框 dialog | 512×512 | 20px | 同上，角更大 |
| 按钮 button | 256×128 | 8px | 左右角 + 上下边 |
| 页签 tab | 256×64 | 8px | 单行，激活/普通两态 |

> 拉伸区用纯色或低对比纹理，避免拉伸变形可见；角区保持描边与高光。
