# 六相定势盘视觉规范与样张（草案）

> 状态：草案（待视觉方向确认）。定义盘框、蜂窝格、棋子、定势座与特效方向的
> 视觉基线，供 ART-002 样张、ART-006 零件设施图与 ART-010 盘面动效依据。
> 运行时盘面由 HexagonGraphic 程序化绘制（点顶六边形），本规范与之一致。

## 1. 结构

盘面为「点顶大六边形」SDF 三分类（Board 层 HexBoardShape，boardRadius 参数化）：

| 档位 | boardRadius | 正常格 | 墙格 | 总格 |
|---|---|---|---|---|
| 教学 | 5 | 133 | 48 | 181 |
| 试机 | 6~8 | — | — | — |
| 普通 | 6~10 | — | — | — |
| 怪谈 | 12 | 649 | 108 | 757 |

- **正常格**：顶点全在边心距内，可落子。
- **墙格**：中心在候选区但顶点越界，残缺暗红，阻挡移动。
- **盘外**：中心超边心距，不渲染。

## 2. 盘框

点顶大六边形轮廓，半径 = 2·(boardRadius+1)·cellSize：
- 描边主色 `#5A6472`，宽 3px。
- 顶部高光（左旋/右旋时边缘流光，b42 已实现 board_edge_glow，alpha 随旋转速度）。

## 3. 蜂窝格

- 正常格填充 `#232833`、描边 `#3A4250`（1px）。
- 墙格填充 `#3A2026`（暗红）、描边 `#5A2A32`。
- 六边形为**点顶**朝向（顶点朝上），旋转后屏幕呈平顶（重力恒指向屏幕下方）。

## 4. 棋子

占位源图 256×256（`Assets/Game/Sprites/Placeholder/Board/*`），运行时以
EntityVisuals 配色 + 占位图标呈现（正式美术由 ART-006 替换）：

| 类别 | 配色基调 |
|---|---|
| 零件 20P | 每件独立色相（橙/青/红/绿/紫…见占位生成器） |
| 形态 15M | 统一冷紫系 + 宿主零件图标 |
| 障碍 8O | 灰/棕冷色系 |
| 异常 8A | 品红紫系 |
| 任务标记 | 金黄（flag） |
| 维修对象 | 紫（wrench） |

## 5. 定势座（6 相位）

重力方向 = 对准定势座的相位边（HexDirection D0~D5）：
- 左旋 = 重力 −1 = 视觉 −60°；右旋 = +1 = 视觉 +60°。
- 样张以 6 个方向箭头标注 D0~D5，相位边高亮示意。

## 6. 特效方向（b42 已实现，样张标注示意）

| 特效 | 表现 |
|---|---|
| 旋转边缘流光 | 盘框 alpha 随旋转速度 |
| 连击脉冲 | 三层嵌套六边环扩张 + 橙→红 lerp |
| 旋转预览 | ghost 半透明块 + hit ring 描边环 |
| 屏幕震动 | board_root DOShake |
| 得分飘字 | Text 上飘 + 淡出 |
