# 人物与怪谈立绘总规范 v0.1

> 目标：把当前“单张全身图 + 纯色占位”的人物表现，升级为可在对话、地图详情、调查和结算中切换的多状态立绘系统。本文覆盖主线人物和 15 案怪谈的视觉约束；不修改剧情文本、角色数值或 Prefab 逻辑。

## 1. 统一风格

采用“都市怪谈绘本”人物语言：半写实比例、清晰剪影、纸面颗粒、局部厚涂高光。人物必须有一个远看可辨认的轮廓钩子（围巾、发带、工具、镜片、鞋、书或布尺），再用一件与剧情绑定的道具形成近看叙事。

- 现实人物：冷灰蓝阴影 + 暖铜主光；皮肤和布料保留纸张纤维，不追求塑料光。
- 怪谈人物：现实轮廓中插入一处不可能的比例、反射或材质变化；异常色只占局部。
- 受伤/失控：用姿态、重心和道具关系表现，不使用血腥细节作为冲击力来源。
- 生动感：每个状态至少改变一个姿态轴（重心、手势、视线或衣摆），禁止只换表情。

## 2. 统一规格

| 项目 | 规范 |
|---|---|
| 成品尺寸 | 840×1360，透明 PNG；工作源建议 1680×2720 |
| 构图 | 全身或 3/4 身，头顶留 5%，脚底留 3%；左右各留 6% 呼吸区 |
| 对话挂点 | 立绘本体不烘焙底座光；由 `DialoguePage` 叠加 `dialogue_portraitbase` |
| 状态 | `normal`、`active`、`story` 三类；怪谈另加 `manifest` 或 `resolved` |
| 光向 | 现实人物默认左上暖光；怪谈异常光从剧情道具方向切入 |
| 线稿 | 轮廓线比内部线重 1.3~1.6 倍；远离脸部的线允许断开 |
| 透明 | 只保留人物和道具，不保留矩形背景；纸白高光为不透明实色 |
| 缩略图 | 270×436 下脸部、主道具和姿态仍需可辨 |

## 3. 状态设计原则

1. `normal`：建立人物日常身份和轮廓。
2. `active`：服务当前交互或说话，动作更开放，视线指向玩家/事件。
3. `story`：承载剧情转折，改变重心、光色或道具关系；不单纯加“生气/悲伤”表情。
4. 怪谈的 `manifest`：让异常机制一眼可见；`resolved`：保留余波但恢复可呼吸的轮廓，方便结算和回访。

状态切换优先使用整张差分图，无法整张重绘时才使用可复用的头像/道具层。任何可拆层必须在资源清单记录锚点，避免运行时拼接错位。

## 4. 当前资源迁移

`Assets/Game/Sprites/人物/玩家/玩家.png` 与 `Assets/Game/Sprites/人物/沈遥/沈遥.png` 当前为 1254×1254 全身透明图。它们保留作对照和临时回退，不直接作为新立绘母版；新资源按角色目录和 840×1360 规范重新导出，完成验收后再替换引用。

## 5. 人物评审清单

- [ ] 不看名字也能通过轮廓和道具辨认角色。
- [ ] 三个状态的姿态、视线和重心确实不同。
- [ ] 脸部在 270×436 缩略图下仍清楚，手部没有融入衣物。
- [ ] 现实人物不被异常色覆盖；怪谈异常集中且有叙事原因。
- [ ] 立绘与 1080×1920 对话背景的暗部和灯向相容。
- [ ] 未烘焙文字、气泡、按钮、底座光或页面边框。
- [ ] 文件名、导入设置和状态 ID 与资源接入文档一致。
