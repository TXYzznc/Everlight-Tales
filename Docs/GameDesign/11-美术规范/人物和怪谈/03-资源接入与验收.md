# 人物与怪谈资源接入与验收 v0.1

## 1. 目录与导入

```text
Assets/Game/Sprites/人物/<角色>/<角色>_<状态>@840x1360.png
Assets/Game/Sprites/怪谈/L<编号>_<语义>/L<编号>_<语义>_<状态>@840x1360.png
```

统一导入：`Sprite/Single`、`Alpha Is Transparency=On`、`Mip Map=Off`、`Wrap=Clamp`、`sRGB=On`。立绘禁止压成 JPG，禁止把对话框、阴影、名字牌和背景烘焙到人物图中。

## 2. DialoguePage 接入

| 事项 | 规则 |
|---|---|
| 挂点 | 左右各 840×1360；显示区域按页面文档缩放，不改变源图比例 |
| 说话态 | 当前说话人 100% 亮度；非说话人 65%~75%；隐藏态淡出 |
| 镜像 | 仅镜像人物本体；带字、明显不对称道具或怪谈机制时必须另出右向图 |
| 切换 | 先淡出旧状态，再淡入新状态；不在一帧内替换造成闪烁 |
| 裁切 | 脚底与头顶留白一致；禁止运行时硬裁掉道具钩子 |

## 3. 地点详情/调查/结算接入

- 地点详情只使用头像或 3/4 身裁切，不把全身图压到小卡片中。
- 调查界面使用 `hint` 或 `story` 状态，热点确认后再切换 `manifest`/`active`。
- 结算界面优先使用 `recovered`/`after`，让结果与剧情状态一致。
- 怪谈档案卡默认 `hint`，解锁详情后显示 `manifest`，处理记录显示 `after`。

## 4. 资源验收清单

- [ ] 文件路径与状态 ID 能从设计文档反查；没有重复状态名或含糊的 `final2`、`new`。
- [ ] 所有成品为 840×1360 RGBA PNG，透明边缘无黑边、白边和压缩色块。
- [ ] 角色脸、手、主道具在 100% 检查下无结构错误，在 270×436 下仍可辨认。
- [ ] 三态或三态以上的轮廓、重心、视线和光色有明确差异。
- [ ] 与 `DialoguePage` 左右挂点、`InvestigationView` 热点层、`SettlementPage` 结果段落完成截图走查。
- [ ] 不修改业务规则，不把美术状态硬编码为枚举外的字符串；配置引用由资源目录或 ScriptableObject 提供。
- [ ] 首批通过后才进入下一批怪谈，保留评审截图和差异记录。
