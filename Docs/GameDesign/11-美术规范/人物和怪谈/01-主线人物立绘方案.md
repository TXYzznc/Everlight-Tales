# 主线人物立绘方案 v0.1

## 2. 状态画面要求

### 玩家

保持第一人称叙事的克制：玩家可以在序章和对话里出现全身，但局内操作优先使用手部、工具和影子局部层，避免玩家立绘遮挡盘面。`night` 状态使用冷蓝轮廓光，把提灯暖光留给手和脸。

### 沈遥

三态要形成完整弧线：失控（鞋带牵引身体）→回应（找回节拍与视线）→恢复（坐姿降低重心）。舞蹈服保持同一套剪影，只有鞋、发带和袖口受异常光影响。

### 周衡

`lost` 不画“死亡”或夸张惊恐；用画框边缘吞没肩线、颜料在衣物上反向流动表达失联。`rescued` 保留失联态的一件小痕迹，证明经历过画壁。

### 林岑与顾师傅

两人承担日常信息与手艺质感，状态差异来自手上动作和道具，不靠换服装堆差异。林岑的纸张/镜片形成锐利线条，顾师傅的布料/软尺形成弧线，放在同一画面时能快速区分。

## 3. 文件命名

```text
Assets/Game/Sprites/人物/<角色>/
├── <角色>_normal@840x1360.png
├── <角色>_active@840x1360.png
└── <角色>_<story-state>@840x1360.png
```

示例：`沈遥_tense-dance@840x1360.png`、`周衡_lost-in-mural@840x1360.png`。目录名沿用项目中文；状态语义用稳定英文短码，便于配置引用和跨工具检索。

## 4. 主线验收

- [ ] 五个角色可在 270×436 缩略图下仅凭轮廓/道具区分。
- [ ] 每人三态的动作轴不同，不能只改脸部表情。
- [ ] 立绘在左/右挂点镜像后，道具和文字安全区不冲突。
- [ ] 沈遥、周衡的状态能对应剧情阶段；玩家和两位日常角色能在非怪谈回访中复用。
- [ ] 首批通过后再建立居民模板和 15 案怪谈的同风格资产。
